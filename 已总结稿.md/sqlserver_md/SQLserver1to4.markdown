# SQL Server 课程导论与基础环境 (SSMS 1-4)

> **文档说明**：本文件基于课堂录音转写稿整理而成。原文为语音识别生成，存在较多误差，已进行修正与逻辑重组。本文档主要涵盖课程导论、计算机基础回顾、数据安全意识和 SQL Server 环境认知。

## 1. 课程概述与学习目标

### 1.1 课程定位
- **适用对象**：大二学生，具备一定计算机基础。
- **核心技能**：SQL Server 数据库管理与应用开发。
- **前置知识**：C# 编程语言、逻辑思维训练。
- **版本环境**：SQL Server 2025（最新版），配套 SSMS (SQL Server Management Studio)。

### 1.2 逻辑思维的重要性
- 数据库学习不仅是语法记忆，更是**逻辑分析能力**的训练。
- 任务拆解能力：将复杂业务需求转化为分步骤的数据库操作。
- 编程语言（如 C#）是工具，逻辑思维是核心竞争力的基础。

## 2. 计算机基础知识回顾

### 2.1 软件系统分类
在数据库学习中，需明确区分以下两类软件：

| 类别 | 定义 | 典型示例 | 备注 |
| :--- | :--- | :--- | :--- |
| **系统软件** | 管理计算机硬件与软件资源，提供公共服务 | 操作系统 (Windows/Linux)、数据库管理系统 (DBMS)、编译器/解释器、驱动程序 | DBMS 属于系统软件范畴 |
| **应用软件** | 为解决特定问题而开发的程序 | 微信、淘宝、办公软件、浏览器 | 依赖系统软件运行 |

### 2.2 语言处理程序
- **编译器 (Compiler)**：将源代码整体翻译成目标代码（如 C#）。
- **解释器 (Interpreter)**：逐句翻译并执行（如早期的 BASIC、Python 部分模式）。
- **SQL 特性**：SQL 是声明式语言，由数据库引擎解析和优化执行计划，兼具编译与解释特征。

### 2.3 数据存储与云安全
- **存储介质演变**：本地硬盘 → 移动存储 → 云存储（网盘/云平台）。
- **隐私安全警示**：
  - 个人敏感数据不建议完全依赖公有云存储。
  - 云服务提供商拥有数据访问权限，存在隐私泄露风险。
  - 建议重要数据本地加密备份或使用私有云。

## 3. 信息安全与密码学常识

### 3.1 密码强度与破解
- **密码组成**：数字(10) + 大写字母(26) + 小写字母(26) + 特殊符号 ≈ 90+ 字符集。
- **暴力破解原理**：通过穷举法尝试所有组合。密码长度每增加1位，破解难度呈指数级增长。
- **安全建议**：
  - 避免使用短密码（6-8位极易被破解）。
  - 推荐使用长密码（12位以上）+ 多字符类型混合。
  - 警惕键盘记录器、钓鱼软件等社会工程学攻击。

### 3.2 网络安全案例警示
- **黑客与法律红线**：未经授权的系统入侵、数据窃取均属违法行为。
- **专业伦理**：信息安全专业旨在防御与保护，而非攻击。
- **历史教训**：早期校企合作中因学员违规操作导致法律风险的案例，强调职业道德的重要性。

## 4. SQL Server 环境与工具

### 4.1 SQL Server 版本演进
- 文中提及版本：SQL Server 2025（最新教学版本）。
- 历史版本参考：2014, 2016, 2019, 2022 等。
- **国产化趋势**：当前信创背景下，国产数据库（如达梦、OceanBase、TiDB 等）也在逐步推广，但 SQL Server 仍是企业级重要平台。

### 4.2 核心工具链
- **SSMS (SQL Server Management Studio)**：官方集成管理环境，用于配置、管理、开发和查询数据库。
- **安装要点**：
  - 数据库引擎服务（Database Engine Services）：核心服务，必装。
  - SSMS 客户端工具：独立安装包，建议始终安装最新版以获得最佳兼容性。
  - 注意区分“系统软件”（DBMS）与“管理工具”（SSMS）的概念。
