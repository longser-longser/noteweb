## 一、实例类型与身份验证模式

### 1.1 实例：默认实例 vs 命名实例

**问题**："咱们安装（数据库）的时候，安装中间一个选项里面，是**默认（实例）**还是**命名（实例）**？"

**答案要点**：

| 类型 | 说明 |
|---|---|
| **默认实例** | **名字就固定了**。一台电脑上用"默认（实例）"就行，**可以第二次再安装** |
| **命名实例** | **第三次再安装的时候，必须要自己起个名字** |

**两个重要结论**：

1. **一个实例，实际上就对应"一个数据库服务器的名字"。**
2. **一台电脑里面可以装多个（数据库）实例/服务器**：
   > 比如 **Web 服务器、文件服务器、数据库服务器**等等，
   > **一台电脑（一个服务器）里面都可以装多个。**

### 1.2 身份验证模式（只有两种）

**问题**："数据库引擎的身份验证模式有哪些？"

**答案**：

> **一共只有两种。**

| 序号 | 模式 | 说明 |
|---|---|---|
| ① | **Windows 身份验证模式** | 只用 Windows 的账号来验证 |
| ② | **混合模式（混合身份验证模式）** | **包含两种验证**：<br>**SQL Server 身份验证** + **Windows 身份验证** |

**老师的追问式讲解**：

> "混合模式里面包含哪（两）种？一个是 Windows，一个 SQL。
> 它（就）这两种嘛——就（这几个）验证模式，不就这两种吗？"

**理解提示**：

```
Windows 身份验证模式  →  只有一种方式
混合模式              →  SQL Server 身份验证  +  Windows 身份验证（两种都行）
```
