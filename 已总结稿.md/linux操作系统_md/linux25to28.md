# Linux 操作系统 课堂笔记（第 25—28 节）——从"建文件"到"改文件内容"：vi/vim 编辑器的三种模式与常用操作

> 前面几节把**文件本身**学会了：`mkdir` 建目录、`touch` 建文件、`cp` 复制、`mv` 移动、`rm` 删除——可这些文件**里面是空的**。本节要解决的是"**内容怎么进去**"：Windows 里双击用记事本改，Linux 命令行里没有"双击"这回事，只能自己把编辑器叫起来 → `vi` 与 `vim` 其实是同一个程序，`vim` 是新版、功能更强 → 一打开**按字母写不进去**，因为它有**三种模式**：默认停在**一般命令模式**（只认命令，不写字）→ 按 `i` / `a` / `o` 进**编辑模式**才能写，`Esc` 退回 → 按 `Shift` + `;` 打出冒号进**末行模式**，`:wq` 保存退出、`:q` 直接退、`:q!` 不保存强退 → 新建的文件如果 `:q!` 出来**等于没建** → 再打开，底部不再显示"新建"，而是文件名、位置、行数与字节数 → 文件一长，用 `:set nu` 看行号、`Ctrl+f` / `Ctrl+b` 翻页、`0` / `$` 到行首行尾、`gg` / `G` 到首末行、数字加回车按行走 → 用 `yy` / `Nyy` 复制、`p` / `P` 粘贴、`v` + `G` + `y` 选段复制、`x` / `dd` 删除、`u` / `U` 撤销 → 最后在末行模式里用 `/`、`?` 查找，用 `:s`、`:%s/.../g` 替换。

### ⛓ 本节主线（一条因果链）

老师这节课是**一层一层往上加**的：先把"内容怎么写进去"解决，再把"在文件里怎么走"解决，最后才讲复制、删除、查找、替换。**每一层都卡在前一层的模式上**，所以模式是本节真正的骨架。

```text
文件建好了，里面却是空的 —— 内容怎么进去？
        ↓
Windows：双击 → 记事本打开 → 改 → 保存；命令行里没有"双击"
        ↓
用编辑器：vi / vim（同一个程序，vim 是新版、功能更强，所以用 vim）
        ↓
vi 文件名          打开；文件不存在，就是"新建"
        ↓ 一打开，按字母怎么打不进去？
因为默认停在【一般命令模式】——这个模式只认命令，不写字
        ↓
i / a / o          → 进【编辑模式】，这时才能写
Esc                → 退回【一般命令模式】
        ↓ 写完了怎么存、怎么走？
Shift + ;          打出冒号 → 进【末行模式】，命令都敲在屏幕最后一行
:wq 保存退出        :q 没改就直接退        :q! 改了不要，强制退出
        ↓ 新建的文件如果 :q! 出来 —— 文件根本没建成
        ↓
再打开：底部不再是"新建"，而是文件名、位置、几行、几字节
        ↓ 文件一长，怎么在里头走？
:set nu 显示行号 → Ctrl+f / Ctrl+b 翻页 → 0 / $ 到行首行尾
                 → gg / G 到首行末行 → 数字 + 回车 往下走几行
        ↓ 一段内容要重复，怎么复制？
yy 复制一行 → p 粘到下一行 / P 粘到上一行 → 5yy 连复制五行
           → v 选到 G（文件末尾）再 y，整段复制
        ↓ 不要的怎么删？
x 删一个字符 → 6x 删六个 → dd 删一行 → 4dd 删四行
        ↓ 手滑了？
u 一步步撤销（能连按）      U 撤销当前行的全部改动
        ↓ 文件里找个东西、批量改个东西？
/ 向下找   ? 向上找
:s/旧/新 当前行（只换第一个）   :%s/旧/新/g 整篇全换   :5,12s/旧/新/g 指定行
```

### 🔗 去路：本节内容后面用在哪里

| 本节内容 | 后面 / 实际运维时用在哪里 |
|---|---|
| **vi/vim 的三种模式与"进编辑 / 退编辑"** | 后面凡是要**改配置文件**（网络、服务、`/etc` 下的各种文件），第一步都是分辨"现在在哪个模式"；模式搞错，按什么键都不对 |
| **`:wq` / `:q` / `:q!`** | 改配置文件的"收尾三件套"：改对了存、没改直接走、改坏了不存强退。⚠️ 少了这一步，改的内容等于没改 |
| **`:set nu` 显示行号** | 报错信息里给的是"第几行"，**没有行号就对不上**；改长配置文件之前先开行号 |
| **`/` 与 `?` 查找** | 几百行的配置文件里找一个参数，靠翻页翻不完 |
| **`:s` / `:%s` 替换** | 同一个参数在文件里出现很多次时要**一次全改**；改完还要能撤销回来 |
| **`yy` / `p` / `dd` / `u`** | 编辑长文件的基本手法：整行搬、整段删、改错了退回去 |
| **本节只讲了"常用的这些功能"** | 老师说编辑器的功能很多，**"大部分在编辑过程当中用不上"**；本节把这些常用的讲到，其余用到再查 |

## 一、开场：文件建好了，内容怎么进去

### 1.1 先把前面几节收个口

老师开场先回顾：**新建目录、新建文件、删除目录、删除文件**——"这些（都）是我们（日常）操作当中最基本的一些操作"，前面都已经讲过。

到这儿，**文件本身已经会建、会复制、会移动、会删了**，但这些都是"对文件整体"的操作。

### 1.2 缺的那一环：文件里是空的

用 `touch` 建出来的文件，**里面什么都没有**。老师打开 `/信息` 目录一看，里面就是几个这样的空文件。

> 问题很自然：**文件建出来了，可我要往里面写东西，怎么写？**

### 1.3 拿 Windows 作对照

| 在 Windows 里 | 在 Linux 命令行里 |
|---|---|
| 在桌面上**双击**文件 | **没有双击**这回事 |
| 系统用**记事本**（或 Office）打开 | 要自己**敲编辑器的命令**把文件打开 |
| 改完点"保存"、关掉窗口 | 在编辑器里**用命令保存、用命令退出** |
| 鼠标点哪儿光标就跳到哪儿 | **键盘操作，不能用鼠标** |

> 老师原话（大意）：**"在 Windows 下，你直接在桌面上打开就行，用记事本打开，修改就可以了。"**

一句话：**Windows 里"打开文件"是图形界面替你做的；Linux 命令行里，得自己把编辑器叫起来。**

## 二、vi 与 vim：命令行里的"记事本"

### 2.1 先认清这是哪个程序

老师先带着看 `vi` 和 `vim` 这两个命令。

| 观察到的 | 说明 |
|---|---|
| **两个命令指向的是同一个程序** | 老师原话：**"实际上（它们）指向的都是一个（程序）。"** —— `vi` 不是另外一套独立的软件 |
| **`vim` 是新版本** | 老师原话：**"一个新版本。"** |
| **`vim` 功能更强大** | 老师原话：**"它的功能比较强大，那我们就要用（它）。"** |
| **两个文件大小不一样** | 老师现场比过大小，`vim` 更大——功能多，程序本身也大 |

### 2.2 结论：平时用 `vim`

> 老师原话：**"所以我们一般都是用新的。"**

| 写法 | 说明 |
|---|---|
| **`vim 文件名`** | 平时用这个 |
| **`vi 文件名`** | 也能用——最后调用的还是同一个程序 |

> 📌 **记住**：**`vi` 和 `vim` 不是两个软件，`vim` 是 `vi` 的增强版。** 本节的演示老师习惯敲 `vi`，换成 `vim` 效果一样。

### 2.3 它和记事本最大的不同

| 对比项 | Windows 记事本 | vi / vim |
|---|---|---|
| 怎么操作 | 鼠标点菜单、拖选、右键 | **全键盘**，**不能用鼠标** |
| 怎么移动光标 | 鼠标点哪儿是哪儿 | **上下左右方向键** |
| 怎么写内容 | 点一下就能打字 | **要先切换模式**（见第四节） |
| 怎么保存退出 | 点"保存"、点"关闭" | 敲命令：`:wq`、`:q`、`:q!` |

> 老师原话：**"在编辑器当中，我们没办法用鼠标。"**
> **"你只能通过键盘来操作……用上下箭头、左右箭头来调它的位置。"**

> ⚠️ **易错点**：刚上手最常见的动作是**伸手去抓鼠标**——这里没有鼠标可用。**光标靠方向键走，操作靠按键完成。**

## 三、打开与新建：`vi 文件名`

### 3.1 一条命令打开文件

```bash
vi 信息/a3.txt
```

| 情况 | 会发生什么 |
|---|---|
| **文件已经存在** | 打开它，屏幕上显示里面已有的内容 |
| **文件不存在** | 打开的是一个空编辑区，**屏幕底部标出"新建"**——这时文件还没真正建出来，要保存以后才算 |

> 💡 **"打开"和"新建"是同一条命令**：`vi` 后面跟的文件名存在，就是打开；不存在，就是新建。**区别只在保存那一步。**

### 3.2 打开时的路径

`vi` 后面跟的是**文件路径**，和前面 `touch`、`cp` 一样，写相对还是绝对取决于人在哪儿。本次演示里老师写的是 `信息/a3.txt`，**文件在 `/信息` 下**。

打开以后，编辑器底部会把**"这个文件到底在哪"**显示出来——这一点在 6.6 还要用到。

### 3.3 打开以后先别急着敲字母

文件一打开，光标停在第一行，看起来"可以打字了"——**其实还不能**。直接敲字母，屏幕上什么都不会出现（原因见下一节）。

## 四、三种模式：vi 的一切操作都先问"现在在哪个模式"

### 4.1 为什么"打字打不进去"

老师打开文件后直接敲字母，**屏幕上的内容没有变化**。

> 老师原话（大意）：**"（在一般命令模式下）你写内容……都写不上。"**

原因：vi/vim 有**三种模式**，**刚打开时停在"一般命令模式"**，这个模式**只认命令，不接收文字**。

### 4.2 三种模式对照表

| 模式 | 老师也叫它 | 怎么进来 | 能干什么 |
|---|---|---|---|
| **一般命令模式** | 一般模式、命令模式 | **打开文件就默认在这里**；在别的模式里按 `Esc` 回来 | 光标移动、翻页、复制粘贴、删除、撤销——**这些操作只能在这个模式里做** |
| **编辑模式** | —— | 在一般命令模式下按 **`i` / `a` / `o`** | **往文件里写内容、改内容、删字符** |
| **末行模式** | 命令行模式 | 在一般命令模式下按 **`Shift` + `;`**（打出冒号 `:`） | 保存、退出、显示行号、查找、替换——**命令都敲在屏幕最后一行** |

> 老师原话：**"你一定要注意，在操作过程当中，你一定要分清（现在在）哪些模式、干哪些事儿。"**

### 4.3 三条铁律

1. **打开文件，默认在一般命令模式**——老师原话：**"打开啥都不动，就叫一般命令（模式）。"**
2. **写字必须先在编辑模式；移动、复制、删除、粘贴必须先在一般命令模式。**
3. **末行模式的命令，都显示在屏幕最后一行**，敲完回车执行；执行完回到一般命令模式。

> ⚠️ **易错点**：在编辑模式里按 `dd`、`yy`、`p`，**不会删除、不会复制、不会粘贴**，只会在文件里写下 `dd`、`yy`、`p` 几个字母。**先按 `Esc` 回到一般命令模式，再按键。**

### 4.4 模式切换一张图

```text
一般命令模式 ──（按 i / a / o）──→ 编辑模式
      ↑                                │
      └────────────（按 Esc）───────────┘

一般命令模式 ──（按 Shift + ;）──→ 末行模式 ──（回车执行）──→ 回到一般命令模式
```

> 📌 **看图记一句话**：**`Esc` 是"回退键"**——不管在编辑模式还是末行模式，先按 `Esc` 回到一般命令模式，一切操作都从这里出发。

## 五、编辑模式：把内容写进去

### 5.1 三个键都能进编辑模式

| 按键 | 作用 | 老师怎么说 |
|---|---|---|
| **`i`** | 进入编辑模式 | **"这三个键按哪一个都（行）。"** |
| **`a`** | 进入编辑模式 | 同上 |
| **`o`** | 进入编辑模式 | 同上 |

> 老师原话：**"根据自己的习惯，写哪一个都行。"**

按下以后，**屏幕左下角会出现提示**（表示现在可以输入了）。

### 5.2 在编辑模式里能做什么

| 能做 | 怎么做 |
|---|---|
| **写字** | 字母、数字、汉字直接敲，出现在光标位置 |
| **换行** | 按回车，光标到下一行 |
| **删字** | 用退格键删掉写错的字符 |
| **移动光标** | **只能用上下左右方向键** |
| **用鼠标** | ⚠️ **不行** |

> 老师原话：**"你只能是（用键盘）往里面写东西、删东西。"**

### 5.3 写完怎么退出来

**按 `Esc`**，回到一般命令模式。

> ⚠️ **易错点**：写完内容**不要直接去敲命令**——你还在编辑模式，敲出来的冒号会被当成一个字符写进文件里。**先按 `Esc`，回到一般命令模式，再按 `Shift` + `;`。**

> 老师原话（大意）：**"你在编辑模式，想进入末行模式，也就叫它命令行模式，你必须（先按 `Esc`）切换，再按 `Shift` 加冒号键。"**

## 六、末行模式（一）：保存与退出

### 6.1 怎么进末行模式

在**一般命令模式**下，按 **`Shift` + `;`**（就是打出冒号 `:` 的那两个键），**屏幕最后一行**出现一个冒号，光标跳到那里等命令。

> 老师特意强调：**冒号是 `Shift` + `;` 两个键打出来的**（他现场还纠正过一次自己的说法），**不是单按某一个键**。

### 6.2 三条保存 / 退出命令

| 命令 | 作用 | 什么时候用 |
|---|---|---|
| **`:wq`** | **保存并退出** | 改完了，要存下来 |
| **`:q`** | **退出**（不保存） | **没有改动过**的时候，直接走 |
| **`:q!`** | **强制退出，不保存** | 改过了但不想要这些改动 |

> 老师原话（`:q!`）：**"加一个感叹号……我们叫它强制退出。"**

### 6.3 `:q` 为什么有时候退不了

老师现场演示：文件**改过了**，直接敲 `:q` 回车——

> 老师原话：**"如果改动了，你退不了。"**
> 屏幕上会给出提示，**不让你走**。

| 情况 | `:q` 的结果 |
|---|---|
| 打开后**什么都没改** | 正常退出 |
| **改过内容、还没保存** | **退不了**——必须先 `:wq` 存，或者 `:q!` 放弃改动 |

> 💡 这是编辑器在替你把关：**改动还没落地，它不让你一走了之。**

### 6.4 ⚠️ 新建的文件，`:q!` 出来就等于没建

老师现场踩过这个坑：对一个**还不存在**的文件执行 `vi 文件名`，写了内容，然后 `:q!` 强制退出。

> 老师原话：**"我强制退出了，等于说这个文件我没有新建成功。"**

| 操作 | 结果 |
|---|---|
| `vi 新文件名` → 写内容 → **`:wq`** | 文件被**创建**出来，内容在里面 |
| `vi 新文件名` → 写内容 → **`:q!`** | **文件根本不存在**——什么都没留下 |

> ⚠️ **易错点**：**"新建"是靠保存来完成的。** `:q!` 是"什么都不留"，新建的文件自然也留不下来。

### 6.5 保存成功之后，回头看

1. `:wq` 退出，回到 shell；
2. `ls 信息` ——`a3.txt` 出现在列表里（**文件真的建出来了**）；
3. 再用查看命令看一眼：内容在里面。

```bash
ls 信息
cat 信息/a3.txt
```

> 老师用的是上节学过的**五个查看命令**（`cat` / `more` / `less` / `head` / `tail`），内容一行一行都在。

### 6.6 再打开一次：底部显示的东西变了

| 打开时 | 屏幕底部显示 |
|---|---|
| **第一次**（文件还不存在） | 标着**"新建"** |
| **保存过以后再打开** | **不再显示"新建"**，而是显示：**文件名**、**文件在哪**、**一共几行、多少个字节** |

老师现场读到的是：**"信息下 `a3.txt` 这个文件，1 行、17 个字节。"**

> 📌 **怎么判断"文件到底建成了没有"**：再打开一次，看底部还有没有"新建"两个字——**没有"新建"，说明它已经是一个存在的文件了。**

## 七、末行模式（二）：行号、查找、替换

> 这一节的命令**都在末行模式里敲**：先 `Esc` 回一般命令模式，再按 `Shift` + `;` 打出冒号。

### 7.1 先解决"这个文件到底有多少行"

老师打开一个**从别处复制过来的、内容比较多的文件**，问题立刻来了：**屏幕上看不出这是第几行，也不知道一共多少行**。

> 老师原话：**"这个文件当中它有很多行，到底有多少行？你得查。"**

### 7.2 显示行号：`:set nu`

| 命令 | 作用 |
|---|---|
| **`:set nu`** | **显示行号**（每行前面出现序号） |
| **`:set nonu`** | **取消行号** |

现场：

1. 按 `Esc` 回一般命令模式；
2. 按 `Shift` + `;` 打出冒号；
3. 输入 `set nu` 回车——**每一行前面出现行号**；
4. 翻到最后一行，**最大编号就是总行数**：老师这个文件是 **37 行**；
5. 再输入 `set nonu` 回车——**行号消失**。

> 💡 `nu`、`nonu` 都是**缩写**（写全了也能用），老师习惯用缩写。
> 💡 **行号是"读"出来的**：不用去数，翻到文件末尾看最后一个编号就知道了。

> ⚠️ **易错点**：`:set nu` 是**末行模式**的命令，**在编辑模式里敲没用**（只会把 `set nu` 这几个字母写进文件）。**先 `Esc`，再打冒号。**

### 7.3 查找：`/` 向下，`?` 向上

| 写法 | 方向 |
|---|---|
| **`/要查找的内容`** | **向下（往后）**找 |
| **`?要查找的内容`** | **向上（往前）**找 |

> 老师原话：**"不管问号也好、斜杠也好，都是一个向前查、一个向后查。"**

- 回车以后，**光标跳到第一个找到的地方**；
- 查找是**从光标当前位置**出发、朝那个方向找的——**光标在哪，决定了先找到哪一处**。

> ⚠️ **易错点**：查找前先看光标在哪。**同样的关键字，光标位置不同，第一次找到的地方也不同。**

### 7.4 替换：`s` 是"替换"的入口

| 写法 | 替换范围 | 说明 |
|---|---|---|
| **`:s/旧内容/新内容`** | **当前行，只换第一个** | 老师演示时：这一行里另外几个同样的字符**被找到了，但没有跟着换** |
| **`:s/旧内容/新内容/g`** | **当前行，全部** | 加 `g` 才是"这一行里都换" |
| **`:%s/旧内容/新内容/g`** | **整篇文档，全部** | `%` 表示整个文件 |
| **`:5,12s/旧内容/新内容/g`** | **第 5 行到第 12 行**，全部 | 指定行范围 |

> 老师原话（演示 `:s` 之后）：**"其他的（地方）找到了，但是他不会给他（全部）替换。"** —— 这正是 `:s` 不带 `g` 的效果。

**现场（整篇替换）**：

1. `Esc` 回一般命令模式 → `Shift` + `;` → 输入 `%s/t/2/g` 回车；
2. 屏幕下方给出这次替换的提示；
3. 再翻文件：**所有的 `t` 都变成了 `2`**——连原先第 12 行里的那几个也变了。

> 老师现场还有一次替换**没成功**，他说是**"特殊符号"**的问题；换成普通字符重新执行就成功了。所以：**替换内容里带特殊符号时要格外小心。**

> ⚠️ **易错点**：`:s/...` 默认**只管当前行、只换第一个**。要"整篇都换"，`%`（整个文件）和 `g`（每一处）**两个都要有**。

### 7.5 替换也能撤销

老师把整篇替换做完以后，又按撤销键把**整篇的替换全部退了回去**——文件恢复成原来的样子。

> 📌 改错了不要慌：**只要还没退出这个文件，撤销就能回来。**

## 八、一般命令模式（一）：光标怎么走

### 8.1 先分清：这些键只在一般命令模式里管用

> 老师原话：**"我们刚才所有的，比如说光标移动、到行首行尾……都是在一般命令模式（下做的）。"**
> **"你不能在编辑模式下操作，也不能在末行模式（下操作）。"**

### 8.2 翻页

| 按键 | 作用 |
|---|---|
| **`Ctrl` + `f`** | **向下翻一页**（往后） |
| **`Ctrl` + `b`** | **向上翻一页**（往前） |
| **`PageDown` / `PageUp`** | 同样可以向下 / 向上翻页 |

> 老师原话（大意）：**"这些你要记不住，（看）键盘上都有。"** —— 翻页键就印在键盘上，不用死背。

### 8.3 到行首、行尾

| 按键 | 作用 |
|---|---|
| **`0`**（数字零） | 跳到**当前行行首** |
| **`$`** | 跳到**当前行行尾** |

> 老师原话：**"零跑到前面，按 `$` 符号跑到后面。"**

### 8.4 到文件第一行、最后一行

| 按键 | 作用 |
|---|---|
| **`gg`**（两个小写 g） | 跳到**文件第一行** |
| **`G`**（大写） | 跳到**文件最后一行** |

> ⚠️ **易错点**：`gg` 和 `G` **不是一回事**，`g` 和 `G` 也不是一回事。老师特意停下来强调：**"Linux 当中要严格区分大小写，一定要注意。"** —— **一个 `G` 到末尾，两个小写 `g` 到开头。**

### 8.5 按行数走

| 写法 | 作用 |
|---|---|
| **数字 + 回车**（例如 `3` 回车） | **从当前行向下走 3 行** |

> 老师原话：**"移动几行，比如说我向下移动三行，直接输数字三、回车，他就行了。"**

> ⚠️ **易错点**：数字要在**一般命令模式**下敲。若在编辑模式里敲，**只会往文件里写一个数字**。

### 8.6 移动键小结

| 想干什么 | 按什么 |
|---|---|
| 往下翻一页 | `Ctrl` + `f` / `PageDown` |
| 往上翻一页 | `Ctrl` + `b` / `PageUp` |
| 到行首 / 行尾 | `0` / `$` |
| 到第一行 / 最后一行 | `gg` / `G` |
| 向下走 N 行 | 数字 + 回车 |

## 九、一般命令模式（二）：复制、粘贴、删除、撤销

### 9.1 复制一行：`yy`

现场（先 `:set nu` 把行号打开，方便看第几行）：

1. 光标移到**第 10 行**；
2. 按 **`yy`**（两个小写 y）——**这一行被复制**，屏幕下方提示复制了 1 行；
3. 光标移到**第 20 行**；
4. 按 **`p`**（小写）——粘贴到**当前行的下一行**，也就是**第 21 行**；
5. 结果：**第 10 行和第 21 行内容一模一样**，文件从 37 行变成 38 行。

> 老师原话：**"小写 yy 复制一行，小写 p 复制到某一行的下（一）行。"**

### 9.2 粘贴到上面还是下面：`p` 与 `P`

| 按键 | 粘贴到哪 |
|---|---|
| **`p`**（小写） | 当前行的**下面** |
| **`P`**（大写） | 当前行的**上面** |

> 老师原话：**"大写的（`P`）就是在（当前）行的上边，小写（`p`）的就是在（当前）行的下边。"**

演示：光标停在某一行的行首，按大写 `P`——**粘进来的内容成了当前这一行，原来这一行被挤到下面去了**。

### 9.3 一次复制多行：数字 + `yy`

| 写法 | 作用 |
|---|---|
| **`5yy`** | 从当前行起，**向下连续复制 5 行** |
| **`yy`** | 复制 1 行（等于 `1yy`） |

现场：

1. 光标移到第 22 行；
2. 按 `5yy`——**22、23、24、25、26 这五行被复制**，屏幕下方提示复制了 5 行；
3. 光标移到第 38 行；
4. 按 `p`——这 5 行被粘到**第 39—43 行**。

### 9.4 选一大段再复制：`v` + `G` + `y`

老师演示的是"从第 30 行一直到文件末尾，整段复制"：

1. 光标移到**第 30 行**；
2. 按 **`v`**（小写）——**开始选择**；
3. 按 **`G`**（大写）——选择范围**一直拉到文件最后一行**；
4. 按 **`y`**——把选中的这一段复制下来，屏幕下方提示**复制了 14 行**（从第 30 行到第 43 行）；
5. 光标移到**最后一行**，按 **`p`**——粘到后面，文件从 **43 行变成 57 行**（新增第 44—57 行）。

> 💡 **`yy` 是按"行"复制，`v` + `G` 是按"一段"复制。** 要复制的内容跨很多行、又不方便数行数时，用后一种。

### 9.5 删除：`x` 与 `dd`

| 写法 | 删什么 |
|---|---|
| **`x`** | 删掉**光标所在的那一个字符** |
| **`6x`** | 从光标起**连删 6 个字符** |
| **`dd`** | 删掉**光标所在的一整行** |
| **`4dd`** | 从当前行起**连删 4 行** |

现场：

1. 光标停在某一行的某个字符上；
2. 按 `x`——这个字符没了；
3. 按 `6x`——从光标位置起连删 6 个字符；
4. 光标移到第 37 行，按 `dd`——**整行消失**，下面的行往上顶；
5. 光标移到第 32 行，按 `4dd`——**从第 32 行起连续 4 行一起消失**。

> 老师原话：**"可以通过 `x` 来删除一个字符，或者说用多少个 `x` 来删除多少个字（符）。"**
> **"两个小写的 `dd`，他就把它删了。"**

### 9.6 撤销：`u` 与 `U`

| 按键 | 作用 |
|---|---|
| **`u`**（小写） | **撤销上一步操作**；**可以连续按**，一步一步往回退 |
| **`U`**（大写） | **撤销当前行上的全部改动**（把这一行恢复原样） |

> 老师原话（大意）：**"在（编辑器）当中，包括我们整个办公软件，都是允许（撤销）的。"**
> **"按小写的 `u`，他会把刚才（做）的这一行给去掉……一直能（撤）回。"**

> ⚠️ **易错点**：`u` 和 `U` 大小写不同，作用也不同；`dd` 删掉的行、`p` 粘出来的行，**都能用 `u` 退回去**。

### 9.7 常用按键总表（全部在一般命令模式下）

| 想干什么 | 按键 |
|---|---|
| 进编辑模式 | `i` / `a` / `o` |
| 回一般命令模式 | `Esc` |
| 复制 1 行 / N 行 | `yy` / `Nyy` |
| 粘贴到下方 / 上方 | `p` / `P` |
| 选一段（到文件末尾） | `v`，再按 `G` |
| 删 1 个字符 / N 个字符 | `x` / `Nx` |
| 删 1 行 / N 行 | `dd` / `Ndd` |
| 撤销 / 撤销整行改动 | `u` / `U` |

## 十、现场走一遍：从空文件到"文件里有内容"

### 10.1 新建一个文件并写入内容

| 步骤 | 做什么 | 输入什么 | 看到什么 |
|---|---|---|---|
| 1 | 打开一个还不存在的文件 | `vi 信息/a3.txt` | 空编辑区，底部标着**"新建"** |
| 2 | 进编辑模式 | `i` | 左下角出现插入提示 |
| 3 | 写一行内容（老师写的是日期时间） | `2026年10月26日14点18分` | 文字出现在光标处 |
| 4 | 回一般命令模式 | `Esc` | 插入提示消失 |
| 5 | 进末行模式 | `Shift` + `;` | 屏幕最后一行出现 `:` |
| 6 | 保存退出 | `wq` 回车 | 回到 shell 提示符 |
| 7 | 确认文件在 | `ls 信息` | 列表里出现 `a3.txt` |
| 8 | 看内容 | `cat 信息/a3.txt` | 刚才写的那一行 |
| 9 | 再打开一次 | `vi 信息/a3.txt` | 底部不再有"新建"，显示文件名、位置、**1 行、17 个字节** |

### 10.2 要改"重要文件"：先复制，再打开

老师要改的是一个**比较重要的文件**，他的做法是：

1. **不直接改原文件**——"这个文件比较重要，我不能直接编辑它"；
2. 先 `cp` 一份到 `/信息` 下；
3. 再 `vi` 打开**复制出来的那一份**去改；
4. 改坏了也没关系——**原件还在**。

> 📌 **一条要养成的习惯**：**改重要文件之前先备份（复制一份）**，改副本，不动原件。

### 10.3 改完之后的三条出路

| 情况 | 怎么做 |
|---|---|
| 改对了 | `Esc` → `:wq` 保存退出 |
| 根本没改，只是想看看 | `Esc` → `:q` 直接退出 |
| 改乱了、不想要 | `Esc` → `:q!` 强制退出，改动全部作废 |

## 十一、小结

### 11.1 一条线串起来

```text
vi 文件名        打开 / 新建
i / a / o        → 编辑模式（能写字）
Esc              → 一般命令模式（能下命令）
Shift + ;        → 末行模式（命令敲在最后一行）
:wq              → 存盘退出      :q → 没改就退      :q! → 不存强退
:set nu / nonu   → 显示 / 取消行号
/关键字  ?关键字   → 向下 / 向上查找
:s/旧/新          → 当前行（只换第一个）
:s/旧/新/g        → 当前行全部
:%s/旧/新/g       → 整篇全换
:5,12s/旧/新/g    → 只换第 5—12 行
Ctrl+f / Ctrl+b  0 / $  gg / G  数字 + 回车
yy / Nyy   p / P   v + G + y
x / Nx    dd / Ndd    u / U
```

### 11.2 必须记住的几条

| 序号 | 要记住的 |
|---|---|
| 1 | `vi` 和 `vim` 是同一个程序，`vim` 是新版、功能更强，平时用 `vim` |
| 2 | **打开文件默认在一般命令模式**——写不进字是正常的，不是键盘坏了 |
| 3 | `i` / `a` / `o` 进编辑模式，`Esc` 回一般命令模式 |
| 4 | **保存退出 `:wq`；没改就 `:q`；改了不要就 `:q!`** |
| 5 | 新建的文件，`:q!` 出来**等于没建** |
| 6 | 移动、复制、删除、粘贴**只能在一般命令模式**里做 |
| 7 | `gg` 第一行、`G` 最后一行；`p` 往下粘、`P` 往上粘；`u` 撤销、`U` 撤销整行 |
| 8 | 替换：`:s` 只管当前行第一个，`:%s/.../g` 才是整篇全换 |
| 9 | 改重要文件之前**先复制一份** |

### 11.3 老师对"讲到什么程度"的交待

> 老师原话（大意）：**"这些（是）我们常用的功能，基本上都是这些。……还有很多功能，但是大部分在编辑过程当中用不上，我们主要讲一下主要的这些功能。"**

本节覆盖的功能就是：**打开 / 新建、进编辑模式写内容、保存退出、光标移动、复制粘贴、删除、撤销、显示行号、查找、替换**。
