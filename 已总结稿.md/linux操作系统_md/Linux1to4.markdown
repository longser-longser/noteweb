# Linux 基础课程知识总结（第1-4节）

## 一、课程背景与 Linux 重要性

### 1.1 为什么学习 Linux？

- 当前国内行政事业单位、企业正在全面转向国产化操作系统
- 国产操作系统（如银河麒麟、统信 UOS 等）底层均基于 Linux 内核
- 华为鸿蒙早期基于 Linux，后完全自研，属于全新方向
- 走向工作岗位后，接触的计算机大概率不再使用 Windows，而是基于 Linux 的操作系统
- Windows 因安全问题在国内许多单位已被禁用

### 1.2 国产操作系统生态

- 银河麒麟、统信 UOS、阿里云 OS、百度云 OS 等均基于 Linux 内核二次开发
- 龙芯、黄河等国产计算机无法安装 Windows，必须使用国产操作系统
- 鸿蒙已基本覆盖日常应用（微信、支付宝、抖音、快手等），生态逐步完善

## 二、Linux 概述

### 2.1 什么是 Linux

- Linux 是一套**免费使用和自由传播**的类 Unix 操作系统
- 由芬兰学者 **Linus Torvalds（林纳斯·托瓦兹）** 开发
- 1991年10月5日首次正式对外公布
- 基于 **POSIX** 和 **Unix**，支持多用户、多任务、多线程和多 CPU
- 采用 **GPL（通用公共许可证）** 协议发布，开源免费

### 2.2 Linux 与 Unix 的关系

- Unix 是封闭、收费的操作系统，价格昂贵
- Minix 是 Unix 的简化版，用于教学
- Linus 因 Minix 使用不便，开始编写 Linux
- Linux 开源免费，全球已有数百个发行版

### 2.3 Linux 内核与发行版的关系（类比：地基与房子）

- **Linux 内核** = 地基：所有基于该内核的系统都属于 Linux 家族
- **发行版** = 房子：各公司在同一地基上按各自设计建造，各不相同
- 例如：Android 底层也是 Linux 内核，但上层设计不同，所以与桌面 Linux 差异大
- 华为鸿蒙：最初基于 Linux 内核，后完全自研，彻底推翻地基重写

### 2.4 主要发行版

- **国外**：Red Hat（红帽子，最正宗）、CentOS（已停止维护）、Ubuntu、Fedora、openSUSE、Debian
- **国内**：OpenEuler（欧拉）、麒麟、统信 UOS、深度等
- 红帽子有收费版和免费版，CentOS 原是免费版但已停止维护
- 国内外超过 **300种** 发行版本

## 三、Linux 系统结构

### 3.1 三大组成部分

| 层次 | 名称 | 说明 |
|------|------|------|
| 第一层 | **内核（Kernel）** | 系统核心，负责与硬件交互，管理 CPU、内存、设备等资源 |
| 第二层 | **Shell（命令解释层）** | 用户与内核交互的接口，接收用户命令并送入内核执行 |
| 第三层 | **实用工具** | 编辑器、过滤器、交互程序等标准工具集 |

### 3.2 Shell 详解

- Shell 是用户界面，提供用户与内核交互的接口
- 接收用户输入的命令，送入内核执行
- 常见 Shell：**BASH**
- 操作环境类型：
  - 桌面环境（GUI）
  - 窗口管理器
  - 命令行（CLI）
- 服务器通常不安装桌面，直接使用文本命令行

### 3.3 实用工具分类

1. **编辑器**：用于编辑文件（如 Vim）
2. **过滤器**：用于接收并过滤数据
3. **交互程序**：允许用户发送或接收来自其他用户的信息

## 四、Linux 内核版本

### 4.1 版本号命名规则

格式：**主版本号.次版本号.修订号**

例如：`5.10.12`

- **主版本号**：5
- **次版本号**：10
- **修订号**：12

### 4.2 内核版本类型判断

**旧规则（Linux 2.6 之前）**：
- **次版本号为奇数**：测试版/开发版（不稳定，用于找 Bug）
- **次版本号为偶数**：稳定版/正式发行版

例如：2.3.x → 测试版；2.4.x → 稳定版

**现代规则（Linux 2.6 之后）**：
- 不再使用奇偶规则判断稳定与否
- 采用 **长期支持（LTS，Long-Term Support）** 版本策略
- LTS 版本提供长期维护和安全更新，适合生产环境
- 例如：5.10、5.15、6.1、6.6 等均为 LTS 版本

## 五、文件系统

### 5.1 基本概念

- 计算机底层只识别**二进制（0 和 1）**
- 不同的文件系统决定了 0 和 1 在硬盘上的排列顺序与读取方式不同
- 新硬盘必须**分区 + 格式化**（指定文件系统）才能使用
- 分区 = 在硬盘上划分区域；格式化 = 指定该区域使用什么规则

### 5.2 Windows 常用文件系统

- FAT32
- NTFS
- exFAT

### 5.3 Linux 常用文件系统

- **EXT2、EXT3、EXT4**（传统 Linux 文件系统）
- **XFS**（现代 Linux 默认推荐，支持超大硬盘可达 PB 级别）
- 默认情况下，Linux 文件系统在 Windows 下无法直接识别读取（但可通过安装第三方工具如 Ext2Fsd、Linux Reader 等实现访问）

## 六、Linux 安装（以 Red Hat Enterprise Linux 9 为例）

### 6.1 虚拟机配置（VMware）

**操作系统选择**：Red Hat Enterprise Linux 9（64位）

**CPU 配置**：
- 根据实际处理器核心数选择

**内存配置**：
- 建议 2048MB（2GB），足以运行

**网络类型**：
- **NAT（网络地址转换）**：通过宿主机共享网络
- **桥接**：直接使用物理网卡，局域网内可直接互通

**磁盘类型**：
- IDE（早期，40针宽线接口）
- SCSI（服务器常用，68针/80针接口）
- **SATA**（家用机械硬盘接口）
- **SAS**（服务器硬盘接口）
- **NVMe/M.2**（现代固态硬盘接口）

**磁盘容量**：建议 40GB，不勾选"立即分配所有磁盘空间"

**磁盘文件模式**：
- 单个文件
- 多个文件（不推荐在 FAT32 格式分区上使用，因为 FAT32 有单文件大小限制）

### 6.2 固件类型

- **BIOS/MBR（传统模式）**：
  - 最多支持 4 个主分区（3 个主分区 + 1 个扩展分区）
  - 使用 32 位逻辑块寻址（LBA），最大支持硬盘约 2.2TB
  - 2016年以前主流
  
- **UEFI/GPT（新模式）**：
  - 最多支持 128 个分区
  - 128 位寻址，支持 PB 级甚至更大硬盘
  - 硬盘超过 2TB 必须使用 UEFI/GPT

### 6.3 安装步骤

1. 选择语言：**简体中文**
2. 键盘：汉语
3. 时区：**亚洲/上海**
4. 软件选择：**带 GUI 的服务器**（初学者推荐桌面环境）
5. **安装目的地（重点）**：选择自定义存储配置

### 6.4 分区挂载点配置（核心重点）

Linux 中所有分区称为**挂载点**，无 C/D/E/F 盘概念。

| 挂载点 | 作用 | 建议大小 |
|--------|------|----------|
| `/boot` | 引导分区（存放内核及引导文件） | 300MB ~ 1GB |
| `/`（根） | 系统最高级目录，所有内容的顶层 | 剩余空间全部 |
| `/home` | 用户家目录，存储所有用户数据 | 根据需求适当分配 |
| `swap`（交换分区） | 相当于 Windows 虚拟内存，当物理内存不足时临时存放数据 | 内存 ≤ 4GB 时建议为内存的 2 倍；内存较大（≥ 8GB）时可适当减少，甚至不设 |

**文件系统类型**：默认使用 **XFS**

**设备类型**：LVM（逻辑卷管理）或标准分区

## 七、Linux 基础操作知识概览

### 7.1 课程主要学习内容

1. **安装 Linux 系统**
2. **命令行操作**（Linux 不像 Windows 靠鼠标点击，需要记忆命令）
3. **网络配置**（IP 地址配置、网络设置）
4. **修改计算机名（主机名）**
5. **文件与目录操作**：
   - 新建文件/文件夹
   - 删除文件/文件夹
   - 修改文件名
   - 编辑文件内容
   - 查找文件/目录
   - 查看文件属性与内容
6. **用户与组管理**：
   - 创建用户
   - 创建用户组
   - 用户分组管理
7. **权限管理**（Linux 权限要求非常严格）：
   - 设置文件权限（读、写、执行）
   - 控制用户对文件的访问
8. **进程管理**：
   - 查看运行进程
   - 结束进程（释放 CPU/内存/显存资源）

### 7.2 Linux 与 Windows 的重要区别

- **Linux 不依赖扩展名识别文件类型**：文件类型通过文件内容特征（如魔数）判断，而非扩展名；Windows 则依赖扩展名识别文件类型
- **Linux 是命令行驱动**：不像 Windows 点点鼠标即可，需要掌握命令
- **文件系统默认不互通**：Linux 原生文件系统（如 EXT4、XFS）在 Windows 下默认无法直接读取

## 八、网络协议基础

- 当前互联网主流协议：**TCP/IP**
- TCP/IP 并非国际标准，而是事实上的行业标准（De Facto Standard）
- 国际标准模型：**OSI 七层参考模型**
- 除 TCP/IP 外还有其他协议：IBM SNA、AppleTalk、Novell IPX/SPX 等
- 1983年以前网络协议无统一标准，各自为政
- Linux 以网络为核心设计，最初就是为网络服务而编写

## 九、Linux 特点总结

- 免费、开源、自由传播
- 支持 32 位和 64 位硬件
- 性能稳定，多用户多任务
- 以网络为核心设计
- 可运行在手机、平板、路由器、台式机、大型机、超级计算机等各类设备
- 严格来讲，"Linux" 仅指内核，但习惯上泛指基于 Linux 内核的整个操作系统
- 主要使用 C 语言编写
- 与 GNU 项目结合构成完整操作系统（GNU/Linux）
