# Linux 命令速查（老师课上讲过的全部命令）

> **这份文件是什么**：把 Linux 操作系统这门课**第 1—16 节**里老师讲过、用到过的命令**全部集中到一处**，按"干什么用"分类，每条都写清**它是干什么的、怎么用、老师上课是怎么讲的**。
>
> **来源**：本文件夹里另外四份课堂笔记（第 1—4 节、第 5—8 节、第 9—12 节、第 13—16 节），**没有添加课上没讲过的命令**。
> 说明：**第 1—4 节是概念课**（Linux 是什么、装系统、分区、文件系统），那节课**没有出现命令**；命令从**第 5—8 节**（装机与分区）开始出现，**第 9—12 节**（界面切换、查帮助、重启关机）、**第 13—16 节**（进程、echo、变量）是命令最集中的两节。
>
> **怎么用**：忘了某个命令是干什么的，先翻第一节的**总表**；想回忆老师当时怎么讲的、有什么坑，看第二节的**逐条说明**。

## 一、总表：这些命令分别是干什么的

### 1. 帮助与"我现在在哪"

| 命令 | 作用（老师讲的意思） |
|---|---|
| **`pwd`** | **查看当前所在位置**（print working directory）。老师用 root 登录时，它显示 `/root` |
| **`命令名 --help`** | 查这个命令**怎么用、能带哪些参数**。写法是**两个横杠 + help**。⚠️ 帮助里**中括号 `[ ]` 包起来的都是"可选项"**，不加也能跑；⚠️ **不是所有命令都有 `--help`** |
| **`man 命令名`** | 查看命令的**详细信息**：属于哪一类（用户命令等）、谁开发的、哪个版本、详细说明。**空格键向下翻页，按 `q` 退出**。⚠️ 只能在后面翻，**很多命令用上下箭头往前翻不动** |

> 老师的话：`man` 和 `--help` 显示的"基本上是一样的"，但 **`man` 详细得多**；"所有的 Linux 发行版当中，都有 `man`"。

### 2. 图形界面／文本界面切换与开关机

| 命令 | 作用（老师讲的意思） |
|---|---|
| **`init 3`** | **图形界面 → 文本界面**（纯键盘；鼠标在文本界面里点不动） |
| **`init 5`** | **文本界面 → 图形界面**。**前提：装系统时装了桌面**，否则"你按这个命令没用，它回不来" |
| **`reboot`** | **重启**。老师强调：服务器在机房里根本摸不到，"我们只能用命令" |
| **`reboot -p`** | 重启命令**加 `-p` 参数就是关机** |
| **`shutdown -h now`** | **立刻关机**（装机那节的速查表里给的写法） |

> 重启之后**默认还是进桌面（图形界面）**。另外：**有些配置必须重启才生效**，这也是必须会重启命令的原因。

### 3. 文件与目录

| 命令 | 作用（老师讲的意思） |
|---|---|
| **`ls`** | 列目录内容。老师说这是**最重要**的一个命令——"他是要一直在用的" |
| **`cat /etc/fstab`** | 查看文件内容。课上用来**看开机自动挂载的配置** |

### 4. 磁盘、分区与内存（主要在第 5—8 节装机那次）

| 命令 | 作用（老师讲的意思） |
|---|---|
| **`lsblk`** | **树形**查看磁盘与分区，最直观。**装完系统用它验证** `/boot`、`swap`、`/home`、`/` 都在、大小与规划一致 |
| **`df -h`** | 查看**已挂载文件系统的使用率**（`-h` 是给人看的大小单位） |
| **`fdisk -l`** | 查看**分区表与分区详情** |
| **`parted -l`** | 同上，另一个查看分区信息的命令 |
| **`blkid`** | 查看分区的 **UUID 与文件系统类型** |
| **`free -h`** | 查看**内存与 swap 的使用情况** |
| **`pvs` / `vgs` / `lvs`** | 查看 LVM 的**物理卷 / 卷组 / 逻辑卷**（对应"标准分区 vs LVM"那一节） |
| **`cat /etc/fstab`** | 看**开机自动挂载**配置 |

### 5. 用户与权限（提权）

| 命令 | 作用（老师讲的意思） |
|---|---|
| **`su`** | **切换用户**：超级管理员 ↔ 普通用户，来回切 |
| **`su -`** | 切换到 **root**（登录式切换，环境也跟着换） |
| **`sudo`** | **以 root 权限执行一条命令**。装系统时"把普通用户设为管理员"，就是为了能用它 |

> 为什么必须有普通用户：**图形登录界面默认不列出 root**，得先用普通用户进桌面，再用 `su -` 或 `sudo` 提权。

### 6. 查看进程（第 13—16 节重点）

| 命令 | 作用（老师讲的意思） |
|---|---|
| **`ps`** | **静态查看进程**——看一眼就结束。**不带参数**：只显示当前这个终端里你自己启动的进程，很少；**加参数**：能看到**所有**进程（系统进程 + 你的进程） |
| **`ps --help`** | 看 `ps` 后面能跟哪些参数（老师原话："后边可以跟很多参数……要详细啊，这里面它就会详细地显示出来"） |
| **`ps -u 用户名`** | 看**某个用户**启动了哪些程序、用了哪些命令（老师："杠 u 就是说我这个用户启动了哪些"） |
| **`pstree`** | 以**树状、分级**的形式看进程之间的**父子/关联关系**（`ps` 是平铺不分级的）。所有进程都挂在 **1 号进程**（`systemd`）底下，往下再分系统进程、应用进程 |
| **`top`** | 界面**一直在刷新**，显示 PID、用户、命令、CPU 占用率等；**按 `q` 退出**。用途：服务器要**实时监视**动态 |

> **`ps` 输出里各列的含义**（老师带着逐列看的）：
>
> | 列 | 含义 |
> |---|---|
> | **PID** | **进程的编号**（进程号）。数字很大（如 3342），**不是从 1 开始连续排的** |
> | **TTY** | 该进程与哪个终端关联。显示 **`?`** 表示**不与终端关联**（后台/系统进程） |
> | **USER / UID** | 这个进程属于哪个用户（这里边一般都是系统） |
> | **时间** | 什么时间启动的 |
> | **CMD / COMMAND** | **命令的名称**——到底是哪个命令 |
> | **（资源）** | CPU 占用多少、内存占了多少（用"详细"形式能看到） |

### 7. 结束进程（第 13—16 节重点）

| 命令 | 作用（老师讲的意思） |
|---|---|
| **`kill PID`** | **按 PID 结束进程**。老师全程拿 `sshd` 举例（远程连接服务，关掉别人就连不上你） |
| **`kill -l`** | **列出所有信号**（老师："杠 l 是显示所有的"） |
| **`kill -s`** | **指定用哪个信号**（后面跟信号名/信号编号） |
| **`kill -9 PID`** | **直接强制杀掉**（老师演示的"第二种方式"） |
| **`killall 进程名`** | **一次结束所有同名进程**，比如 `killall sshd`；**关联的子进程也会一起关掉**。（网站服务会起好几个同名进程，"你只结束一个不行，结束不干净"） |
| **`pidof 进程名`** | 知道进程名、查它的 PID |
| **`ps` + `grep` 过滤进程名** | **判断某个进程在不在运行**：比如查 `httpd`，**查得到=在运行，查不到=没运行** |

> ⚠️ **三条铁律**（老师专门停下来讲的）：
> 1. **PID 会变**——同一个 `sshd`，杀掉再启动，PID 就从 127 变成了 3800。"你只要结束再启动，这个 PID 是一直在变"，所以**每次杀之前都要重新查一遍 PID**；
> 2. **别把自己的"壳"杀掉**——你现在敲命令的 **`bash` 本身就是个进程**，杀了它你和系统的交互就断了，**必须重新登录**；
> 3. **系统进程绝对不能杀**——"你关了以后，系统就不能继续运行了"。

### 8. 输出与变量（第 13—16 节）

| 命令 / 写法 | 作用（老师讲的意思） |
|---|---|
| **`echo 内容`** | 把内容**输出到屏幕上**。老师还说它**能向文件写入、追加内容**，但**这两块留到后面讲**，这次只讲了输出到屏幕 |
| **`变量名=值`** | **定义变量**（和程序设计课里"什么什么 = 什么什么"一样） |
| **`$变量名`** | **调用（显示）变量**，变量名前加 `$`。⚠️ **调用一个不存在的变量，什么也不显示（空），不会报错** |
| **`export 变量名`** | 把**局部变量升级为全局变量** |

> **引号规则（老师用好几个例子对比出来的）**：
>
> | 情况 | 怎么用引号 |
> |---|---|
> | ① 普通内容 | **可以不加引号** |
> | ② 内容里有 `$` 这类特殊符号 | **单引号、双引号、不加引号，三种结果各不相同** |
> | ③ 特殊内容（比如带空格） | **必须用双引号** |
>
> 关键理解：**不加引号 / 加双引号时，`$` 会被当成变量先"算"出来**（输出的是它的值）；**只有单引号是原样照抄**，`$` 才会原样输出。
>
> **局部变量 vs 全局变量**：默认定义的变量都是**局部**的——"我只要一换位置，它就调不来了"；**升级成全局变量**以后，"不管它在哪个区域，它都能调过来"。老师的类比：局部变量 = 只在**二班的花名册**上，换到别的班就找不到；全局变量 = 登记在**学院大名单**上，到哪儿都能找到。
>
> **Linux 严格区分大小写**（Windows 基本上不区分）——"你大写就是大写，小写就是小写，它两个不是一个东西"。变量、命令、文件名、用户名都一样。

### 9. 服务、网络与系统信息（第 5—8 节"装完之后要做的几件事"）

| 命令 | 作用 |
|---|---|
| **`systemctl start / stop / enable 服务名`** | 启动 / 停止 / 设为**开机自启**某个服务 |
| **`systemctl status firewalld`** | 查看**防火墙服务**的状态 |
| **`getenforce`** | 查看 **SELinux** 状态（练习环境可临时关闭，**生产环境不要关**） |
| **`hostnamectl set-hostname 你的学号`** | **修改主机名**（计算机名） |
| **`ip addr`** | **查看 IP 地址** |
| **`ip route`** | **查看路由** |
| **`ping`** | **测试网络通不通** |
| **`nmtui`** | **文本图形界面**配置网络（像菜单一样选） |
| **`nmcli`** | **命令行**配置网络 |
| **`dnf install -y open-vm-tools open-vm-tools-desktop`** | 安装**虚拟机工具**，装完分辨率自适应、剪贴板互通、时间同步 |
| **`lscpu`** | 查看 CPU 信息 |
| **`lspci`** | 查看 PCI 设备 |
| **`lsusb`** | 查看 USB 设备 |

> 顺带认识两个**服务进程**的名字：**`sshd`**（远程连接服务，关掉别人就连不上）、**`httpd`**（网站服务）。后面学网络服务配置时它们就是主角。

## 二、老师反复强调的几条规矩（最容易考、最容易错）

1. **AI 能帮你生成命令，但你必须看得懂、改得动**——"只要是用 AI 输入的，基本上都不会改"，换个环境就废了。
2. **命令大多要带参数**，不知道带什么就 `命令 --help` 或 `man 命令`；帮助里**中括号 `[ ]` 里的全是可选项**。
3. **`man` 用空格往后翻、`q` 退出**，很多命令**往前翻不动**。
4. **服务器在机房里摸不到，重启关机只能靠命令**；有些配置还必须重启才生效。
5. **名字相同 ≠ 同一个进程**（Chrome 一开就是 17 个同名进程），**PID 相同才是同一个进程**。
6. **PID 每次重启都会变**，所以**杀进程前必须重新查 PID**，不能记死。
7. **别杀 `bash`**（你现在敲命令的壳），**别杀系统进程**。
8. **文件类型不靠扩展名判断**（Linux 看文件内容特征），**严格区分大小写**——这两条是和 Windows 最根本的区别。
9. **为什么服务器不装桌面**：一开桌面就要起一大堆进程、浪费资源；没有桌面，**管理服务器就只能靠命令**。
