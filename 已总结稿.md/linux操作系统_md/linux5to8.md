## 一、这次课要解决什么问题

**一句话**：在一台物理电脑里，用 VMware 造出一台"虚拟电脑"，并在它里面从零装好一套 Linux 系统——其中最关键、最容易出错的动作是**手动规划磁盘分区**。

装机全链路（后续章节按此顺序展开）：

```
准备环境 → 新建虚拟机 → 配置虚拟硬件 → 挂载 ISO 光盘 → 引导安装程序
      → 选语言与软件 → 手动分区 → 设置 root 密码并建用户 → 重启 → 首次启动验证
```

**为什么用虚拟机来学装系统：**

| 理由 | 说明 |
|---|---|
| 不怕装坏 | 装错了、配崩了，删掉重来，完全不影响物理机上的系统 |
| 可以回滚 | 做实验前**拍快照**，出问题一键恢复 |
| 可以复制 | **克隆**出一台配置相同的机器，做多机实验不用重复安装 |
| 可以并存 | 一台物理机上同时有 Windows 和 Linux，互不干扰 |
| 资源可控 | CPU、内存、磁盘按需分配，不够随时加 |

> **实操提示**：虚拟机文件（`.vmx`/`.vmdk`）要放在**非还原分区**（如 D 盘里以自己的姓名/学号命名的文件夹）。机房机器的 C 盘通常**重启即还原**，放 C 盘等于白装。

## 二、动手前必须懂的六个概念

### 2.1 宿主机 / 虚拟机 / 客户机

- **宿主机（Host）**：真实的那台物理电脑。
- **虚拟机（VM）**：由软件虚拟出来的"电脑"，拥有自己**虚拟的** CPU、内存、硬盘、网卡、光驱。
- **客户机（Guest）**：虚拟机里安装的那个操作系统（本次装的是 Linux）。
- 提供虚拟化能力的软件统称 **Hypervisor**：
  - **Type-1（裸金属型）**：直接装在硬件上，如 ESXi、Hyper-V、KVM；
  - **Type-2（宿主型）**：装在操作系统上，如 **VMware Workstation**、VirtualBox——本课程用的就是这一类。
- **前提条件**：物理机必须在 BIOS/UEFI 中**开启 CPU 虚拟化**（Intel VT-x / AMD AMD-V），否则建不了 64 位虚拟机，或直接报错。
- **资源红线**：处理器数量 × 每处理器核心数 **不能超过物理机的核心数**；分配给所有虚拟机的内存之和不要超过宿主机可用内存。

### 2.2 虚拟磁盘：它本质上就是一个文件

- 虚拟机里的"硬盘"，其实是宿主机上的**一个（或一组）文件**，扩展名 `.vmdk`。
- 创建时两个选项：
  - **立即分配所有磁盘空间**：一次性把 40GB 从宿主机上划走，性能略好、**占空间**；
  - **按需增长**（不勾选）：用多少占多少，**省宿主机空间**——学习环境选这个。
- **拆分成多个文件 / 单个文件**：学习环境两者都可以。
- **要点**：虚拟磁盘的类型（NVMe / SATA / SCSI / IDE）与宿主机用的是机械盘还是 M.2 固态**没有关系**，只影响虚拟机内部的性能与兼容性。

### 2.3 固件类型：BIOS 还是 UEFI

| 对比项 | 传统 BIOS（Legacy） | UEFI |
|---|---|---|
| 是什么 | 老式的基本输入输出系统 | 新一代固件 |
| 引导方式 | 读磁盘第一个扇区 | 读 **ESP 分区**里的引导文件 |
| 分区表要求 | MBR | **GPT** |
| 容量上限 | 2TiB | 远大于 2TiB |
| 启动速度 | 慢 | 快 |
| 安全启动 | 不支持 | 支持 Secure Boot |

- **改的位置**：虚拟机 → **设置 → 选项 → 高级 → 固件类型**（**必须关机状态**才能改）。
- **一句话结论**：**硬盘大于 2TB 就必须用 UEFI**；用 UEFI 却没建 ESP 分区，会出现开机找不到系统。

### 2.4 分区表：MBR 还是 GPT

| 对比项 | MBR | GPT |
|---|---|---|
| 最大磁盘 | **2TiB（约 2.2TB）** | 远大于 2TiB |
| 分区数量 | 最多 **4 个主分区** | 最多 **128 个分区** |
| 配套固件 | BIOS | UEFI |

> **要纠正一个常见说法**：不是"传统 BIOS 只能支持 2T 的硬盘"，而是**MBR 分区表**的地址位数决定了 2TiB 上限；固件、分区表、控制器三者要配套。
> （另有一点：SCSI 控制器里的 **BusLogic** 类型本身也不支持大于 2TB 的虚拟磁盘。）

### 2.5 挂载点：Linux 里没有 C 盘、D 盘

- Windows 用**盘符**（C:、D:）访问分区；**Linux 没有盘符**，用的是**挂载点**——把某个分区"接到"目录树的某个目录上，之后往这个目录写文件，就是写进那个分区。
- 所有存储最终构成**一棵目录树**，最顶端是根目录 `/`。
- 设备文件集中在 `/dev` 下（"一切皆文件"）：
  - SATA/SCSI/USB 硬盘：`/dev/sda`、`/dev/sda1`、`/dev/sda2`…
  - NVMe 硬盘：`/dev/nvme0n1`、`/dev/nvme0n1p1`…
- **所以装 Linux 时要手工"添加挂载点"**，而不是选"C 盘装系统"。

### 2.6 swap 与文件系统

- **swap（交换分区）**：Linux 的**虚拟内存**，作用相当于 Windows 的**页面文件**。内存不够时，把暂时不用的数据挪到 swap 里。
- **文件系统**：分区格式化后使用的格式。
  - **XFS**：RHEL **7 及以后**的默认文件系统（本次装的就是它）；
  - **ext4**：RHEL **6** 的默认文件系统；
  - 还有 Btrfs、vfat（UEFI 的 ESP 分区用 FAT32）等。
- **注意**：默认文件系统由**所安装的发行版**决定，与你在 VMware 里选的"客户机操作系统版本"无关——客户机类型只影响 VMware 给出的**推荐硬件配置**。

## 三、装机全流程（照着做）

### 阶段 1：准备

1. 确认物理机 **BIOS 已开启虚拟化**（VT-x/AMD-V）。
2. 准备好 **ISO 映像**（放在容易找到的位置，例如 C 盘根目录）。
3. 确定虚拟机存放位置：**非还原分区**。
4. （按老师要求）在宿主机上**禁用虚拟网卡**：右击桌面"网络"→**更改适配器设置**→ 右键 `VMware Network Adapter VMnet1`、`VMnet8` → **禁用**。
   - 它们分别对应"仅主机"和"NAT"网络；禁用后**宿主机与虚拟机的互联、NAT 上网会受影响，桥接不受影响**，课堂目的是避免与机房网络互相干扰、也避免查看 IP 时看花眼。

### 阶段 2：新建虚拟机向导

| 步骤 | 怎么选 |
|---|---|
| 1. 创建方式 | 选**自定义（高级）**——才能逐项看到并控制硬件参数 |
| 2. 硬件兼容性 | 保持默认，不动（它决定虚拟机可用的硬件上限） |
| 3. 安装来源 | 选**"稍后安装操作系统"**——先建一台空机器，再挂 ISO 安装 |
| 4. 客户机操作系统 | **Linux** → 版本选**红帽系（Red Hat Enterprise Linux）64 位**。理由：兼容性好，很多应用版本都兼容 |
| 5. 虚拟机名称 | 例如 **SERVER**；**建议改成自己的学号/姓名**，多台机器时好区分 |
| 6. 安装位置 | **改路径**，放到非还原分区 |
| 7. 处理器 | 处理器数量 × 每处理器核心数 = 总核心数；**不超过物理机核心数** |
| 8. 内存 | Linux 练习 **2GB 起**；装图形界面建议 **4GB**（2GB 会很卡） |

### 阶段 3：虚拟硬件与固件

| 项目 | 怎么选 | 说明 |
|---|---|---|
| 网络类型 | **NAT** / 桥接 / 仅主机 | NAT ≈"给你配了个路由器"，能上网、外部访问不到；桥接 ≈"多了一张独立网卡"，可直接与局域网其他机器互访；仅主机只能和宿主机通。**本学期不需要对外互通，选哪个都行；要联网装软件就选 NAT** |
| I/O 控制器 | 用默认推荐（Linux 常为 **LSI Logic**） | 它就是硬盘控制器类型；**BusLogic 不支持 >2TB 的虚拟磁盘** |
| 磁盘类型 | **NVMe**（也可 SATA/SCSI） | 与宿主机物理硬盘类型无关；不要用已淘汰的 IDE |
| 磁盘容量 | **新建虚拟磁盘，40GB** | 学习够用 |
| 磁盘选项 | **不勾选"立即分配所有磁盘空间"** | 按需增长、省空间；单个文件/多个文件都行 |
| 固件类型 | **BIOS 或 UEFI**（二选一，要配套分区表） | 大于 2TB 必须 UEFI |
| CD/DVD | **使用 ISO 映像文件** → 浏览到 ISO → 勾选**启动时连接** | 相当于把光盘插进虚拟光驱 |
| 其他设备 | USB 控制器、声卡、打印机等用不到的可以**移除** | 减少干扰 |

### 阶段 4：挂载介质并引导

1. 打开虚拟机电源，进入引导菜单。
2. **选第 1 项"Install …"直接安装。**
   - **不要选第 2 项**：那是"**测试安装介质并安装**"，会逐块校验整个 ISO，**要等很久**（不是死机，但练习时没必要）。
3. 出现安装界面后，选择安装语言：**简体中文** → 下一步。

### 阶段 5：安装程序里的三处选择

| 项目 | 怎么选 |
|---|---|
| **时间和日期** | 时区/时间会自动检测，正确就**不用动** |
| **软件选择** | 选**"带 GUI 的服务器"**（第一次学、习惯用桌面）——装上图形界面，后续操作直观 |
| **安装目的地** | 勾选那块 40GB 磁盘；**存储配置选"自定义"**（想练分区就不能用"自动"） |

### 阶段 6：手动分区（本次课重点）

在"安装目的地 → 自定义"页面：

1. 点 **＋**（添加）按钮，逐个添加分区，每个分区填三项：
   - **挂载点**（选 `/boot`、`swap`、`/home`、`/` 等）
   - **期望容量**（如 500MiB、4096MiB、10GiB）
   - **设备类型**（标准分区 / LVM / LVM Thin…）与**文件系统**（默认即可）
2. 按下面的方案添加四个分区（本次课就是这一套）：

| 挂载点 | 容量 | 文件系统 | 作用 |
|---|---|---|---|
| `/boot` | 500MiB | XFS | 内核与引导文件，**给 1GiB 更稳妥** |
| `swap` | 4096MiB | swap | 交换分区（虚拟内存） |
| `/home` | 10GiB | XFS | 普通用户的家目录 |
| `/` | **剩余全部**（约 25.5GiB） | XFS | 根分区 |

3. 分完可能还剩几 MB 未分配空间，**不用管**。
4. 点 **"完成"** → 弹出**更改摘要**（列出将执行的分区动作）→ 核对无误后点 **"接受更改"**。
   - 摘要里的**警告不等于错误**，但一定要看清；
   - **"接受更改"会清空这块磁盘上的数据**——新盘无所谓，**老机器务必先备份**；
   - **只勾选你要装的那块盘**，这是整个安装过程中最危险的一步。

### 阶段 7：密码与用户

1. **设置 root 密码**：root 是 Linux 超级管理员（相当于 Windows 的 Administrator）。
   - 课堂为方便用了简单密码，安装器会提示"密码太简单"，**再点一次"完成"**才生效；
   - **生产环境必须用复杂密码**，并且**必须自己记住**——忘了只能重装。
2. **创建一个普通用户**：建议**勾选"将此用户设为管理员"**（可用 sudo）。
   - 图形登录界面**默认不列出 root**，必须有普通用户才能登录桌面，再用 `su -` 或 `sudo` 提权。
3. 等待软件包安装完成。

### 阶段 8：重启与首次启动

1. 安装完成点**重启**；**重启前先断开 CD/DVD**（取消"启动时连接"），否则可能又从光盘启动。
2. 首次启动进入**初始设置**：**许可信息 → 我接受许可协议**（不接受无法进入系统）。
3. 用**普通用户**登录桌面。
4. 验证：终端执行 `lsblk`、`df -h`，确认 `/boot`、`swap`、`/home`、`/` 都在、大小与规划一致。

## 四、分区专题（把这件事彻底弄明白）

### 4.1 每个挂载点是干什么的

| 挂载点 | 放什么 | 建议大小 |
|---|---|---|
| `/boot` | 内核、initramfs、GRUB 引导文件 | **1GiB**（下限 500MiB） |
| `/boot/efi` | **UEFI 必需的 ESP 分区**（FAT32） | **200MiB** |
| `swap` | 交换分区（虚拟内存） | 见 4.3 |
| `/` | 根分区，除已单独挂载的内容外的一切 | 剩余全部（≥20GiB） |
| `/home` | 普通用户的家目录与个人文件 | 按需（10—50GiB） |
| `/var` | 日志、网站、数据库等会不断增长的数据 | 服务器建议单独分 |
| `/tmp` | 临时文件 | 可选 |

> 最小可用方案是 **`/boot` + `swap` + `/`** 三件套；要更规范再加 `/home`、`/var`。
> **分区方案由需求决定**——就像给了你一块地，盖一层还是两层、尖顶还是平顶，由你决定。

### 4.2 两套可直接照抄的方案

| 分区 | 方案 A：BIOS + MBR（本次课） | 方案 B：UEFI + GPT |
|---|---|---|
| `/boot/efi` | 不需要 | **200MiB（FAT32，ESP）** |
| `/boot` | 500MiB—1GiB，XFS | 1GiB，XFS |
| `swap` | 4GiB | 4GiB |
| `/home` | 10GiB | 10GiB |
| `/` | 剩余全部 | 剩余全部 |

### 4.3 swap 到底给多大

| 物理内存 | 建议 swap |
|---|---|
| ≤ 2GB | **内存的 2 倍**（本次 2GB → 4GB，就是这个规则） |
| 2GB — 8GB | **等于内存大小** |
| 8GB — 64GB | **4GB — 内存的一半**（至少 4GB） |
| > 64GB | **至少 4GB**（按实际负载） |

> 附加规则：**需要休眠（hibernate）时，swap 必须 ≥ 内存容量**。
> 记住：**swap 不是越大越好**——硬盘再大也别把 swap 设成几百 G，浪费空间还没什么收益。

### 4.4 标准分区 vs LVM

| 对比项 | 标准分区 | LVM 逻辑卷 |
|---|---|---|
| 结构 | 直接对应 `/dev/sda1` 这样的分区 | **PV（物理卷）→ VG（卷组）→ LV（逻辑卷）** 三层 |
| 扩容 | 麻烦（受相邻分区位置限制） | **可在线扩容、可跨多块磁盘** |
| 缩容 | 相对简单 | 较麻烦（**XFS 不支持缩容**） |
| 谁在用 | 手动分区时选 | **RHEL 的"自动分区"默认就用 LVM** |
| 查看 | `lsblk`、`fdisk -l` | `pvs`、`vgs`、`lvs` |

> 学习顺序建议：**先用标准分区把"挂载点、容量、文件系统"搞清楚**，再对比 LVM 体会它"能长大"的价值。

## 六、常见误解与易错点

**概念类（容易被讲错，记正确的）**

1. **"传统 BIOS 只能支持 2T 硬盘"** → 准确说是 **MBR 分区表**的上限是 2TiB（且最多 4 个主分区）；要用更大容量必须 **UEFI + GPT**。
2. **"引导菜单第二项会卡死"** → 不是死机，是**在测试安装介质**，很慢；练习直接选第一项。
3. **"swap 一律是内存的两倍"** → 只对 **≤2GB 内存**成立，大内存按 4.3 的表。
4. **"/boot 给 500M，再大也没用"** → 500MiB 只是**下限**。`/boot` 放内核与 initramfs，**每次内核升级都会累积旧内核**，空间不足会导致升级失败；建议 **1GiB**。
5. **"硬盘是 M.2，所以虚拟机里要选 NVMe"** → 两者没有因果关系；虚拟磁盘只是宿主机上的文件，类型按需选。
6. **"客户机类型选了红帽 6，所以默认文件系统是 ext4"** → 客户机类型只影响 VMware 的**推荐硬件配置**；默认文件系统由**所装的发行版**决定（RHEL 7+ 是 XFS）。
7. **"Linux 里没法看硬件"** → Linux 有图形工具（磁盘、设置中的"关于"），命令行更多：`lsblk`、`lspci`、`lsusb`、`lscpu`、`free -h`、`df -h`。
8. **"密码太简单，安装器不让过"** → 会提示"密码太简单"，**再点一次"完成"就能通过**；但生产环境必须用强密码。

**操作类（真正会踩的坑）**

9. **固件类型与分区表必须配套**：UEFI ↔ GPT（要有 `/boot/efi`），BIOS ↔ MBR；改固件类型必须先关机。
10. **"安装目的地"必须手动选"自定义"**，否则就是自动分区，等于没练分区。
11. **中途千万别勾错磁盘**：安装器只对"安装目的地"里勾选的磁盘动手，**确认只勾了虚拟磁盘**。
12. **"接受更改"前先问自己备份了没有**——这一步会清空所选磁盘。
13. **重启前断开 ISO**，否则可能又进安装界面。
14. **CPU 与内存不能超配**：超过物理机核心数/可用内存，宿主机会严重卡顿。
15. **虚拟网卡禁用要知情**：禁用的是宿主机上的 VMnet1/VMnet8，会影响主机与虚拟机的互联及 NAT 上网。

---

## 七、装完之后要做的几件事

1. **接受许可协议**（首次启动必须）。
2. **配网络**：`nmtui`（文本图形界面）或 `nmcli`；用 `ip addr` 查看、`ping` 测试。
3. **设置主机名**：`hostnamectl set-hostname 你的学号`。
4. **安装虚拟机工具**：`dnf install -y open-vm-tools open-vm-tools-desktop`，之后分辨率自适应、剪贴板互通、时间同步。
5. **检查安全组件**：`systemctl status firewalld`、`getenforce`（练习环境可临时关闭，**生产环境不要关**）。
6. **拍一张快照**：作为后续所有实验的"干净起点"。
7. **记录信息**：主机名、IP、用户名、密码——**写进笔记**。
