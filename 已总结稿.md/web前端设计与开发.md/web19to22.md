## 一、复习：数组（把上节课内容过一遍）

### 1.1 数组是干什么用的

老师的话（`[00:07:20]`）：

> **数组其实它就是一个工具**——（一种）数据的形式。想要存储的数据**数量稍微多一些**的时候，把它**组合到一起**。
> **成绩是一类的数据，而且呢我们需要批量地处理**——比如对成绩做一个（统计），或者从中**找出一些规律**……这种情况就是最适合（用数组）的。

> ★ 关键词：**数量多的、同一类的数据 + 要批量处理**，就用数组装起来。

### 1.2 数组的形式与元素特点

（`[00:08:40]`、`[00:09:20]`）

- 主要要掌握的形式就是**字面量的写法**：**一个中括号**，把数据写在里面；
- **数据之间用逗号隔开**；
- **数组里面的元素可以是空的**（也就是空数组），（元素的类型）也可以（是任意的）；
- **元素是按顺序排列的**——第一个、第二个、第三个……**每个数据都有自己的位置**。

> 老师课上演示了几种数组（空数组、中间带空位的数组、四个元素的数组、字符串元素），**具体代码内容转写看不全**，见附录 B。

### 1.3 创建数组之后要用变量指向它

（`[00:11:40]`）

> 知道了怎么去创建以后，操作数组的时候大家注意：**这个数组你创建完了之后，要用一个变量去指向它**。
> 因为后面要（用）这么长的数据，**（得先）给它起一个简单的名字——变量名**，然后咱们才可以用这个变量去进行各种操作。

```javascript
var arr = [1, 2, 3, 4];   // arr 就是这个数组的名字
arr.length;               // 用变量名去操作它
```

### 1.4 数组长度 `length`，以及"为什么要长度"

（`[00:12:40]`）

> 后期想要对数组进行**遍历**——也就是**访问数组里面每一个元素**的时候，**我们为什么要获取这个长度？**

老师的理由：

- 你**没法提前写死**——"人家（可能）写五十个、一百个、一千个"，这种直接（写数字）是不行的；
- **数组到底有多少个元素，很多时候是由用户输入的**：我们现在学着（做）交互，**用户输入的数据存到数组里，你是不知道有多少个的**；
- 所以要用 **`数组名.length`** 来获取（`[00:13:40]`）。

> ⚠️ 老师特别提醒：**空位也算一个元素**，也会被算进长度里（`[00:14:20]`）。

课堂演示的两个数组（`[00:14:40]`）：

| 数组 | 元素情况 | 长度 |
|---|---|---|
| 第一个 | 一、二、三、四（四个元素） | **4** |
| 第二个 | （带空位） | **6** |

### 1.5 修改数组的长度（规则要记住）

（`[00:15:40]`、`[00:16:20]`）老师的原话：**"这个数组的长度也很简单，直接重新给它赋一个值。"**

| 情况 | 结果 |
|---|---|
| **赋的值大于原来的长度** | **在末尾添加（空位）**——一个两元素的数组把长度改成 4，就会在末尾添加两个（空位） |
| **赋的值小于原来的长度** | **后面的元素会被丢掉**——原来长度是 4 的数组把长度改成 3，（第 4 个）会被丢掉，只剩 0、1、2 |

> ★ 老师原话：**"就是修改数组的长度，这个规则大家要记住。"**

### 1.6 访问数组元素

（`[00:17:00]`、`[00:18:00]`）

> 访问数组元素才能够对数据进行处理——**不管是做（求和）也好、求平均值也好、排序也好。**

- **索引号就像座位号一样**：每个人都有它的（座位）号，元素从前到后**依次按顺序排列**；
- ⚠️ **但是要从零开始**，大家一定要（记住是）**从零开始**的，"（一个数组有五个元素，）索引号是零一二三四"；
- **语法格式**：

```javascript
数组名[索引号]
```

- 想访问**第一个元素**：`数组名[0]`；
- 想访问**最后一个元素**：`数组名[数组的长度 - 1]`（`[00:18:20]`）；
- ⚠️ **一旦超过了这个数组的长度**，就取不到了——老师课上举的是一个**课程名数组**的例子，（数组里存的是）语文、（数学）、英语、政治、历史，**（取）第五个（就）超过了最后一个元素的范围**，那就是 `undefined`（`[00:19:20]`）。

### 1.7 为什么要遍历（用求平均值举例）

（`[00:19:40]`）

> 如果想要求一个班级所有同学成绩的平均值，五个（也好）……如果说你们（班有三四十）个学生，**难道说你要用这种（一个一个）相加（的办法）吗？不要太麻烦了！**

> 所以我们可以使用**数组遍历**的方法——也就是（利用）里面每一个索引号**是有规律的**，实现数组元素的遍历。

### 1.8 遍历的写法与执行过程

（`[00:20:20]`）

**什么叫遍历**（老师的原话）：

> **遍历数组，就是数组里面的每一个元素（都访问），用的是循环——`for` 循环可以实现对数组元素的访问，全部访问一遍。**

**怎么写**（`[00:20:40]`、`[00:21:40]`）：

- `for` 语句，**小括号里面三个表达式**（和上节讲的一样）；
- 从第一个元素到最后一个元素的访问，**怎么控制呢？就用一个变量**：

```javascript
for (var i = 0; i < arr.length; i++) {
  console.log(arr[i]);   // 数组名 + 方括号里面是 i
}
```

- **条件写"小于数组的长度"**：最大值（是长度）减一，也就是**最后一个元素**了；
- **更新的方法就是 `i++`，每次增一**。

**执行过程**（老师一步步念的）：

| 第几次循环 | `i` 的值 | 访问到的是 |
|---|---|---|
| 第 1 次 | 0 | 第 1 个元素 |
| 第 2 次 | 1 | 第 2 个元素 |
| 第 3 次 | 2 | 第 3 个元素 |
| …… | 一次增一 | …… |
| 直到 | **`i` 等于"数组长度减一"** | **最后一个元素** |

> 循环体在每次循环都会执行。

## 二、作业讲评：筛选"偶数且大于 60"的元素（★本节难点）

### 2.1 作业要求

（`[00:23:20]`）

> 题目是让大家**自己定义一个数组**，这里面全是数（整数），然后需要咱们去**遍历这个数组，筛选出满足条件的元素**。

**两个条件**：

1. **这个元素是偶数**；
2. **（这个元素）大于 60**。

### 2.2 循环体里的条件怎么组合

（`[00:24:20]`）

> 两个条件**同时满足**，需要写一个什么（运算符）呢？**逻辑运算符里面的（与）**——那就是（"与"）的意思，之前学过的。

> ★ 也就是用 **`&&`**。（这是第 13—16 节讲过、当时老师专门停下来强调过的"逻辑与"。）

**两个条件分别怎么写**：

| 条件 | 写法 | 老师的解释 |
|---|---|---|
| 大于 60 | `元素 > 60` | "那是不是（元素）大于六十" |
| 是偶数 | `元素 % 2 == 0` | "**打百分号**……**做个取余，余数为零就是偶数了**"（`[00:26:00]`） |

**判断结构**（`[00:27:00]`）：

> 两个条件同时满足，才把这个元素挑出来。那这个时候我们用**一个 `if` 语句**。

```javascript
if (arr[i] % 2 == 0 && arr[i] > 60) {
  // 满足条件，把它挑出来
}
```

### 2.3 ★ 难点：挑出来的元素往哪放？——新数组的索引号怎么确定

（`[00:27:20]`）老师先回到"添加元素"这条老知识：

> 现在知道了怎么去访问数组里面的元素——**用（它）在数组里面的位置**。要添加元素，就是**把这个值赋给这个数组里面的某一个位置**。
> （如果这个位置）**原来有值**，你再给它赋一个值，这就叫**修改**；（原来）没有值，就是**添加**。

**作业的整体结构**（`[00:28:40]`）：

> 我在前面**首先定义了一个有数据的数组**，这是我们需要进行操作（遍历）的；**（然后）定义了一个空数组**，这是我们最后需要输出的——输出的（就是）满足条件的元素。

```javascript
var arr = [12, 65, 78, 43, 90, ...];   // ① 有数据的源数组
var arr2 = [];                          // ② 空数组，用来装结果
```

**★ 关键问题**：`arr2[?] = 元素` —— **这个问号（索引号）怎么确定？**

老师的推导过程（`[00:30:00]`、`[00:31:00]`）：

> 第一次你去进行操作的时候，**这个第二个数组它肯定是空的**，对吧？然后找到一个元素把它放进去，放进去以后，**它是不是就变成（长度）一了？**
> 然后又找到了一个元素，再把它往里放，往里放的时候，这个第二个数组（的长度已经）变成一了……
> 也就是把这个元素放到了**（第）二（个）位置**。

**老师用实际数字又讲了一遍**：

| 第几次找到 | 新数组当前的 `length` | 执行 | 结果 |
|---|---|---|---|
| 第 1 次（找到 78） | `0` | `arr2[0] = 78` | 数组里放进去一个 70（多） |
| 第 2 次（找到 90） | `1` | `arr2[1] = 90` | 90 插在 78 的**后面** |

> ★★★ **结论：这个位置要用"数组的长度"，而不是一个固定的值。**
>
> ```javascript
> arr2[arr2.length] = 元素;    // 每次都追加到新数组的末尾
> ```

### 2.4 完整思路（按老师讲解还原）

```javascript
var arr = [12, 65, 78, 43, 90, 55, 82];   // ① 有数据的数组（自己定义，含奇偶）
var arr2 = [];                             // ② 空数组，装结果

for (var i = 0; i < arr.length; i++) {     // ③ 遍历源数组
  if (arr[i] % 2 == 0 && arr[i] > 60) {    // ④ 两个条件：偶数 且 大于 60
    arr2[arr2.length] = arr[i];            // ⑤ 追加到新数组末尾
  }
}
console.log(arr2);                         // ⑥ 输出新数组
```

> 老师反复强调：**"最重要的（就是）中间这一部分、做循环这一部分"**——循环里面有一个 `if` 语句，满足条件（就放入）第二个（数组）（`[00:57:20]`）。

### 4.4 ★ 形参与实参（必须掌握的两个概念）

## 五、函数的返回值（★本节最重要的新知识）

### 5.1 为什么需要返回值

（`[02:01:20]`）

> 通常情况下，我们会需要的函数**（要）有一个输出、有一个返回（的）数值**——**那咱们可以利用这个返回值来进行下一步的操作。**
> 那这个返回值呢，**也是写在函数里面的**。可以**把运算的结果、处理的结果作为返回值**（返回），**也可以返回一个其他的数据**。

### 5.2 `return` 关键字

（`[02:01:47]`）

> 那（返回）值呢，**是需要用到一个关键字 `return`**——**这个单词就是"返回"的意思**。

**写法**（`[02:01:59]`、`[02:02:28]`）：

> 也很简单，**直接把你需要返回的（值放）在那个后面**……**空格加上需要返回的这个值**，**通常情况下写到函数体里面的（最后）**。

```javascript
function sumRange(start, end) {
  var sum = 0;
  for (var i = start; i <= end; i++) {
    sum = sum + i;
  }
  return sum;        // ← return + 空格 + 要返回的值，写在函数体最后
}
```

> ★ **（写了返回值的函数）你去调用一个函数的时候，就会获得这个（返回）值。**（`[02:04:08]`）

### 5.3 没有写 `return` 会怎样（★）

（`[02:04:41]`）

> **（如果）你的这个函数没有设置返回值，默认的（返回）值就是未定义（`undefined`）。**
> 这个时候咱们再去（控制台）去打印（它得到的结果），那（打印出来的）结果呢，它就是那个（`undefined`）。

| 函数的情况 | 调用它得到什么 |
|---|---|
| 写了 `return 值;` | **那个值** |
| 没写 `return` | **`undefined`** |

### 5.4 两种输出方式的区别（★老师专门纠正的易错点）

（`[02:18:39]`、`[02:19:00]`）

> 这个思路讲起来很简单，**但是还有那些误区**。比如说我们**之前写的那个（求和）函数，`console.log` 是不是写到函数（体）里面了？**
> **（有了 `return` 之后）咱们就不需要在里面去写输出了**——**把你的返回值（return 出来）就直接（行了）**。

| 做法 | 怎么写 | 什么时候用 |
|---|---|---|
| **函数里直接输出** | 在函数体里写 `console.log(结果);` | 这个函数只是**为了打印一下**，不需要结果去做别的事 |
| **用 `return` 交出来** | 函数体里 `return 结果;`，**在调用处**用变量接住再输出 | **结果还要进行下一步操作**时必须这样写 |

```javascript
// ❌ 老师指出的易错写法：函数里就把结果打印掉了，外面拿不到值
function sum(a, b) {
  var c = a + b;
  console.log(c);
}

// ✅ 正确：把结果 return 出来，在调用处处理
function sum(a, b) {
  var c = a + b;
  return c;
}
var result = sum(1, 2);
console.log(result);
```

> 老师反复强调：**"（返回）值那个输出的（地方），你可以定义一个变量去接收这个返回值，再去把这个变量打印到控制台。"**（`[02:12:25]`）

### 5.5 ★ `return` 的三个特点（老师专门讲了这一段）

**特点①：`return` 后面的代码不会被运行**（`[02:50:20]`）

> 这个 `return` 它有一个特点啊，大家看代码——**（return 后面的代码）不会被运行，它就（被）忽略掉了。**
> 比如说如果你再给它加一个（语句）——**"我要输出个什么东西"，它是不会被执行（的）。**
> 所以**一般情况下（return）都是在函数体里面的（最后）**。

**特点②：也可以用 `return` 提前退出函数**（`[02:51:00]`）

> **（除）了一种情况——去提前退出去**。比如说有某些需要**中断函数的执行**（的场合）。

**老师举的例子：除法函数防除零**（`[02:51:40]`）

> 比如说大家（看）这个代码，这个代码呢**是一个除法（函数）**，第二个（地方）说明两个形参，**函数体里面做的是一个除法，`a / b`**。
> 如果（传）入了一个**除数（是）零**（的情况）……这个时候咱们就给他（`return` 掉），**然后后面的这个除法就不会去操作了，不会去（除）了**。
> 这个时候**可以避免执行无效或者错误的（操作）**——（避免）**有可能会让你的程序陷入死循环、可能会死机**的这种情况。

```javascript
function divide(a, b) {
  if (b == 0) {
    return "除数不能为 0";    // 提前退出，后面的代码不再执行
  }
  return a / b;
}
```

> ★ 一句话总结：**`return` 不只是"交结果"，还是"提前结束函数"的开关。**

**特点③：想返回多个值，就把它们打包成一个数组**（`[02:54:00]`）

> 下面呢我们来看这个啊——**这个也可以返回一个（数组）**。这个函数它有**多个返回（值）的时候，我们可以把这多个返回值作为一个数组，放到 `return` 的后面。**
> （看）这个图片上的一样，（把结果）作为一个（数组）——（数组的）括号里面分别计算了**两个参数的和、差、（积）、商**，它**返回了四个值**。

```javascript
function calc(a, b) {
  return [a + b, a - b, a * b, a / b];   // 四个结果打包成一个数组返回
}
var r = calc(10, 2);
console.log(r[0]);   // 和
console.log(r[1]);   // 差
```

> 那你在进行（调用）的时候……**其他的结果呢，它（拿）到的那个（结果）它会是一个（数组）的形式**——也就是说，**可以用索引去取其中某一个结果**。

### 6.2 案例二：求数组中的最大值（★思路最重要）

（`[02:28:20]`）老师先讲了"思路"的重要性：

> 先想一想嘛，**你们写程序的话，思路是最重要的。**

**问题**：里面有（比如）一二三四五个数，怎么求**多个数**的最大值？

> （这）就不能简单地（两两比），**是不是需要用到数组的（遍历）访问**？上课（讲）需要用哪种（语句）呢？（用 `for` 循环）——**循环里面的三个表达式，还是就这样写**。（`[02:30:40]`、`[02:33:00]`）

**★ 算法思路**（老师一步步讲的，`[02:33:20]`）：

> 那就**需要对数组里面的元素进行比较，依次地比较，（把最大的）值挑出来**。
> **（先）存在一个变量（里），继续和后面的数组元素进行比较；如果遇到比这个值更大的元素，再把这个大的（存到）你这个变量里。**
> 就可以把最大的值给挑出来了。
> 所以**我们需要定义一个变量，用于存储（最大值），然后依次地去进行比较**。最终（遍历）之后，就可以把（数组里）最大的元素给它挑出来。
> **挑出来以后，咱们在函数里面就可以把它作为返回值返回。**

**代码结构**（老师逐行走的，`[02:36:40]`—`[02:38:20]`）：

> **（函数）名、小括号里面是参数、大括号里面是函数体**，这个结构……
> （函数体）里面，**首先先说明一个变量**，**（把数组的）第一个值付给它**（也就是数组里的第一个元素）；
> **对数组进行遍历**，**它的表达式就是从（索引 1）开始进行比较**——因为第一个值已经拿来当初始值了；
> 你要什么时候结束呢？**（遍历）完的时候就可以结束了**。

```javascript
function getArrayMax(arr) {
  var max = arr[0];                      // ① 先拿第一个元素当"目前最大"
  for (var i = 1; i < arr.length; i++) { // ② 从索引 1 开始遍历
    if (arr[i] > max) {                  // ③ 遇到更大的
      max = arr[i];                      //    就把它存进变量
    }
  }
  return max;                            // ④ 作为返回值返回
}
```

**老师当堂跑的代码（一步步念的过程）**（`[02:39:20]`—`[02:41:40]`）：

| 循环 | `max` 的变化 |
|---|---|
| 循环开始前 | `max` 是数组的第一个值（转写为"十三"） |
| 比较 68 和 13 | 68 大 → **`max` 变成 68** |
| `i` 加一，比较 79 和 `max` | 79 大 → **`max` 变成 79** |
| 再循环，比较 92 和 `max` | 92 大 → **`max` 变成 92** |
| 再加一，比较 83 和 92 | 83 不大于 92 → `max` 不变 |
| 遍历结束 | **最大值挑出来了，就是 92** |

```javascript
console.log(getArrayMax([13, 68, 79, 92, 83]));   // 92
```

> ⚠️ 演示用的数组数值是**从老师的讲解过程倒推**出来的，见附录 B。

**怎么调用**（`[02:41:40]`）：

> 那我们调用的时候，用的是**函数名加上实参**——**也就是你给它写进去一个真实的（数组），然后它就会把这个（数组）带到这个参数（里）去**，把（数组）里面最大的这个（值）来作为返回值。
> （我们）写了一个（变量）赋值（接收）……再（看）这个程序运行的最终的结果。

> ★ 老师顺带强调：**"同样的，如果给它换一个数据，它也是可以实现相似的功能。"**（`[02:43:20]`）——这正是函数"一次定义、反复使用"的好处。

### 6.3 案例三：判断闰年（经典题）

（`[02:55:40]`）

> 今天呢还有一个案例，**（判断）是否为闰年**——**这是一个非常经典的（题），经常会用（来）练习**。

**闰年的规则**（`[02:56:00]`，⚠️ 转写较乱，按标准规则整理）：

> 年份**能被 4 整除，且不能被 100 整除**；**或者能被 400 整除**。

**函数的要求**（`[02:56:40]`）：

> 那咱们就根据它的这个规则去写这个函数——**返回一个真（`true`）、返回一个假（`false`）**。

**两种写法**（`[02:57:40]`）：

**写法一：用标志变量**（老师课上重点演示的）

> 首先**把这个标志给它设置成假**（也可以先设置成真）……（如果）判断出来这个（年份符合条件），**你再把这个（标志）给它设置成真**……最后呢在这个（函数体）里面**作为一个返回值返回就可以了**。

```javascript
function isLeapYear(year) {
  var flag = false;                       // ① 先假设不是闰年
  if (year % 4 == 0 && year % 100 != 0) { // ② 第一个条件
    flag = true;
  }
  if (year % 400 == 0) {                  // ③ 第二个条件
    flag = true;
  }
  return flag;                            // ④ 返回真假
}
```

**写法二：直接返回**

```javascript
function isLeapYear(year) {
  return (year % 4 == 0 && year % 100 != 0) || year % 400 == 0;
}
```

**代码讲解要点**（`[02:58:40]`、`[03:00:40]`）：

- 用的是 **`if` 结构 / `if` 语句**——**小括号里面写判断条件，如果满足条件就运行后面（大括号里）的（语句）**，把标志设置成真（代表是闰年）；
- **不管这个条件（是否满足），（不满足）我们就把这一段代码跳过，运行下面的代码**；
- 判断整除用的是**取余运算符**：**`年份 % 4 == 0`**（"（年份）模 4 等于零"）；

**怎么调用**（`[03:03:40]`）：

> （那节）课的代码我们写了，**只写了函数的定义**。**调用（时）输入一个年份**呢，把它的返回值给它一个什么呢？（返回）一个（`true`/`false`）……
> **（代码是）判断（闰）年的（函数），后面是调用（它）去（做）判断结构**——（看）这个函数的返回值是真还是假。

```javascript
var year = 2026;
if (isLeapYear(year)) {
  console.log(year + " 是闰年");
} else {
  console.log(year + " 不是闰年");
}
```
