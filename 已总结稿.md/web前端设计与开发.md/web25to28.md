## 一、为什么要学对象：从"变量 → 数组 → 二维数组"的痛点讲起

### 1.1 老师提出的问题

这节课开头，老师先抛出一个具体的数据处理需求：

> **要处理"所有同学的姓名、学号、性别"这样的一批数据。**

这不是一个简单数据，而是**一系列数据、一系列复杂类型**——"要处理的一系列数据……在这个处理的过程中需要一系列的操作"。

### 1.2 三条老路，各有什么问题

| 做法 | 怎么写 | 老师指出的问题 |
|---|---|---|
| **① 用变量一个一个存** | 第一位同学声明 `姓名`、`学号`、`性别` 三个变量，第二位同学再声明三个…… | **"44（个）人……就需要 44（乘 3）个变量"**——变量名太多、代码行数太多，根本管不过来 |
| **② 用一维数组存** | 把所有名字放进一个方括号里，用逗号隔开 | 老师的追问点：**"每个同学都对应了三个数据"**——一维数组把一个人的三个数据**拆散**了，姓名和学号对不上号 |
| **③ 用二维数组存** | 一个同学 = 一个内层小数组，再把 44 个小数组包在一个大数组里 | **能存**，但访问时必须"知道位置"（见 1.3） |

二维数组的写法回顾（第 17—18 节已学过）：

```javascript
// 每个内层数组是一个同学：姓名、性别、学号
var students = [
    ["小智", "男", 1001],
    ["小明", "男", 1002],
    ["小红", "女", 1003]
];

console.log(students[0][0]);   // "小智" —— 要两层索引才取到一个姓名
```

> 老师的话：**"可以用二维数组去存储这种比较复杂的数据类型——每一个同学对应一个小数组，然后再把（所有）同学的（信息）包在大数组里面。"**

### 1.3 ★ 数组方案的三个好处与一个硬伤

**好处**（老师逐条讲的）：

- **"节省了很多的变量名"**；
- **"也节省了很多行的代码"**；
- **"而且对这个数据呢有一定的规范，它能组织起来"**——数据是有结构、有秩序的，不是散着的。

**硬伤**（★这是引出对象的关键）：

> **"在这个数组里面，你如果想去把这个数据（取出来），你必须得清楚这个数据它的位置。"**

- 访问数组元素只能靠**索引号**：**"通过数组名加上方括号，里面写上该元素的（索引）号"**；
- 所以老师的要求是：**"你必须得清楚你（要处理的）这个数据它是第几个"**；
- **数据一多、层数一多，处理起来就比较困难**——老师特别点了二维数组：**"特别是二维（数组），涉及到（的层数）……"**。

> ⚠️ **易错点**：二维数组取数据是 `数组名[外层][内层]`，两层索引都写对才拿得到；一旦记错位置，取到的就是**别的同学的数据**或者 `undefined`。数组"只能按位置找"，这就是它的局限。
> 💡 **记忆点**：**数组按"位置"存数据，对象按"名字"存数据。** 位置要记，名字不用记。

### 1.4 于是就有了"对象"

> 老师的话：**"（这里）涉及的一个概念叫做对象——对象就是为了处理这种复杂的数据类型（而存在的）"**，"可以对这个对象里面的一些数据进行增、删、改、查等等这些操作"。

**对象的定义（本节第一个必背概念）**：

> **对象就是一种复杂的数据类型，它由「属性」和「方法」组成。** 它里面存储的**不是简单的数据，而是一系列的属性和方法**。

| 组成 | 是什么 | 老师举的例子 | 值是什么 |
|---|---|---|---|
| **属性** | 描述对象的**特征** | 学生的**姓名、性别、年龄** | 值通常是字符串、数字、布尔值，也可以是数组等 |
| **方法** | 描述对象的**行为**（偏向"动作"） | 学生**唱歌**这样的行为 | ⚠️ **方法的值是一个函数** |

> 老师的补充：**"也可以只有属性，也可以只有方法。"**——对象不一定两样都齐。

> 💡 **记忆点**：**属性 = 名词（是什么样），方法 = 动词（能干什么）。** 一句话：学生"叫什么、多大"是属性，"会唱歌"是方法。

## 二、创建对象：字面量写法（最常用的方式）

### 2.1 基本格式：花括号 + 键值对

> 老师的话：**"（属性或者方法）是通过（键值对）的形式来保存的"**——保存的成员形式是**一个一个的"名 : 值"**，也就是**属性名（或方法名）对应着属性值（或方法值）**。

```javascript
var 对象名 = {
    属性名: 属性值,
    方法名: function () {
        // 方法体
    }
};
```

| 组成部分 | 说明 |
|---|---|
| `{ }` **花括号** | **"用大括号去表示对象的数据（形式）"**——⚠️ 和数组的中括号区分开：**数组用 `[ ]`，对象用 `{ }`** |
| `属性名:` | 名字和值之间用**冒号** |
| `每个成员之间` | 用**逗号**隔开（老师原话：**"用逗号去隔开，非常（方便）"**） |
| 整体 | 最后**用分号收尾**，通常再**用一个变量去接住它**（和数组一样：创建完要用变量指向它） |

> 老师的提醒：**"它也是一个（数据）类型，同样可以给它建一个变量，用来（保存）这个对象的名字。"**

### 2.2 一个完整的例子：学生对象

整理成代码（属性和方法都齐）：

```javascript
// 一个有成员的对象：姓名、性别、年龄是属性，sing 是方法
var student = {
    name: "小智",          // 属性：姓名
    sex: "男",             // 属性：性别
    age: 20,               // 属性：年龄
    sing: function () {    // 方法：值是一个函数
        console.log("小智在唱歌");
    }
};
```

> 老师课上这个例子里，"姓名"接的是**"小智"**，年龄是 **20 岁**——后面用构造函数演示时老师又用了"我叫小智，今年二十岁"这句话，可以对照着记（见 7.2）。

### 2.3 创建空对象，后面再添加

老师专门演示了另一种情形——**先建一个空对象**：

> 老师的话：**"那就是一个大括号，（里面）什么都没有表示，对象（建）出来了（再往）里去添加。"**
> **"就是创建了一个空的对象，它的名字叫做 `obj`。"**

```javascript
var obj = {};          // 空对象：花括号里什么都不写
console.log(obj);      // 输出：{} —— 一个空对象
```

> ⚠️ 老师当堂说的原话是"**在控制台里面把它打印出来，是有点（空）**"——**空对象打印出来就是一对空的花括号**，这是正常现象，不是写错了。
> 💡 **记忆点**：对象**不是一次写完就定死的**——空着建、后来补，完全合法（怎么补见第四节）。

### 2.4 老师强调的学习方式

> 老师反复说的：**"一定要多动手。"**

本节对象这一块，"**创建对象 → 添加属性与方法 → 访问对象的（属性）和方法**"这三步是**必须掌握**的（老师原话："需要大家掌握的就是（这些）"）。

## 三、访问对象成员：点 与 方括号（★本节重点）

### 3.1 第一种：用「点」访问（最常用）

> 老师的话：**"使用对象（的）名字，点加上（成员）的名字，去访问对象的一系列特征。"** 方法也是**"用点加上方法（名）"**。

```javascript
对象名.属性名;      // 取属性
对象名.方法名();    // 调用方法——注意后面要加小括号
```

对照 2.2 的对象：

```javascript
console.log(student.name);   // "小智"
console.log(student.age);    // 20
student.sing();              // "小智在唱歌"（调用方法）
```

> ★★ **最关键的一个区别**（老师反复强调的点）：
> **访问属性不用加小括号；访问方法必须加小括号。**
> 因为**方法本身就是对象里面的一个函数**——"（方法就是）对象里面的一个函数，让它去运行"。你写 `student.sing` 只是"把函数本身拿出来"，写 `student.sing()` 才是"让它运行"。

> 老师的话：**"这就是使用点去访问对象成员的方法——**（用它）**可以实现（网页上）很多的交互效果。"**

### 3.2 第二种：用「方括号」访问

> 老师的话：**"在对象的后面加一个（方括号），方括号（里面）放（的是）……（属性名）"**——**"（方括号里面）需要加引号。"**

```javascript
对象名["属性名"];      // ⚠️ 属性名必须写成字符串（加引号）
对象名["方法名"]();    // 方法也要加小括号调用
```

```javascript
console.log(student["name"]);   // "小智"
console.log(student["age"]);    // 20
student["sing"]();              // "小智在唱歌"
```

> ⚠️ **易错点**：方括号里**不加引号**，JS 会把里面的东西当成**变量**去找：
> ```javascript
> var student = { name: "小智" };
> console.log(student[name]);      // ❌ name 是个没定义的变量 → 报错/取不到
> console.log(student["name"]);    // ✅ 字符串形式的成员名才对
> ```

### 3.3 两种方式怎么选：什么时候非用方括号不可

> 老师的话：**"点（这种写法）用得比较多"**，但**"有些情况下必须要用第二种方法"**。

**必须用方括号的两种情况**：

| 情况 | 说明 | 例子 |
|---|---|---|
| **① 成员名本身是"特殊"的** | 名字里带空格、横线、或者不是合法的标识符，用点写就是**语法错误** | `obj["user-name"]`、`obj["my age"]` |
| **② 成员名藏在变量里** | 老师说：**"（成员名）连起来的那种情况——你就不能用（点）这个形式了"**，要用**方括号里面加这个字符串（或变量）** | `var k = "name"; obj[k]` |

```javascript
var student = { name: "小智", age: 20 };

// 情况 ②：想访问哪一个成员是"临时决定"的
var key = "name";
console.log(student[key]);        // "小智" ← 方括号里放变量，取到的是变量里的那个名字
console.log(student.key);         // ❌ undefined：点后面写死的就叫 key，对象里没有叫 key 的成员
```

> 💡 **记忆点**：**点名用"固定名字"，方括号能"动态取名"。**
> ⚠️ 老师也说了句实在话：方括号这种写法**"（带的）引号比较多"**、写起来啰嗦，所以日常还是点用得多——**但要知道有它、知道什么时候必须用它**。

### 3.4 三种写法的对照表（便于复习）

| 写法 | 能不能访问属性 | 能不能访问方法 | 成员名能不能是变量 | 常用程度 |
|---|---|---|---|---|
| `对象名.成员名` | ✅ | ✅（后面加 `()`） | ❌ | ★★★ 最常用 |
| `对象名["成员名"]` | ✅ | ✅（后面加 `()`） | ❌（写死字符串） | ★★ |
| `对象名[变量名]` | ✅ | ✅（后面加 `()`） | ✅ | ★★ 动态取值时必用 |

## 四、动态给对象添加属性与方法

### 4.1 用赋值运算符 `=` 添加属性

> 老师的话：**"用赋值运算符等号去为对象添加（成员）"**——**"（对象名）点加上（新）属性名，（再）用赋值（运算符）给它（一个）值。"**

```javascript
对象名.新属性名 = 值;
```

老师当堂的演示（往空对象里加）：

```javascript
var obj = {};              // ① 先建一个空对象
obj.name = "小智";          // ② 用等号加一个属性
console.log(obj);          // ③ 输出：{ name: "小智" } —— 说明添加成功
```

> 老师讲的效果：**"我给他添加了一个（成员），这个（对象里）就出现了……说明我们的添加是成功的。"**

**继续加**：

```javascript
obj.age = 20;
obj.sex = "男";
console.log(obj);          // { name: "小智", age: 20, sex: "男" }
```

> ⚠️ **易错点**：往对象里加成员，**不是"新写一个对象"，而是在原来这个对象上"补一笔"**——所以写法是 `对象名.新成员 = 值;`，前面**不再写 `var`**。

### 4.2 添加方法：值必须是一个函数

> 老师的话：**"跟（添加）属性的（格式）是一样的，我们需要（给方法名）加上（一个函数），（再用）赋值等号去给这个（方法）赋（值）。"**
> **"方法是一个函数，所以说后面肯定是一个函数体了。"**

```javascript
对象名.方法名 = function () {
    // 方法体
};
```

```javascript
var obj = {};

obj.name = "小智";                        // 加属性
obj.sayHello = function () {              // 加方法（值是函数）
    console.log("大家好，我叫" + this.name);
};
obj.sayHello();                           // "大家好，我叫小智"
```

**两种添加方式都能用**（老师原话：**"这两种方法都可以给对象添加（成员）"**）：

```javascript
obj.sayHello = function () { ... };        // ① 点 + 等号
obj["sayHello"] = function () { ... };     // ② 方括号（方法名需要加引号）+ 等号
```

> 💡 **记忆点**：**添加属性和添加方法，格式上只差"等号右边是不是函数"。**
> 老师课上的案例里，往对象上添加了**两个方法**（两个函数），"这两个函数执行的结果都是在（控制）台打印出来"。

### 4.3 不要忘记"访问"这一步

> 老师讲完添加后紧接着强调：**"（还要）再去访问"**——添加完成后，用 3.1/3.2 的方式把成员取出来、把方法调用起来，**在控制台看到结果才算验证成功**。

## 五、外部 JS 的引入与路径规则

本节涉及"JS 写在哪儿"的两条规则（老师当作上机要点讲的）：

| 步骤 | 做什么 | 说明 |
|---|---|---|
| ④ | **写 JS 的两种位置** | **内部**写（`<script>` 标签里）与**外部**写（单独的 `.js` 文件，用 `<script src="...">` **引入**) |

## 六、构造函数：批量创建同一种对象

### 6.1 为什么要构造函数

> 老师的话：**"（用构造函）数去创建对象，它可以把一类的对象一次性地创建（出来）"**——比如**"整个班级中所有的（同学）对象"**。

一个问题：**一个一个用字面量写，44 个同学就要写 44 遍，太笨**。
解决：**先做一个"模板"，再用模板批量生产。** 老师原话：构造函数是**"一系列对象的一个模板"**。

### 6.2 构造函数的定义格式（和普通函数一模一样）

> 老师的话：**"（构造函数）和（我们）上课学习的普通函数（是）一样的"**——**"（用）关键字 `function`"** 开头，**"后面（跟）的是（函数）名字"**，**"里面呢有两个参数"**。

```javascript
function 构造函数名(参数1, 参数2) {
    this.属性1 = 参数1;        // 用 this 给"将来创建的那个对象"加属性
    this.属性2 = 参数2;
    this.方法名 = function () {
        // 方法体
    };
}
```

| 组成部分 | 说明 |
|---|---|
| `function` 关键字 | 和普通函数一样，**定义格式不变** |
| **构造函数名** | 老师课上用的例子是 **`Student`**（学生的意思）；**首字母大写**是构造函数命名的通用习惯 |
| `(参数)` | **需要几个属性就设几个参数**——老师在案例里"里面有两个参数：内容和（地址）"这类不定数量的参数，**"在创建新对象的时候，这两个参数是需要我们去指定的"** |
| `{ 函数体 }` | **"函数体里面就是对我们要创建的新对象进行（规定）——我里面有几个（属性）、我（里面）有几个方法"** |
| **`this`** | ★ **构造函数里的新关键字**：**"用 `this` 来替代这个新创建的对象，为它添加属性"** |

### 6.3 老师在案例里逐行讲的代码（整理）

老师当堂写的构造函数（"学生"模板：两个属性 + 一个方法）：

```javascript
// 构造函数：学生的"模板"
function Student(name, age) {
    this.name = name;          // ① 属性：把参数 name 的值，赋给新对象的 name
    this.age = age;            // ② 属性：把参数 age 的值，赋给新对象的 age
    this.introduce = function () {   // ③ 方法：值是一个函数
        return "大家好，我叫" + this.name + "，今年" + this.age + "岁。";
    };
}
```

> 老师对这三段逐一解释：
> - **前两个成员是属性**——"（把）指定的参数的值"分别赋给这两个属性；
> - **第三个是方法**——**"大家看就知道这是一个方法，因为（它）后面（跟）的是一个函数"**；
> - 方法体里做的是**把要显示的内容拼起来**（**"把需要显示的（字符串）拼到一起"**），**可以用 `return` 把结果返回出来**，也可以在方法里直接输出。

> ⚠️ 老师原话里强调过一句：**"（这个）是没有（参数）的（情况）也可以"**——方法可以有参数，也可以没有。

### 6.4 用 `new` 创建实例对象（★实例化）

> 老师的话：**"（用）`new` 关键字，后面空格加上写好的那个构造函数的名字；如果有参数的话，把参数也写上。"**
> **"（用）`new` 加构造函数的名字（和）需要的参数，就可以生成一个新的对象。"**

```javascript
new 构造函数名(实参1, 实参2);
```

**"创建的这个对象肯定要给它起个名字"**——所以前面用一个变量接住：

```javascript
var stu1 = new Student("小智", 20);    // 创建第一个对象
var stu2 = new Student("小明", 21);    // 再创建一个
var stu3 = new Student("小红", 19);    // 想要几个就 new 几个
```

> 老师的话：**"使用 `new`……可以创建一个具有（两个属性、一个方法）的对象，然后再给它一个（变量）名字就可以了。"**

**对照着看，两种创建方式的关系**：

| | 字面量创建 | 构造函数 + `new` |
|---|---|---|
| 写法 | `var o = { name: "小智", age: 20 };` | `var o = new Student("小智", 20);` |
| 适合 | **一次只建一两个**、属性各不相同 | **批量建同一类对象**（44 个同学） |
| 每个对象 | 各写各的 | **同一个模板生产，结构完全一致，数据各自独立** |

> 老师的话：**"通过构造函数创建多个具有（相同结构）的对象，这些（对象是）独立的。"**——**"一个同学创建一个对象"**，一个模板能造出很多个。
> 老师把用模板造出来的对象叫做**"实例对象"**（这也是"实例化"这个说法的来历）。

### 6.5 ★ 两个新关键字（老师点名的）

> 老师的话：**"这里我（们）遇到了两个新的关键字。"**

| 关键字 | 用在哪 | 作用 |
|---|---|---|
| **`this`** | **构造函数的函数体里** | **"用 `this` 来替代这个新创建的对象，为它添加属性"** |
| **`new`** | **创建对象时** | **"在创建的过程中，要用 `new` 这个关键字"**——`new` + 构造函数名 + 参数 = 一个新对象 |

### 6.6 定义完的验证：访问实例的成员

> 老师当堂跑的验证方式：

```javascript
console.log(stu1.name);          // "小智"
console.log(stu1.introduce());   // "大家好，我叫小智，今年20岁。"
```

> 老师讲的效果：方法"调（用）一下"就能看到结果——**"（输出）也就是'大家好，我叫小智，今年二十岁'"**。
> 老师提醒：**"每一个新创建的对象里面都是两个属性、一个方法"**——**"指定的就是那个参数了，参数指定好以后，里面这三个成员就可以确定了。"**

## 七、实例成员 与 静态成员

### 7.1 怎么区分

| | **实例成员** | **静态成员** |
|---|---|---|
| 加在哪 | **构造函数体里面，用 `this.` 加** | **直接加在构造函数上**（不在函数体里） |
| 属于谁 | **实例对象**（`new` 出来的那个） | **构造函数本身** |
| 怎么访问 | **用实例对象去访问**：`stu1.name`、`stu1.introduce()` | **用构造函数的名字去访问**：`Student.成员名` |
| 新实例里有没有 | ✅ 每个实例**都有** | ❌ **没有**——"在你创建的对象里面有没有这个（成员）？**没有**" |

```javascript
function Student(name, age) {
    this.name = name;                     // ← 实例成员（属性）
    this.introduce = function () { ... };  // ← 实例成员（方法）
}

// 静态成员：直接挂在构造函数上（不在函数体里）
Student.school = "某某大学";

var s = new Student("小智", 20);
console.log(s.name);            // "小智"          ← 访问实例成员：用实例对象
console.log(Student.school);    // "某某大学"       ← 访问静态成员：用构造函数名
console.log(s.school);          // undefined       ← ⚠️ 静态成员不会出现在实例里
```

> ★ 老师用一连串追问让学生体会这条规则：
> - **"（实例对象里的成员）叫做实例成员"**——**"也就是咱们刚才创建的那个（对象）里面的（属性）和方法"**；
> - **"（用）构造函数的名字去访问"**的（成员）**"可以称为静态（成员）"**；
> - **"（静态成员）会不会出现在每一个（用这个模板）创建出来的实例对象里面呢？没有"**——**"一个模板（归）一个模板"**，静态成员只挂在模板（构造函数）自己身上。

> ⚠️ **易错点**：用**构造函数名**去访问**实例成员**（`Student.name`）取不到学生的姓名；用**实例对象**去访问**静态成员**（`s.school`）也取不到。**认准"成员加在哪，就用谁去访问"。**

### 7.2 老师强调的落点

> 老师的话：**"（在）写（JS）代码的时候，经常会用到这个关键字（`this`）"**，"（我们）要（能）正确区分……知道它指的是谁"。

## 八、`this` 的指向（★本节难点，分三种情况）

> 老师的话：**"这个 `this` 其实也很重要……主要有三个具体的场景。"**
> 一句总纲：**"我们要明白它指向的（是）哪（一个）——通常情况下，指向的是调用的对象。"**

### 8.1 三种情况对照表

| # | `this` 写在哪 | `this` 指向谁 | 老师的说法 |
|---|---|---|---|
| **①** | **全局**（没有写在任何函数里面）**或普通函数里面** | **浏览器的全局对象 `window`**（"整个浏览器全局（环境）"） | "如果是在全局或者是普通函数中，（`this`）指向的是……浏览器、整个（全）局环境，也就是 `window`" |
| **②** | **对象里面的一个方法里** | **调用这个方法的那个对象** | "如果这个函数它是对象里面的一个方法，那么 `this` 指向的……就是**调用这个方法的对象**" |
| **③** | **构造函数里** | **`new` 新创建出来的那个实例对象** | "在构造函数（里）……（指向）新创建的这个对象"——**"不是（指向）构造函数，而是实例对象"** |

### 8.2 逐个看代码

**情况 ①：全局 / 普通函数里 → `window`**

```javascript
// 例子没有写在任何函数里面
console.log(this);          // 输出：window（浏览器的全局对象）

// 写在普通函数里面
function fn() {
    console.log(this);
}
fn();                       // 也输出：window
```

> 老师的话：**"（这个例子）没有写在任何函数里面……（指向）整个浏览器全局（环境）"**；**"在普通的函数里面，也是（指向）整个浏览器全局"**。
> ⚠️ 老师补了一句限定：**"它是在非严格（模式）的情况下"**——这是 `this` 指向 `window` 的前提条件（严格模式下不成立，超出本节范围）。

**情况 ②：对象的方法里 → 调用它的那个对象**

```javascript
var user = {
    name: "小智",
    showName: function () {
        console.log(this.name);      // this 指向 user
    }
};

user.showName();       // "小智"  ← this 就是 user，this.name 取到 user 的 name
```

> 老师的话：**"这个函数它是位于一个名字叫（`user`）的对象里面"**——**"这个时候 `this` 指向的就是（调用）它的（那个对象）"**；
> **"我们如果用（这个名字）去（调用）的话，操作的就是（这个）对象，而不是浏览器了。"**
> ⚠️ 老师特别提示过：**"（要用）`user` 去（调用），不要用（别的名字）"**——**谁调用这个方法，`this` 就是谁。**

**情况 ③：构造函数里 → 新创建的那个实例对象**

```javascript
function Student(name) {
    this.name = name;      // this = 即将 new 出来的那个对象
}

var s1 = new Student("小智");
console.log(s1.name);      // "小智"  ← this 指向的正是 s1
```

> 老师的话：**"（用）`new` 关键字加上构造函数名去创建新的实例"**——**"那这个 `this` 指向的就是……新创建的这个（实例）对象"**；
> **"（它指向的）不是构造函数，而是实例对象。"**

### 8.3 三句话总结（老师最后归纳的）

> **① 在全局环境（没有在任何函数里，或者在普通函数里面）→ 指向浏览器全局对象 `window`；**
> **② 在（某个）对象里面 → 指向（调用这个方法）的这个对象；**
> **③ 在构造函数（里）→ 指向新创建的那个实例对象。**

> ⚠️ **易错点**（考试最爱在这里挖坑）：**同一条 `this.name`，写在对象方法里取到的是"对象的 name"，写在普通函数里取到的是"window 的 name"（通常是 `undefined`）。** 判断 `this` 是谁，**先看它写在哪个函数里、这个函数是被谁调用的**。
> 📌 **考试/上机常考**：给出三段代码，问 `this` 分别指向什么。**背上面那张三行表就够。**

## 九、对象的遍历：`for…in`

> 老师的话：**"我们本周的最后一个内容……讲一讲对象的遍历。"** 要求是"**对对象的遍历的方法有一个简单的认识，然后练一个小的（例子）就可以了**"。

### 9.1 什么是"遍历对象"

> 老师的话：**"访问对象的所有的（属性）和方法……（这就是）遍历的意思。"**——也就是**"对象的所有（的属性和方法），访问（一遍）"**。

**为什么要遍历**：

> 老师的话：**"有的时候你可能需要查询一下这个对象里面到底都有一些什么数据……（看）出来以后，你才能够决定（怎么）去（用）它去实现那些功能。"**

> ⚠️ 和**数组遍历**做个对照：数组是**按索引号从小到大**一个一个访问；对象**没有索引号**，它是**按"成员名"一个一个访问**。
> 老师原话：**"（对象遍历）和速度（数组）那（一节）……有一定的（区别）。"**

### 9.2 `for…in` 的语法格式

```javascript
for (let 变量名 in 对象名) {
    // 变量名 依次取到每一个"成员名"
    // 具体操作：对象名[变量名]
}
```

> 老师的话：**"（用）`for…in` 这个语法格式（去写）"**——
> **"（`in`）前面的（这个变量）……（`in`）后面的对象呢，是我们想要遍历的这个对象的名字"**；
> **"（花括号里）就是具体的操作——就是我们具体要怎么去（处理）"**（**"里面写的是具体的操作，不一定是（打印），也可以是其他的"**）。

### 9.3 ★ 为什么里面要用方括号

> ★★★ **这是本节和第 3.3 节严丝合缝的一个点**：`for…in` 里那个变量**装的是成员名的"字符串"，而且是会变的**——这正是"成员名藏在变量里"的情形，**必须用方括号访问**。

```javascript
var car = {
    brand: "奔驰",
    price: 500000,
    color: "黑色"
};

for (var key in car) {
    console.log(key);          // 依次输出：brand、price、color   ← 变量里是"名字"
    console.log(car[key]);     // 依次输出：奔驰、500000、黑色      ← 用方括号按名字取值
}

// ❌ 错误写法：car.key 每次取的都是"名字叫 key 的成员"，对象里没有 → undefined
```

> 💡 **记忆点**：**`for…in` 拿到的是"名字"，不是"值"。要取值，就把它塞进方括号：`对象名[变量]`。**

### 9.4 老师当堂练的小例子

老师建了一个对象、里面**有三个成员**（"全部都是属性"），然后用 `for…in` 把它从头到尾过了一遍：

```javascript
var obj = {
    成员一: "值一",
    成员二: "值二",
    成员三: "值三"
};

for (var k in obj) {
    console.log(k + "：" + obj[k]);    // 把每个"名字：值"都打印出来
}
```

> 老师的话：**"可以看出，这个对象里面都有哪些（成员）"**——**"这个对于我们（遇到）不知道某一个对象里面（有什么）成员的时候"很有用**；然后再"根据以后的需求，或者（写）程序的过程中的需求"去操作它。

### 9.5 配套：用 `in` 判断成员是否存在

> 老师的话：**"（还有）没有其他的（方法）？……（判断）一个对象（里）某一个成员是否存在？"**

```javascript
"成员名" in 对象名        // 返回 true 或 false
```

```javascript
var car = { brand: "奔驰", price: 500000 };

console.log("brand" in car);    // true   —— 这个成员是存在的
console.log("color" in car);    // false  —— 这个成员不存在
```

> 老师当堂的演示顺序：**先写一个"本来就存在"的成员名**，结果说明它**存在**；**再换成"不存在"的成员名**（老师举的是"小明"这样的成员名），结果就**不存在**。
> ⚠️ **易错点**：`in` 左边的**成员名要写成字符串**（"brand"），不写成字符串会当成变量去找。
> 📌 **考试/上机常考**：`for…in` 的写法 + `in` 运算符的返回值。

## 十、本节完整案例：把"一个学生"到"一批学生"串起来

以下是把本节所有知识点串成一个可以运行的完整案例（**结构按老师课上讲的顺序：创建 → 添加 → 访问 → 构造函数 → 实例化 → 遍历**）。

**① 网页文件（练习用，内部方式写 JS）**

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>认识对象</title>
</head>
<body>
    <h1>打开控制台（F12）看结果</h1>

    <script>
        // 1. 字面量创建一个学生对象（属性 + 方法）
        var student = {
            name: "小智",
            sex: "男",
            age: 20,
            sing: function () {
                console.log("小智在唱歌");
            }
        };

        // 2. 用「点」访问属性、调用方法
        console.log(student.name);      // 小智
        console.log(student.age);       // 20
        student.sing();                 // 小智在唱歌

        // 3. 用「方括号」访问（成员名写在字符串里）
        console.log(student["sex"]);    // 男

        // 4. 用变量装着成员名 —— 只能用方括号
        var k = "name";
        console.log(student[k]);        // 小智

        // 5. 动态添加属性与方法
        var obj = {};                   // 先建空对象
        obj.school = "某某大学";         // 加属性
        obj.hello = function () {       // 加方法
            console.log("你好，我是" + this.name);
        };
        obj.name = "小智";
        obj.hello();                    // 你好，我是小智
    </script>
</body>
</html>
```

**预期效果**：在浏览器里按 <kbd>F12</kbd> 打开控制台，会依次看到 `小智`、`20`、`小智在唱歌`、`男`、`小智`、`你好，我是小智`。

**② JS 文件（外部引入，用构造函数批量建对象）**

```javascript
// 构造函数：学生的"模板"
function Student(name, age) {
    this.name = name;               // 实例成员（属性）
    this.age = age;
    this.introduce = function () {  // 实例成员（方法）
        return "大家好，我叫" + this.name + "，今年" + this.age + "岁。";
    };
}

// 静态成员：直接加在构造函数上
Student.school = "某某大学";

// 实例化：用 new 造出一个个实例对象
var stu1 = new Student("小智", 20);
var stu2 = new Student("小明", 21);

console.log(stu1.introduce());      // 大家好，我叫小智，今年20岁。
console.log(stu2.introduce());      // 大家好，我叫小明，今年21岁。
console.log(Student.school);        // 某某大学     ← 静态成员：用构造函数名访问
console.log(stu1.school);           // undefined    ← 实例里没有静态成员

// 遍历对象：把这个学生对象的所有成员过一遍
for (var key in stu1) {
    console.log(key + "：" + stu1[key]);
}

// 判断成员是否存在
console.log("name" in stu1);        // true
console.log("school" in stu1);      // false
```

**网页里引入这个 JS 文件**（同目录，直接写文件名）：

```html
<script src="对象.js"></script>
```

**预期效果**：控制台依次打印两名学生的自我介绍；`Student.school` 有值而 `stu1.school` 是 `undefined`；`for…in` 把实例的成员名和值成对打印出来；最后两行是 `true` 和 `false`。

## 十一、易错点一览（复习时先看这张表）

| # | 易错点 | 正确做法 |
|---|---|---|
| 1 | 对象用 `[ ]`、数组用 `{ }` | **数组 `[ ]`、对象 `{ }`**，别写反 |
| 2 | 对象成员之间忘了写逗号 | 成员之间**用逗号隔开**，最后一个后面可以不写 |
| 3 | 访问方法忘了加小括号 | `对象名.方法名()`——**加了括号才是"让它运行"** |
| 4 | 方括号里忘了加引号 | `对象名["属性名"]`——**不加引号会被当成变量** |
| 5 | 用 `对象名.变量` 想动态取值 | 动态必须写 `对象名[变量]` |
| 6 | 往已有对象加成员时又写了 `var` | **`对象名.新成员 = 值;`**，前面不写 `var` |
| 7 | 以为 `new` 出来的实例里也有静态成员 | **静态成员只挂在构造函数上**，用构造函数名访问 |
| 8 | 在构造函数里把 `this` 当成"构造函数自己" | 构造函数里的 `this` = **新创建的那个实例对象** |
| 9 | 在普通函数里用 `this` 取对象的属性 | 普通函数里的 `this` 是 **`window`**，取不到对象属性 |
| 10 | `for…in` 里写 `对象名.key` | 写成 **`对象名[key]`**——`key` 是变量不是成员名 |
| 11 | 二维数组取数据少写一层索引 | `数组名[外层][内层]`，两层都要写对 |
