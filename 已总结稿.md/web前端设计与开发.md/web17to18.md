## 一、复习：选择结构（接上节）

### 1.1 选择结构有哪几种

老师开场说的是：**选择结构主要是 `if` 语句、（`switch`）语句，以及它们结合起来的用法**（`[00:02:32]`）。

上一节（第 13—16 节）已经把 `if` 系列讲完了：单分支、双分支、多分支。**本节先把它补完。**

### 1.2 `switch`：多分支的选择结构（★）

老师原话（`[00:05:21]`）：

> **`switch` 语句也是一个选择结构，是多分支的选择结构。**

和 `if` 的关系与区别（`[00:04:34]`）：

| | `if` 系列 | `switch` |
|---|---|---|
| 判断依据 | 按**条件表达式**的真假分支 | 按**表达式的值**去匹配 |
| 写法 | `if / else if / else` | `switch` + `case` + `default` |
| 老师的话 | —— | "**它的语法比较简洁一些，根据这个表达式的值去判断到底走哪一个分支**" |

`switch` 的匹配规则（`[00:04:34]`、`[00:05:02]`）：

- `switch` 后面小括号里放一个**表达式**，算出结果；
- 拿这个结果去和每一个 `case` **关键字后面的值**逐个匹配；
- **匹配上哪一个值，就执行哪个值后面的代码**；
- **如果每一个 `case` 后面的值都不匹配**，就执行 `default` 后面的语句；
- 执行完（遇到 `break`）就直接退出，整个 `switch` 就结束了。

按课堂讲法还原的结构（⚠️ 具体语法请以教材为准，老师当堂展示的代码录音里看不到）：

```javascript
switch (表达式) {
  case 值1:
    语句;
    break;
  case 值2:
    语句;
    break;
  default:
    语句;
}
```

### 1.3 上节课的程序：按商品名称输出价格

老师带着回顾（`[00:05:31]`）：

> 上节课写了一个程序：**输入商品的名称，根据名称输出该商品对应的价格。**

这个程序就是用 `switch` 写的——**按"名称"这种具体的值来分支**，正是 `switch` 最擅长的场景。

### 1.4 `switch` 与 `if` 可以互相替换，但适合的场景不同

老师明确说过两点（`[00:06:40]`、`[00:06:45]`）：

1. **两者可以互相替换，换着来写**（同一个功能，用 `if` 写或者用 `switch` 写都能实现）；
2. **但它们适合的场景不太一样**——判断具体的值用 `switch` 更清爽，判断范围/复杂条件用 `if` 更合适。

## 二、循环结构（本节重点之一）

### 2.1 循环能用来干什么

老师先讲了"什么时候该想到用循环"（`[00:15:47]`、`[00:16:08]`、`[00:16:21]`）：

1. **重复运行同一段代码**（同一件事要做很多遍）；
2. **重复做计算**——需要用到奇数、偶数，或者要反复累加、反复算表达式的场合。

> 老师的提醒：**凡是要求你把计算表达式写出来的题，基本都可以用循环来做**（`[00:16:21]`）。

### 2.2 `for` 循环：小括号里的三个表达式（★重点）

老师讲得非常清楚（`[00:06:54]`）：

> **`for` 的小括号里面写三个表达式，分别是：初始化变量、条件表达式、操作表达式。**

按课堂讲法还原：

```javascript
for (初始化变量; 条件表达式; 操作表达式) {
  循环体;
}
```

| 表达式 | 作用 | 老师的话 |
|---|---|---|
| **① 初始化** | 定义变量并给初值，**这个变量就是"计数器"** | "初始化计数器"（`[00:07:11]`） |
| **② 条件表达式** | **决定循环是否继续** | "它是一个终止循环的条件"（`[00:07:25]`） |
| **③ 操作表达式** | 每循环一次，把计数器**加一或减一** | "每循环一次，把变量加一或者减一"（`[00:07:37]`） |

**怎么用计数器控制循环次数**（`[00:07:47]`）：

> 想让循环只跑 10 次，就让计数器每次加一，**当它加到 10 的时候条件不再成立，循环就退出了**——用这种方式控制循环次数。

### 2.3 例 1：在控制台输出 1 到 100

（`[00:08:16]`）老师给的最简单的例子：

- **循环次数就是 100 次**；
- **每执行一次循环体，就会在控制台输出一个数**。

按课堂讲法还原：

```javascript
for (var i = 1; i <= 100; i++) {
  console.log(i);
}
```

老师逐句解释了这段代码（`[00:08:47]`—`[00:09:51]`）：

- 计数器 `i` **从一开始**；
- 每循环一次 `i` 加一：第一次是 1，第二次是 2，第三次是 3……依次往后；
- 条件写 **`i <= 100`**：当 `i` 超过 100 的时候条件不满足，就不再执行了，循环结束；
- 之所以"不需要 101"，就是因为条件卡在 100。

### 2.4 例 2：求 1 到 100 的和

（`[00:10:06]`—`[00:11:45]`）老师的思路，一步步是：

1. **先想清楚"结果存在哪里"**——需要一个变量来存放累加的结果，所以在循环前面**先定义一个变量**（初值为 0）；
2. 循环开始前 `i` 从 1 开始（`[00:11:03]`）；
3. 循环里做**累加表达式**：把当前这个数加到那个变量上；
4. 条件是 **`i <= 100`**——因为要算的是 1 到 100 的叠加结果（`[00:11:14]`）；
5. 加完这一项，计数器 `i` 再加一（`[00:11:27]`）；
6. 当 `i` 超过 100，不再满足条件，就不再加了（`[00:11:43]`）。

按课堂讲法还原：

```javascript
var sum = 0;              // ① 先定义变量存结果
for (var i = 1; i <= 100; i++) {
  sum = sum + i;          // ③ 累加
}
console.log(sum);
```

> ★ **这个"先准备一个变量存结果，再在循环里累加"的套路，后面的案例（求和、求平均、筛选）都要反复用。**

### 2.5 `while` 循环：只剩一个条件表达式

老师对比着讲（`[00:12:11]`）：

> **`while` 循环只有一个条件表达式。**

```javascript
while (条件表达式) {
  循环体;
}
```

### 2.6 `for` 与 `while` 的互相改写（★容易考）

老师的讲法（`[00:12:14]`—`[00:13:32]`）：**两种循环的写法要能互相转换**，转换的关键就是"把 `for` 括号里的三个部分拆开摆放"：

| `for` 里的位置 | 改写成 `while` 时放到哪里 |
|---|---|
| ① 初始化变量 | **提到循环前面**，在前面声明并赋初值 |
| ② 条件表达式 | **留在 `while` 的小括号里** |
| ③ 操作表达式 | **放到循环体的最后**，每次循环体执行完再更新 |

按课堂讲法还原：

```javascript
// for 的写法
for (var i = 1; i <= 100; i++) { ... }

// 等价的 while 写法
var i = 1;                 // ① 初始化提到前面
while (i <= 100) {         // ② 条件留在括号里
  ...
  i++;                     // ③ 更新放到循环体最后
}
```

### 2.7 `do…while`：先执行一次，再判断（★易错）

老师讲 `do…while` 时的两句关键话（`[00:14:14]`、`[00:14:30]`）：

> **循环体放到前面去了，循环的条件放到大括号的后面。**
> **先执行一次循环，然后再去判断条件。**

```javascript
do {
  循环体;
} while (条件表达式);
```

**什么时候必须用它**（`[00:14:40]`）：

> **如果你的程序需要"至少执行一次"，就可以用 `do…while` 循环。**

三种循环对比：

| 循环 | 判断时机 | 最少执行几次 |
|---|---|---|
| `for` | **先判断**条件，再执行 | 0 次 |
| `while` | **先判断**条件，再执行 | 0 次 |
| `do…while` | **先执行**一次，再判断 | **至少 1 次** |

### 2.8 例 3：求所有偶数的和、所有奇数的和（循环 + `if` 结合）

（`[00:19:30]`—`[00:23:16]`）这是本节把两个结构合起来的案例：

1. **先定义两个变量**，分别用来存**偶数的和**和**奇数的和**（`[00:20:11]`）；
2. 循环（常规写法，中间设置好循环次数）；
3. **在循环里判断当前的 `i` 是奇数还是偶数**（`[00:20:55]`，用取余 `%` 判断）；
4. **如果是偶数，就加到"偶数和"那个变量上**；**如果不是偶数（也就是奇数），就加到"奇数和"那个变量上**（`[00:21:41]`、`[00:22:09]`）；
5. 最后输出两个结果。

**输出时的写法**（`[00:22:40]`）——老师专门讲了：

> 用**加号**把字符串拼接起来：**字符串要加引号，变量直接写变量名**，这样就可以把"说明文字"和"变量里的内容"接在一起。

```javascript
var evenSum = 0, oddSum = 0;
for (var i = 1; i <= 100; i++) {
  if (i % 2 == 0) {
    evenSum = evenSum + i;   // 偶数
  } else {
    oddSum = oddSum + i;     // 奇数
  }
}
console.log("所有偶数的和为：" + evenSum);
console.log("所有奇数的和为：" + oddSum);
```

## 三、新章节：数组（本节重点之二）

### 3.1 数组是什么

老师先用一句话给概念（`[00:31:40]`、`[00:31:44]`）：

> **数组就是把一组数据——若干个，比如十个、二十个——放到一起，方便统一操作。**
> **它由一个或者多个元素组成。**

放到一起之后就**有了位置**（`[00:32:06]`）：

> 每一个数据在数组里都有自己的**位置**——是在第一个还是最后一个？

**老师用的类比**（`[00:35:50]`—`[00:36:40]`）：

- 数组就像**一列火车的车厢**：一节车厢有**固定的位置数**（"前车厢有五个位置"）；
- 车厢里坐两个人也好、坐五个人也好，**位置是固定的**；
- **每个位置对应一个"索引号"**，要描述"是谁"就得靠这个位置（索引）。

### 3.2 ★ 数组元素的索引从 0 开始（最容易错）

老师反复强调（`[00:32:35]`、`[00:32:47]`）：

> **数组元素的索引是从零开始的，不是一。**
> 有五个元素，索引就是 **0、1、2、3、4**。

再看一次（`[00:33:04]`、`[00:33:58]`）：

| 元素的位置 | 第 1 个 | 第 2 个 | 第 3 个 | 第 4 个 | 第 5 个 |
|---|---|---|---|---|---|
| **索引** | **0** | **1** | **2** | **3** | **4** |

> **所以"第 5 个元素"的索引是 4，而不是 5——这是本节最容易错的一点。**

### 3.3 创建数组的两种方法

老师讲了两种（`[00:33:43]`、`[00:35:19]`）：

**方法一：用 `new Array()` 构造函数创建**（⚠️ 名字转写不清，见附录 B）

```javascript
var arr = new Array(1, 2, 3, 4, 5);
```

**方法二：用字面量（中括号 `[ ]`）创建**——**老师主要用这一种**

```javascript
var arr = [1, 2, 3, 4, 5];
```

> 老师的说法：**"这就写到方括号里面就行了"**（`[00:34:23]`），**元素与元素之间用逗号隔开**。

**两种方法创建出来的都是数组**，把数组赋值给一个变量之后，**这个变量只是数组的名字**（`[00:37:26]`、`[00:38:04]`）：

> 你**可以用这个变量去对数组进行操作**——它就是这个数组的名字。
> （老师顺带打的比方：同一个东西会有两个名字，像是"微信名不一样"。）

### 3.4 创建数组时的三个注意点

老师明确列的三点（`[00:36:55]`、`[00:37:02]`、`[00:37:06]`）：

1. **数组可以有"多余的空位"**——长度可以比现有元素多；
2. **元素与元素之间也可以有空位**；
3. **数组里面的元素可以是任意类型**（`[00:46:22]`：**"我们不仅仅可以加数字"**）。

### 3.5 数组的长度：`length`

（`[00:50:33]`—`[00:53:16]`）

- 要**先知道数组里有多少个元素**，然后才能去做遍历、修改、删除这些操作（`[00:50:50]`）；
- 用 **`数组名.length`** 可以**获取到数组的长度**（`[00:52:19]`）；
- **数组的长度是一个整数**（`[00:51:24]`）；
- ⚠️ **空位也会被计算在数组的长度之内**（`[00:53:12]`）。

```javascript
var arr = [1, 2, 3, 4, 5];
console.log(arr.length);   // 5
```

### 3.6 修改数组的长度

（`[00:53:21]`—`[00:55:47]`）老师讲得非常直白：

> **给它的长度赋一个数字就可以了**——"非常简单、粗暴"。

```javascript
arr.length = 3;   // 长度改成 3
arr.length = 8;   // 长度改成 8
```

要点：

- **把长度改得比原来短**：**后面的元素就不显示了**（`[00:55:19]`：原来有五个，改短之后"后面的就不显示了"）；
- **把长度改得比原来长**：多出来的位置是**空位**，而**空位也会被算进长度**（`[00:53:12]`）。

### 3.7 访问数组元素

（`[00:56:37]`—`[00:59:38]`）老师的讲法：

> **首先我们得先找到这个元素**，也就是要**访问某一个元素**。
> 数组**有一个索引号**，那我们**通过这个索引号就可以访问到某一个元素**。
> **数组名加上索引号，索引号包裹在一对方括号里面。**

```javascript
数组名[索引号]
```

- 课上的例子：**一共 7 个数据，索引范围就是 0—6**（`[00:57:41]`）；
- 对应关系：**第一个数据用什么？索引 0；第二个数据用什么？索引 1；第三个用 2，第四个用 3，第五个用 4**（`[00:58:17]`—`[00:58:30]`）；
- ⚠️ **索引超出数组的范围**：**索引号就指不到任何元素，会返回 `undefined`**（`[00:57:56]`）。

### 3.8 添加元素与修改元素

（`[00:59:50]`—`[01:04:33]`）老师说这一节的操作**用的都是索引号**，而且**添加和修改是同一句写法**：

```javascript
数组名[索引号] = 值;
```

**怎么分辨是"修改"还是"添加"**（`[01:00:48]`、`[01:01:02]`）：

| 情况 | 结果 |
|---|---|
| **这个索引号上已经有数据** | **就是修改**（把这个位置的值换成新的） |
| **这个索引号不存在（比数组长度大 / 就是末尾的下一位）** | **就是在数组的最后添加一个元素** |

课上的例子（`[01:01:28]`—`[01:03:18]`）：

- 数组里 `小明` 的索引是 0、`小字` 的索引是 1；
- **把"小娜"赋给索引 2 的位置** → 小娜就排在第三个位置；
- 结果：**修改了一个值、添加了两个值**（数组变成 4 个人）。

**想在末尾添加元素怎么办**（`[01:03:24]`）：

> 数一下现在有 0—6 七个位置，那**给它配第 7 个索引（下一个索引号）并赋值就可以了**。

### 3.9 ★ 遍历数组（名词解释，要背、要手写）

（`[01:04:43]`—`[01:07:34]`）

**为什么要遍历**（`[01:04:53]`）：

> 我们有时候需要**把数组里面所有的元素**全部访问一遍——
> 比如**计算数组里面所有数值的和**，比如**要对数组里所有的元素进行排序**，是不是都要**一个个去访问**？
> 一个一个手写太麻烦了，那我们就可以**写一个循环**来做。

> ⚠️ **老师原话：`遍历数组` 是一个名词解释，需要大家背下来、能手写出来**（`[01:05:35]`）。

**名词解释（按老师课堂原话整理）**：

> **遍历数组，就是把数组里面的每一个元素都访问一遍，用的是 `for` 循环的形式。**

**写法要点**（`[01:05:54]`—`[01:07:26]`）：

- 循环里定义的 **`i` 代表的是"索引号"**；
- 让 `i` 的值 **从 0 开始，一直到"数组长度减一"为止**；
- 循环条件写 **`i < 数组名.length`**（等价于"到数组长度减一为止"）；
- 循环体里用 **`数组名[i]`** 访问到当前这个元素。

```javascript
for (var i = 0; i < arr.length; i++) {
  console.log(arr[i]);   // 逐个访问每一个元素
}
```

> ⚠️ **为什么条件不写"小于等于"？** 因为**索引最大只到"数组长度减一"**（`[01:06:40]`），写成 `<=` 就会多访问一次、取到一个不存在的元素。

**遍历能做什么**（`[01:07:39]`）：把数组里所有元素访问一遍之后，**就可以对它们进行操作**——比如加起来求和、比如比较大小。

### 3.10 例：用遍历求平均分

（`[01:08:11]`—`[01:10:42]`）老师的案例：

> 要看**全班同学的语文成绩**，几十个同学，如果你简单地"把每个成绩加起来再除以数组长度"，一个个加太麻烦了。**所以我们可以用遍历数组的方式来做。**

步骤：

1. **初始化条件：`i` 从 0 开始**（⚠️ 转写为"i 等于一"，见附录 B）；
2. 循环到**最后一个元素**——**最后一个元素的索引是"数组长度减一"**（`[01:09:34]`）；
3. **声明一个变量用于存放累加的结果**；
4. **循环执行完毕之后，就实现了数组里所有成绩的累加**，结果就在这个变量里（`[01:10:07]`）；
5. **最后用这个"和"除以数组的长度**，得到的结果**就是平均分**（`[01:10:25]`、`[01:10:40]`）。

```javascript
var scores = [85, 92, 78, 96, 88];
var sum = 0;
for (var i = 0; i < scores.length; i++) {
  sum = sum + scores[i];
}
var avg = sum / scores.length;
console.log("平均分：" + avg);
```

### 3.12 冒泡排序（课堂现场演示）

（`[01:13:21]`—`[01:18:35]`）老师先说了排序是干什么的：

> **把数组中两个元素的值按照你指定的顺序来调**——你是想**从小到大**排，还是想**从大到小**排（`[01:13:43]`）。

**核心动作**（`[01:13:52]`、`[01:17:21]`、`[01:18:03]`）：

> **比较这两个索引位置上的值**，如果顺序不对，**就把它们的位置交换**。
> 比较的是"第几个元素和第几个元素"；**交换要用循环来做**。

**课堂演示的第一轮**（老师当场一步步念的，`[01:14:14]`—`[01:15:00]`）：

| 步骤 | 比较 | 结果 |
|---|---|---|
| ① | 31 和 98 比 | 顺序对，不变 |
| ② | **98 和 5 比** | **98 往下移，5 往上** |
| ③ | **98 和 27 比** | **98 继续往下移，27 往上** |
| ④ | **98 和 78 比** | **98 继续往下移** |

**第一轮结束后的顺序**（`[01:15:24]`）：**31、5、27、78、98**
——可以看到**最大的 98 已经被"顶"到了最后一位**。

**第二轮**（`[01:15:25]`—`[01:15:46]`）：

| 步骤 | 比较 | 结果 |
|---|---|---|
| ① | **31 和 5 比** | **31 往下，5 往上** |
| ② | **31 和 27 比** | **31 往下，27 往上** |
| ③ | 31 和 78 比 | 顺序对，不变 |

**第二轮结束后的顺序**：**5、27、31、78、98** —— 已经排好了。

> ⚠️ 老师课堂上念的原始数组数值转写得很糊，上面的初始数组是**从两轮结果倒推**出来的（`[31, 98, 5, 27, 78]`），建议回听核对（见附录 B）。

**理解要点**：

- 每一轮都把**当前还没排好的部分里最大的那个数**"冒"到最后；
- **每比较一对，就要判断一次要不要交换**——所以是**循环里面套判断**；
- **交换本身也要用循环**（`[01:18:03]`）。
