## 一、字符串也是对象：用 `new String()` 创建

### 1.1 先把上一节造对象的语法拎出来

> ★ 老师的话：**"之前学习对象里面如何创建对象的时候，（用构造函数）创建对象，是 `new` 关键字加上构造函数名。"**

并且顺口补了一句两者的区别：**构造函数和普通函数的区别在名字上——构造函数名首字母大写。**

```javascript
// 第 25—28 节造学生对象：
// var stu1 = new Student("小智", 20);

// 本节造字符串对象，同一个套路，构造函数换成 String：
var str1 = new String("Hello");
```

| | 上一节 | 本节 |
|---|---|---|
| 构造函数 | `Student`（自己写的模板） | `String`（**系统自带**的） |
| 写法 | `new Student("小智", 20)` | `new String("Hello")` |
| 造出来是什么 | 一个学生实例对象 | 一个**字符串对象** |

### 1.2 创建字符串对象的语法模式

> ★ 老师的话：**"这个就是创建字符串对象的语法模式。"**

```javascript
var str = new String("Hello");
```

| 部分 | 写什么 | 说明 |
|---|---|---|
| `new` | 关键字 | 和上一节造对象一模一样 |
| `String` | 构造函数名 | **首字母大写**，是系统自带的 |
| `("Hello")` | 括号里放内容 | 老师说的：中文、英文、数字都可以往里面放 |

> 💡 **记忆点**：`new` + 构造函数名 + 一对小括号——上一节造学生是这句，本节造字符串对象还是这句，**换的只是构造函数名**。

### 1.3 怎么知道创建成功了：看打印出来的样子（★）

> ★ 老师的判断办法：**"把它打印出来，看它输出的是什么形式——就是已经创建成功了，它是一个字符串对象，它不是一个简单的字符串。"**

```javascript
var str1 = new String("Hello");
var str2 = "Hello";

console.log(str1);   // String {'Hello'}   前面带 String 标记，两边有引号
console.log(str2);   // Hello              只有内容，没有标记也没有引号
```

> ★ 老师的话：**"用简单的方式，你没有这几个构造函数……那个时候你去看 `console.log`，它输出的就只是这个字符串的内容，就没有前面那个标记，也没有（那对）引号。"**

| 写法 | 浏览器控制台里打印出来 | 它是什么 |
|---|---|---|
| `new String("Hello")` | `String {'Hello'}` | **字符串对象**（一个对象） |
| `"Hello"` | `Hello` | **简单字符串**（原始类型的一个值） |

老师说，那个"前面带 `String`、内容两边裹着引号"的样子，就是它**是一个对象**的明显标志；而简单字符串打印出来没有那对花括号。

> 💡 **记忆点**：看打印结果就能分家——**带 `String` 前缀、内容裹着引号的，是对象；光秃秃只有内容的，是简单字符串。**

### 1.4 两种存法摆在一起看

> ★ 老师的话：**"这两个一定要（分清）——它同样都是用一个变量保存的，但是数据类型不同。"**

```javascript
var a = "Hello";              // 简单字符串：不是对象
var b = new String("Hello");  // 字符串对象：是对象
```

| | `var a = "Hello";` | `var b = new String("Hello");` |
|---|---|---|
| 怎么来的 | 直接写字面量 | `new` 一个构造函数 |
| 是不是对象 | 不是 | 是 |
| 打印带 `String` 标记 | 不带 | 带 |
| 打印内容带引号 | 不带 | 带 |

## 二、`length` 属性：这个字符串有多长

### 2.1 用「点」取属性，后面不加小括号（★）

> ★ 老师的话：**"其中一个就是它的常用属性 `length`，用它可以来获取字符串的长度。"**

```javascript
var str = new String("JavaScript");
console.log(str.length);      // 10
```

紧接着老师专门提醒了一句：**"后面不需要加（小括号）。"**

```javascript
var str = new String("JavaScript");
console.log(str.length);      // 10   属性取值，不加括号
```

> ⚠️ **易错点**：写成 `str.length()` 会报"不是一个函数"。**属性取值不加括号，方法调用才加括号**——这条规矩和第 25—28 节访问对象成员是同一个。

### 2.2 长度就是字符的个数

> ★ 老师的话：**"它里面有几个（字符），它的长度就是几。"**

并当堂举了个例子：**"这个单词它一共七个字母，所以它输出的结果是七。"**

```javascript
var word = "student";       // s t u d e n t，一共 7 个字母
console.log(word.length);   // 7
```

| 字符串 | 字符个数 | `length` |
|---|---|---|
| `"student"` | 7 | 7 |
| `"JavaScript"` | 10 | 10 |
| `""`（空字符串） | 0 | 0 |

### 2.3 两种字符串都能用，结果还一样（★易混）

> ★ 老师特意点出来的：**"这个 `length` 属性，是对于两种类型的数据都可以去使用的——不管是（简单）字符串型的数据，还是对象型的字符串……结果都是一样的。"**

```javascript
console.log("Hello".length);                  // 5   ← 简单字符串
console.log(new String("Hello").length);      // 5   ← 字符串对象
```

> ★ 老师紧接着交代了一句：**"这一点是我们需要区分的。"**——要区分的**不是** `length`（它两种都认），而是下面第三节的 `typeof`（它两种结果不同）。

### 2.4 用途：卡用户输入的长度

> ★ 老师举的用处：**"如果用户输的密码，你想让它达到八个以上，我们是不是可以检测它的长度？如果不满足要求……"**

```javascript
var pwd = "abc12345";        // 假设这是用户输入的密码
console.log(pwd.length);     // 8

if (pwd.length >= 8) {
    console.log("密码长度符合要求");
} else {
    console.log("密码长度不足 8 位");
}
```

| 用户输入 | `length` | 结果 |
|---|---|---|
| `abc123` | 6 | 不足 8 位 |
| `abc12345` | 8 | 符合要求 |

## 三、`typeof`：它到底是什么类型

### 3.1 `typeof` 是一个运算符

> ★ 老师的话：**"还有一个常用到的（写法），就是如何去检测这个（字符串）对象它的数据类型……可以用 `typeof` 去检测。"**

讲写法时又特意纠正了一次：**"它不算是一个（对象）的方法，这个是一个运算符。"**

| 项 | 说明 |
|---|---|
| 是什么 | **运算符**（不挂在某个对象身上，所以不是 `str.typeof()` 这种样子） |
| 怎么写 | `typeof 变量名`，中间一个空格 |
| 给出什么 | 一个字符串，说明这个值是什么类型 |

```javascript
var str = new String("Hello");
console.log(typeof str);      // object
```

### 3.2 两种字符串，`typeof` 结果不一样（★本节重点）

```javascript
var a = "Hello";              // 简单字符串
var b = new String("Hello");  // 字符串对象

console.log(typeof a);        // string
console.log(typeof b);        // object
```

> ★ 老师的结论：**"如果是 `string` 的话，那说明它是一个普通的（简单）字符串；如果是对象型的数据，输出的就是这个 `object`——它表示该数据类型是对象型。"**

| 写法 | `typeof` 的结果 | 怎么读 |
|---|---|---|
| `"Hello"` | `"string"` | 简单字符串（原始类型） |
| `new String("Hello")` | `"object"` | **对象**——它是对象型的字符串 |

> ⚠️ **易错点**：用 `new String()` 造出来的东西，`typeof` 给的是 `"object"`，**不是** `"string"`。老师说这就是"用 `new` 的语法格式创建的是字符串行的**对象**"。

### 3.3 一张表把两件事摆清楚

| 检测手段 | 简单字符串 `"Hello"` | 字符串对象 `new String("Hello")` | 结论 |
|---|---|---|---|
| `length` | `5` | `5` | **两种都一样** |
| `typeof` | `"string"` | `"object"` | **两种不一样** |

> 💡 **记忆点**：**长度不分家，类型分家。** `length` 谁都能用，`typeof` 一照就照出"谁是对象"。

## 四、`indexOf` / `lastIndexOf`：某个字符出现在哪个位置

### 4.1 两个方法的分工

> ★ 老师的话：**"下面我们来看一下这两个方法，是在这个字符串中去搜索某一个（字符或子串），（看）它在这个字符串里面（出现在哪）。"**

| 方法 | 找哪一次 | 返回什么 |
|---|---|---|
| `indexOf(要找的内容)` | 第一次出现 | 这个内容**第一次**出现的**索引号** |
| `lastIndexOf(要找的内容)` | 最后一次出现 | 这个内容**最后一次**出现的**索引号** |

> ★ 老师拆词讲 `lastIndexOf`：**"`last` 就是最后一个的意思——就是该字符在字符串中最后一次出现的索引。"** 而且点明它是**"从后往前去搜索的"**：**"从后往前搜索，那么第一次搜到的，就是这个（字符）在字符串中最后一次出现的（位置）。"**

### 4.2 返回的是索引号，从 0 开始数（★）

> ★ 老师当堂追问了一句：找"三"，为什么返回的不是 3？——**"从零开始的：零、一、二，所以返回的是 2 这个数字。"**

```javascript
var str = "一二三";
console.log(str.indexOf("三"));    // 2
```

| 字符 | 一 | 二 | 三 |
|---|---|---|---|
| 索引号 | 0 | 1 | 2 |

> ⚠️ **易错点**：索引号从 **0** 开始，所以"第三个字符"的索引号是 **2**，不是 3。这条和第 17—18 节数组的规矩完全一样。

### 4.3 找不到就返回 `-1`（★必须记住）

> ★ 老师的话：**"如果找不到，这两个方法返回的都是（负一）。"**

```javascript
var str = "一二三";
console.log(str.indexOf("五"));       // -1   ← 根本没有这个字符
console.log(str.lastIndexOf("五"));   // -1
```

> ⚠️ **易错点**：判断"有没有"不能直接写 `if (str.indexOf("五"))`——因为找到时可能返回 `0`，而 `0` 在条件里被当成假，会被误判成"没找到"。**要和 `-1` 比**：`if (str.indexOf("五") !== -1)`。这个写法后面第 9.4 节验证用户名时还要用到。

### 4.4 第二个参数：从哪个索引号开始找

> ★ 老师的话：**"我们可以去指定……它不一定是从第一个字符开始搜索。"** 这个"从哪儿开始"就写在**第二个参数**里。

| 方法 | 第一个参数 | 第二个参数 |
|---|---|---|
| `indexOf(内容, 起始索引)` | 要找的内容 | 从哪个索引**开始往后**搜 |
| `lastIndexOf(内容, 起始索引)` | 要找的内容 | 从哪个索引**开始往前**搜 |

```javascript
var str = "三心二意三思而行";
//   索引：  0 1 2 3 4 5 6 7

console.log(str.indexOf("三"));         // 0   第一次出现
console.log(str.lastIndexOf("三"));     // 4   最后一次出现
console.log(str.indexOf("三", 1));      // 4   从索引 1 开始往后找
console.log(str.lastIndexOf("三", 3));  // 0   从索引 3 开始往前找
```

> ★ 老师的举例：**"比如说我从第二个字符开始搜索；或者是用 `lastIndexOf` 的时候，我想让它从第八个字符开始往前（找），也可以。"**

| 写法 | 从哪里开始 | 往哪个方向 | 结果 |
|---|---|---|---|
| `indexOf("三")` | 索引 0 | 往后 | 0 |
| `indexOf("三", 1)` | 索引 1 | 往后 | 4 |
| `lastIndexOf("三")` | 末尾 | 往前 | 4 |
| `lastIndexOf("三", 3)` | 索引 3 | 往前 | 0 |

### 4.5 和数组的同名方法对照

> ★ 老师的话：**"这个（和）数组类似——系统里面也有两个搜索数组元素的（方法），第一次出现以及最后一次出现的（方法）。"**

| | 数组 | 字符串 |
|---|---|---|
| 找第一次出现 | `arr.indexOf(元素)` | `str.indexOf("字符")` |
| 找最后一次出现 | `arr.lastIndexOf(元素)` | `str.lastIndexOf("字符")` |
| 找不到时 | 返回 `-1` | 返回 `-1` |

## 五、把结果说出来：`+` 拼接与模板字符串

### 5.1 在结果前面加一句话：字符串拼接

> ★ 老师的话：**"我想（让提示）再清晰一点，在这个（结果）前面想加一句话——'三在字符串当中第一次出现的索引号是……'"** 随后给这种做法定了名：**"这个就叫字符串拼接。"**

```javascript
var str = "三心二意三思而行";
var index = str.indexOf("三");

console.log("三第一次出现的索引号是：" + index);
// 三第一次出现的索引号是：0
```

> ★ 老师的解释：**"等于说我们在输出结果前面加了一句话。"**——用 `+` 把一段文字和一个变量接起来，接出来的仍然是一个字符串。

| 写法 | 结果 |
|---|---|
| `"索引号是：" + 0` | `"索引号是：0"` |
| `"a" + "b"` | `"ab"` |

### 5.2 另一种拼法：模板字符串（反引号 + `${}`）

> ★ 老师的话：**"它（拼接）的方法就是另外一种——我用的是模板字符串的方法。"** 特点说得很干脆：**"就是美元符号 `$` 加上大括号；用反引号把它括起来。"**

```javascript
var str = "三心二意三思而行";
var index = str.indexOf("三");

console.log(`三第一次出现的索引号是：${index}`);
// 三第一次出现的索引号是：0
```

| 部分 | 写什么 |
|---|---|
| 外层 | 一对**反引号**（键盘左上角、数字 1 左边那个键），不是单引号也不是双引号 |
| 里面 | 普通文字照写 |
| 要插值的位置 | `${变量名}` |

> ★ 老师的话：**"……左边和右边分别输入一个反引号——这就是模板字符串的特点：用反引号把它括起来。"**

> 💡 **记忆点**：`+` 拼接是"断开—加号—接上"；模板字符串是**整句写下来，变量往里一塞**。

> ⚠️ **易错点**：外层必须是反引号。写成 `"…${index}…"`（双引号）时，`${index}` 会被原样当成文字打出来，不会换成变量的值。

| 写法 | 打印结果 |
|---|---|
| `` `索引号是：${index}` `` | `索引号是：0` |
| `"索引号是：${index}"` | `索引号是：${index}` |

## 六、案例：统计一个字符在字符串里出现了几次

### 6.1 需求

> ★ 老师的话：**"这个功能是在一个字符串里面去找到所有字符 `o` 的索引，并统计它出现的次数。"** 并点明要害：**"这个就涉及到需要用到循环了。"**

| 要什么 | 说明 |
|---|---|
| 所有 `o` 的索引号 | 一个一个打印出来 |
| `o` 一共出现几次 | 最后输出一个总数 |

### 6.2 先想清楚用哪两个变量

| 变量 | 作用 | 初始值 |
|---|---|---|
| `index` | 装 `indexOf` 找出来的索引号 | 第一次查找的结果 |
| `count` | **计数器** | `0` |

> ★ 老师的话：**"第二个变量……它的作用我先给大家说，它是计数用的，我们最后输出的就是那里面的值。"**

### 6.3 循环的条件：`indexOf` 的返回值

> ★ 老师的话：**"首先先判断条件。`index` 是谁呢？`index` 是 `o` 第一次出现的这个索引。"** 接着补了一个关键情况：**"还有一个情况——在这个串里面没有 `o`。没有了的话，那你是不是就不需要进入循环了？不需要进入循环，直接输出。"**

```text
index !== -1   →  说明还找得到，进循环
index === -1   →  说明没有了，循环结束
```

> 💡 **记忆点**：`-1` 在这里就是**循环的开关**——只要 `indexOf` 还找得到就继续转，一返回 `-1` 循环自然停。

### 6.4 循环体里做三件事（★）

| 顺序 | 做什么 | 老师的说法 |
|---|---|---|
| ① | 把当前索引号打印出来 | **"先把那个 `o` 出现的所有（索引）给他打出来"** |
| ② | 计数器 `count++` | **"然后给这个计数器加一"** |
| ③ | 从**当前索引 + 1** 的位置继续找 | ★ **"这个时候查找的时候，就不是从第一个开始查找了——从哪开始查找呢？从当前位置加一。"** |

> ★ 老师总结这一段：**"通过这种循环的方法，把整个字符串里面所有的 `o`、它的索引号打印出来，并且统计它的次数。"**

> ★ 老师专门解释过这第③步为什么要多传一个参数：**"需要注意的就是，咱们这个 `indexOf` 方法里面除了检测的（内容）之外，还多了一个参数，就是从某一个索引号开始。"**

> ⚠️ **易错点**：第三步如果还写 `str.indexOf("o")`（不带第二个参数），每次都会返回**同一个**第一次出现的索引，`index` 永远是那个值，判断条件永远为真——**死循环**。

### 6.5 完整代码

```javascript
var str = "hello world, hello javascript";

var index = str.indexOf("o");     // 第一次出现的位置
var count = 0;                    // 计数器

while (index !== -1) {
    console.log("找到 o，索引号是：" + index);
    count++;
    index = str.indexOf("o", index + 1);   // 从下一位继续找
}

console.log("o 一共出现了 " + count + " 次");
```

输出：

```text
找到 o，索引号是：4
找到 o，索引号是：7
找到 o，索引号是：17
o 一共出现了 3 次
```

### 6.6 逐段对照

| 代码 | 为什么这么写 |
|---|---|
| `var index = str.indexOf("o");` | 先找到第一个，拿它当循环的起点 |
| `var count = 0;` | 计数器从 0 开始数 |
| `while (index !== -1)` | 找得到就继续转；返回 `-1` 就结束 |
| `console.log("找到 o，索引号是：" + index);` | 打印这一轮找到的索引号（拼接见 5.1） |
| `count++;` | 数一个 |
| `index = str.indexOf("o", index + 1);` | ★ 把"下一次查找的起点"挪到这一位的后一位，然后再赋回 `index` |
| `console.log("o 一共出现了 " + count + " 次");` | 循环结束后输出总数（老师说"我们最后输出的就是那里面的值"） |

## 七、字符串常用方法（一）：截取

### 7.1 三个截取方法的分工（★易混）

> ★ 老师的话：**"还有几个（方法），比如说截取……这三个方法是类似的，但是参数（不一样）。"**

| 方法 | 两个参数的意思 | 记忆 |
|---|---|---|
| `slice(起始索引, 结束索引)` | 从哪截到哪 | **两点定一段** |
| `substring(起始索引, 结束索引)` | 从哪截到哪 | 同上，只是写法不同 |
| `substr(起始索引, 长度)` | 从哪开始、**截几个** | ★ 第二个参数是**长度** |

> ★ 老师特别指出 `substr` 特殊：**"`substr` 它是比较特别的，它可以指定截取长度。"**

### 7.2 `slice`：从起始索引截到结束索引（不含结束）

> ★ 老师的话：**"（如果）你设置了起始（索引）和终止（索引），它就要把这一段给截出来。"**

```javascript
var str = "helloworld";
console.log(str.slice(1, 6));    // ellow
```

| 索引 | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| 字符 | h | e | l | l | o | w | o |

> ★ 老师当堂数着索引说明的：**"一、二、三、四、五、六，所以（索引）六是 `o`——那是不包括那个，所以（截到）六（之前）。"** 也就是**不包含结束索引那一位**。

> ★ 省略第二个参数时：**"如果（第二个参数）省略，它是默认截取到末尾。"**

```javascript
var str = "helloworld";
console.log(str.slice(5));       // world
```

### 7.3 `substring`：写法不同，用法一样

> ★ 老师的话：**"`substring` 这个方法（和 `slice`）差不多，它的截取也是可以指定起始和结束；如果（参数）省略的话，默认是到末尾。"** 只指定起始索引时，**"就从（起始索引）开始一直截止到最后"**。

```javascript
var str = "helloworld";
console.log(str.substring(1, 6));   // ellow
console.log(str.substring(5));      // world
```

| 写法 | 结果 |
|---|---|
| `str.substring(1, 6)` | `ellow` |
| `str.substring(5)` | `world` |

### 7.4 `substr`：第二个参数是"截几个"

> ★ 老师的原话：**"从索引三开始截取三个字符。"** 并反复提醒：**"它就不是从三到三——它第二参数指定的是截取的长度。"**

```javascript
var str = "helloworld";
console.log(str.substr(3, 3));   // low
```

| 索引 | 3 | 4 | 5 |
|---|---|---|---|
| 字符 | l | o | w |

> ⚠️ **易错点**：最容易混的一处——`slice(3, 3)` 和 `substring(3, 3)` 是**空字符串**（起点终点在同一处），而 `substr(3, 3)` 是**三个字符**。

### 7.5 小结

| 想做的事 | 写法 |
|---|---|
| 从索引 1 截到索引 5（不含 6） | `str.slice(1, 6)` |
| 同上，换一种写法 | `str.substring(1, 6)` |
| 从索引 5 截到末尾 | `str.slice(5)` 或 `str.substring(5)` |
| 从索引 3 开始截 3 个字符 | `str.substr(3, 3)` |

## 八、字符串常用方法（二）：大小写、分割、替换、连接、取字符

### 8.1 `toLowerCase()` / `toUpperCase()`：转换大小写

> ★ 老师的话：**"（有时候）你只需要小写，或者你只需要大写，那么我们可以用到（字母）转换的方法……这两个是转换大小写的，比较简单，也比较明了。"**

```javascript
var str = "Hello World";
console.log(str.toLowerCase());   // hello world
console.log(str.toUpperCase());   // HELLO WORLD
```

| 方法 | 作用 |
|---|---|
| `toLowerCase()` | 全部转成**小写** |
| `toUpperCase()` | 全部转成**大写** |

> 💡 这两个本节马上就要用上——用户名验证里"不管用户输大写还是小写"，就是先 `toLowerCase()` 全转小写再去查敏感词（见 9.4）。

### 8.2 `split`：把字符串切成数组

> ★ 老师的话：**"`split` 是把字符串分割成数组，它可以随便指定一个（分隔符）——比如说你的这个串里面有很多个 `l`，你可以指定 `l` 作为分隔符，把整个字符串分成几个部分。"**

```javascript
var str = "hello world";
console.log(str.split("l"));       // [ 'he', '', 'o wor', 'd' ]
```

> ★ 老师当堂数的结果：**"一个、两个、三个、四个，分成四部分"**——**"因为它这里面有三个 `l`，所以（把它）分成四部分。"**

| 字符串里有几个分隔符 | 切成几段 |
|---|---|
| 3 个 `l` | 4 段 |

> ★ 老师还讲到第二个参数：**"同样我们可以指定一个（限制）参数，来限制你这个分割（出来）的数量。"**

```javascript
var str = "hello world";
console.log(str.split("l", 2));    // [ 'he', '' ]   只要前两段
```

> 💡 **记忆点**：`split` 的结果是**数组**，不是字符串——后面要按数组的方式去取元素。

### 8.3 `replace`：用第二个参数替换第一个参数

> ★ 老师的话：**"`replace` 是用第二个参数去代替第一个参数。"**

```javascript
var str = "hello world";
console.log(str.replace("l", "1"));    // he1lo world
```

> ★ 老师当堂的演示说法：**"我想把字符串里面的 `l` 替换成 `1`。"**

> ⚠️ **易错点**：只给字符串的话，`replace` **只换掉找到的第一个**——上面的例子里只有第 3 位那个 `l` 被换成了 `1`，后面两个 `l` 还照旧。

> 💡 **记忆点**：老师反复用的词是"**代替**"——第一个参数是"被代替的"，第二个参数是"拿来代替的"。

### 8.4 `concat`：把一串字符串首尾连起来

> ★ 老师的话：**"`concat` 是可以把一个或者多个字符串首尾相（连）连起来。"**

```javascript
var str = "hello";
console.log(str.concat(" world", "!"));   // hello world!
```

| 参数个数 | 效果 |
|---|---|
| 一个 | 在后面接上一段 |
| 多个 | 一个接一个接上去 |

### 8.5 `charAt`：取某个索引号上的那个字符

> ★ 老师的话：**"用 `charAt` 检测每一个索引号，它的位置上（是什么）——（它会）返回该索引号的字符。"** 然后**"与你想要的目标结果进行匹配"**。

```javascript
var str = "hello";
console.log(str.charAt(0));    // h
console.log(str.charAt(1));    // e
```

| 方法 | 参数 | 返回 |
|---|---|---|
| `charAt(索引号)` | 一个索引号 | 这个位置上的**一个字符** |

> 💡 **记忆点**：`charAt` 和 `indexOf` 正好是一对——**`indexOf` 是"给字符、问位置"，`charAt` 是"给位置、要字符"**。

## 九、综合案例：验证用户名是否合法

### 9.1 需求：两个条件

> ★ 老师的话：**"在做网站的时候，经常（会）使用到用户的（用户名、）密码验证。"** 这个案例的要求就两条：

| # | 条件 | 不满足时 |
|---|---|---|
| ① | 用户名长度必须是 **3 到 6 位** | 弹窗提示长度不对 |
| ② | **不允许出现敏感词** | 弹窗提示不能包含它 |

> ★ 老师解释为什么要禁这个词：**"（`admin`）是管理的意思……（很多）管理员的用户名都是这个，所以用户在注册的时候就尽量（不要让）他注册这个（词）。"**

| 词 | 老师为什么禁它 |
|---|---|
| `admin` | 它是"管理"的意思，管理员的账号常用，容易冒充 |

### 9.2 收输入

> ★ 老师的话：**"肯定是（要）用户去输入……让用户（输）入，存到一个变量里面，然后我们对这个变量进行检测。"**

```javascript
var name = prompt("请输入用户名（3 到 6 位）");
```

### 9.3 条件一：长度不对就拦下来（两个比较 + 逻辑或）

> ★ 老师的话：**"用户名长度必须为三到六，说明用户的长度有问题……（什么）问题啊？就是两个问题：要么太短了，要么太长了。所以用这个（或）。"**

```javascript
if (name.length < 3 || name.length > 6) {
    alert("用户名长度必须为 3 到 6 位");
}
```

| 用户输入 | 长度 | 哪个条件成立 | 结果 |
|---|---|---|---|
| `ab` | 2 | `name.length < 3` | 弹窗 |
| `zhang` | 5 | 两个都不成立 | 不弹 |
| `zhangsan` | 8 | `name.length > 6` | 弹窗 |
| `a` | 1 | 两个都成立 | 弹窗（`\|\|` 一个真就够） |

> ★ 老师对这个写法的评价：**"非常巧妙地运用了逻辑或运算符。"**

> ⚠️ **易错点**：这里不能用 `&&`。长度不可能同时又小于 3 又大于 6，两个条件**永远不可能同时成立**，用 `&&` 就一个都拦不住。

### 9.4 条件二：含敏感词就拦下来（先转小写，再 `indexOf`）

> ★ 老师的话：**"（要求是）任何大小写形式都不得出现。那我们是不是可以把用户输的这个字符串，先给它转换成小写……全部转成小写，然后再去（判断）。"**

> ★ 判断的办法：**"我们要用（`indexOf`）在字符串里面搜索……如果找不到（才）算（通过）。"**——**"（结果）不等于 `-1`，说明用户（输）的里面包含有（敏感词），那么就需要弹窗。"**

```javascript
if (name.toLowerCase().indexOf("admin") !== -1) {
    alert("用户名不能包含 admin");
}
```

| 用户输入 | `toLowerCase()` 之后 | `indexOf("admin")` | 判断 |
|---|---|---|---|
| `Admin` | `admin` | `0` | 含 → 拦 |
| `ADMIN` | `admin` | `0` | 含 → 拦 |
| `zhang` | `zhang` | `-1` | 不含 → 放行 |

> 💡 **记忆点**：查敏感词的标准三步——**先 `toLowerCase()` 统一大小写，再 `indexOf()` 查位置，最后跟 `-1` 比。** 少了第一步，用户输 `ADMIN` 就绕过去了。

### 9.5 完整代码

```javascript
var name = prompt("请输入用户名（3 到 6 位）");

if (name.length < 3 || name.length > 6) {
    alert("用户名长度必须为 3 到 6 位");
} else if (name.toLowerCase().indexOf("admin") !== -1) {
    alert("用户名不能包含 admin");
} else {
    alert("用户名可以使用");
}
```

> ★ 老师说这个案例的价值在于：**"这里面出现了比较运算符、还有逻辑运算符、还有咱们的流程分支（结构）"**——全串到一起了。

### 9.6 三种测试情况（★上机就照这个试）

> ★ 老师的验证办法：**"在浏览器里面去运行一下，看看结果是不是符合我们的预期。"**

| # | 输入 | 走哪个分支 | 应该看到 |
|---|---|---|---|
| ① | `ab`（两个字符） | 第一个条件 | 用户名长度必须为 3 到 6 位 |
| ② | `Admin`（长度对，含敏感词） | 第二个条件 | 用户名不能包含 admin |
| ③ | `zhang`（长度对，不含敏感词） | `else` | 用户名可以使用 |

### 9.7 这个案例用到了哪些旧知识

| 用到的 | 来自 |
|---|---|
| `prompt()` / `alert()` | 第 7—10 节 |
| `length` | 本节 二 |
| 比较运算符 `<` `>` `!==` | 第 11—12 节 |
| 逻辑或 `\|\|` | 第 13—16 节 |
| `if` / `else if` / `else` | 第 13—16 节 |
| `toLowerCase()` / `indexOf()` | 本节 四、八 |

## 十一、易错点速查

| # | 错误写法 | 后果 | 正确写法 |
|---|---|---|---|
| 1 | `str.length()` | 属性不是方法，报"不是一个函数" | `str.length` |
| 2 | 以为 `new String("x")` 的类型是 `string` | `typeof` 给的是 `object`，判断全错 | 认准"`new` 出来的是对象" |
| 3 | `typeof(str)` | `typeof` 是运算符不是方法，不写小括号 | `typeof str` |
| 4 | 用 `if (str.indexOf(x))` 判断有没有 | 找到时若返回 `0`，会被当成假 | `if (str.indexOf(x) !== -1)` |
| 5 | 循环里还写 `indexOf("o")`，不带第二个参数 | 每次返回同一个索引 → **死循环** | `str.indexOf("o", index + 1)` |
| 6 | 把 `substr` 的第二个参数当结束索引 | 截出来的长度不对 | `substr(起点, 长度)` |
| 7 | 以为 `slice(1, 6)` 包含索引 6 | 多截一个字符 | 结束索引**不含** |
| 8 | 模板字符串外层写成双引号 | `${x}` 原样打出来 | 外层用**反引号** |
