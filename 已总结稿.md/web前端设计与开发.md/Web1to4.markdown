## 一、开发工具与环境配置

### 1. VS Code 编辑器

- **软件名称**：Visual Studio Code（简称 VS Code）
- **特点**：轻量、安装方便、跨平台
- **安装方式**：官网下载 `.exe` 可执行文件，双击安装，全程下一步即可

### 2. 必装插件（扩展）

| 插件名称 | 作用 |
|---|---|
| **Chinese (Simplified)** | 汉化插件，将 VS Code 界面从英文切换为中文简体，安装后需点击「Change Language and Restart」重启 |
| **Open in Browser** | 在浏览器中打开当前网页，若不安装则无法在浏览器中预览网页 |
| **Live Server** | 在浏览器中打开网页后，修改代码无需手动刷新，浏览器自动更新页面，实现动态热加载 |
| **Auto Rename Tag** | 修改 HTML 起始标记时，尾部结束标记自动同步更改，避免只改前面忘记改后面 |

### 3. VS Code 设置

- **自动保存**：文件 → 自动保存（勾选），避免忘记手动保存导致代码修改不生效

## 四、HTML 基础回顾

### 1. 网页基本结构

- 完整网页由 `<html>` 双标签包裹
- 内部包含两部分：
  - **`<head>`**：放编码格式、标题（`<title>`）、CSS 样式链接、JS 脚本链接等
  - **`<body>`**：页面主体结构，所有可见内容

### 2. 常见 HTML 标签

| 标签 | 类型 | 作用 |
|---|---|---|
| `<p>` | 双标签 | 段落标记，包裹一段文本 |
| `<hr>` | 单标签 | 水平线 |
| `<br>` | 单标签 | 换行（与段落的区别：换行后仍在同一段落内，无行间距） |
| `<img>` | 单标签 | 图片标记 |
| `<a>` | 双标签 | 超链接，`href` 属性指定跳转目标 |
| `<div>` | 双标签 | 盒子，独占一行，用于页面布局 |

## 五、CSS 样式回顾

### 1. CSS 引入方式（三种）

| 方式 | 写法位置 | 说明 |
|---|---|---|
| **内联式** | 直接写在标签的 `style` 属性中 | 适用于单个元素 |
| **内嵌式** | 写在 `<head>` 中的 `<style>` 标签内 | 适用于当前页面 |
| **外链式** | 通过 `<link>` 标签引入外部 `.css` 文件 | 代码量较大时推荐使用 |

### 2. CSS 选择器

| 选择器 | 写法 | 说明 |
|---|---|---|
| **ID 选择器** | `#id名` | 选中具有该 ID 的元素，前面用 `#` 号 |
| **类选择器（class）** | `.类名` | 选中具有该类名的元素，前面用 `.` 点号 |

- 在 HTML 中通过 `class="类名"` 或 `id="id名"` 给元素命名
- CSS 语法格式：`选择器 { 属性: 值; }`

## 六、JavaScript 输出语句（重点）

### 四种输出方法

| 方法 | 关键字 | 作用 |
|---|---|---|
| **弹窗输出** | `alert()` | 弹出提示窗口，给用户提示信息 |
| **页面写入** | `document.write()` | 向页面写入内容（可以是文字、HTML 元素、CSS 等） |
| **控制台输出** | `console.log()` | 在控制台显示内容，用于开发者调试，不显示在页面上 |

> **注意**：`console.log()` 主要用于调试，让开发者在后台查看某段代码/函数的输出，而不影响页面显示。

---

## 七、JS 引入方式（三种）

| 方式 | 说明 |
|---|---|
| **行内式** | 写在 HTML 标签的属性中（如 `onload`），使用极少 |
| **内部式** | 写在 `<script>` 标签内，可放在 `<head>` 或 `<body>` 中，代码量少时使用 |
| **外部式** | 单独 `.js` 文件，通过 `<script src="xxx.js">` 引入，代码量大时推荐 |

> **建议**：非首屏必需的脚本尽量放在 `<body>` 末尾，以提高页面加载速度。

| 组成部分 | 占比 | 说明 |
|---|---|---|
| **平时成绩** | 40% | 签到 10 分 + 作业 20 分 + 课堂表现 10 分（提问、抢答、点名、纪律等） |
