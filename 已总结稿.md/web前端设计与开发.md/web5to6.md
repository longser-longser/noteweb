## 三、JavaScript 概述（复习）

### 3.1 它是干什么的

> 老师原话：**"是为了给网页添加交互动画效果。"**

- JavaScript 的作用就是**给网页添加交互动画效果和交互功能**。

### 3.2 三个组成部分（老师重复强调）

> 老师原话：**"所以说（它）由这三个部分去组成。"** 并且**"本学期就从这三个（部分）去来学习 JavaScript。"**

| 组成部分 | 老师课堂上的说法 | 作用 |
|---|---|---|
| **① ECMAScript（核心语法）** | **基本部分**——"你要知道把它的这些格式……怎么去（写）" | 基本语法、格式、变量、数据类型、运算符、流程控制、函数等 |
| **② DOM（文档对象模型）** | "用（后）面这两个模型去操作网页的**结构**" | 操作网页结构（元素、内容） |
| **③ BOM（浏览器对象模型）** | "以及……**去控制浏览器**" | 控制浏览器行为 |

> 老师特别说明：**"（前）面这些都不说了"**——即 **JavaScript 的基本概念、是哪个公司发明的、发展历史等，本次课没有再展开讲**，只作了解。

## 五、JavaScript 的三种插入方式（本节第一个重点）

> 老师原话：**"它（的）基本（写法）方式和（上）学期（学的）样式表有一点相似，它也是分为行内式……"**

**对照记忆**：JavaScript 的三种插入方式，**和上学期 CSS 的三种引入方式一一对应**：

| | CSS（上学期） | JavaScript（本节） |
|---|---|---|
| 第一种 | 内联式（标签的 `style` 属性里） | **行内式**（标签的事件属性里） |
| 第二种 | 内嵌式（`<style>` 标签对里） | **内嵌式**（`<script>` 标签对里） |
| 第三种 | 外链式（`<link>` 引入外部 `.css`） | **外部式**（`<script src="…">` 引入外部 `.js`） |

### 5.1 行内式

| 项目 | 说明 |
|---|---|
| **写法** | 直接在 **HTML 标签的事件属性**里写 JavaScript 代码，如 `<button onclick="alert('hi')">` |
| **老师的态度** | **基本上不用**——"因为你看（代码）写在哪里（就知道了）"：代码和标签混在一起，**不利于阅读和维护** |
| **适用** | 极少数的简单（事件）场景，正式项目中**推荐用内嵌式或外部式** |

### 5.2 内嵌式

**（1）写法**（老师原话：**"包裹在一对（`script`）的标签里面。"**）

```html
<script>
    // 这里写 JavaScript 代码
</script>
```

**（2）放在哪里？** 老师原话：**"这一部分内容你把它放到网页代码的（`head`）的部分里面，也可以的哈。"**——**`<head>` 或 `<body>` 里都可以**，但**推荐放在"结构的后面"**。

**（3）⚠️ 位置为什么重要：脚本执行会影响网页加载**

> 老师原话：**"这个地方大家需要注意，因为脚本执行会影响网页加载。"**
> **"如果不需要提前加载的脚本效果，我们尽量放在（网页）结构的（后）面，让网页结构（先加载），（再）运行脚本。"**

| 情况 | 结果 |
|---|---|
| **脚本放在前面** | **"他会先加载那个脚本，先（执行）……然后再去加载网页结构"**——**脚本先执行，网页结构后加载** |
| **脚本放在结构后面** ✅ | **先加载网页结构，然后再去（执行）脚本** |

> **记忆**：**先结构、后脚本**——除非脚本必须提前加载，否则 `<script>` 尽量写在**结构的后面**（即 `</body>` 之前）。

### 5.3 外部式（第三种，**工作中最常用**）

> 老师原话：**"第三个方法嘛……我们在工作中啊，经常（用这个）。"**

**（1）写法**：**单独写一个 `.js` 文件**，`<script>` 标签对里**不写代码**，而是**"在标签的属性位置给它添加了一个路径"**——属性名 **`src`**。

```html
<script src="js文件路径"></script>
```

| 要点 | 说明 |
|---|---|
| **标签** | 老师原话：**"（`script`）标记是要添加一个 `src` 属性，用于写（js）文件的路径"** |
| **路径类型** | **相对路径**——"是个相对路径啊，相对于（网页文件）来说" |
| **两文件在同一文件夹** ✅ | **"可以直接写文件的名字，不需要（写）任何文件夹"**，如 `src="main.js"` |
| **在下级文件夹** | 写成相对路径，如 `src="js/main.js"` |
| ⚠️ **后缀必须带上** | 老师原话：**"后面（的 `.js`）也是需要带上的"** |

**（2）为什么要用外部式**：老师原话 **"为了实现代码的（复）用"**、**"（方便以后）维护"**。
外部 `.js` **可被多个页面重复使用**；**有些内容（在不同页面）效果不一样**，**"那就是需要把你的内容给他稍微的进行调整"**——即**复用的是框架，具体内容按页面微调**。

> 老师收尾原话：**"这就是（`script`）的三种（引入）方式。"**

> 老师原话：**"然后再来看一下（它的）格式啊……（它的）格式是有一点类似于我们上学期学习的……"**

### 6.1 与 CSS 的对照

| 项目 | CSS（上学期） | JavaScript（本节） |
|---|---|---|
| **相似点** | — | **基本方式与样式表有一点相似**，都有"行内 / 内嵌 / 外部"三种写法 |
| **每行结尾** | **需要在每行结尾写一个分号** | **比较宽松，不是那么严格要求的**——**很多情况下可以不写** |

| 情况 | 是否要写分号 |
|---|---|

| **一行里写了两条语句** ⚠️ | **一定要写分号**——老师原话：**"你（看它）是两个（语句）放到一起了，这种情况下，我们这个地方一定要加（分）号"** |

> **宽松 ≠ 随便**：**建议参考上学期的代码规范，该写的分号还是写上**，养成好习惯。

## 七、四个基础输入输出语句（本节核心重点）

> 老师原话：**"最常用也是最简单的四个句，两个输入，两个输出。"**
> **"他们的（名字）和（各自）的功能，需要大家去（记）住的。"**
> **"最重要最简单的四个啊，就要……好好（记）了。"**

### 7.1 四个语句总表（★背下来）

| 序号 | 语句 | 类型 | 代码示例 | 结果出现在哪里 |
|---|---|---|---|---|
| ① | **`prompt()`** | **输入** | `prompt("请输入手机号")` | **弹窗**——让用户在里面输入内容 |
| ② | **`alert()`** | **输出** | `alert("提示信息")` | **弹窗**——在页面上弹出一个小提示窗 |
| ③ | **`document.write()`** | **输出** | `document.write("内容")` | **网页本身**——写到网页的文档（结构）里 |
| ④ | **`console.log()`** | **输出** | `console.log("内容")` | **控制台**——开发者工具的控制台里 |

> **记忆要点**：老师按"**两个输入、两个输出**"的说法讲，但**按方法名去数是 1 个输入 + 3 个输出**：
> **`prompt`（进）、`alert` / `document.write` / `console.log`（出）**——
> 三个输出的区别只在**"出"的地方不同**：**弹窗 / 网页 / 控制台**。

### 7.2 输入语句：`prompt()`

**（1）作用**

> 老师原话：**"这是一个（输入语句），是可以让用户去输入内容的。"**
> **"然后会通过这个语句来获取用户的一些信息，比如说用户名、密码、手机号。"**

| 要点 | 内容 |
|---|---|
| **作用** | **弹出一个输入框，让用户输入内容** |
| **获取什么** | **用户名、密码、手机号**等用户信息 |
| **运行结果** | 老师原话：**"这条（代码）在浏览器里面运行起来哈，它就是一个弹窗"** |

**（2）括号里的提示文字怎么写**

> 老师原话：**"咱们（在）这个小（括号）里面呢，可以去（写）提示用户'请输入（什么什么）'。"**
> **"（括号里）的信息是必须要加引号的"**——**"（用）引号填写上'请输入手机号'"**。

```javascript
prompt("请输入手机号");     // ✅ 提示文字要用引号括起来
```

- **括号里的提示信息必须加引号**，否则会被当成变量名（不是字符串）；
- 引号里的内容**就是弹窗上显示给用户看的那句话**。

**（3）⚠️ 关键一步：用变量把用户输入的内容存起来**

> 老师原话：**"收到（'请输入手机号'），那这个时候我们（就可以）在里面输（入）手机号。"**
> **"输完（手机号）以后，他（获取）过（内容）后，我们（要）把它存到一个变量里面，是不是？"**
> **"这边还需要再加一个变量的。"**

```javascript
var phone = prompt("请输入手机号");   // 把用户输入的内容存进变量
```

- **有输入 → 就必须有变量来接**，否则输入的内容就丢了；
- 这一步也是后面作业里"**定义变量 + 输入语句**"的写法基础。

### 7.3 赋值运算符 `=`（写作业必用）

老师原话：**"（这个符号）的意思是可以把右侧的内容（赋）给左侧的（变量）。"**

- **方向从右往左**：**把右边的值赋给左边的变量**；
- 它是**赋值**，**不是数学上的"等于"**；
- 典型用法：把用户输入的内容**存进变量**、**交换两个变量的值**。

```javascript
var a = prompt("请输入第一个数：");   // 右侧输入的结果 → 赋给左侧变量 a
```

### 7.4 弹窗输出：`alert()`

老师原话：**"它的作用就是在我们页面上弹出一个小的提示窗。"**

- **输出位置**：**弹窗**（页面上弹出的一个小提示窗）；
- **写法**：`alert("提示信息");`——**括号里要输出的内容同样必须加引号**；
- **适用**：提示信息、警告信息。

### 7.5 页面输出：`document.write()`

老师原话：**"（这个代码）写到你的页面上了"**——**"它就会显示在你的网页结构里面"**、**"（写）在你的网页的文档（里）"**。

- **输出位置**：**网页本身**（不是弹窗、也不是控制台）；
- **写在哪一行**：**写在当前 `<script>` 所在的位置**——老师原话 **"就是（写在当前这个）地方"**；
- ⚠️ **写完/改完要在浏览器里刷新一下**（老师原话：**"（写到页面上），线下（刷新）一下。"**）才能看到最新结果；
- 与 `console.log()` 的区别：它的结果**直接长在网页结构里**，是"看得见"的输出：

```javascript
document.write("内容");    // → 输出到【网页文档】里，会改变页面显示
console.log("内容");       // → 输出到【控制台】，不改变页面显示
```

### 7.6 控制台输出：`console.log()`

> 老师原话：**"这个代码是写到哪的？它也是输出，它不是输出到网页里面的，它输出在哪里呢？"**
> ——**"开发（者）工具里面的控制台。"**

| 要点 | 内容 |
|---|---|
| **输出位置** | **浏览器开发者工具的控制台（Console）** |
| **打不打开页面** | **不影响网页结构**——不会在页面上显示出来 |
| **主要用途** | **调试**：看程序运行到某一步时，某个变量里的值到底是什么 |
| **怎么看结果** | `F12` 打开开发者工具 → 切到**控制台** → **"就在这个位置"**（老师课堂指认过控制台的位置） |

### 7.7 四个语句的"输出位置"对比（最容易混）

| 语句 | 输出位置 | 会不会改变页面显示 | 典型用途 |
|---|---|---|---|
| `prompt()` | **弹窗（输入框）** | 不影响页面（弹窗是临时的） | **获取用户输入**（用户名、密码、手机号） |
| `alert()` | **弹窗（提示框）** | 不影响页面（弹窗是临时的） | 提示用户 |
| `document.write()` | **网页文档里** | ✅ **会**（内容直接写进页面结构） | 把结果展示在页面上 |
| `console.log()` | **控制台** | ❌ **不会** | 调试、查看变量的值 |

## 九、复习要点（考前/写作业前速查）

### 9.1 一句话版

| 编号 | 要点 | 一句话 |
|---|---|---|
| 1 | **三个组成部分** | ECMAScript（核心语法）+ DOM（操作网页结构）+ BOM（控制浏览器） |
| 2 | **三种插入方式** | 行内式（标签属性里）、内嵌式（`<script>` 标签对里）、外部式（`src` 引入 `.js`） |
| 3 | **脚本放哪里** | **不需要提前加载的脚本尽量放结构后面**——否则脚本会先执行，影响网页加载 |
| 4 | **外部式的路径** | 用 **`src` 属性**写**相对路径**；同一文件夹下**直接写文件名**，**后缀要带上** |
| 5 | **分号规则** | **一行一句可省，一行多句必写** |
| 6 | **四个语句** | `prompt`（进）、`alert` / `document.write` / `console.log`（出） |
| 7 | **输入必须接变量** | `prompt` 拿到的内容要**存进变量**，否则白输 |
| 8 | **引号** | 括号里要输出的**文字内容必须加引号** |
| 9 | **`=` 的方向** | **把右侧的内容赋给左侧的变量** |
| 10 | **三个插件** | 下次课上课前装好 |

### 9.2 三种插入方式对比表（★核心）

| 方式 | 写法 | 代码写在哪 | 优点 | 缺点 / 注意 |
|---|---|---|---|---|
| **行内式** | `<button onclick="alert('hi')">` | **HTML 标签的事件属性里** | 简单、就近 | **基本上不用**，不利于维护 |
| **内嵌式** | `<script>代码</script>` | **`<head>` 或 `<body>` 里**（推荐放结构后面） | 页面专属、书写方便 | 位置不对会影响网页加载 |
| **外部式** ✅ | `<script src="main.js"></script>` | **单独的 `.js` 文件** | **代码复用、便于维护**（工作中最常用） | 路径要写对，**后缀要带上** |

## 十、易错点清单（老师课上点到的坑）

| # | 易错点 | 正确做法 |
|---|---|---|
| 1 | 把 `prompt` 的返回值丢掉 | **必须用变量接住**：`var phone = prompt("请输入手机号");` |
| 2 | 括号里的提示文字不加引号 | **文字内容一律加引号**：`prompt("请输入手机号")` |
| 3 | 把 `=` 当成"等于" | **它是赋值**，**右边的值给左边** |
| 4 | 脚本乱放位置 | **不需要提前加载的脚本放结构后面**，避免"脚本先执行、结构后加载" |
| 5 | 外部式只写文件名忘了后缀 | **相对路径要写全**（`main.js`），同文件夹可直接写文件名 |
| 6 | 一行写两条语句却不写分号 | **一行多句必须加分号**；一行一句可省略，但**建议统一写上** |
| 7 | 分不清 `document.write()` 和 `console.log()` | 前者**写进网页**（刷新可见），后者**只在控制台**、**不影响网页结构** |
| 8 | 改完代码看不到变化 | `document.write()` 的结果要**刷新页面**才更新 |
| 9 | 用"打开文件"而不是"打开文件夹" | VS Code 里要用 **"打开文件夹"** 打开整个项目 |
| 10 | 控制台的提示全当成错误 | **有些只是提示，不影响运行**；真正要看的是报错信息 |
