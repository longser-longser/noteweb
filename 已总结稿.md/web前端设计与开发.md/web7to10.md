## 一、作业讲评：两个变量的交换（本节重点案例）

### 1.1 作业要求

> **把两个变量里面存的值进行交换。**

**这道题考察的是第一节课学过的三个知识点**：

1. 变量的**定义**
2. **输入语句**的使用
3. 变量的**赋值**
4. （验证环节）**输出语句**的使用

### 1.2 解题思路：借助"第三个变量"

**老师用的生活类比**：

> 你两只手各拿一个苹果，想把左右手的苹果**对调**，直接换是换不了的——
> 得先**借助一张桌子**：把其中一个苹果先放到桌子上，腾出一只手，再把另一个苹果拿过来，最后把桌上那个拿回来。

**对应到代码上，就是用"第三个变量"充当那张桌子。**

### 1.3 完整步骤（按老师课堂演示还原）

**第 1 步：定义第一个变量并输入**
```javascript
var a = prompt("请输入第一个苹果：");   // 例如输入"红苹果"
```
- 用 `var` **定义一个变量**；
- 通过**输入语句**，让用户输入**第一个数据**，并把它**存储到变量里**。

**第 2 步：定义第二个变量并输入**
```javascript
var b = prompt("请输入第二个苹果：");   // 例如输入"青苹果""绿苹果"都可以
```
- 同样是 `var` 定义 + 输入语句赋值；
- 到这一步，**两个数据已经分别存储在"变量一"和"变量二"里了**。

**第 3 步：用第三个变量做中转**
```javascript
var c = a;   // 把"变量一"里的值先交给"变量三"
```
- 现在"变量一"里的值**已经转存到第三个变量**，
- 所以**"变量一"可以放心重新赋值了**。

**第 4 步：把第二个变量的值交给第一个变量**
```javascript
a = b;
```

**第 5 步：把第三个变量里的值交给第二个变量**
```javascript
b = c;
```

**第 6 步：验证交换结果**

用**输出语句**在**控制台**里把这两个变量显示出来，**看一看是不是完成了最终交换**。

### 1.4 老师讲解时的调试技巧

- **先把暂时不用的行"注释掉"**：老师讲评时把后面那两行先注释掉，**先看前四行代码**；
- **前四行代码实现了**：**变量的定义 + 赋值**；赋值时用的是**输入语句**，让用户输入信息。

## 二、输出语句与控制台（本题用到的重要工具）

### 2.1 输出语句是干什么的

> **在控制台输出内容，它不影响我们的网页结构。**

- **主要用途是"调试"**：
  - 程序运行时，想知道**某一部分**、
  - **某些变量里面的值**、
  - 或者**某些函数运行的结果**到底是什么，
  - 就可以**用输出语句在控制台里打印出来看**。

### 2.2 怎么看输出结果

1. 打开**开发者工具**（浏览器里）；
2. 切换到**控制台（Console）**面板；
3. 就能看到刚才**输出的内容**及其结果。
   - 例如：一个变量里存的是"苹果"，第二个变量里存的是"绿（苹果）"。

> **一句话**：`输出语句 = 把值打到控制台，专门用来调试，不改变页面显示。`

### 2.3 用它来判断变量的数据类型（后面第五、六节反复用到）

> 变量里的值**到底属于哪种类型**，也可以**通过输出语句把变量里的值显示到控制台里**去看。

## 四、数据类型（重点）

### 4.1 为什么需要"数据类型"

- 之前接触的**原来都是数字**；
- 但在**计算机**里面，**不仅仅是数字，还有文本等这些内容**；
- **这些不同的东西属于不同的数据类型，在计算机里面怎么对它们进行操作**——这就是数据类型要解决的问题。

### 4.2 两大类数据类型

```
JavaScript 数据类型
├── ① 基本（简单）数据类型
│     ├── 数字型 number
│     ├── 布尔型 boolean
│     ├── 字符串型 string
│     └── 空的数据（null / undefined）
└── ② 复杂数据类型（也叫"对象"）
      └── 后面（第五章）详细讲
```

### 4.3 基本数据类型逐个说

#### （1）数字型（number）

- 就是 **1、2、3、4、5、6……** 这样的数；
- **看到它你就知道它是一个数字型的数据**；
- ⚠️ **也包括负数**（如 `-2`）。
- **数字型再往下分两种**：

| 细分 | 说明 |
|---|---|
| **整型** | 整数 |
| **浮点型** | **用来表示小数的**。比较简单的小数**直接写小数点**的形式就可以了；比较长的、带**科学计数法**的数后面再说 |

#### （2）布尔型（boolean）——本节第二个重点

- **只有两个值**：**真（true）** 和 **假（false）**；
- **主要用途：表示程序中"判断"的结果**，用于**流程控制**：
  > **控制程序的走向**——条件为**真**，走一个流程；为**假**，走另外一个流程。
- 含义对应：
  | 值 | 含义 |
  |---|---|
  | `true` | 事件**成功** / 条件**成立** |
  | `false` | **失败** / 条件**不成立** |
- **举例**：
  > 判断"**数字 3 是否大于数字 2**" → 这个条件**成立** → 用布尔数据表示就是 **`true`**。

> ⚠️ **本节的坑（老师专门强调）**：
> **`true` / `false` 只有全部写成小写的时候，才表示布尔值**——
> **JavaScript 是严格区分大小写的！**

#### （3）字符串型（string）

- 用来**写一些文本**；
- **文本和数字混合在一起**的，**也叫做字符串**。

#### （4）空的数据

- 老师提到还有**空的**那种数据（`null` / `undefined` 一类），本节不展开。

### 4.4 复杂数据类型（对象）

- **也叫"对象"**；
- 特点：**它不是一个简单的单个数据，它是成对儿出现的**；
- 属于比较复杂的内容，**后面（第五章）再给大家详细解释**。

## 五、JavaScript 的"弱类型"特性（重点，容易考也容易错）

### 5.1 结论

> **JavaScript 是有一个比较松散的"弱类型"语言。**

意思是：**在变量的使用过程中，它的值可以通过不同类型的数据进行修改。**

### 5.2 具体表现

| 表现 | 说明 |
|---|---|
| **两次赋值类型可以不同** | 我们给这个变量的**第一次赋值和第二次赋值，可以是不同的数据类型** |
| **不需要强制类型转换** | **不需要去进行数据类型的强制转换** |
| **类型由"值"决定** | **JS 里面变量的数据类型，取决于你赋给它的值的类型**——你给它赋予什么样的值，它就是什么样的数据类型 |

### 5.3 课堂演示的例子

```javascript
var x = 24;      // 第一次赋值 24 → 这个变量是【数字型】数据类型

x = "abc";       // 第二次赋值是一个字符串 → 类型随之改变
```
- **第一步**：赋值为 **24** → 该变量里面的数据类型是**数字型**；
- **第二步**：给它重新赋值一个**字符串** → **它可以通过赋值去改变其类型**；
- **结论**：**不需要再对它进行数据类型的转换。**

### 5.4 怎么验证类型

用**输出语句**把变量里的值显示到**控制台**里，就能看到它到底是什么类型。
