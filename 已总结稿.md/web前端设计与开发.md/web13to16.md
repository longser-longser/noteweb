## 二、复习上节课：运算符（本节重点之一）

### 2.1 字符串拼接的两种方式

**方式一：加号 `+`**

> - 这种方式**使用加号运算符来实现**；
> - **拼接可以使用"变量名 + 变量名"，也可以"字符串 + 变量名"，或者是混合去拼接都可以**；
> - **只要用加号连起来就可以了**。

**方式二：模板字符串**

> 使用模板字符串，**"不用加号了"**。

（回顾：模板字符串用**反引号**开头结尾，变量写在 `${ }` 里。）

### 2.2 隐式转换

> 上节课学了一种**隐式转换**——也就是**某些不同类型的数据，它可以默认（自动）转换**，
> **不需要你手动去转，它直接就给你转了**。

### 2.3 复合赋值运算符

| 写法 | 含义 | 说明 |
|---|---|---|
| **`a += b`** | **`a = a + b`** | 加上**并赋值**——结果**再次（赋值给）左侧的变量** |
| `a -= b` | `a = a - b` | 减等 |
| `a *= b` | `a = a * b` | 乘等 |
| `a /= b` | `a = a / b` | 除等 |

**两个要点**：

1. **"只有加号对字符串（有用）"**——即 `+=` 可以用在字符串上（做拼接），其余三个只能用于数字；
2. 减等、乘等、除等**都是对变量或者数据进行一个计算的**，它们的含义和加等一样——**先运算，再赋值**；
3. 老师评价：**"还是简写的方式，别人用的比较多。"**

### 2.4 比较运算符：相等 vs 全等（★重点）

> 老师原话：**"那个（比较）运算的结果是布尔型的数据。"**
> ——也就是结果只有 **`true`** 或 **`false`**；
> **条件成立就是真，条件不成立就是假。**

**⚠️ 本节最容易踩的坑：`==` 和 `===` 不一样**

> 老师原话：**"所以以后（要注意）这个运算（的结果）——如果你想要（判断）它这一个（数据）它的类型是否相等，
> 那三个等号 或者是 两个等号 是不一样的。"**

| 写法 | 名称 | 含义 |
|---|---|---|
| **`==`** | **相等**（相等运算符） | 只比较**值**是否相等，**会发生隐式类型转换** |
| **`===`** | **全等**（严格相等） | **既要值相等，也要类型相同**，不做类型转换 |

> 记忆：**等号越多越严格**——`===` 要求"值和类型都相等"。
> 想知道"两个数**类型**是否也相等"，就必须用 **`===`**。

### 2.5 逻辑运算符：`&&` 与 `||`（★重点）

#### （1）逻辑与 `&&`——"a 真则取 b"

| 情况 | 结果 |
|---|---|
| 如果 **a 的值是真** | **结果就是 b 的值**（"它不是 a 的值"） |
| 如果 **a 的值是假**（比如 `0`） | **结果就是 a 的值** |

**老师的举例**：

> "比如说像这个结果，**因为 100 是一个真的值**……"
> "如果 a 的（值），比如说 **0**，就是（假）……"

#### （2）逻辑或 `||`——"a 真则取 a"

| 情况 | 结果 |
|---|---|
| 如果 **a（的值）是真** | **结果是 a 的值** |
| 如果 **a 是假** | **结果是 b 的值** |

> 老师把它拆成"（两条）规则"讲的，并现场举了例子让大家判断结果。

> 💡 **两张表合起来记**：
> - **`&&`（与）**：**遇到假就返回假的那个**，全真才往后走 → **a 假返回 a，a 真返回 b**
> - **`||`（或）**：**遇到真就返回真的那个**，全假才往后走 → **a 真返回 a，a 假返回 b**

### 2.6 检测数据类型：`typeof`

**它是干什么的**：

> **可以检测某一个变量，它里面存储的（到底是）什么类型。**

**为什么需要它（老师讲的应用场景）**：

> "有的时候你在写（代码）的时候，会发现：**我明明（要的是）那个（数字），为什么结果（不对）？**
> 有可能是（类型问题）——**（这个时候）可以（用它）检测一下**，这个（变量）里面它的（类型到底是什么）：
> **到底是数字（型）数据（还）是（别的）？**"

**它的返回值特征**：

| 特征 | 说明 |
|---|---|
| **返回的是英文单词** | **对于各种数据类型，检测出来的结果是英文单词**，比如数字型返回 `number` 这类 |
| **未声明的变量** | 如果这个（括号）里面（放的是）**没有声明/没有赋值的变量**，会得到另一种结果（如 `undefined`） |
| **看懂单词就知道类型** | "你把（这个）变量的（类型）检测出来以后，**这个单词你也知道是什么意思**" |

**课堂演示**：

1. 定义一个变量；
2. 用输入（语句）让用户输入一些内容，给这个变量赋值；
3. 用这个运算符去检测它是什么类型；
4. 看结果是什么。

> 因为用输入语句拿到的内容**一律是字符串**，所以检测结果通常是 `string`——这也是老师说"**那是什么类型的？**"这个追问的意义。

### 2.7 运算符优先级：判断不了就用小括号

> 老师原话：
> "**它（跟）原来（课本）里面的（讲法）差不多。**
> **那如果你判断不了这个（运算符）的优先级，特别是（几）个放在一起的时候**……
> **这个小括号啊，小括号（把你想）要（的）给它括起来就可以了。**"

**结论（很实用的一条）**：

> **当你不确定谁先算谁后算时，就用小括号把你想先算的部分括起来。**

## 三、新内容：流程控制（本节重点之二）

> 老师提到：**"（程序设计有）三个（基本）结构"**，这些内容**上学期的《网页设计基础》里学过**，这节课重新过一遍。
> 本节重点讲**选择结构**和**循环结构**。

### 3.1 两种结构

> 老师原话：**"选择结构和循环结构嘛，选择结构也就是分支结构。"**

| 结构 | 别名 | 作用 |
|---|---|---|
| **选择结构** | **分支结构** | 根据条件走不同的分支 |
| **循环结构** | — | 重复执行一段代码 |

### 3.2 选择结构之 `if`（单分支）

**特点**：

| 要点 | 说明 |
|---|---|
| 最简单的形式 | **最简单的就是 `if`** |
| 分支数量 | **它只有一个分支**——所以也叫**单（分支）语句** |
| 执行规则 | **如果符合条件，就执行（大括号）里面的（内容）；不符合条件，直接就（跳过）** |

> 老师原话：**"如果符合条件，他们就执行（这）段；不符合就跳过判断，继续向后执行。"**

**代码结构**：

```javascript
if (条件) {
    // 满足条件时执行的内容
}
```

### 3.3 `if-else`（双分支）

**课堂演示的完整过程**：

1. **先定义一个变量**（老师用了类似 `23`、`24` 这样的值）；
2. **下面写一段 `if`**：

```javascript
if (条件) {
    // 满足条件时执行的内容
}
```

3. 讲解："**如果满足条件的话，就执行（大括号）里面的内容**"；
4. 演示判断：**如果这个值不满足条件，会直接退出（跳过这一段）**；
5. **那如果想要"不满足时也做点事"呢？**——就用 **`if...else`**：

```javascript
if (条件) {
    // 条件成立时执行
} else {
    // 条件不成立时执行
}
```

**写法顺序（老师强调的）**：

> **先判断条件 → 然后（大括号）先打好 → 再（往中间）写内容 → 后面再跟上一个 `else`。**

### 3.4 ⚠️ 写代码的规范（老师专门停下来强调）

> **"这个我们在写程序的时候，一定要注意啊——在我们写这种成对出现的符号的时候，一定要一起把它打出来。"**

**具体做法**：

| 步骤 | 做法 |
|---|---|
| ① | **一定要先打一个小括号**，再往（里面）去填 |
| ② | **要先把这一个大括号都（打）出来，然后再往中间去（写）内容** |
| ③ | 用老师的话说：**"我先打一个（大括号）来把我包起来，写完之后再打后边的"** |

**不这么做的后果**：

> - **"（不然）你可能会弄丢（括号）"**；
> - **"或者是出现这个第一个（大）括号跟中间（的）两个（配不上）"**——也就是括号不匹配，程序报错。

> 老师原话：**"（所以）大家在输这个（括号）的时候，一定要把它先全部输出来。这是我们先（前）经常（会）经历的一个小（问题）。"**

> **记忆**：**先配对，再填空**——凡是成对出现的符号（`()`、`{}`、`""`），**先把一对打完，再回到中间写内容**。

### 3.5 `else if`（多分支）

**特点**：

> 老师原话：**"（`else if`）语句也就是它**可以（判断）多个条件**，它（不再只）支持一个条件了。"**
> **"它不只是（判断）一个（条件），它是（把多个条件）放在一起的判断，多个条件，针对不同情况去处理。"**

**执行流程**：

1. **先判断第一个条件**；
2. **如果是假（不成立），再判断第二个条件**；
3. **如果还不成立，再继续往下判断**；
4. **哪个条件满足了就执行对应的那段，然后结束**。

**代码结构**：

```javascript
if (条件1) {
    // 情况 1
} else if (条件2) {
    // 情况 2
} else if (条件3) {
    // 情况 3
} else {
    // 以上都不满足
}
```

### 3.6 课堂案例：判断成绩等级

> 老师说：**"（这个例子）就是要判断学生的成绩（等级）。"**

**教材上的做法**：

- 书上这段代码**是先输入一个分数**（比如满分 `100` 或者 `60`）；
- 演示时用了 **55** 这样的值；
- **用分数段"最低的一个数"去判断**——也就是从低到高（或从高到低）逐段比较。

**配套练习（老师提到的）**：

> 老师提到一个"**未成年**"的判断例子：
> **输入年龄 → 判断 → 输出对应的提示**（如"未成年"）。
> 老师原话：**"（这样）都可以实现一个这个简单的自动化（判断）。"**

### 3.7 循环（本节只做了概述）

| 要点 | 内容 |
|---|---|
| **循环是什么** | **可以重复（执行）的行（语句），有一个条件表达式** |
| **两种形式的区别** | 老师强调两种循环的区别是"**一个是先（执行），再判断条件**"，另一个（先判断再执行）——**即"先判断"还是"先执行"的区别** |
| **可以嵌套** | **"循环可以啊，外层里层，两层、三层的都有"**——即**嵌套循环** |
| **经典案例** | 老师问"**你们之前有没有做过打印（图形）？**"，并说这是**比较经典**的例题 |
