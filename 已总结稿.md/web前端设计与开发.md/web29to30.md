## 一、先把上一节的对象收口：怎么创建、怎么起名

### 1.1 创建对象最省事的写法：一对空花括号

> ★ 老师回顾时的第一句：**"创建对象的第一个最简单的方法，就是花括号里面什么都不放。"**

```javascript
var obj = {};        // 一个空对象：里面一个成员都没有
```

本节出现了三种造对象的写法，先摆在一起看：

| 写法 | 代码 | 特点 |
|---|---|---|
| **空对象** | `var obj = {};` | 里面一个成员都没有，成员后面再补（见第四节） |
| **带成员的** | `var person = { name: "小智", age: 20 };` | 一次把属性和方法都写进去 |
| **构造函数 + `new`** | `var stu1 = new Student("小智", 20);` | 先写模板，再批量造（见第三节） |

### 1.2 花括号里放的两种东西：属性与方法

- **属性**：一个"名值对"——左边是成员名，右边是值。
- **方法**：值是一个**函数**。
- 两者都叫对象的**成员**，之间用逗号隔开。

> ★ 老师的话：**"属性和方法……用花括号把它包起来。"**

| 成员 | 右边是什么 | 怎么用 | 例 |
|---|---|---|---|
| **属性** | 一个值（数字、字符串……） | 取出来就是那个值 | `name: "小智"` |
| **方法** | 一个**函数** | 调用它，会执行函数体里的语句 | `introduce: function () { … }` |

```javascript
var person = {
    name: "小智",                    // 属性：名值对
    age: 20,                         // 属性
    introduce: function () {         // 方法：值是一个函数
        return "大家好，我叫" + this.name + "，今年" + this.age + "岁。";
    }
};
```

老师说，方法右边那个函数"紫色的方块里面是该函数的函数体"，也就是说：**花括号里写的是这个函数被调用时要执行的语句**，不调用就一条也不执行。

> 💡 **记忆点**：属性和方法都叫"成员"，区别只在**右边是不是函数**。右边是函数，它就是一个方法。

### 1.3 创建完一定要起名字：用变量接住

> ★ 老师反复强调的一句：**"创建完对象之后，肯定要给它起一个名字，所以我们需要声明一个变量来代表它——不管用哪种方法，都需要一个变量。"**

```javascript
var person = { name: "小智" };          // 字面量：用变量接住
var stu1 = new Student("小智", 20);     // 构造函数：也用变量接住
```

> ⚠️ 造出来的对象如果没人接住，后面就再也找不着它了，一个成员都用不上。

## 二、访问对象成员：一个点，一对小括号

### 2.1 访问属性：对象名 + 点 + 属性名

> ★ 老师的话：**"我们只需要用对象的名称，后面加个点。"**

```javascript
console.log(person.name);        // "小智"
console.log(person.age);         // 20
```

老师说得很直接：访问属性，**返回的就是这个属性的值**。

### 2.2 访问方法：点完之后必须加一对小括号（★）

```javascript
console.log(person.introduce);     // 打印出这个函数本身，不会执行
console.log(person.introduce());   // 执行函数体，拿到 return 的值
```

> ⚠️ `person.introduce` 只是把函数"拿出来看看"；要让它执行，必须写成 `person.introduce()`。老师说访问方法"结果需要加（小括号）"，就是这个意思。

### 2.3 两种访问写法对照

| 要拿什么 | 写法 | 结果 |
|---|---|---|
| 属性 | `对象名.属性名` | 属性的值 |
| 方法（要它执行） | `对象名.方法名()` | 执行函数体，拿到 `return` 的值 |
| 成员名是变量或字符串 | `对象名["成员名"]` | 同上，只是成员名可以动态给 |

```javascript
console.log(person.name);        // "小智"
console.log(person["name"]);     // "小智"   —— 方括号里放字符串形式的成员名
```

> ★ 老师的定性：**"访问成员这个也非常重要，大家都必须要掌握。"**

## 三、构造函数：一个模板，批量造对象

### 3.1 为什么要模板

> ★ 老师的话：**"相似结构的这些对象，就是先写一个模板。"**

三个五个还能一个字面量一个字面量地写，十个二十个就得一遍遍抄；而且抄错一个，后面全要改。构造函数解决的就是这件事。

### 3.2 第一步：写模板

模板就是一个**普通函数**，用 `function` 的语法格式写，只是函数体里用 `this` 往"将来要造的那个对象"上加成员。

| 位置 | 写什么 |
|---|---|
| 开头 | 关键字 `function` |
| 函数名 | 构造函数名（首字母大写，如 `Student`） |
| 小括号里 | 形参（要传进来的数据，如 `name`、`age`） |
| 花括号里 | `this.成员名 = 值;`——属性、方法都这么挂 |

```javascript
// 第一步：写模板（构造函数）
function Student(name, age) {
    this.name = name;          // 属性：把参数 name 的值挂到新对象上
    this.age = age;            // 属性

    this.introduce = function () {     // 方法：值是一个函数
        return "大家好，我叫" + this.name + "，今年" + this.age + "岁。";
    };
}
```

### 3.3 第二步：`new` + 构造函数名 + 实参

> ★ 老师的话：**"用一个关键字加上构造函数。"** 那个关键字就是 `new`；**别忘了给造出来的东西起个名字。**

```javascript
var stu1 = new Student("小智", 20);
var stu2 = new Student("小明", 21);
var stu3 = new Student("小红", 19);     // 想要几个就 new 几个
```

| 两步 | 做什么 | 代码 |
|---|---|---|
| **第一步** | 写模板 | `function Student(name, age) { … }` |
| **第二步** | 用模板造实例 | `var stu1 = new Student("小智", 20);` |

> ⚠️ `new` 后面必须跟**构造函数名 + 一对小括号**。写成 `var stu1 = Student("小智", 20);`（少了 `new`）就不是实例化了，`this` 也指不到新造的对象，成员会挂到别处去。

### 3.4 实例对象与 `this`

- 用 `new` 造出来的对象叫**实例对象**，造一次就叫**实例化**一次。
- 构造函数里的 `this`，指的就是 `new` 刚造出来的那个实例；`this.name = name` 就是"给这个实例加一个 name 属性"。
- 老师说，这里面用到的 `this`（和 `new`）**是上一节学过的新关键字**，本节只是又用了一遍。

```javascript
console.log(stu1.name);            // 小智
console.log(stu1.introduce());     // 大家好，我叫小智，今年20岁。
console.log(stu3.age);             // 19
```

### 3.5 一个模板，三个对象

| 变量 | 实参 | 造出来的实例 |
|---|---|---|
| `stu1` | `"小智", 20` | 小智，20 岁 |
| `stu2` | `"小明", 21` | 小明，21 岁 |
| `stu3` | `"小红", 19` | 小红，19 岁 |

> 💡 **记忆点**：模板只写一次，数据在 `new` 的时候一个一个填进去。**模板决定"有哪些成员"，实参决定"每个成员是什么值"。**

## 四、对象造好了还能改：动态添加成员

### 4.1 空对象也是"造"出来的

> ★ 老师的话：**"这里的花括号，其实也是一个构造函数。"**

这个构造函数**系统里已经定义好了，不需要我们再去写它**；用它造出来的对象**"里面是空的，没有任何成员"**。

```javascript
var obj = {};        // 等同于用那个现成的构造函数造了一个空对象
```

### 4.2 添加属性：赋值就完事

> ★ 老师的话：**"对象中添加成员，可以通过对属性或方法赋值的方法来添加。"**

```javascript
var obj = {};               // 空对象
obj.name = "小智";           // 加一个属性
obj.age = 20;               // 再加一个
console.log(obj);           // { name: "小智", age: 20 }
```

### 4.3 添加方法：赋值号右边必须是函数

```javascript
obj.introduce = function () {
    return "大家好，我叫" + this.name + "，今年" + this.age + "岁。";
};

console.log(obj.introduce());     // 大家好，我叫小智，今年20岁。
```

老师说添加方法时"后面（要）跟一个函数"——因为方法的值本来就是一个函数，没有函数它只是普通属性。

> ⚠️ 右边忘了写 `function`，就成了给属性赋值；后面再 `obj.introduce()` 会报"不是一个函数"。

### 4.4 点与方括号：两种写法效果一样

```javascript
obj.name = "小智";          // 点：后面直接写成员名，不加引号
obj["name"] = "小智";       // 方括号：成员名写成字符串，要加引号
```

> ★ 老师说这两种方式**"效果是一样的，用哪个都一样"**。

| 写法 | 什么时候用 |
|---|---|
| 点 `obj.name` | 成员名是固定的、写死的 |
| 方括号 `obj["name"]` | 成员名是变量、是拼出来的（遍历时就靠它，见第五节） |

## 五、遍历对象：`for…in`

### 5.1 用途

> ★ 老师说这是"比较特别的一个"写法，**在 JS 里经常会用到**：它能把**"对象里面所有成员都展示出来"**，或者对**"里面所有成员执行一遍大括号里的操作"**。

### 5.2 语法

```javascript
for (var key in obj) {
    console.log(key);           // 成员名
    console.log(obj[key]);      // 成员值
}
```

> 💡 **读法**：对 `obj` 里的每一个成员，把它的**名字**交给 `key`，然后执行一遍大括号里的操作；对象有几个成员，就转几圈。

### 5.3 为什么取值必须用方括号（★最容易错）

| 写法 | 含义 | 结果 |
|---|---|---|
| `obj.key` | 去找一个**名字就叫 `key`** 的成员 | `undefined`（没有这个成员） |
| `obj[key]` | 用 `key` 里装的那个名字去找成员 | 成员的**值** |

因为 `key` 是**变量**，里面装的是 `"name"`、`"age"` 这样的字符串；`obj.key` 是"写死的名字"，`obj[key]` 才是"按变量里的名字去找"。

> ⚠️ 遍历时把 `obj[key]` 写成 `obj.key`，打印出来全是 `undefined`。

### 5.4 和 `for` 循环的区别

| | `for` | `for…in` |
|---|---|---|
| 小括号里 | 三个表达式：初始化; 条件; 更新 | 一个：`var 变量 in 对象` |
| 循环几次 | 自己控制 | 对象有几个成员就转几圈 |
| 循环变量拿到的是 | 数字（下标、计数） | **成员名（字符串）** |

> ★ 老师的话：**"循环里边用 `for…in` 也是很大的帮助，不过格式不太一样。"**

## 六、`Math` 对象：JS 自带的"数学工具箱"

### 6.1 是什么

> ★ 老师引入时的问法：**"我们今天要学习的一个特殊的对象——这个单词是什么意思？"**（`Math` 就是"数学"。）

- 它可以**"实现一些数学计算"**，这些计算**系统里早就写好了**，"让我们在编程的过程中不需要再（自己写）"。
- 用法和普通对象完全一样：`Math.成员名`。

> 💡 前面几节的对象都是**自己造**的，`Math` 是**现成**的——造对象、点成员、加小括号调用，这一套完全照旧，只是不用自己写模板。

### 6.2 常用成员表

| 成员 | 作用 | 例子 | 结果 |
|---|---|---|---|
| `Math.abs(x)` | 取 `x` 的绝对值 | `Math.abs(-5)` | `5` |
| `Math.floor(x)` | 向下取整（往小的方向取整） | `Math.floor(3.9)` | `3` |
| `Math.ceil(x)` | 向上取整（往大的方向取整） | `Math.ceil(3.1)` | `4` |
| `Math.max(a, b)` | 取较大的那个 | `Math.max(3, 8)` | `8` |
| `Math.min(a, b)` | 取较小的那个 | `Math.min(3, 8)` | `3` |
| `Math.random()` | 取 0~1 之间的随机小数 | `Math.random()` | `0.7382…` |

```javascript
console.log(Math.abs(-5));       // 5
console.log(Math.floor(3.9));    // 3
console.log(Math.ceil(3.1));     // 4
console.log(Math.max(3, 8));     // 8
console.log(Math.min(3, 8));     // 3
```

> ★ 老师说，对这些"常用的属性和方法"先有"一个初步的了解"就行，不用背，用的时候查。

### 6.3 `Math.random()` 的三个特点（★）

| 特点 | 说明 |
|---|---|
| **① 范围** | `0 ≤ 结果 < 1`——**会取到 0，但取不到 1**。老师特意点明"不包括 1" |
| **② 每次不同** | **"每一次调用输出的结果都不同"**，所以结果没法提前猜 |
| **③ 是小数** | 是"一个很长的小数"，0.4 几、0.3 几……，**不是整数** |

```javascript
console.log(Math.random());   // 0.4629137456…
console.log(Math.random());   // 0.0813572019…  每次都不一样
```

> ⚠️ `Math.random` 后面那对小括号不能省。省了就变成"拿这个函数本身"，不是拿随机数。

### 6.4 指定范围的随机整数：一条公式（★本节重点）

> ★ 老师的话：**"如果我们想要让它生成一个指定范围的随机整数，可以用算式去限制一下。"**

先定两个变量来限制上下限：`m` 是最小值，`n` 是最大值。拿 1~5 走一遍四步：

| 步骤 | 算式 | 结果落在 |
|---|---|---|
| ① 取随机小数 | `Math.random()` | `[0, 1)` |
| ② 乘上"整数的个数" `n - m + 1` | `Math.random() * 5` | `[0, 5)` |
| ③ 加上最小值 `m` | `Math.random() * 5 + 1` | `[1, 6)` |
| ④ 向下取整 | `Math.floor(Math.random() * 5 + 1)` | `1、2、3、4、5` |

> ★ 老师的话：**"n 减 m 加一，再加上 m，最后再做一个向下取整。"**

```javascript
// 求 [m, n] 范围内的随机整数（含 m，也含 n）
function randomInt(m, n) {
    return Math.floor(Math.random() * (n - m + 1) + m);
}

console.log(randomInt(1, 5));      // 1 ~ 5
console.log(randomInt(1, 10));     // 1 ~ 10
```

为什么是 `n - m + 1`：1~5 一共是 **5 个**整数，而 0~1 这一段长度是 1，乘以 5 正好把它切成 5 段，每段落一个整数。

> ⚠️ 少写"加一"：`Math.floor(Math.random() * (n - m) + m)` 永远取不到最大值 `n`。以 1~5 为例，它只能给 1~4。
>
> ⚠️ 忘了向下取整：拿到的是一串小数，不是整数，当数组下标用会直接取不到元素。

老师说上下取整两种都能用，"这里咱们用向下取整"——本节统一用 `Math.floor`。

### 6.5 案例一：随机点名（随机数 + 数组索引）

思路就三步：**名字放进数组 → 随机出一个索引 → 按索引取元素**。

```javascript
var arr = ["小智", "小明", "小红", "小刚", "小丽", "小华"];   // 6 个元素，索引 0~5

var index = Math.floor(Math.random() * arr.length);    // 0~5 的随机整数
console.log(arr[index]);                               // 随机取到一个名字
```

老师说这个例子里数组放了 6 个元素，**索引号就是 0 到 5**；而**"减一指的是最后一个元素"**——最后一个元素的索引是 `length - 1 = 5`。

| 元素个数 | 索引范围 | 乘什么 |
|---|---|---|
| 6 | `0 ~ 5` | `arr.length`（= 6） |

套 6.4 的公式就能对上：`m = 0`、`n = 5`，于是 `n - m + 1 = 6`，正好就是 `arr.length`，所以写成 `Math.random() * arr.length` 就行。

> ⚠️ 不取整就当下标用：`arr[0.73]` 这种下标找不到元素，结果是 `undefined`，必须先 `Math.floor`。
>
> 💡 **记忆点**：`arr[随机数]` —— 数组名后面那对方括号里放什么，就取哪个元素。位置换成随机整数，就成了"随机点名"。

放到网页上，就是一个按钮加一次弹窗：

```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>随机点名</title>
</head>
<body>
    <button onclick="pick()">随机点一个</button>

    <script>
        var arr = ["小智", "小明", "小红", "小刚", "小丽", "小华"];

        function pick() {
            var index = Math.floor(Math.random() * arr.length);
            alert(arr[index]);
        }
    </script>
</body>
</html>
```

## 七、综合案例：猜数字

### 7.1 规则

| 谁 | 做什么 |
|---|---|
| 程序 | 先随机一个 **1~10 之间的整数**（不告诉用户） |
| 用户 | 在弹窗里输入自己猜的数 |
| 程序 | 大了 → "太大了"；小了 → "猜小了"；相等 → "恭喜你猜对了" |

### 7.2 先出目标值

老师说随机整数"里面两个参数，这两个范围设置成 **1 和 10**"——就是 6.4 写的那个函数：

```javascript
var target = randomInt(1, 10);      // 1~10 的随机整数
```

如果不用函数、直接写，就是同一个公式：

```javascript
var target = Math.floor(Math.random() * 10) + 1;    // 1~10
```

### 7.3 三种结果：一个多分支

> ★ 老师说这就是"之前学过的一种三种情况输出"——`if-else if-else`。

```javascript
if (num > target) {
    alert("太大了");
} else if (num < target) {
    alert("猜小了");
} else {
    alert("恭喜你猜对了");
}
```

| 情况 | 条件 | 提示 |
|---|---|---|
| 猜大了 | `num > target` | 太大了 |
| 猜小了 | `num < target` | 猜小了 |
| 猜对了 | 剩下的一种（`num === target`） | 恭喜你猜对了 |

### 7.4 一直猜：循环

猜一次就结束不行，得让用户反复猜，所以外面套一个循环。

> ★ 老师的话：**"加入一个循环……初始条件是真，也就是说我们第一次肯定是要进到循环里。"**

```javascript
while (true) {
    // 循环体
}
```

`true` 就是"真"，条件永远是真 → 循环会一直转，**必须有地方能跳出去**，否则就是死循环。

### 7.5 三种必须"兜住"的情况（★易错重点）

老师说写循环时"会出现一些死循环的情况，比如说没有正确的输入"，还专门讲了一句话：**如何避免由于用户输入有误造成的死循环。**

| # | 情况 | 判断 | 处理 |
|---|---|---|---|
| ① | 用户点了**取消**，什么都没输入 | `num === null` 或 `num === ""` | 直接退出循环 |
| ② | 输入的**不是数字** | `isNaN(num)` 为真 | 弹窗"请输入有效数字"，跳过本次，让用户重新输入 |
| ③ | **猜对了** | 三种分支的最后一支 | 提示后退出循环 |

**情况 ② 用到的 `continue`**：老师说"在循环里面还有这个关键字，可以跳过（本次循环），重新进入循环，把本次循环的代码给退出，让用户重新输入数字"。

**情况 ② 用到的 `isNaN`**：

> 💡 `isNaN(x)` 问的是"它**不是**一个数字吗"。所以 `isNaN("abc")` 是 `true`，`isNaN("12")` 是 `false`；`if (isNaN(num))` 读作"如果用户输的不是数字"。

**比大小之前还有一步：转成数字型**——`prompt` 拿到的永远是字符串，要"转换成数字型的数据"再比大小。

| 语句 | 作用 |
|---|---|
| `break;` | 结束整个循环，跳到循环后面 |
| `continue;` | 结束**本次**循环，回到循环开头重新判断 |

### 7.6 完整代码

```javascript
// ① 目标值：1~10 的随机整数
var target = Math.floor(Math.random() * 10) + 1;

// ② 一直猜，直到猜对或者用户取消
while (true) {
    var num = prompt("请输入 1 到 10 之间的整数");

    // 情况一：点了取消，或者什么都没输 → 结束
    if (num === null || num === "") {
        break;
    }

    // 情况二：输的不是数字 → 提示后重新输入
    if (isNaN(num)) {
        alert("请输入有效数字");
        continue;
    }

    // ③ 转成数字型，才能比大小
    num = parseInt(num);

    // ④ 三种结果
    if (num > target) {
        alert("太大了");
    } else if (num < target) {
        alert("猜小了");
    } else {
        alert("恭喜你猜对了");
        break;
    }
}
```

### 7.7 逐段对照

| 段 | 代码 | 为什么这么写 |
|---|---|---|
| 出题 | `var target = Math.floor(Math.random() * 10) + 1;` | 1~10 的随机整数就是本节的公式，`m = 1`、`n = 10` |
| 撑住循环 | `while (true) { … }` | 初始条件为真，第一次一定进循环 |
| 收输入 | `var num = prompt("…");` | `prompt` 的返回值必须用变量接住 |
| 兜底 ① | `if (num === null \|\| num === "") break;` | 取消了就没必要再问 |
| 兜底 ② | `if (isNaN(num)) { alert("请输入有效数字"); continue; }` | 不是数字就不往下比，免得死循环 |
| 转类型 | `num = parseInt(num);` | 字符串转数字型 |
| 判断 | `if / else if / else` | 大、小、相等三种情况 |
| 结束 | `break;` | 猜对了跳出循环 |

> ⚠️ `prompt` 拿到的是**字符串**。两个字符串比大小是按字符逐个比的（`"10" < "9"` 居然成立），所以"转换成数字型"这一步不能省。

## 九、易错点速查

| # | 错误写法 | 后果 | 正确写法 |
|---|---|---|---|
| 1 | 对象造完不用变量接 | 对象找不到了，成员一个也用不上 | `var obj = {};` |
| 2 | `person.introduce` | 拿到函数本身，**不执行** | `person.introduce()` |
| 3 | `var stu1 = Student("小智", 20);` | 少了 `new`，没有实例化 | `var stu1 = new Student("小智", 20);` |
| 4 | 遍历时写 `obj.key` | 全打印 `undefined` | `obj[key]` |
| 5 | `Math.random()` 忘了取整 | 下标是小数，取不到元素 | `Math.floor(…)` |
| 6 | 公式里 `n - m` 少加一 | 永远取不到最大值 | `n - m + 1` |
| 7 | `prompt` 的值直接比大小 | 字符串比较会出鬼 | 先 `parseInt` |
| 8 | 输入非数字不判断 | 一直弹提示，死循环 | `isNaN` + `continue` |
