## 一、复习：基本数据类型

### 1.1 布尔型

- **有两个值：真（`true`）或假（`false`）**；
- **主要用于判断逻辑结果**。

### 1.2 数字型

#### （1）整数

- **整数就是没有小数的**；
- **除十进制以外，还有二进制、八进制、十六进制**；
- ⚠️ **最常用的是十进制**。

#### （2）浮点数

- 就是**带小数点的数据**；
- **两种表示方法**：

| 表示方法 | 说明 | 例子 |
|---|---|---|
| **① 普通表示法** | 直接写出来 | `2.15` |
| **② 科学计数法** | 用 `e` 表示"乘以 10 的多少次方" | **`2.15e3` 表示 2.15×10³**（即 2150） |

### 1.3 字符串型（本节复习的第三个重点）

#### （1）作用

- **主要用于表示文本**；
- 各种文字、符号都可以。

#### （2）怎么表示：用引号包裹

> **把内容用引号"包裹"起来，就表示字符串。**

- 引号可以用：
  - **单引号** `' '`
  - **双引号** `" "`
- 只要把内容**用引号括起来**就行。

#### （3）引号的嵌套（重要，容易出错）

**需求**：如果**字符串的内容里本身要显示引号**，怎么办？

> **就用"跟它不同的引号"去嵌套。**

| 写法 | 是否可行 |
|---|---|
| **单引号嵌套双引号** | ✅ 可以 |
| **双引号嵌套单引号** | ✅ 可以 |
| **单引号嵌套单引号**（相同符号） | ❌ **会出现错误** |

#### （4）相同引号嵌套时的解决办法：转义

> **在里面的那个引号前面加一个反斜杠 `\` 进行转义。**

**怎么判断哪个要转义**：
- **第一个引号是开头，最后一个引号是结尾**；
- **中间的那些引号**需要**在前面加斜杠转义**；
- 这样才能**正确地把引号显示出来**。

**老师总结的规则**：
> **只要是相同的符号嵌套，就需要转义——也就是在前面加一个斜杠 `\`。**

## 二、数据类型转换（本节第一个重点）

### 2.1 转换为布尔型数据

**做法**：用一个命令（`Boolean()`）**把数据转换成布尔型数据**，结果只有两个值：**真**或**假**。

**转换规则（要背）**：

| 原数据 | 转换结果 | 说明 |
|---|---|---|
| **空的**、**`0`**、代表"**空**"或"**没有**"含义的数据 | **`false`（假）** | 前面这一部分，**只要是空的或者是 0**，都转成假 |
| **有内容的字符串** | **`true`（真）** | 有内容的都会转换成真 |

> **一句话记忆**：**"空"和"零"是假，有内容是"真"。**

### 2.2 转换为数字型数据

**共三个方法**：

#### （1）`parseInt()` —— 转成整型

- **不管转换的内容带不带小数点，结果都是一个整数部分**；
- ⚠️ **如果带小数，会把小数点后面的部分直接舍弃掉**；
- **注意：是"舍弃"，不是"四舍五入"**。

#### （2）`parseFloat()` —— 转成浮点型（小数）

- 它的含义就是**浮点数**的意思；
- **所有的数据都可以进行转换**；
- **转换的结果是可以带小数点的**。

#### （3）`Number()` —— 把布尔型转换为数字

- 如果需要**把布尔型数据转换为数字**，就要用 `Number()`；
- **对应关系**：

| 布尔值 | 转成数字 |
|---|---|
| `true` | **1** |
| `false` | **0** |

### 2.3 隐式转换（自动化转换，很实用）

- **定义**：还有一种转换方式叫**隐式转换**——就是**它会自动转换**，**你不用去进行专门的转换**；
- **某些情况下，它会按照既定的规则自动地进行转换**；
- **对开发人员来说比较方便**。

**课堂举的例子**：

| 表达式 | 发生了什么 | 结果 |
|---|---|---|
| 引号包着的数字 **做减法** | **自动把字符串转成数字型数据**再运算 | 如 `"13" - 3` → **10** |
| 同样情况做**乘法 / 除法** | 同样是**默认先转成数字型数据再运算** | 有结果 |
| **数字 + 空字符串** | 也能得到结果 | 如 `13 + ""` → **13** |
| **布尔型 + 数字** | 也会按规则转换后运算 | 有结果 |

> **用途**：以后写代码的时候，**可以利用这种隐式转换**去做判断/验证——**有的时候不需要专门去做数据类型的转换**就能实现。

## 三、运算符

### 3.1 算术运算符与"取余"的坑

- 加减乘除比较**简单**；
- ⚠️ **需要注意的就是"取余（`%`）"这个运算**：

> **取余运算结果的正负，取决于左边的数（被除数），和右边的数无关。**
> **所以只要看左边数的正负就可以了。**

### 3.2 自增 `++` 与自减 `--`（重点）

**符号**：**两个加号 `++`** 以及**两个减号 `--`**。

**位置决定名称**：

| 位置 | 名称 |
|---|---|
| 运算符放在**前面** | **前置**（如 `++a`） |
| 运算符放在**后面** | **后置**（如 `a++`） |

**⚠️ 计算结果取决于符号的位置**：

| 写法 | 返回什么 | 举例（设 `a` 原来是 2） |
|---|---|---|
| **前置** `++a` | **自增之后的结果** | 先自增 1 → `a` 变成 **3** → **输出的结果是 3** |
| **后置** `a++` | **自增之前的结果** | **先返回原来的值 2**，然后再对 `a` 自增 → 此时 `a` 里面的值变成 **3** |

> **老师的学习提示**：
> **咱们专科阶段的学习，基本上用到的是"后置"的多一些**；
> 而且**主要是用于"循环"里面去做计数**。

### 3.3 字符串拼接：用 `+` 号

#### （1）原理

> **把两段比较短的字符串"首尾相连"，形成一个长的字符串。**

- 进行拼接用的**也是加号 `+`**；
- ⚠️ **关键特点**：
  > **加号的左边或者右边，只要有一个是字符串，那么这个加号就是"连在一起（拼接）"的意思**，而不是数学加法。

#### （2）课堂代码示例（完整还原）

**第 1 步：定义两个变量存用户信息**
```javascript
var name = prompt("请输入用户名：");   // 存储用户名
var sex  = prompt("请输入性别：");     // 存储用户的性别
```
- 老师说明：**实际开发中经常会这样**——分别获取用户输入的**姓名、性别，或者更多的一些信息**。

**第 2 步：建立新变量存放拼接结果**
```javascript
var str = name + "，" + sex;   // 拼接后的字符串
```

**第 3 步：理解中间那一段**
- **直接用"变量名 + 变量名"进行拼接**；
- 中间加的那个东西，是**为了让输出的结果有一个好看的展示**：
  - 在第一个变量和第二个变量中间，**加一个符号**（如逗号）；
  - 这个符号要**用一对引号括起来**才算字符串——**在程序里面，需要用引号括起来表示字符串**。
- 这样就实现了**三个内容进行运算**，结果是**三个内容拼在一起**。

**第 4 步：输出验证**
- 最后用**输出语句**在控制台把内容输出，看拼接的结果。

**拼接的三种写法**（都可以）：
1. **变量 + 变量**
2. **变量 + 字符串**（变量之间加一个字符串）
3. **变量 + 变量 + 字符串** 等组合

### 3.4 模板字符串（重点，比 `+` 更方便）

#### （1）它是什么

> 除了用加号拼接，还有一种方法叫做**模板字符串**——**不用加号了**。

#### （2）写法（两个要点）

```javascript
var str = `用户名：${name}，性别：${sex}`;
```

1. **以反引号 `` ` `` 开头，以反引号 `` ` `` 结尾**
   （注意：反引号是键盘左上角那个键，**不是单引号**）
2. **需要拼接的变量写在 `${ }` 结构里**
   - 就是 **美元符号 `$` + 一对大括号 `{ }`**；
   - **变量名写在大括号里面**。

#### （3）两个优点

| 优点 | 说明 |
|---|---|
| **代码更短** | 不需要再写一堆加号和引号 |
| **更灵活** | 中间想加别的符号（比如**想加一个句号**），**直接在反引号里写就行**，不用管什么符号 |

**对比感受一下**：
- **用 `+` 拼接**：想再加一个句号 → **还得再写一个加号、再写一对引号、中间再加句号**，很啰嗦；
- **用模板字符串**：想加句号 → **直接在模板里面写就完了**。

> **结论**：**两种方式都可以实现字符串的拼接，用哪一种都可以。**

### 3.5 赋值运算符

#### （1）回顾：`=` 是"赋值"，不是"等于"

> **对变量来说，`=` 这个符号就是一个"赋值"的作用。**

- `变量a = 1` → 意思是**把 1 这个值赋值给变量 a**；
- `变量b = 2` → 就是把值 2 **赋值给变量 b**；
- ⚠️ **它不是简单意义上的"等于"**；**赋值是从右向左**（把右边的值赋给左边的变量）。

#### （2）复合赋值运算符：`+=` `-=` `*=` `/=`（加等 / 减等 / 乘等 / 除等）

**含义：运算并赋值**，相当于做了一个**简写**。

| 写法 | 等价于 | 说明 |
|---|---|---|
| `a += b` | `a = a + b` | **加并赋值** |
| `a -= b` | `a = a - b` | **减并赋值** |
| `a *= b` | `a = a * b` | **乘并赋值** |
| `a /= b` | `a = a / b` | **除并赋值** |

#### （3）⚠️ 本节最容易错的点：`+=` 对字符串也有效

> **只有 `+=` 对字符串是有作用的。**

**例子**：
```javascript
var a = "abc";
a += "另外一个字符串";   // 意思是 a = a + 字符串
// 结果：两个字符串被"拼接"到一起
```
- **含义**：`a += 另一个字符串` 就是 **`a = a + 字符串`**，
- 也就是**把这两个字符串拼接到一起**，**所以 `a` 的结果就成了拼接后的新字符串**。

#### （4）`-=` `*=` `/=` 只能用于数字

> ⚠️ **`-=`、`*=`、`/=` 都只能对数字型数据进行操作。**
> 它的含义和 `+=` 是一样的，都是"**运算并赋值**"。
