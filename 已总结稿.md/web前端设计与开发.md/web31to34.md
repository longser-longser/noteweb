## 一、开场回顾：对象怎么用，`Math` 那张表

### 1.1 对象：成员、创建、访问

老师先用几句话把前面学的对象收了口：对象由**属性**和**方法**组成，属性描述特征，方法描述行为（写在对象里的函数）。

| 操作 | 写法 | 说明 |
|---|---|---|
| 创建（字面量） | `var obj = { name: "小智", age: 18 };` | 花括号里写"成员名: 值"，成员之间用逗号隔开 |
| 创建（构造函数） | `new 构造函数()` | 用 `new` 生成一个实例对象 |
| 访问属性 | `obj.name` | 对象名 + 点 + 成员名 |
| 调用方法 | `obj.say()` | 方法后面要加小括号 |
| 方括号访问 | `obj["name"]` | 方括号里是**字符串**，要加引号 |
| 添加 / 修改成员 | `obj.age = 20;` | 用赋值号，等号左边是成员，右边是值 |

> 💡 这一节学的日期和数组**都是对象**，所以"对象名.方法名()"这套动作会从头用到尾。

`Math` 是上一节的主角，本节开场又把它的一张表过了一遍：

| 成员 | 作用 | 例子 | 结果 |
|---|---|---|---|
| `Math.PI` | 圆周率 | `Math.PI` | `3.141592653589793` |
| `Math.abs(x)` | 绝对值 | `Math.abs(-5)` | `5` |
| `Math.max(a, b, …)` | 最大值 | `Math.max(3, 8)` | `8` |
| `Math.min(a, b, …)` | 最小值 | `Math.min(3, 8)` | `3` |

## 二、日期对象：先造一个"时间"

### 2.1 为什么需要日期对象

页面上要显示"当前时间"、要做倒计时、要统计一段代码跑了多久，都得先有一个能表示"某个时刻"的东西。JavaScript 把这件事交给了内置的**日期对象 `Date`**。

> ⚠️ `Date` 是内置对象，用之前要先用 `new` 造一个出来。

### 2.2 创建方式一：不写参数 = 当前时间

小括号里什么都不写，拿到的是**运行这行代码时**的系统时间：

```javascript
var now = new Date();
console.log(now);   // 当前系统时间
```

> 💡 这个"当前时间"来自运行代码的那台电脑；电脑时间不准，取到的就不准。

### 2.3 创建方式二：数字参数（年、月、日、时、分、秒）

按顺序写数字，就能造出一个指定时刻：

```javascript
var d = new Date(2023, 11, 13, 9, 35, 40);
console.log(d);   // 2023 年 12 月 13 日 09:35:40
```

| 参数位置 | 含义 | 取值范围（正常情况） |
|---|---|---|
| 第 1 个 | 年 | 四位数，如 `2023` |
| 第 2 个 | 月 | **0~11** |
| 第 3 个 | 日 | 1~31 |
| 第 4 个 | 时 | 0~23 |
| 第 5 个 | 分 | 0~59 |
| 第 6 个 | 秒 | 0~59 |

> ⚠️ **月份是从 0 开始数的**：`0` 表示一月，`11` 表示十二月。上面写 `11`，出来的才是 12 月。
>
> ⚠️ 数字超出范围不会报错，会自动往相邻的年份/月份进位：传 `12` 表示"明年一月"。

```javascript
console.log(new Date(2023, 12, 1).getFullYear());   // 2024
console.log(new Date(2023, 12, 1).getMonth());      // 0
```

> 💡 年和月是必须给的，后面的日、时、分、秒可以省略，省略时使用默认值。
>
> 💡 星期几不用自己算，日期对象内部会算好。

### 2.4 创建方式三：字符串参数

也可以直接把一个时间字符串传进去：

```javascript
var d = new Date("2023-12-13 09:35:40");
console.log(d);   // 2023 年 12 月 13 日 09:35:40
```

> ⚠️ 整个字符串要加引号；年月日之间用**短横线**连接，时分秒之间用**冒号**连接。

### 2.5 三种创建方式对照

| 写法 | 拿到的时间 | 什么时候用 |
|---|---|---|
| `new Date()` | 当前系统时间 | 显示现在几点、算耗时、倒计时取"现在" |
| `new Date(2023, 11, 13, 9, 35, 40)` | 指定的年月日时分秒 | 时间由几个数字分别给出时 |
| `new Date("2023-12-13 09:35:40")` | 指定的年月日时分秒 | 时间是一整串现成字符串时 |

## 三、把时间拆开：`get` 系列

### 3.1 年月日：`getFullYear` / `getMonth` / `getDate`

```javascript
var d = new Date(2023, 11, 13, 9, 35, 40);

console.log(d.getFullYear());        // 2023
console.log(d.getMonth());           // 11
console.log(d.getMonth() + 1);       // 12
console.log(d.getDate());            // 13
```

| 方法 | 返回 | 注意 |
|---|---|---|
| `getFullYear()` | 四位年份 | 直接就是要的年份 |
| `getMonth()` | 0~11 | **显示给人看时要 +1** |
| `getDate()` | 1~31 | 是"这个月的第几天"，不是月份 |

> ⚠️ `getMonth()` 返回 `11` 不代表十一月，而是十二月。新手最常在这里少加 1。
>
> 💡 `getDate()` 里的 `Date` 是"日期（几号）"，不是"日期对象"，别和构造函数混了。

### 3.2 星期：`getDay()` + 一个数组

`getDay()` 返回的是 **0~6** 的数字：

| 返回值 | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| 星期 | 星期日 | 星期一 | 星期二 | 星期三 | 星期四 | 星期五 | 星期六 |

要显示成中文，就建一个数组，把返回值当**索引**去取：

```javascript
var weeks = ["星期日", "星期一", "星期二", "星期三", "星期四", "星期五", "星期六"];
var d = new Date(2023, 11, 13, 9, 35, 40);

console.log(d.getDay());             // 3
console.log(weeks[d.getDay()]);      // 星期三
```

> 💡 数组索引从 0 开始，`getDay()` 也正好返回 0~6，两者**天然对得上**，所以可以直接 `weeks[d.getDay()]`。
>
> ⚠️ `0` 是星期日，不是星期一；`getDay()` 也不是"这个月第几天"（那是 `getDate()`）。

### 3.3 时分秒毫秒

```javascript
var d = new Date(2023, 11, 13, 9, 35, 40);

console.log(d.getHours());           // 9
console.log(d.getMinutes());         // 35
console.log(d.getSeconds());         // 40
console.log(d.getMilliseconds());    // 0
```

| 方法 | 返回范围 | 含义 |
|---|---|---|
| `getHours()` | 0~23 | 小时（24 小时制） |
| `getMinutes()` | 0~59 | 分钟 |
| `getSeconds()` | 0~59 | 秒 |
| `getMilliseconds()` | 0~999 | 毫秒 |

### 3.4 时间戳：`getTime()`

`getTime()` 返回一个**毫秒数**：从 1970 年 1 月 1 日 0 点整（UTC）算起，到这个时刻一共过了多少毫秒。

```javascript
var d = new Date(2023, 11, 13, 9, 35, 40);

console.log(d.getTime());   // 毫秒数（具体数值随运行环境的时区变化）
```

> 💡 时间戳可以理解成"一根数轴上的刻度"：越晚的时间数值越大，两个时间戳**相减**就是时间差（毫秒）。
>
> ⚠️ 单位是**毫秒**，不是秒；换算成秒要除以 1000。

### 3.5 `get` 系列总表

| 方法 | 返回什么 | 课例（2023-12-13 09:35:40，星期三） |
|---|---|---|
| `getFullYear()` | 四位年份 | `2023` |
| `getMonth()` | 0~11 的月份 | `11` |
| `getDate()` | 1~31 的日 | `13` |
| `getDay()` | 0~6 的星期 | `3` |
| `getHours()` | 0~23 的小时 | `9` |
| `getMinutes()` | 0~59 的分 | `35` |
| `getSeconds()` | 0~59 的秒 | `40` |
| `getMilliseconds()` | 0~999 的毫秒 | `0` |
| `getTime()` | 毫秒时间戳 | 毫秒数 |

## 四、改时间：`set` 系列

### 4.1 `set` 就是"设置"

老师说，`set` 这个单词在电子闹钟的按键旁边就能看到，它的意思就是**设置**。日期对象里带 `set` 的方法，都是用来改时间的。

### 4.2 设置年月日

```javascript
var d = new Date(2026, 0, 15, 8, 0, 0);   // 基准时间：2026 年 1 月 15 日 08:00:00

d.setFullYear(2026);                      // 设置年份
d.setMonth(7);                            // 设置月份：7 表示 8 月
d.setDate(1);                             // 设置日
d.setHours(14);                           // 设置小时
d.setMinutes(30);                         // 设置分钟
d.setSeconds(0);                          // 设置秒

console.log(d.getFullYear());             // 2026
console.log(d.getMonth() + 1);            // 8
console.log(d.getDate());                 // 1
console.log(d.getHours());                // 14
console.log(d.getMinutes());              // 30
console.log(d.getSeconds());              // 0
```

> ⚠️ 设置月份时同样要 **减 1**：想设成 8 月，参数要写 `7`。
>
> 💡 设置完不要凭想象，马上用 `get` 取出来打印一遍，才能真正确认改对了。

### 4.3 时分秒也能设

| 方法 | 作用 |
|---|---|
| `setFullYear(年)` | 改年份 |
| `setMonth(月)` | 改月份（0~11） |
| `setDate(日)` | 改"几号" |
| `setHours(时)` | 改小时 |
| `setMinutes(分)` | 改分钟 |
| `setSeconds(秒)` | 改秒 |

### 4.4 设置改的是这个日期对象本身

`set` 系列不是"返回一个新时间"，而是**直接把这个日期对象改掉**。所以设置之后再 `get`，取到的就是改过之后的值（上面的代码就是这么验证的）。

## 五、把时间变成人看的样子：补零、星期、拼接

### 5.1 直接拼会出什么问题

把 `get` 到的数字直接连起来，会有三个毛病：

| 毛病 | 例子 | 正确处理 |
|---|---|---|
| 月份少 1 | `getMonth()` 给 `8`，直接显示成"8 月" | `getMonth() + 1` → 9 月 |
| 一位数不补零 | 9 点 5 分显示成 `9:5` | 补成 `09:05` |
| 星期是数字 | `getDay()` 给 `3` | `weeks[3]` → 星期三 |

### 5.2 补零：三元表达式

```javascript
var h = 9;
h = h < 10 ? "0" + h : h;

console.log(h);   // "09"
```

三元表达式的格式是：**条件 ? 条件成立时的值 : 条件不成立时的值**。

> ⚠️ 条件是 `h < 10`，不是 `h <= 10`：10 本身已经是两位数，不需要补零。
>
> 💡 补零的本质是"把数字变成字符串再拼一个 `"0"`"，所以结果的数据类型变成了字符串。

### 5.3 星期用数组换成中文

见 3.2：把 `["星期日", …, "星期六"]` 存好，用 `getDay()` 的返回值当下标。

### 5.4 完整的 `formatDate`

把"取值 → 补零 → 拼接"串起来，封装成一个函数：

```javascript
function formatDate(date) {
    var weeks = ["星期日", "星期一", "星期二", "星期三", "星期四", "星期五", "星期六"];

    var y = date.getFullYear();
    var m = date.getMonth() + 1;
    var d = date.getDate();
    var h = date.getHours();
    var mi = date.getMinutes();
    var s = date.getSeconds();

    m = m < 10 ? "0" + m : m;
    d = d < 10 ? "0" + d : d;
    h = h < 10 ? "0" + h : h;
    mi = mi < 10 ? "0" + mi : mi;
    s = s < 10 ? "0" + s : s;

    return `${y}年${m}月${d}日 ${h}:${mi}:${s} ` + weeks[date.getDay()];
}

console.log(formatDate(new Date(2023, 11, 13, 9, 35, 40)));
console.log(formatDate(new Date(2026, 7, 1, 14, 5, 9)));
```

运行结果：

```text
2023年12月13日 09:35:40 星期三
2026年08月01日 14:05:09 星期六
```

### 5.5 这段代码拆开看

| 步骤 | 代码 | 作用 |
|---|---|---|
| ① 取各部分 | `getFullYear / getMonth / getDate / …` | 把时间拆成一个个数字 |
| ② 月份 +1 | `date.getMonth() + 1` | 把 0~11 换成 1~12 |
| ③ 补零 | `m < 10 ? "0" + m : m` | 一位数前面补 0 |
| ④ 拼年月日时分秒 | `` `${y}年${m}月${d}日 ${h}:${mi}:${s} ` `` | 模板字符串，`${}` 里放变量 |
| ⑤ 接星期 | `+ weeks[date.getDay()]` | 用加号把"星期几"接在后面 |

> 💡 模板字符串用**反引号**包起来，里面用 `${变量}` 占位；它和加号 `+` 都能拼字符串，这一段是两种写法混用的。

## 六、案例一：统计一段代码跑了多久

### 6.1 思路

在代码开始前记一个时间戳，代码跑完再记一个时间戳，两个一减就是这段代码花掉的毫秒数。

### 6.2 取时间戳的两种常见写法

| 写法 | 说明 |
|---|---|
| `new Date().getTime()` | 先造当前时间对象，再调 `getTime()` |
| `+new Date()` | 用加号把日期对象直接转成数字（本节代码用的是这一种） |

> 💡 日期对象前面加一个 `+`，效果和调 `getTime()` 一样，都是拿到毫秒时间戳。

### 6.3 完整代码

```javascript
var start = +new Date();          // 开始时间的时间戳（毫秒）

var sum = 0;
for (var i = 1; i <= 1000000; i++) {
    sum += i;
}

var end = +new Date();            // 结束时间的时间戳（毫秒）

console.log(sum);                 // 500000500000
console.log("耗时：" + (end - start) + " 毫秒");
```

### 6.4 结果与单位

| 输出 | 说明 |
|---|---|
| `500000500000` | 1 加到 1000000 的结果，用来证明中间真的跑了循环 |
| `耗时：8 毫秒` | 具体毫秒数随电脑性能变化，不是固定值 |

> ⚠️ 两个时间戳相减，单位还是**毫秒**。要换成秒就除以 1000，换成分钟再除以 60。
>
> 💡 这个套路不只用来算循环：后面测一段请求、一个动画、一次渲染花了多久，都是"开始记一个、结束记一个、相减"。

## 七、案例二：活动倒计时

### 7.1 思路：两个时间戳相减

倒计时算的是"**活动开始时间** 距离 **现在** 还有多久"：

1. 用 `new Date("活动开始时间")` 造出目标时间；
2. 用 `new Date()` 造出当前时间；
3. 分别用 `getTime()` 取时间戳，**目标减当前**，得到一个毫秒差；
4. 把这个毫秒差换算成天、小时、分钟、秒。

### 7.2 单位换算

| 单位 | 换算公式 | 说明 |
|---|---|---|
| 天 | `Math.floor(diff / (1000 * 60 * 60 * 24))` | 一天 = 24 小时 |
| 小时 | `Math.floor(diff / (1000 * 60 * 60) % 24)` | 先算总小时，再对 24 取余 |
| 分钟 | `Math.floor(diff / (1000 * 60) % 60)` | 先算总分钟，再对 60 取余 |
| 秒 | `Math.floor(diff / 1000 % 60)` | 先算总秒，再对 60 取余 |

> 💡 为什么小时、分钟、秒都要取余？因为"总小时数"里包含了整天，"总分钟数"里包含了整小时——取余才是"剩下不够进位的部分"。

### 7.3 完整代码

```javascript
var target = new Date("2026-11-11 00:00:00");   // 活动开始时间
var now = new Date();                           // 当前时间

var diff = target.getTime() - now.getTime();    // 两个时间戳相减，单位是毫秒

var day = Math.floor(diff / (1000 * 60 * 60 * 24));        // 天
var hour = Math.floor(diff / (1000 * 60 * 60) % 24);       // 小时
var minute = Math.floor(diff / (1000 * 60) % 60);          // 分钟
var second = Math.floor(diff / 1000 % 60);                 // 秒

console.log("距活动开始还有 " + day + " 天 " + hour + " 小时 " + minute + " 分 " + second + " 秒");
```

运行结果（示例，具体数字随当前时间变化）：

```text
距活动开始还有 18 天 22 小时 44 分 51 秒
```

### 7.4 坑点

> ⚠️ 一定是"目标时间 − 当前时间"。写反了会得到负数，倒计时就成了"已经开始了多久"。
>
> ⚠️ 每一步都要 `Math.floor` 向下取整，否则会算出"18.7 天"这种带小数的结果。
>
> ⚠️ 取余的除数要写对：小时对 24 取余，分钟和秒对 60 取余。

> 💡 记住这串换算：1 天 = 24 小时 = 1440 分钟 = 86400 秒 = 86400000 毫秒。

## 八、数组对象：它也是对象

### 8.1 `typeof` 数组得到的是 `"object"`

数组看起来和普通对象不一样（用方括号、有索引、有 `length`），但它的类型归到底还是对象：

```javascript
var arr = [1, 2, 3];
console.log(typeof arr);   // object
```

> 💡 所以前面学的"用点调方法"在这里完全适用：`arr.push()`、`arr.join()` 都是"对象.方法()"。

### 8.2 两种创建方式

```javascript
var arr1 = ["苹果", "香蕉", "橙子"];             // 字面量
var arr2 = new Array("苹果", "香蕉", "橙子");    // 构造函数
var arr3 = new Array();                         // 空数组
var arr4 = [1, "苹果", [2, 3]];                  // 元素类型可以不同，还能嵌套

console.log(arr1);
console.log(arr2);
console.log(arr3);
console.log(arr4);
```

| 写法 | 说明 |
|---|---|
| `[]` 字面量 | 最常用，直接把元素写在方括号里 |
| `new Array(元素, 元素, …)` | 用构造函数创建，小括号里写元素 |
| `new Array()` | 不写元素，得到一个空数组 |

### 8.3 元素可以是任意类型

数组里不要求所有元素长得一样：可以放数字、字符串、对象，甚至可以再放一个数组（嵌套数组，第 17—18 节学过）。

> 💡 数组里放对象，就是"一个列表里每一行都是一条完整数据"的雏形。

### 8.4 怎么确认"它是不是数组"：`Array.isArray`

`typeof` 只能告诉你"是个对象"，认不出数组。要判断是不是数组，用 `Array.isArray()`：

```javascript
var arr1 = ["苹果", "香蕉", "橙子"];

console.log(typeof arr1);              // object
console.log(Array.isArray(arr1));      // true
console.log(Array.isArray("苹果"));    // false
```

| 方式 | 写法 | 结果 | 能不能认出数组 |
|---|---|---|---|
| `typeof` | `typeof arr` | `"object"` | ❌ 只能看出是对象 |
| `Array.isArray` | `Array.isArray(arr)` | `true` / `false` | ✅ 可以 |

> ⚠️ `typeof` 是**运算符**，后面直接跟值；`Array.isArray` 是**方法**，要用点调用、加小括号。
>
> 💡 什么时候用？要确认一个值到底是不是数组时，就用它。

## 九、增与删：五个方法里的前四个

### 9.1 `push` / `unshift` / `pop` / `shift` 总表

| 方法 | 操作位置 | 做什么 | 返回值 |
|---|---|---|---|
| `push(元素)` | 末尾 | 添加一个元素 | **添加后的新长度** |
| `unshift(元素)` | 开头 | 添加一个元素 | 本节未讲 |
| `pop()` | 末尾 | 删除一个元素 | 本节未讲 |
| `shift()` | 开头 | 删除一个元素 | 本节未讲 |

> 💡 记法：`push` / `pop` 是一对，都在**末尾**；`unshift` / `shift` 是一对，都在**开头**。`push` / `unshift` 是加，`pop` / `shift` 是删。

### 9.2 演示

```javascript
var arr = ["星期一", "星期二", "星期三", "星期四", "星期五"];

console.log(arr.push("星期六"));    // 6  返回添加后的新长度
console.log(arr);                   // 星期一到星期六

arr.unshift("星期日");               // 从开头添加
console.log(arr);                   // 星期日到星期六

arr.pop();                          // 从末尾删除一个
console.log(arr);                   // 星期日到星期五

arr.shift();                        // 从开头删除一个
console.log(arr);                   // 星期一到星期五
```

### 9.3 `push` 的返回值是新长度

上面 `arr.push("星期六")` 打印出来是 `6`，不是数组本身。原因是原来有 5 个元素，添加后变成 6 个，`push` 把"新的长度"返回了。

> ⚠️ 别写成 `arr = arr.push("星期六")`——那样 `arr` 就变成数字 6 了。

### 9.4 这四个方法一次只动一个元素

`push`、`unshift`、`pop`、`shift` 都没有"批量"的参数：一次添加一个，或者一次删除一个。要一次删多个、或者在中间动手脚，得用后面的 `splice`。

## 十、`splice`：在任意位置删、插、换

### 10.1 三个参数

```text
数组.splice(起始索引, 删除个数, 要添加的元素1, 要添加的元素2, …)
```

| 参数 | 含义 |
|---|---|
| 第 1 个 | 从哪个索引开始动手 |
| 第 2 个 | 删除几个（写 `0` 表示一个都不删） |
| 后面的参数 | 要插入的新元素，可以不写 |

### 10.2 删：`splice(起始索引, 删除个数)`

```javascript
var arr = ["猴子", "熊猫", "老虎", "狮子"];

arr.splice(1, 2);                   // 从索引 1 开始，删除 2 个
console.log(arr);                   // [ '猴子', '狮子' ]
```

从索引 1（熊猫）开始删 2 个，熊猫和老虎被删掉，只剩下猴子和狮子。

### 10.3 换：删掉一个，再插入一个

```javascript
var arr2 = ["猴子", "熊猫", "老虎"];

arr2.splice(1, 1, "狮子");           // 删除索引 1 上的 1 个，再插入"狮子"
console.log(arr2);                  // [ '猴子', '狮子', '老虎' ]
```

### 10.4 插：删除个数写 0

```javascript
var arr3 = ["猴子", "熊猫", "老虎"];

arr3.splice(1, 0, "狮子");           // 删除 0 个 → 只插入
console.log(arr3);                  // [ '猴子', '狮子', '熊猫', '老虎' ]
```

### 10.5 和 `push` / `unshift` 的分工

| 需求 | 用什么 |
|---|---|
| 只在末尾加一个 | `push` |
| 只在开头加一个 | `unshift` |
| 只在末尾删一个 | `pop` |
| 只在开头删一个 | `shift` |
| 在中间删、中间插、一次删多个 | `splice` |

> ⚠️ `splice` 的第二个参数是"**删除几个**"，不是"到哪个索引结束"——别和后面 `slice` 的"起始、终止"搞混。
>
> ⚠️ `splice` 会直接改动原数组，执行完再打印 `arr`，看到的就是改过之后的样子。

## 十一、案例：筛选 90 分以上的成绩

### 11.1 需求

给一组成绩，把所有 **≥ 90 分** 的挑出来，放进一个新数组。

### 11.2 两个数组

| 数组 | 作用 |
|---|---|
| 原数组 `scores` | 存放全部成绩，只读不改 |
| 新数组 `result` | 存放筛选出来的成绩，一开始是空的 |

### 11.3 循环 + `if` + `push`

```javascript
var scores = [88, 92, 75, 96, 90, 59, 100];
var result = [];                          // 新数组，保存 90 分以上的成绩

for (var i = 0; i < scores.length; i++) {
    if (scores[i] >= 90) {
        result.push(scores[i]);           // 符合条件就添加到新数组
    }
}

console.log(result);                      // [ 92, 96, 90, 100 ]
```

### 11.4 逐行对照

| 代码 | 作用 |
|---|---|
| `var result = [];` | 先准备一个空数组接结果 |
| `i < scores.length` | 遍历到最后一个元素（索引最大是 `length - 1`） |
| `scores[i] >= 90` | 判断当前成绩符不符合条件 |
| `result.push(scores[i])` | 符合就追加到新数组末尾 |
| `console.log(result)` | 打印筛选结果 |

### 11.5 变式

- 把 `>= 90` 改成 `< 60`，就是筛出不及格的；
- 改成 `>= 80 && < 90`，就是筛出 80 到 89 这一档；
- 换一个判断条件，就是换一个筛选需求——**"新数组 + 循环 + `if` + `push`"这四件套不变**。

> 💡 筛选的关键是"原数组不动，结果放新数组"。

## 十二、排序与反转：`reverse`、`sort`

### 12.1 `reverse()`：反转顺序

```javascript
var fruits = ["苹果", "香蕉", "橙子", "葡萄"];

fruits.reverse();                  // 反转顺序
console.log(fruits);               // [ '葡萄', '橙子', '香蕉', '苹果' ]
```

> 💡 `reverse` 不带参数，作用就是把数组头尾对调；它也是**直接改原数组**。

### 12.2 `sort()`：要告诉它"怎么比"

`sort` 不是简单地"从小到大"——它的排序规则要你**传一个函数**进去，告诉它任意两个元素谁排前面。

```javascript
var nums = [5, 1, 9, 3, 7];

nums.sort(function (a, b) {
    return a - b;                  // 升序：小的排前面
});

console.log(nums);                 // [ 1, 3, 5, 7, 9 ]
```

| 部分 | 含义 |
|---|---|
| `sort(…)` | 数组的排序方法 |
| `function (a, b) { … }` | 比较函数，作为参数传进 `sort` 的小括号 |
| `a`、`b` | 数组里被拿出来比较的两个元素 |
| `return a - b` | 返回值决定谁在前 |

### 12.3 升序与降序

```javascript
var nums = [5, 1, 9, 3, 7];

nums.sort(function (a, b) {
    return a - b;                  // 升序：小的排前面
});
console.log(nums);                 // [ 1, 3, 5, 7, 9 ]

nums.sort(function (a, b) {
    return b - a;                  // 降序：大的排前面
});
console.log(nums);                 // [ 9, 7, 5, 3, 1 ]
```

| 比较函数 | 顺序 |
|---|---|
| `return a - b;` | 升序（从小到大） |
| `return b - a;` | 降序（从大到小） |

> 💡 为什么 `a - b` 是升序？返回负数说明 `a` 比 `b` 小，`a` 就排到前面；返回正数说明 `a` 大，`a` 排后面。
>
> ⚠️ 比较函数要写在 `sort()` 的小括号里当参数，不要先算好再传；函数里必须有 `return`，否则排序结果不会按你想要的来。

## 十三、查找与去重：`indexOf`、`lastIndexOf`

### 13.1 返回值：索引或 `-1`

```javascript
var arr = [10, 20, 30, 20, 10];

console.log(arr.indexOf(20));        // 1
console.log(arr.lastIndexOf(20));    // 3
console.log(arr.indexOf(99));        // -1  找不到
```

| 方法 | 返回 |
|---|---|
| `indexOf(元素)` | 该元素**第一次**出现的索引；找不到返回 `-1` |
| `lastIndexOf(元素)` | 该元素**最后一次**出现的索引；找不到返回 `-1` |

### 13.2 比较用的是全等

`indexOf` 找元素时，要求**数据类型和值都相等**（三个等号的全等），不是"看起来差不多"：

```javascript
var arr2 = [1, "1", 2];

console.log(arr2.indexOf(1));        // 0
console.log(arr2.indexOf("1"));      // 1  类型不同，不算同一个
```

> ⚠️ `1` 和 `"1"` 是两个不同的元素。查找时写错类型，就会得到 `-1`。
>
> ⚠️ 判断"在不在"要写 `indexOf(x) !== -1`，不要写成 `if (indexOf(x))`——索引 `0` 也是假值。

### 13.3 去重案例

一组课程名里有重复，把重复的去掉，只留第一次出现的：

```javascript
var courses = ["音乐现场", "话剧表演", "音乐现场", "营养健康", "话剧表演"];
var unique = [];

for (var i = 0; i < courses.length; i++) {
    if (unique.indexOf(courses[i]) === -1) {   // 新数组里还没有它
        unique.push(courses[i]);
    }
}

console.log(unique);   // [ '音乐现场', '话剧表演', '营养健康' ]
```

### 13.4 去重思路拆解

| 步骤 | 做什么 |
|---|---|
| ① | 准备一个空数组 `unique`，存"已经收下的" |
| ② | 循环原数组，逐个拿出元素 |
| ③ | 用 `unique.indexOf(元素)` 查它在新数组里有没有 |
| ④ | 返回 `-1`（没有）→ `push` 进去；返回其他值（已有）→ 跳过 |

> 💡 `indexOf(...) === -1` 就是"**还没有**"；`!== -1` 就是"**已经有了**"。这两句会反复出现。
>
> 💡 这个思路不只用于去重：判断"这个 id 是否已选中""这个标签是否已添加"，都是同一套。

## 十四、数组转字符串：`join` 与 `toString`

### 14.1 `join(分隔符)`

`join` 把数组里所有元素用一个分隔符连成一个字符串：

```javascript
var arr = ["苹果", "香蕉", "橙子"];

console.log(arr.join());        // 苹果,香蕉,橙子
console.log(arr.join("-"));     // 苹果-香蕉-橙子
console.log(arr.join(""));      // 苹果香蕉橙子
console.log(arr.toString());    // 苹果,香蕉,橙子
```

### 14.2 三种写法对照

| 写法 | 分隔符 | 结果 |
|---|---|---|
| `arr.join()` | 不写参数，默认**逗号** | `苹果,香蕉,橙子` |
| `arr.join("-")` | 短横线 | `苹果-香蕉-橙子` |
| `arr.join("")` | 空字符串，等于**没有分隔符** | `苹果香蕉橙子` |

### 14.3 `toString()` 等同于 `join()`

`toString()` 不写参数时的效果，和 `join()` 不写参数完全一样：都用逗号连接。

> ⚠️ `join()` 和 `join("")` 是两回事：前者有逗号，后者首尾相连。想把数组拼成"一整串"字符，要写 `join("")`。
>
> 💡 `join` 常用于把数组变成页面上的一行文字，或者把一个数组拼成 `class="a b c"` 这种形式。

## 十五、另外三个常用方法：`fill`、`slice`、`concat`

### 15.1 `fill(值)`：填满整个数组

```javascript
var arr = [1, 2, 3, 4];
arr.fill(0);                    // 用 0 填满整个数组
console.log(arr);               // [ 0, 0, 0, 0 ]
```

> 💡 `fill` 改的是原数组，相当于把每个位置都覆盖成同一个值。

### 15.2 `slice(起始, 终止)`：截取一段

```javascript
var arr2 = [10, 20, 30, 40, 50];
console.log(arr2.slice(1, 3));  // [ 20, 30 ]          不含索引 3
console.log(arr2.slice(2));     // [ 30, 40, 50 ]      省略第二个参数就截到末尾
```

| 参数 | 含义 |
|---|---|
| 第 1 个 | 从哪个索引开始截（包含） |
| 第 2 个 | 到哪个索引结束（**不包含**），省略就截到末尾 |

> ⚠️ `slice` 的结果**不包含终止索引**：`slice(1, 3)` 取的是索引 1 和 2，不是 1、2、3。
>
> 💡 `slice` 返回一个新数组，原数组不变——这一点和 `splice` 正好相反。

### 15.3 `concat()`：连接

```javascript
var a = [1, 2];
var b = [3, 4];
console.log(a.concat(b));       // [ 1, 2, 3, 4 ]      两个数组首尾相连
console.log(a.concat(5));       // [ 1, 2, 5 ]         连接一个元素
```

`concat` 可以接数组，也可以接单个元素；返回连接后的新数组，原数组不变。

### 15.4 三个方法总表

| 方法 | 作用 | 是否改原数组 | 返回值 |
|---|---|---|---|
| `fill(值)` | 用同一个值填满 | 是 | 改过的原数组 |
| `slice(起, 止)` | 截取一段 | 否 | 新数组 |
| `concat(…)` | 连接数组或元素 | 否 | 新数组 |

## 十六、易错点速查

| # | 错误写法 / 错误理解 | 后果 | 正确写法 |
|---|---|---|---|
| 1 | `new Date(2023, 12, 13)` 以为 month 是 12 月 | 变成 2024 年 1 月 | 12 月写 `11` |
| 2 | 显示月份直接用 `getMonth()` | 少一个月 | `getMonth() + 1` |
| 3 | 以为 `getDay()` 是"几号" | 拿到 0~6 的星期 | 几号用 `getDate()` |
| 4 | 星期数组写成 `weeks[getDay]` | 取到 `undefined` | `weeks[date.getDay()]` |
| 5 | 用 `getTime()` 算时间差后忘了单位 | 把毫秒当秒 | 毫秒；换秒除以 1000 |
| 6 | 倒计时写成"当前 − 目标" | 结果是负数 | 目标 − 当前 |
| 7 | 倒计时不算余数，直接除 | 小时数超过 24 | 小时 `% 24`、分秒 `% 60` |
| 8 | `arr = arr.push(x)` | `arr` 变成数字长度 | 单独调用 `arr.push(x)` |
| 9 | `splice(1, 2)` 以为"到索引 2 结束" | 删错个数 | 第二个参数是删除个数 |
| 10 | `splice(1, 1, x)` 以为只插入 | 原来那个被删了 | 纯插入第二个参数写 `0` |
| 11 | `if (arr.indexOf(x))` 判断存在 | 索引 0 被当成不存在 | `arr.indexOf(x) !== -1` |
| 12 | `arr.join()` 以为没有分隔符 | 中间带逗号 | 无分隔符写 `arr.join("")` |
| 13 | `slice(1, 3)` 以为包含索引 3 | 少截一个 | 终止索引不包含 |
| 14 | `typeof arr === "array"` | 永远不成立 | 用 `Array.isArray(arr)` |
| 15 | `sort()` 不写比较函数就以为按数字大小 | 顺序不对 | 传 `function (a, b) { return a - b; }` |
