## 一、复习：函数是什么、为什么要用它

### 1.1 书上那句定义

老师让同学**翻书看函数的定义**，并强调了定义里的关键词（"实现某个特定功能"）：

> 老师原话（`[00:05:47]` 附近，转写原文）：**"大家可以看一下那个（书）上对于函数的定义啊，函数它是第一句……实现某个特定功能……"**

⚠️ 这一句转写被切得很碎（详见**附录 B 第 1 条**）。按老师后面反复强调的意思，函数可以记成一句话：

> **函数就是"把实现某个特定功能的一段代码打包起来、起一个名字"，以后要用这个功能，写名字就行，不用再把那一段代码重写一遍。**

### 1.2 老师讲的两个好处

> 老师原话（`[00:06:24]` 附近）：**"这个函数它的优势啊……可以提高（代码）的（复用性），降低（程序）的维护（难度）。"**

| 好处 | 老师怎么解释的 |
|---|---|
| **提高代码的复用性** | "我们遇到还需要实现这个功能的情况，就可以**重复地去使用这个函数的名字**，就不需要再把那些长段的代码全部给它打出来——只需要写这个函数的名字就可以"（`[00:06:55]`） |
| **降低程序的维护难度** | "我们**不需要去关心这一段代码它到底是怎么运行的**，你不用去管这一长段代码到底是什么意思，你只需要知道它是可以实现（这个）功能，那我们维护起来就更加的简单了"（`[00:07:05]`—`[00:07:21]`） |

> 💡 这两句话是"**封装**"思想的通俗版（上节课老师已经点过名：这叫封装）。用一句话概括：**管用不管实现**。

## 二、两类函数：内置函数与自定义函数

> 老师原话（`[00:09:13]` 附近）：**"两种函数啊，一个是内置函数啊，一个是自定义函数。"**

| 类型 | 是什么 | 老师举的例子 | 要不要自己定义 |

## 三、自定义函数的定义格式（本节第一个重点）

> 老师原话（`[00:09:33]` 附近）：**"我们需要在 VS Code 里面去写……首先（写）关键字 function，后面跟上你想给（函数）取的名字，……（名字后面）跟一对小括号……大括号里面就是重点。"**

```javascript
function 函数名(参数1, 参数2, ...) {
    // 大括号里面：实现这个功能的代码
}
```

老师逐段解释（原话在 `[00:09:55]`—`[00:11:49]`）：

| 组成部分 | 老师怎么说的 | 注意点 |
|---|---|---|
| `function` | "**关键字 function**"（起头必须写它） | 不能省 |
| 函数名 | "**你想给函数取个名字**"，名字"**见名知义**"（看名字就知道功能） | 命名有习惯问题，见第九节 |
| `( )` 小括号 | "**小括号里面是需要写函数所需要用到的一些参数**" | **参数可以是 0 个、1 个、2 个或多个** |
| 参数 | "如果需要用到两个参数，那你就分别去设置两个……**类似于变量的名称**，用来传递真实的数据，所以这个也叫做**形参**"（`[00:10:55]`） | 不需要参数就**什么也不写** |
| `{ }` 大括号 | "**大括号里面就是重点**……我们要实现的这个功能的这些代码**全部写到大括号里面**"（`[00:11:06]`） | 函数体 |

> 老师对"完整定义"的复述（`[00:11:49]` 附近，转写原文）：**"关键字 function，第二个（是）我们自己给它起的名字，接下来小括号里面是参数，大括号里面是（函数体）——这是一个完整的函数的定义。"**

## 四、案例：写一个"从 a 累加到 b"的函数

老师用一个**累加**的例子来演示"定义函数"（`[00:12:05]` 起）：

### 4.1 要做什么

> 老师原话（`[00:12:05]` 附近）：**"这个函数它是带有什么功能？（累加）功能啊……怎么样去实现？哪（一）系列的数字给它加起来呢？那也就是（从）a 加到 b。"**

### 4.2 思路（老师边写边讲）

1. **需要一个变量存结果**——"我在循环之前定义了一个变量……**用来存储累加的结果**"（`[00:12:54]`）——这就是 `sum`。
2. **需要一个循环**——"要使用（for）循环……从某一个数（比如 i）从开始加到（b）"（`[00:12:27]`、`[00:12:5x]`）。
3. **循环体里做累加**——"`sum += i`……这个运算符的意思是**相加并赋值**"（`[00:13:03]` 附近）。
4. **循环结束，结果就在 `sum` 里**。

整理成代码：

```javascript
// 从 a 累加到 b
function sum(a, b) {          // a、b 是形参
    let s = 0;                // 循环之前先定义变量，存累加结果
    for (let i = a; i <= b; i++) {
        s += i;               // 等价于 s = s + i（相加并赋值）
    }
    return s;                 // 把结果交出去（返回值，见第九节）
}

console.log(sum(1, 50));      // 1 加到 50
```

> 老师带着同学把过程走了一遍（`[00:13:0x]`—`[00:14:0x]`）：从 `i = 1` 开始，"第一次加一……i 变成 2 再加……一直到 i 等于 50 的时候"，
> 最后"**一加五十（的）结果都存储在（变量）里**"。
> ⚠️ 教师演示时用的是 `1` 到 `50` 这个例子（"我们从一（加）到五十"），**代码里的变量名以老师演示为准**（见附录 B 第 2 条）。

## 五、调用函数：形参是不确定的，实参是调用时定的

> 老师原话（`[00:14:21]` 附近）：**"因为函数它是实现某一个特定功能，那我们在调用它的时候，需要把这个参数（传进去）……也就是根据用户的需要实现任意两个数之间（的累加），从任意的一个数累加到第二个数。"**

| 概念 | 什么时候定 | 老师的话 |
|---|---|---|
| **形参** | **定义函数时**写在括号里的"类似变量的名称" | "这里面（定义时）的参数都类似一个变量，它是**不确定的**，它叫形参"（`[00:10:55]`、`[00:15:38]`） |
| **实参** | **调用函数时**真正传进去的值 | "我们在（调用）这个函数的时候，再把这个参数来确定，这个时候它就叫（实参）"（`[00:15:1x]`） |

**调用的语法**（`[00:15:55]` 附近，转写原文）：

> **"语法（是）这样：函数名小括号，再把你确定好了的参数给它写进去，写到这个小括号里面去调用。"**

```javascript
函数名(25, 360);        // 老师举的例子：调用函数实现"从 25 加到 360"
```

> 老师原话（`[00:16:5x]` 附近）：**"比如说下面这一行代码……它调用这个函数来实现从二十五（加）到三百六……这个时候两个参数就确定了，第一个参数是 25，第二个参数是 360……函数就会把这两个参数代入进去进行运算，最终会输出一个（运算的）结果。"**

⚠️ "**函数名 + 小括号 + 实参**"这条语法是固定的；**实参的个数、顺序要和形参一一对应**（上节课已强调，本节再次用到）。

## 七、函数进阶 ① 函数表达式（把函数赋给一个变量）

> 老师原话（`[00:18:45]` 附近）：**"（把）函数（赋值）给一个变量以后，我们不需要通过函数名去调用，而是用这个变量（名去调用）……这叫函数表达式。"**

对比着记：

```javascript
// 普通写法：定义时就起好了名字
function sayHi() { console.log("你好"); }
sayHi();                       // 用函数名调用

// 函数表达式：把函数赋给一个变量
let fn = function () { console.log("你好"); };
fn();                          // 用变量名调用（也可以）
```

**为什么要这么写？** 老师说得很直白——**为了避免函数重名**（`[00:18:56]`、`[00:19:35]`、`[00:20:49]`）：

> 老师原话（`[00:20:49]` 附近）：**"为了避免这个函数的重名这样的（问题）。"**

老师进一步解释了两层意思：

1. **函数名不能随便起**——"函数（名）要**见名知义**……程序员在写程序的时候，很多情况下就是一种**惯性思维**，有一些函数在命名（上）有（固定）的习惯"，所以不同人写的代码里**很容易撞名字**（`[00:19:40]`）。
2. **用变量接住以后就自由了**——"我可以把这个函数**赋值给一个变量**，这个变量（名）你**随便起**，这样就可以避免我在调用的时候**调用错**"（`[00:19:40]`—`[00:20:49]`）。

> 老师的定调（`[00:20:5x]`）：**"大家了解一下哈，了解一下，有这种用法，别到以后用的时候（看）见（了）不知道（是什么）。"**

## 八、函数进阶 ② 匿名函数与"自己调用自己"

### 8.1 匿名函数

> 老师原话（`[00:21:30]` 附近）：**"（在）函数表达式里面去用这个变量代表那个（函数）……那我们在调用的时候，还是用这个变量去（调用）。"**

所谓**匿名函数**，就是**没有名字的函数**——它通常出现在两种地方：

1. 出现在**函数表达式**的右边（上面 `let fn = function () {...}` 里的 `function () {...}` 就是匿名的）；
2. 直接**当作参数**传进别的函数（见第十节回调函数）。

> 老师原话（`[00:21:5x]` 附近）：**"（在）函数（表达式）里面……（这个函数）后面和参数之间是没有名字的。"**

### 8.2 自调用（让匿名函数"自己执行一次"）

> 老师原话（`[00:22:39]`—`[00:22:44]` 附近）：**"就是只实现一次，自己（调用）自己……把这个匿名函数给那个小括号括起来，后面（跟）上（小括号）。"**

```javascript
(function () {
    console.log("我只执行一次");
})();          // 用小括号括起来，后面直接再跟一对小括号
```

- 老师把它叫"**函数它有一个自调用的功能**"，并明确说：**"用的机会也比较少，所以了解一下"**（`[00:22:39]`）。
- ⚠️ 老师的原话里没有出现"**立即执行函数 / IIFE**"这类术语（见附录 B 第 4 条），考试以老师课上说法和教材为准。

## 十、函数进阶 ④ 回调函数（本节最绕的一个概念）

> 老师原话（`[00:25:50]` 附近）：**"下面我们来看（回调函数），回调函数也是一个比较复杂的概念啊，大家看看能不能听懂。"**

### 10.1 和以前不一样在哪

> 老师原话（`[00:26:0x]` 附近）：**"咱们在前面学习函数的定义的时候，你用函数的时候，（传的）参数是一个（数字）对吧？但是回调函数里面是把函数作为参数（传进去）。"**

> 老师原话（`[00:30:17]`—`[00:32:43]` 附近）：
> **"这个参数它是一个函数的时候，就把这个函数它的返回值作为这个数值，传递给当前这个函数的第一个参数。"**
> **"（就是）我们可能有一个函数，它的执行依赖于另外一个函数的值，就可以这样去写。"**

### 10.2 老师演示的结构（整理）

> 老师原话（`[00:30:46]`—`[00:31:45]` 附近）：**"前面是定义了一个（函数）……中间（几）行定义了第二个（函数）……第一个函数里面有一个（返回值），第二个函数里面有两个参数……（然后）调用第二个函数，那里面的参数（不再是）一个数字，而是它这个函数。"**

```javascript
// 第一个函数：负责算出一个值（有返回值）
function fnA() {
    return 10;
}

// 第二个函数：它有两个参数，第一个参数位置上"交给它一个函数"
function fnB(x, y) {
    return x + y;      // x 拿到的是 fnA() 的运行结果
}

// 调用第二个函数：第一个实参不是一个数字，而是函数 fnA
fnB(fnA(), 5);         // fnA() 先跑，返回值 10 进到 x 里
```

> ⚠️ 上面代码是按老师的讲述复原的**结构示意**，不是老师屏幕上代码的逐字誊录（那段转写几乎空白，见 0.2 表与附录 B 第 5 条）。

### 10.3 老师的类比：饭店里"点菜"和"做菜"

> 老师原话（`[00:32:58]` 附近）：**"我们拿这个（饭店）里面（厨师）加工饭菜（来说）啊，那顾客那点菜以后啊，再就是对于厨师们这（个要的）……"**

老师想说的是：**两件事之间是有依赖、有先后顺序的**——顾客先点菜（一个函数先跑出结果），厨师才能按点菜单做菜（另一个函数拿着这个结果继续干活）。这也正是回调函数的用途：**一个函数的执行依赖于另一个函数的值**。

> ⚠️ 这段类比在转写稿里断得很厉害，只有前半句可靠（附录 B 第 6 条）。

> 老师对这一整块的定调（`[00:32:56]` 附近）：**"……理解一下……"**——转写稿里这句只剩"理解一下"四个字清楚（原句像"……理解一下，就是我们拿这个……"），随后 `[00:33:30]` 用一句"就讲这些啊？"收了尾。**所以这一块老师只要求"了解"，不要求会写**（附录 B 第 6 条）。
