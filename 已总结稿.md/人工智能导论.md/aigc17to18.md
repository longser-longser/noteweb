## 一、为什么要用 AIGC 做图

### 1.1 图像在信息传递上的位置

老师开场先做了一个对比：同样一件事，**用图像传递比用文字传递更快，冲击力也更强**。

| | 文字 | 图像 |
| :--- | :--- | :--- |
| **传递速度** | 要读完才明白 | **更快**，一眼就懂 |
| **冲击力** | 弱 | **更强** |

> 📌 一句话记：**图文相比，图先到人心里**——这就是"为什么要学图像生成"的起点。

### 1.2 传统手绘的三道门槛

| 门槛 | 具体表现 |
| :--- | :--- |
| **要长期练** | 高质量的插画、海报靠手绘，得先有**长期的绘画训练**打底 |
| **一张图很费时间** | 行业里画一张，往往要**花很长时间**（几天量级） |
| **换风格等于重练** | 想把一种画风换成另一种，得**重新练很久**，不是改个参数的事 |

### 1.3 AIGC 带来的三点变化

| 变化 | 说明 |
| :--- | :--- |
| **① 生成快** | 借助工具，能在很短时间内把脑子里的画面生成出来 |
| **② 能改** | 对新生成的图、或**已有的图**，都能做**编辑与增强**——也就是在图上做二次创作 |
| **③ 效率高、换风格便宜** | **一键切换画风**：同一张图换一种风格，成本比手绘低得多 |

> ⚠️ **易错点**：**"提高效率"不等于"替代人"**。课上在讲堆友时明确说过：它替代不了设计师、美工，只是把他们的效率提上去了；做出来的图，还是不如人设计的。把这句话记成"AI 会取代设计师"，方向就错了。

## 二、图像生成的三个阶段

### 2.1 三个阶段各管什么

| 阶段 | 要解决的问题 | 关键动作 |
| :--- | :--- | :--- |
| **① 输入理解阶段** | 把用户给的东西**读懂** | 数据处理（清洗、分词）、多模态输入、读参考图 |
| **② 图像输出生成阶段** | 真正**把图画出来** | 按选定模型初始化 → GAN 对抗训练／扩散模型降噪 |
| **③ 输出优化阶段** | 从"能出图"到"**能交付**" | 质量评估与技术增强、内容合规检验、格式适配与交付 |

> 📌 一句话记：**先读懂、再生成、最后善后**——和文本生成的三阶段是同一副骨架，只是把"写字"换成了"画画"。

### 2.2 阶段一：输入理解——文字和图片都能进

**输入有两条路，也可以一起给：**

| 输入方式 | 给的是什么 | 用在哪 |
| :--- | :--- | :--- |
| **一段文字** | 提示词，描述你想要的画面 | 文生图（无中生有） |
| **一张参考图** | 上传图片，让工具照着这个"样子"来 | 图生图、风格迁移、局部改图 |

- 文字和图片**同时给**，就叫**多模态输入**——文字一路、图像一路，都要先经过处理。
- **数据处理这一步管什么**：
  - **文字侧**：**清洗**（把标点符号、没有用的词去掉）＋**分词**。
  - **图像侧**：同样要先过一遍，比如画面里模糊的区域、线条这类信息，都得先处理。

老师打了个很生活化的比方：交一份材料之前你会先检查有没有错别字，交一张图之前你会把尺寸统一一下——**模型在"动手"之前，做的也是同一件事**。

> 💡 记忆点：**输入理解不只是"读一句话"**。它读的是两路东西：文字（清洗＋分词）和图像（预处理）。

### 2.3 阶段二：图像输出生成——先选模型，再出图

**第一步是初始化**：按**选定的生成模型**做初始化。为什么要先选？因为工具里往往摆着很多种模型／风格，**先定用哪一个，它才知道往哪个方向画**。

**出图靠两条技术路线，课上一条一条讲了：**

| | **生成对抗网络（GAN）** | **扩散模型** |
| :--- | :--- | :--- |
| **怎么出图** | **生成器**造图、**判别器**辨真伪，**两者对抗训练**，图越造越像 | 从噪声出发，**一步步降噪**，把图像一点点"还原"出来 |
| **效果** | 图像**细节更丰富** | 越降噪越清晰，直到还原成完整的画面 |
| **一句话** | 靠"**互相比**"进步 | 靠"**一点点擦干净**"成像 |

```text
   文字／参考图
        │  预处理（清洗·分词／图像处理）
        ▼
   按选定模型初始化
        │
        ├──► GAN：生成器 ⇄ 判别器（对抗训练）
        └──► 扩散模型：纯噪声 ──反复降噪──► 逐步还原 ──► 图像
        ▼
     图像输出
```

> ⚠️ **易错点**：出图时走的是**降噪**这一头，别记成"加噪"。加噪（正向扩散）是训练时把图毁掉的那一段，去噪（逆向扩散）才是把图"长"回来的那一段——第 13—14 节讲扩散模型时就是这个方向。

> 💡 记忆点：**GAN 记"两个网络打架"，扩散模型记"一遍遍降噪"**。

### 2.4 阶段三：输出优化——三关过完才算交付

老师把这一步拆成三件事，并且点明它们各自对应一个要求：**质量、合规、场景适配**。

| 环节 | 干什么 | 课上举的例子 |
| :--- | :--- | :--- |
| **① 质量评估与技术增强** | 用**算法检测**图像上的缺陷，再**针对性**地把质量提上去 | 用**超分辨率**把**低分辨率图放大**、**修复像素细节**、**消除伪影或颗粒感** |
| **② 内容合规检验** | 检查内容**合不合规**，把不该出的东西拦下来 | 涉黄这类违规内容不能出；确保内容符合规范 |
| **③ 格式适配与结果交付** | 按**用户的要求**把图调整成能直接用的样子 | 改**尺寸大小**、加**水印**或**版权信息**，交付合适的图像 |

> 📌 一句话记：**技术手段提质量、合规把关守底线、格式适配才交付**——三关缺一关，图就还不能用。

## 四、应用场景之一：文生图

### 4.1 文生图适合什么

老师把图像生成工具的应用场景归成**两大类**：**① 生成图像（文生图）**、**② 图像编辑与美化**。

**文生图**是"**从文字到图像**"：把描述画面的文字（提示词）交给工具，它按描述把图生成出来。它适合**需要根据特定的概念、场景或物体来创作图像**的情况——脑子里有画面，手上却没有素材。

### 4.2 八个应用领域

| 领域 | 用来做什么 | 课上举的例子 |
| :--- | :--- | :--- |
| **艺术创作** | 直接产出画面作品 | — |
| **广告营销** | 出**广告海报、宣传图**这类物料 | — |
| **新闻媒体** | 给报道**配图** | 一篇关于**太空探索**的报道配图，画面是"**宇宙飞船在太空中飞行，周围是闪烁的星星，远处有一个蓝色的星球**" |
| **教育培训** | 帮老师做**教学课件**和教学用图 | **科学实验示意图**、**历史场景图** |
| **游戏娱乐** | 造游戏里的**角色、场景、道具** | — |
| **建筑与室内设计** | 出方案效果图，设计师也用得上 | — |
| **时尚与零售** | 服装、商品相关的视觉素材 | — |
| **影视与动画** | 概念图、分镜这类前期画面 | — |

> 📌 一句话记：**凡是"要一张图上来说话"的地方，都能用文生图**——从海报、配图、课件，到角色、场景、效果图。

> 💡 记忆点：**新闻配图那条提示词本身就是范例**——"飞船＋星星＋蓝色星球"三样东西，就把画面说清楚了。

## 五、应用场景之二：图像编辑与美化

这一类是"**在已有图片上做二次创作**"，基于图像工具对图片做修改、修复与增强。

### 5.1 重绘与局部编辑

| 动作 | 改哪儿 | 改成什么 |
| :--- | :--- | :--- |
| **重绘** | **整张画面** | 按需要的风格**重新设计和渲染**，换出**新的视觉效果** |
| **局部编辑** | 图上**某一个特定区域** | 对这一块做**精确的调整和优化**，别处不动 |

> 💡 记忆点：**重绘改"整张"，局部编辑改"一块"**——一个换气质，一个修细节。

### 5.2 风格迁移

- **是什么**：把**用户上传的图片**转换成**选定的风格**；也可以把一张图的风格**迁到另一张图**上。
- **课上举的两个例子**：

| 例子 | 做法 |
| :--- | :--- |
| **梵高《星月夜》** | 提示词写成"**基于梵高《星月夜》的画作风格**"，生成一幅**新的城市夜景图** |
| **头像换风格** | 给一张**参考图**，按它的风格**生成一张风格相似的新头像** |

> 📌 一句话记：**风格迁移给的是"风格"，不是"内容"**——内容照你的，笔触照参考的。

### 5.3 四个最常用的编辑动作

| 动作 | 解决什么麻烦 | 课上的场景 |
| :--- | :--- | :--- |
| **换底（背景替换）** | 证件照底色不对 | **蓝底要换成红底**，只要有电子版，交给**豆包**就能换 |
| **修复** | 图上某处坏了、缺了 | 对**图片中的某一个地方**做修复 |
| **消除** | 画面里有不该有的东西 | 从**微博下载的图**想当电脑桌面，**水印**碍眼，用工具**消掉** |
| **增强** | 图太暗、不清楚 | 图偏暗看着不舒服，**调亮度、对比度**，把**清晰度**提上去 |

- 这一类的总效果是两句话：**提升图片的整体质量**，同时**给图片增添个性化的视觉效果**。

> ⚠️ **易错点**：**"生成"和"编辑"不是一回事**。文生图是从零开始造一张；编辑与美化是在**已有的图**上动刀。题目里给了"已经有一张图，想改风格"，答案落在**编辑与美化**这一边。

## 六、图像生成的提示词：一条六要素公式

### 6.1 公式

老师给了一条能直接照着填的公式：

```text
主体 ＋ 场景 ＋ 风格 ＋ 镜头语言 ＋ 氛围词 ＋ 细节修饰
```

> 📌 老师特别提醒：**上传图片、写提示词的时候，先照这条公式想一遍**——六个位置各填什么，画面就清楚了。

### 6.2 六个要素逐个拆

| 要素 | 写的是什么 | 怎么写／例子 |
| :--- | :--- | :--- |
| **① 主体** | 图像里**主要表现的对象** | 可以是**人、动物、植物、物品**，也可以是**现实里不存在的想象之物**；写的时候交代它的**特征或动作** |
| **② 场景** | **主体所处的环境** | 可以是**真实的空间**，也可以是想像出来的**虚幻场景** |
| **③ 风格** | 图像具有的**艺术风格、表现手法或视觉特征** | **山水画、水彩、漫画**风格……按你要的那一种写 |
| **④ 镜头语言** | 用来**传达信息、表达情感、讲故事**的视觉语言 | 落到具体的**视角**（仰视／平视／俯视）和**景别**上 |
| **⑤ 氛围词** | 对**画面氛围**的描述 | **梦幻、孤独**这一类词，给画面定情绪 |
| **⑥ 细节修饰** | 对画面的**进一步优化** | 增强**表现力、层次感和美感**；比如**光源的位置**、元素之间的**搭配** |

> 💡 记忆点：六要素可以串成一句话——"**画谁（主体）、在哪儿（场景）、什么画风（风格）、怎么拍（镜头语言）、什么情绪（氛围词）、哪儿再抠一下（细节修饰）**"。

### 6.3 镜头语言：视角、景别与光线

这一项最容易漏，课上单独拆开讲了：

| 手段 | 有哪些 | 效果 |
| :--- | :--- | :--- |
| **视角** | **仰视、平视、俯视** | 同一个主体，视角一换，气势和关系就变了 |
| **景别** | 远景、中景、近景 | **镜头拉近去表现人物的细节，冲击力更强** |
| **光线（自然光）** | **太阳光**；**逆光**——光源在拍摄对象**后方**，与拍摄方向**相对** | 光从哪儿来，画面的情绪就从哪儿起 |
| **光线（人造光）** | **荧光灯**这类人工光源的发光效果 | 冷、硬、有舞台感，适合特定的环境氛围 |

- 光线的总作用：**营造特定的环境氛围、带出情绪**。

> ⚠️ **易错点**：**"逆光"不是"光从正面打过来"**。逆光的光源在被拍对象的**背后**，和拍摄方向**相对**——写反了，出来的画面就完全不是那个意思。

### 6.4 一条完整的提示词长什么样

**结构模板（照着填）：**

```text
【主体】一只_____，正在_____（特征／动作）
【场景】在_____（真实空间／想象场景）
【风格】_____（水墨／水彩／漫画／写实……）
【镜头语言】_____视角，_____景别
【氛围词】_____（梦幻／孤独／静谧……）
【细节修饰】光源在_____，画面里还有_____
```

**教材上那条示例**：一只拟人化的大熊猫，**头戴斗笠、腰束精致的腰带、手戴黑色丝绸手套、足踏靴子**，在夜色中大步前行——从"主体"一路写到"细节修饰"，装束、道具、姿态全在提示词里交代清楚了。老师让大家对着这条示例看：**同一个主体，这些细节一换，出来的就是另一张图**。

> 📌 一句话记：**提示词不是形容词堆得越多越好，而是六个位置各就各位**——主体说清是谁，场景说清在哪，风格、镜头、氛围、细节各自补上缺的那一块。

## 七、本节要记住的清单（复习用）

1. **图像比文字传递更快、冲击力更强**——这是图像生成值得学的原因。
2. **手绘的三道门槛**：要长期练、一张图费时间、换风格等于重练。
3. **AIGC 做图的三点变化**：生成快、能改（编辑与增强）、一键切换画风。
4. **图像生成三阶段**：输入理解 → 图像输出生成 → 输出优化。
5. **输入理解**：两条输入路（文字／参考图），文字侧清洗＋分词，图像侧也要预处理；两路一起给就是**多模态输入**。
6. **出图前先按选定模型初始化**；出图两条路线——**GAN 靠生成器与判别器的对抗训练**，**扩散模型靠一步步降噪还原**。
7. **输出优化三关**：质量评估与技术增强（超分辨率、修像素、消伪影）、内容合规检验、格式适配与交付（尺寸、水印、版权）。
8. **通义万相**：文生图，一句"中国传统水墨画风格，海上生明月的宁静美景"能出一组图。
9. **堆友**：阿里巴巴旗下、面向美工与设计师的设计服务平台，有 AI 作图入口；**提效不替代**。
10. **两大应用场景**：文生图（从文字到图像）／图像编辑与美化（在已有图上二次创作）。
11. **文生图八个领域**：艺术创作、广告营销、新闻媒体、教育培训、游戏娱乐、建筑与室内设计、时尚与零售、影视与动画。
12. **编辑美化四类动作**：重绘（整张）／局部编辑（一块）／风格迁移（换风格）／换底·修复·消除·增强。
13. **六要素公式**：主体＋场景＋风格＋镜头语言＋氛围词＋细节修饰。
14. **镜头语言**看视角（仰视／平视／俯视）与景别（拉近更抓细节）；**光线**分自然光（含逆光）与人造光（荧光灯）。
