## 一、先复习：生成式模型（本节的底层技术打底）

老师在这一节开头先带大家回顾了**生成式模型**——因为"文本生成"本身就是生成式模型的一种应用，不把这一层弄清楚，后面讲原理会悬空。

### 1.1 生成对抗网络（GAN）

- **一句话定位**：生成对抗网络是**生成式模型**的代表之一，思路是让**两个网络互相对抗**。
- **两个角色、一场博弈**：

| 角色 | 干什么 | 博弈中怎么变强 |
| :--- | :--- | :--- |
| **生成器（Generator）** | 负责**生成伪样本**（假的、合成出来的数据） | 不断**提高自己生成伪样本的能力**，目标是骗过判别器 |
| **判别器（Discriminator）** | 负责**判断**一份样本是伪样本还是真实样本 | 不断**提高自己辨别伪样本与真实样本的能力** |

- **关键机制**：**两者分别不断地提高自己的能力**——生成器越会造假，判别器就越会识假；判别器越会识假，生成器就越要造得更像。**这个"互相追着提高"的过程就是博弈过程**，最终生成器造出来的样本会越来越接近真实样本。

> 💡 记忆点：**生成器管"造"，判别器管"辨"，两者互相逼着对方升级**——记住这一句，GAN 就不会记反。

> 📖 **教材 P18—P19 · 单元 1「1.3」1. 生成式模型（1）生成对抗网络（GAN）**：生成器负责生成**逼真的假数据**，判别器负责**判断数据的真伪**，二者在训练中**相互对抗、不断优化**；通过这种**对抗训练**，生成器最终能生成**接近于真实数据分布**的新数据。

### 1.2 扩散模型

- **两段过程**：
  - **正向扩散**：**不断地往图片上加噪声**——一步一步加，直到这张图片**变成纯噪声**为止（老师用的说法是"不断地去造"）。
  - **逆向扩散**：反过来，**从纯噪声一步步还原**，最终生成一张新的图片。
- **为什么要这么绕**：先学会"怎么把一张图毁掉"，再学会"怎么把它还原回来"，模型就掌握了**数据本身的分布**，于是能从纯噪声"长"出一张新图。

> ⚠️ 易错点：**正向扩散是"加噪"，逆向扩散是"去噪"**，两者方向相反，别把"加噪"记到逆向上去。名字里的"扩散"来自自然界的扩散现象——**往清水里滴一滴墨，墨自己散开**，这就是"从有序到无序"的正向过程。

> 📖 **教材 P20—P21 · 单元 1「1.3」（3）扩散模型**：扩散模型的名字来源于**自然界的扩散现象**，通过**逆转扩散过程**生成新数据——**① 正向扩散**：按预定的**噪声调度策略**逐步向样本数据中添加噪声，每次添加后都生成一个新版本，逐渐破坏原始信息，**直到最终得到完全由噪声组成的数据**；**② 逆向扩散**：把**纯噪声作为输入逐步迭代去噪**，每一步利用训练好的神经网络**预测当前噪声中的原始信息残留**，**逐步重建细节（如物体轮廓、色彩纹理）**。

## 二、AIGC 的工作流程（5 步，本节又完整走了一遍）

老师把这条流程**从头到尾串了一遍**，并且强调：**后面写题的时候要把这几步写出来**。

> 📌 一句话记：**数据 → 模型 → 训练优化 → 生成与后处理 → 反馈再优化**。

### 2.1 第（1）步：数据收集与处理

- **数据是前提**：AIGC 离不开**海量训练数据**，训练数据涵盖**文本、图像、音频、视频**等多种格式。
- **数据的质量与多样性，直接决定最终生成内容的优劣**——这一点和第 5—8 节讲的"数据要准确、完整、一致、有代表性"是同一条道理。
- **收集完必须做预处理**：包括**数据清洗、标注、格式化以及增强**，为模型的有效学习奠定基础。

> 📖 **教材 P22 · 单元 1「1.3」2. AIGC 的工作流程（1）数据收集与处理**：训练数据涵盖**文本、图像、音频、视频**等多种格式，**数据的质量与多样性直接决定了最终生成内容的优劣**；收集之后须做**数据清洗、标注、格式化以及增强**等预处理。

### 2.2 第（2）步：模型选择与训练

- **按生成内容的类型选模型**：文本生成用文本类模型，图像、语音各有各的模型——**任务不一样，模型就不一样**。
- **可以选机器学习模型，也可以选深度学习模型**：老师明确说，**"一般情况下会（优先）选深度学习模型"**，因为效果更好。

> ⚠️ 易错点：**"机器学习"与"深度学习"不是并列关系，而是包含关系**——人工智能 ⊃ 机器学习 ⊃ 深度学习（第 5—8 节讲过）。所以说"可以选机器学习模型，也可以选深度学习模型"，是说**选一个较浅的模型还是选一个更深的模型**，不是两个互不相干的阵营。

### 2.3 第（3）步：特征学习与优化

模型要**识别并理解输入数据的核心特征**，不同类型的输入关注点不同：

| 输入类型 | 模型要掌握的内容 |
| :--- | :--- |
| **文本** | **语法规则、语义关系、文本的逻辑脉络** |
| **图像** | **视觉元素**——色彩、形状、纹理等 |
| **语音** | **和语音相关的特征**（老师提到要结合语音与文本的对应关系一起处理） |

**优化手段**：常采用**梯度下降**等优化算法，**不断调整模型参数，持续缩小预测结果与实际数据之间的差距**；经过多轮迭代，模型性能达到理想水平，就具备了内容生成能力。

> 📖 **教材 P23 · 单元 1「1.3」2. AIGC 的工作流程（3）特征学习与优化**：训练中模型的关键任务是**识别并理解输入数据的核心特征**——**文本**要掌握**语法规则、语义关系以及文本的逻辑脉络**，**图像**要捕捉**视觉元素**（色彩、形状、纹理等）；优化模型性能**常采用梯度下降等优化算法**，通过不断调整参数**持续缩小预测结果与实际数据之间的差距**。

### 2.4 第（4）步：内容生成与后处理

- **能生成 ≠ 能直接用**：模型训练好之后，可以接收**特定输入**（如种子文本、图像样本）**生成全新内容**；但**初始生成的内容可能存在瑕疵**，必须做**后处理**。

| 内容类型 | 后处理要做什么 |
| :--- | :--- |
| **文本** | **校正语法错误、优化语句表达**，让它更通顺自然（老师提醒要检查**语病、语序、表达是否流畅**） |
| **图像** | **提升分辨率、增强画质**，让图像更清晰美观 |
| **视频** | 同样要**提高分辨率**，让画面质量越来越好 |

> ⚠️ 易错点：后处理不是"可选步骤"，而是**流程里的固定一环**——教材把它和"内容生成"合在同一阶段里，正是因为**原始输出达不到交付标准**。

### 2.5 第（5）步：反馈与模型优化

- 为了**持续提高生成内容的质量和逼真度**，还要**通过反馈不断优化模型**，让它生成的内容越来越贴合用户预期。
- 老师把这一环放在最后的用意：**流程是闭环的**——生成出来的东西交给用户，用户的反馈又回到模型里，下一轮生成才会更好。

> 📖 **教材 P23 · 单元 1「1.3」2. AIGC 的工作流程（4）（5）**：**（4）内容生成与后处理**——模型达到预期水平后接收特定输入（如**种子文本、图像样本**）生成全新内容，但**初始生成的内容可能存在瑕疵**，针对文本需**校正语法错误、优化语句表达**，针对图像需**提升分辨率、增强画质**；**（5）反馈与模型优化**——为持续提高生成内容的**质量和逼真度**，通过反馈持续优化模型。

### 2.6 老师补充的现实约束：硬件、算力与成本

老师在讲流程时插了一段很实在的提醒——**这些东西不是免费的**：

- **对硬件软件都有要求**：训练和生成对设备有门槛，**电脑配置有要求**，还要有**算力**；专业设备**很贵**。
- **对网络也有要求**：老师提到**网速**是影响因素之一（要传数据、要调服务）。
- **要花大量时间**：训练本身**很耗时**，需要长时间跑。
- **按量计费很烧钱**：老师举的是视频生成的例子——**生成一秒的视频要花费几块钱**；如果上传十几秒、渲染一晚上，那就是**很烧钱**的事情。

> 💡 理解要点：老师举"生成一秒视频几块钱"，是为了让大家对**算力的价格**有一个直观感受——**模型能力背后是实打实的算力开销**。这也解释了为什么平台会区分免费版与收费版。

## 三、AIGC 的文本生成原理（正式进入单元 2）

### 3.1 底层技术：基于 Transformer 的大语言模型

- 当前 AIGC 文本生成模型**大多是**基于 **Transformer 架构的大语言模型（Large Language Model, LLM）**。
- **技术路线**：先结合**自然语言处理（NLP）**技术，在**大规模语料**上进行**预训练**，再针对具体任务进行**微调**，从而实现文本生成。

> 📌 一句话记：**大规模语料预训练 + 具体任务微调 = 能写文章的文本生成模型**。

### 3.2 文本生成的三大阶段

老师给出的主干是**三个阶段**，并且明确说：**考试写题时要把它们写出来**。

| 阶段 | 一句话说明 |
| :--- | :--- |
| **① 输入文本理解阶段** | 先把用户输入的提示词读懂 |
| **② 内容决策阶段** | 决定"该说什么、按什么策略说" |
| **③ 输出生成文本阶段** | 真正把文字一个词一个词写出来 |

### 3.3 阶段一：输入文本理解阶段（3 个环节）

#### （1）文本预处理

- **定位**：**和前面的数据预处理是类似的思路**——数据进模型之前要先"洗干净、切整齐"。
- **三件事**：

| 环节 | 做什么 | 例子 |
| :--- | :--- | :--- |
| **清洗** | 移除文本中**无关字符**，并对**明显的拼写错误做基础校正** | 把 `the` 写成 `teh` 时要改回来 |
| **分词** | 把文本**拆分成一个个 token（词元）**；切分后的 token 可能是**一个词、子词或符号** | "小明在北京大学学习" → 切成"小明 / 在 / 北京大学 / 学习"这样的单位 |
| **归一化** | 把文本转成**统一的大小写形式**、把单词**还原为基本形式** | `App` 与 `apple` 的写法统一；`go / went / gone` 归一化后统一还原为 `go` |

- **为什么要这么折腾**：模型并不认识"字"，它只能处理被切好的、统一格式的内容——**token 是大语言模型的基本计算单位**，模型对 token 做处理与分析来理解语义与上下文，并进行生成、推理等操作。
- **清洗带掉的无关内容就是"占内存"的负担**：老师点明，把没用的东西剔除掉，是为了**不白占资源**。

> 💡 记忆点：**文本预处理三步——清洗、分词、归一化**；"分词"是把句子切成 token，"归一化"是把不同写法统一成一种。

> 📖 **教材 P35 · 单元 2「2.1」阶段一（1）文本预处理**：① **清洗**——移除无关字符，并对明显的拼写错误做**基础校正**（如 `the` 写成 `teh`）；② **分词**——把文本拆分成一个个 **token（词元）**，切分后的 token 可能是**一个词、子词或符号**，**token 是大语言模型的基本计算单位**；③ **归一化**——转换为**统一的大小写形式**、把单词**还原为基本形式**（如 `go / went / gone` 统一还原为 `go`）。

#### （2）向量化表示

- **要解决的问题**：文本被切成词之后，还需要**把每个词变成一串数字**，计算机才能算。
- **做法**：把文本中的**每个词映射为低维空间中的向量**。
- **目的——抓住语义关系**：让**语义相近的词在向量空间中距离更近**。

| 词的对比 | 向量空间中的表现 |
| :--- | :--- |
| **"国王"与"皇帝"** | 意思相近 → **距离比较近** |
| **"苹果"与"汽车"** | 意思不相干 → **距离就远** |

- **好处**：既能**降低数据维度**，又能**有效保留词语之间的语义信息**，为分类、翻译等后续任务提供高质量的输入特征。

> ⚠️ 易错点（也是最好考的一处）：**向量化的实现方式是"词嵌入（word embedding）技术"，不是"归一化"**。归一化属于**文本预处理**（统一大小写、还原词形），两者别混。

> 💡 记忆点：**"国王"离"皇帝"近，"苹果"离"汽车"远**——一个例子记住"向量空间里距离 = 语义相似度"。

> 📖 **教材 P35—P36 · 单元 2「2.1」阶段一（2）向量化表示**：通常通过**词嵌入（word embedding）技术**实现，把每个词映射为**低维空间中的向量**，使**语义相近的词在向量空间中距离更近**；既能**降低数据维度**，又能**有效保留词语之间的语义信息**。

#### （3）编码与特征提取

- 向量化之后的数据进入 Transformer 的**编码器（Encoder）**部分。
- 编码器由**多个相同的层堆叠**而成，每个层都包含**多头自注意力层**和**前馈神经网络层**。
  - **多头自注意力层**：从**多个角度**捕捉文本中不同位置的语义信息——例如输入"鸟儿在天空中飞翔"，模型能确定"鸟儿"与"飞翔""天空"等词的**关联程度**，为每个词**分配不同的注意力权重**。
  - **前馈神经网络层**：对多头注意力层的输出做**特征提取与变换**，把文本编码为**富含语义信息的中间表示向量**。

> 📖 **教材 P36 · 单元 2「2.1」阶段一（3）编码与特征提取（与前表对应）**
> 向量化后的数据进入 Transformer 的**编码器（Encoder）**；编码器由**多个相同的层堆叠**而成，每层包含**多头自注意力层**和**前馈神经网络层**——多头自注意力层从多个角度捕捉不同位置的语义信息，为每个词**分配不同的注意力权重**；前馈神经网络对多头注意力层的输出做特征提取与变换，把文本编码为**中间表示向量**。
>

### 3.4 阶段二、阶段三（老师只点了名，未展开）

老师把三大阶段的主干交代完之后，**没有再逐环节展开**后两个阶段。为保持知识链完整，这里只把教材的骨架列出，**作为对照用**，不作为课堂重点：

- **内容决策阶段（3 个环节）**：**外部资源检索**（从数据库、知识图谱及 API 获取信息，确保用最新最准确的信息）→ **逻辑推理**（把模型内部知识与检索到的外部资源结合，生成联合逻辑推理结果）→ **内容选择或策略生成**（从训练数据中抽取相关信息，或按预先设定的规则选择最佳响应）。
- **输出生成文本阶段（4 个环节）**：**解码器初始化**（由 Transformer 的解码器主导，生成第一个词时用起始标记向量）→ **自回归生成**（从左到右依次生成每个词，输出表示所有可能单词的概率分布向量）→ **采样策略与多样化生成**（如温度采样，使模型有一定可能选择概率较低的词，让文本更有创意）→ **生成文本优化与完善**（检查流畅性、连贯性和语义合理性，低于预设阈值则重新生成或做语法修正、敏感性检查、重复内容过滤）。

## 四、AIGC 的文本生成工具

### 4.1 两大类：写作工具 vs 智能对话工具

**分类依据**：按**交互方式**不同来分。

| 类别 | 定位 | 主要形态 |
| :--- | :--- | :--- |
| **写作工具** | **任务导向型**的文本生成工具 | 支持**结构化写作**与**创作型写作** |
| **智能对话工具** | 支持**开放式自然语言对话及多轮交互**的工具 | 一个输入框，发需求，收回复；能依据**上下文连续对话** |

> 📌 一句话记：**写作工具是"帮你交稿"，对话工具是"陪你聊出来"。**

### 4.2 写作工具的两种写法

| 类型 | 含义 | 适用内容 |
| :--- | :--- | :--- |
| **结构化写作** | 根据**特定场景**，利用**模板、规则或领域知识**生成具有**明确结构和格式**的文本 | **公文、新闻稿**等 |
| **创作型写作** | 提供**更高的开放度和自由度**，强调**创意和个人风格** | **营销文案、故事**等需要灵活性和独特性的内容 |

- 两者的差别就一个字：**收** vs **放**——结构化写作**收**（按格式来，不能跑偏），创作型写作**放**（思维发散，突出个人风格）。

> ⚠️ 易错点：**"结构化写作"匹配的是公文、新闻稿**；**"创作型写作"匹配的是营销文案、故事**。这两组对应关系最容易互换出错。

## 五、AIGC 的文本生成提示词设计（3 步走）

**总方法**：文本生成的提示词设计大致分为 **3 步**。

```text
第 1 步  明确生成目标  →  第 2 步  细化需求要点  →  第 3 步  测试和迭代优化
```

> 📌 这三步是一条**单向推进、但要回头迭代**的链条：目标定不下来，细化就没有意义；细化完了还要靠测试发现问题、回头改提示词。

### 5.1 第 1 步：明确生成目标

先要明确需要工具生成**哪个领域、哪种类型**的文本（如故事、文案、学术分析等）。生成目标应具备**两个特性**：

| 特性 | 含义 | 书上示例 |
| :--- | :--- | :--- |
| **（1）具体性** | 生成目标**越具体，越有利于文本的准确生成**；描述不能含糊不清 | ❌ 模糊：写一篇科普文章。<br>✅ 具体：写一篇关于**自然语言处理原理**的科普文章。 |
| **（2）独一性** | 提示词中**只设置一个生成目标**，避免一次设置多个不同类型的目标导致**生成内容杂乱** | ❌ 多个：创作以"春雨"为主题的诗、5 月健身计划及五一旅游攻略。<br>✅ 独一：以"春雨"为主题，创作**一首七言绝句**。 |

- **老师说得很直白**：如果你只写"写一篇科普文章"就丢给它，它一定会反过来问你——**"你想要什么领域呢？"** 与其被反问一轮，不如**一步到位**，把具体的生成目标直接写出来。
- **"独一性"反例的要点**：像"写一首以创意为主题的诗 + 一份 5 月健身计划 + 一篇五一旅行攻略"这种，**三个不同类型的目标挤在一句提示词里**，生成出来的内容一定是**杂乱**的。

> ⚠️ 易错点：**"独一性"≠"唯一性"的写法**要按教材记作**独一性**，意思是"**只设一个生成目标**"，不是"目标必须独一无二、别人没写过"。

> 📖 **教材 P46 · 单元 2「2.3 AIGC 的文本生成提示词设计」第 1 步（原文要点）**
> 首先要明确需要 AIGC 文本生成工具生成**哪个领域、哪种类型**的文本（如故事、文案、学术分析等）。**（1）具体性**——生成目标越具体，越有利于文本的准确生成，描述应不含糊不清；示例：❌ 模糊"写一篇科普文章"／✅ 具体"写一篇关于**自然语言处理原理**的科普文章"。**（2）独一性**——提示词中**只设置一个生成目标**，避免一次设置多个不同类型目标导致生成内容杂乱；示例：❌ 多个"创作以'春雨'为主题的诗、5 月健身计划及五一旅游攻略"／✅ 独一"以'春雨'为主题，创作**一首七言绝句**"。

### 5.2 第 2 步：细化需求要点（7 个维度）

在明确生成目标的基础上，对需求的要点进行细化——**这 7 个维度是本节的重点，老师逐条举了例子**。

| 维度 | 说明 | 提示词示例 |
| :--- | :--- | :--- |
| **① 风格** | 决定生成文本的**语言特点、表达方式和整体氛围** | 请用**严谨、正式的学术风格**，分析**人工智能在医疗诊断中的应用和潜在风险** |
| **② 字数** | 明确文本的**篇幅**。根据具体字数要求和使用场景设定合适的字数范围，使文本既包含足够信息，又不至于过于冗长或简短 | 请创作一首**不超过 20 行**的现代诗歌，主题为"城市的夜晚"（日常写作中老师常提的是"**不超过 200 字**"这类限制） |
| **③ 受众** | 文本的**目标读者群体**。考虑受众的**年龄、性别、教育程度、兴趣爱好、专业背景**等因素，使文本更贴合其需求与理解水平 | 面向**专业的程序员**，介绍一种新的编程语言特性，需包含技术细节和实际应用案例 |
| **④ 目的** | 生成文本想达成的目标，如**宣传推广、教育科普、娱乐休闲、说服劝导**等。明确目的有助于确定重点内容和表达方式 | 创作一篇关于环保的科普文章，**目的是加强公众的环保意识**，介绍一些简单易行的环保生活方式 |
| **⑤ 语言** | 文本所使用的**语种或方言**，如中文、英文、粤语等 | 使用**四川方言**创作一个简短的幽默故事，体现当地的生活气息 |
| **⑥ 背景** | 与文本相关的**背景情境信息**，如特定的时间、地点、事件、行业背景 | 在**当前全球气候变暖的背景下**，撰写一篇关于**可再生能源发展前景**的分析报告，需结合最新的科研数据和政策动态 |
| **⑦ 限制条件** | 对生成文本的**特殊要求**，如必须引用特定文献资料、不能包含某些词汇或内容、要遵循特定规则或标准 | 撰写一篇关于科技发展的文章，**限制条件是不能使用"人工智能"这个词**，但需提及相关的技术概念 |

- **受众这一条老师说得很具体**：要**说明面向的群体是什么样的**（面向谁写，用词深浅完全不同）。
- **语言这一条最好记的例子**：**用四川方言写一个简短的幽默故事，体现当地的生活气息**。
- **背景这一条的例子**：**在当前全球变暖的背景下**，写一篇**可再生能源发展前景**的分析报告——把那句"背景"直接写进提示词里。
- **限制条件的例子**：写科技发展主题的文章，**不许出现"人工智能"这四个字**，但又要提到相关技术概念——这就是典型的"限制条件"。

> 💡 记忆点：**风格、字数、受众、目的、语言、背景、限制条件**——7 个维度可以简化记成一句话："**怎么说（风格）· 说多长（字数）· 说给谁（受众）· 为什么说（目的）· 用什么话（语言）· 在什么情况下说（背景）· 什么不能说（限制条件）**"。

> 📌 考点提示：这 7 个维度是表 2-3 的内容，**教材课后习题里专门考了"细化需求要点的常见维度有（多选）"**——所以**七个都要能报出来**。

### 5.3 第 3 步：测试和迭代优化

当 AIGC 生成的内容**不符合用户预期**时，需要对提示词进行**测试和迭代优化**。老师给出的关键动作是：**先测试，再根据结果不断调整、更新提示词**。

**三类常见偏差与对应优化策略**：

| 偏差类型 | 典型表现 | 优化策略 |
| :--- | :--- | :--- |
| **① 内容缺失** | **核心信息缺失**，例如产品参数、关键数据没有呈现 | ① **参数显性化**，明确核心指标——如把提示词片段"介绍续航能力"改为"**标注 72 小时连续续航参数**"；② **场景具象化**，补充时空限定条件——如"分析 **2025 年五一**国内旅游人次数据" |
| **② 表达精确性差** | **语言风格与目标受众不匹配**，例如对青少年群体使用高深的专业术语 | ① **风格锚定**，指定参照对象——如"采用《**博物**》杂志的科普语言风格"；② **细化受众画像**，补充群体特征——如"**面向 12~15 岁学生**，需采用**游戏化表达方式**" |
| **③ 逻辑失衡** | **任务复杂度超出模型单次处理能力**，例如**逻辑链条断裂、推理步骤缺失** | ① **分步骤下达指令**——如"**第一步**分析行业现状与痛点；**第二步**基于上述结论提出 3 种解决方案"；② **优先级标注**，明确执行顺序——如"**优先**完成竞品对比分析，**次要**补充市场趋势" |

- **"参数显性化"的典型改法**：原话里"七十四片段七十续航能力"这类说法含混不清，**改成明确写清是 72 小时的准确续航参数**，模型才知道该报什么数字。
- **"表达精确性"的典型改法**：把受众写死——比如明确"**面向 12 到 15 岁的学生，采用游戏化的表达方式**"，生成出来的语气立刻就变了。

> ⚠️ 易错点：**优化策略要和偏差类型配对记**——"内容缺失"配**参数显性化／场景具象化**；"表达精确性差"配**风格锚定／细化受众画像**；"逻辑失衡"配**分步骤下达指令／优先级标注**。这三对一旦错位，选择题必错。

> 📖 **教材 P47 · 单元 2「2.3」第 3 步（原文要点）**
> 当 AIGC 生成的内容不符合用户预期时，需要对提示词进行**测试和迭代优化**。**① 内容缺失**——核心信息缺失，例如产品参数、关键数据未呈现；优化策略：**参数显性化**（明确核心指标，如把"介绍续航能力"改为"标注 **72 小时**连续续航参数"）、**场景具象化**（补充时空限定条件，如"分析 **2025 年五一**国内旅游人次数据"）。**② 表达精确性差**——语言风格与目标受众不匹配，例如对青少年群体使用高深的专业术语；优化策略：**风格锚定**（指定参照对象，如"采用《**博物**》杂志的科普语言风格"）、**细化受众画像**（补充群体特征，如"面向 **12~15 岁学生**，需采用**游戏化表达方式**"）。**③ 逻辑失衡**——任务复杂度超出模型单次处理能力，例如逻辑链条断裂、推理步骤缺失；优化策略：**分步骤下达指令**（如"第一步分析行业现状与痛点；第二步基于上述结论提出 3 种解决方案"）、**优先级标注**（明确执行顺序，如"优先完成竞品对比分析，次要补充市场趋势"）。

### 6.1 科普文章写作：定义、痛点与 AIGC 的优势

- **科普文章写作的定义**：将**科学知识、科学方法以及科学思想**，以**通俗易懂、生动有趣**的文字向**普通大众**普及的一种写作形式，旨在让**非专业人士能够理解和接受**科学内容，激发他们对科学的兴趣和探索欲望。
- **传统方式的痛点**：对写作者要求较高，需要具备**扎实的科学知识、良好的文字表达能力、对受众认知特点的准确把握**。
- **AIGC 的优势**（三条）：
  1. 内置**海量多学科数据**，可快速整合领域信息，**弥补写作者的知识缺陷**；
  2. 支持按指令**灵活切换语言风格**（如童趣风格、学术风格），高效适配不同受众需求；
  3. 能**自动优化文本、提升文本质量**。

### 6.2 实践任务 2-1：科普文章《河流是如何形成的》

**任务情境**：假设你是一名优秀的科普文章写作者，需编写一篇**微信公众号文章**，主题是"**河流是如何形成的**"，主要受众是 **8~12 岁的小学生**，用 AIGC 文本生成工具完成。**使用工具：讯飞绘文。**

**总方法：分阶段设计提示词**——**先设计生成文章大纲的提示词**，待生成的大纲**符合要求后**，再**基于大纲设计生成文章的提示词**。这样才能确保最终产出与预设架构一致。

```text
第 1 步  设计"生成大纲"的提示词
            关键要素：写作者角色 · 生成目的 · 文章的类型 · 文章的主题 · 文章的受众 · 大纲标题数量
                ↓
第 2 步  生成大纲，并核对是否符合预期
            不符 → 手动修改大纲内容，或单击 ↻ 按钮重新生成
                ↓
第 3 步  设计"生成文章"的提示词（基于已确认的大纲）
                ↓
第 4 步  生成文章 → 复核（一次会给出多篇，可挑选参考）
```

**第 1 步：大纲提示词把哪些要素写进去了**——老师逐项点了名：

| 要素 | 本例的取值 |
| :--- | :--- |
| **写作者角色** | 儿童科普作家 |
| **生成目的** | 为一篇**校园公众号**的科普文章撰写一份大纲 |
| **文章的类型** | 科普文章（校园公众号推文） |
| **文章的主题** | **河流是如何形成的** |
| **文章的受众** | **8~12 岁的小学生** |
| **文章的风格** | **拟人化叙事风格** |
| **大纲标题数量** | **不少于 3 个**大纲标题 |

> （2）文章的受众：8~12 岁的小学生。

**第 2 步：生成大纲**

1. 在**讯飞绘文**的创作首页中单击"**知识科普**"按钮，进入**起稿页面**；

> 📖 **教材 P49—P50 · 实践任务 2-1 步骤 3：书中示例提示词**

### 6.3 实践任务 2-2：课题报告《中学生课后辅导模式优化》（教材对照）

老师在讲完科普文章之后**接着说明了下一个任务**：同样是**分阶段设计提示词**——先设计生成大纲的提示词，待大纲符合要求后，再基于大纲生成课题报告；**使用工具：豆包**。

- **课题报告的定义**：对科研课题的研究过程与成果进行**系统梳理、深入分析和全面呈现**的书面材料。它围绕特定研究主题，科学阐述**研究背景、目标、方法、实施过程、成果及核心结论**，具有较强的**严谨性、科学性与逻辑性**。
- **传统方式的痛点**：需写作者手动整理大量研究资料与数据，**耗时较长**，也对**信息整合能力与表达水平**提出较高要求。
- **AIGC 的优势**：可在已有研究成果基础上**快速生成结构清晰、语言规范的报告初稿**，显著提升写作效率与文本质量。

## 七、本节要记住的清单（复习用）

1. **生成对抗网络（GAN）** = **生成器**（造伪样本）＋ **判别器**（辨真伪），两者**互相博弈、交替提高**。
2. **扩散模型** = **正向扩散**（逐步加噪到纯噪声）＋ **逆向扩散**（逐步去噪还原）。
3. **AIGC 工作流程 5 步**：数据收集与处理 → 模型选择与训练 → 特征学习与优化 → 内容生成与后处理 → 反馈与模型优化。
4. **预处理要针对不同内容分开做**：文本管语法/语义/逻辑脉络，图像管色彩/形状/纹理；**后处理**里文本改语法语句、图像视频提分辨率。
5. **文本生成三大阶段**：输入文本理解 → 内容决策 → 输出生成文本。
6. **文本预处理三步**：**清洗**（去无关字符、纠正拼写）→ **分词**（切成 token，token 是大语言模型的基本计算单位）→ **归一化**（统一大小写、还原词形）。
7. **向量化表示**用**词嵌入**技术，把词映射为低维向量；**语义相近的词在向量空间中距离更近**（国王↔皇帝近，苹果↔汽车远）。
8. **文本生成工具两大类**：**写作工具**（结构化写作↔公文/新闻稿；创作型写作↔营销文案/故事）＋ **智能对话工具**（开放式、多轮）。
9. **新华妙笔**：新华社系、面向党政机关/事业单位/国企央企的公文平台；对话框 5 项设置——**写作场景、基础信息、摘要信息、大纲信息、参考文档**；工具 **AI 写作、AI 校对、AI 润色、AI 提纲**。
10. **讯飞绘文**：科大讯飞基于**讯飞星火大模型**的一站式写作平台；首页写作类型含**知识科普**等；起稿页面三块——**告诉我你想写什么 / 参考素材 / 文章配置区域**。
11. **DeepSeek 四大优势**：**长**（约 128K，普通开源模型 4~32K）、**省**（比 GPT-4 Turbo 低约 30%）、**通**（兼容 OpenAI 格式）、**快**（推理快约 20%）；V/R 系列**数字越大版本越新**。
12. **豆包**：字节跳动多模态智能交互平台；四功能——**自然语言交互、文本创作、编程辅助、多模态处理**；访问方式 **3 种（App、网页端、客户端）**。
13. **提示词设计 3 步**：**明确生成目标**（具体性 + 独一性）→ **细化需求要点**（7 维度）→ **测试和迭代优化**。
14. **细化需求要点 7 维度**：**风格、字数、受众、目的、语言、背景、限制条件**。
15. **三类偏差与优化策略**：内容缺失 → 参数显性化／场景具象化；表达精确性差 → 风格锚定／细化受众画像；逻辑失衡 → 分步骤下达指令／优先级标注。
16. **实践任务的主方法**：**分阶段设计提示词**——先出大纲、核对修改，再基于大纲出正文；**生成结果必须人工复核**。
