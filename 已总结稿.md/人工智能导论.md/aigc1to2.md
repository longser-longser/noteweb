## 2. 核心知识结构

### 2.1 智能与 AI

- **智能（Intelligence）**：人类具备的**认知、学习、理解、推理、创造、解决问题**等能力。
- **AI（Artificial Intelligence）**：通过载体（如机器人）**模拟人类智能**。

> 📖 **教材 P2 · 智能与人工智能（原文）**
> **智能**：描述人类所具备的**认知、学习、理解、推理、创造和解决问题**的能力。**人工智能**是通过机器**模拟智能**的技术探索。
> 老师原话："智能呢是一个非常广泛，而且是一个复杂的概念……它通常用来描述人类所具备的认知、学习、理解、推理、创造和解决问题的一些能力""人工智能呢，它就是通过一个载体，比如机器人，来模拟人类的智能"。

### 2.2 AI 定义的三层面

| 层面 | 定义 | 涉及学科 / 技术 |
|---|---|---|
| **学科层面** | 模拟人类智能的**交叉学科** | 计算机科学、数学、心理学、神经科学、语言学（含自然语言处理 NLP） |
| **功能层面** | 能执行人类任务的**智能系统** | 感知（图像识别、语音识别）· 认知（理解、推理）· 决策（医疗辅助诊断）· 创作（AIGC） |
| **技术层面** | 实现 AI 的**具体技术栈** | 机器学习、深度学习、自然语言处理、计算机视觉 |

> 📌 模型层数越高 → 计算能力要求越高 → 硬件（内存、GPU）需求越高 → 成本越贵。

> 📖 **教材 P2 · 1. 人工智能的定义（3 个层面，原文要点）**
> 1. **从学科层面**：致力于解释和模拟人类智能、人类智能行为及其内在规律的**学科**，与计算机科学、数学、心理学、神经科学、语言学等密切相关，主要任务是建立智能信息处理理论。（老师："我们人工智能从学科层面来讲，它是一个**交叉学科**"）
> 2. **从功能层面**：是一种**智能系统**，使计算机能执行通常需要人类智能方可完成的任务——图像识别/语音识别（**感知**任务）、自然语言理解/逻辑推理（**认知**任务）、自动驾驶/医疗诊断（**决策**任务）、艺术创作/音乐生成（**创造**任务）。老师举的身边的例子：出校门时的**人脸识别**、**语音识别**、医院里辅助医生看片（"哪些是正常的组织，哪些是病变的组织"）。
> 3. **从技术层面**：一系列**技术的集合**，主要包括**机器学习、自然语言处理（NLP）、计算机视觉**。

### 2.3 AI 分类（按智能水平）

| 类别 | 含义 | 实现状态 |
|---|---|---|
| **弱人工智能** | 专用型，只能完成特定任务 | ✅ 当前阶段 |
| **强人工智能（AGI）** | 通用型，全面模拟人脑智能 | ❌ 概念提出，未实现 |
| **超人工智能** | 超越人类智能 | ❌ 概念阶段 |

> 📖 **教材 P3 页边手写批注 + 老师课堂口头补充**
> 教材正文没有印"弱/强/超"这套分类，第 3 页页边有**手写批注**"弱人工智能、强人工智能、超人工智能"；老师课上口头讲了三条：
> - **弱人工智能**：专用型，只能完成特定任务——**我们现在所处的阶段**；
> - **强人工智能**：通用型，全面模拟人脑智能——**概念已提出，尚未实现**；
> - **超人工智能**：超越人类智能——属概念阶段（老师："帮我们人类完成一些更高度的一些任务"）。
> 老师原话："那其实人工智能呢也可以分好几类，分成三类，有一个弱人工智能。第二个就是……第三个就是超（智能）……我们现在所处的（阶段）呢，就是这种（弱人工智能）。"

### 2.4 AI 发展史（四阶段）

| 阶段 | 时间 | 关键事件 | 特点 |
|---|---|---|---|
| **萌芽期** | 20 世纪 40–50 年代 | 阿西莫夫 1942 年提出"机器人三大定律"；图灵提出图灵测试 | 思想萌芽，未成学科 |
| **早期探索期** | 1956 年起 | **1956 达特茅斯会议** → "Artificial Intelligence" 一词被提出，**AI 成为独立学科**；研究聚焦**逻辑推理 + 专家系统**（将领域知识编码，模拟专家决策） | 专家系统未发展起来 |
| **低谷期**（AI 寒冬） | 教材为准 | ① **硬件跟不上**（内存、CPU 速度）；② 公众与投资界**期望落差**→撤资 | 发展停滞 |
| **崛起期** | 21 世纪以来 | 机器学习算法兴起（SVM、CNN 等）+ 大数据 + 算力提升；**2016 AlphaGo 击败李世石**成为标志事件 | AIGC、深度学习爆发 |

> ✅ 必考点：达特茅斯会议 1956 年 → AI 成为独立学科。

> 📖 **教材 P3 · 2. 人工智能的发展历程（4 个阶段，原文要点）**
> - **（1）萌芽阶段（20 世纪 40—50 年代）**：1942 年科幻小说作家**艾萨克·阿西莫夫**提出**机器人三大定律**；1950 年数学家**阿兰·图灵**提出**图灵测试**（机器与人类通过电传设备对话且人类无法辨别其机器身份即具有智能，成为开创性、可操作的智能判定标准）；**1956 年达特茅斯会议**上科学家们首次提出"人工智能"这一概念并提出研究目标（使机器能够模拟人类智能），标志人工智能正式成为一门独立学科。
> - **（2）早期探索阶段（20 世纪 60—70 年代）**：集中于**逻辑推理**（基于形式化逻辑规则，如命题逻辑规则、谓词逻辑规则）与**专家系统**开发；首个自然语言处理系统 **Eliza** 可模拟心理治疗师与人类对话；受计算能力和数据量限制发展缓慢。
> - **（3）低谷阶段（20 世纪 80—90 年代）**：受计算机内存和处理速度限制，政府与企业投资热情大幅减退，研究陷入资金匮乏、项目停滞。
> - **（4）崛起阶段（21 世纪初至今）**：机器学习、支持向量机等技术重大突破，大数据时代提供海量训练数据，**深度学习**技术开始崭露头角。
>
> 老师原话："这个会议叫**茅斯会议**（＝达特茅斯会议），就一九五六年……它标志着这个人工智能成为了一个独立的学科""早期探索阶段……主要研究的是模拟推理（＝逻辑推理）和专家系统""低谷……还是因为这个硬件跟不上，比如在内存还有 CPU 的处理速度""崛起阶段……包括一些算法，像机器学习的 SVM 这些"。

### 2.5 AIGC 与生成式 AI

- **AIGC（AI-Generated Content）**：用 AI 生成内容（文本、图像、音视频、代码）。
- **生成式 AI（Generative AI）**：与 AIGC 近义，覆盖文本/图像/视频生成。
- **AIGC 工作流程**（教材展开）：输入需求 → 选择模型 → 生成内容 → 评估与迭代。
- **常见生成式模型 / 创作平台**（教材列四个，老师未一一列举，**请以教材为准**）：
  - 文生图：豆包图像、即梦、Stable Diffusion、Midjourney、DALL·E
  - 文生视频：可灵（快手）、Sora、Vidu，以及老师口头提到的国内（清华 / 百度系）视频生成模型
  - 文生文：豆包、文心一言、通义千问、ChatGPT、DeepSeek
- **AIGC 发展意义**：这两年（尤其本年）AIGC 话题极热，是 AI 应用的爆发方向。

### 2.6 提示词工程（Prompt）

- **提示词（Prompt）**：与 AI 沟通时的输入文本。
- **构成要素**（教材展开）：
  - **角色**（Role）：让模型扮演的身份
  - **任务**（Task）：明确要做什么
  - **上下文**（Context）：背景信息
  - **格式**（Format）：输出形式（表格 / JSON / Markdown / 列表等）
  - **约束**（Constraints）：字数、风格、禁用词等
- 写法细节 → **下节课继续讲**。

### 2.7 AI 幻觉（Hallucination）

- **定义**：AI 模型**看似合理但实际错误或编造**的内容输出。
- **常见现象**：用豆包等大模型时，它可能"一本正经胡说八道"。
- **分类**（教材展开）：
  - **事实性幻觉**：编造不存在的事实
  - **忠实性幻觉**：与输入指令矛盾
  - **上下文幻觉**：多轮对话中遗忘前文

## 4. 实操：conda 环境管理

### 4.1 命令速查表

| 功能 | 命令 | 说明 |
|---|---|---|
| **创建环境** | `conda create -n 环境名` | `-n` = `--name`，新建独立环境 |
| **切换 / 激活环境** | `conda activate 环境名` | 进入指定环境（命令行前缀会变化） |
| **退出环境** | `conda deactivate` | 回到默认 base 环境 |
| **安装 Python** | `conda install python==3.8` | 在当前激活环境安装指定版本（示例为 3.8） |
| **查看已安装包** | `conda list` | 列出当前环境所有包及版本 |
| **查看所有环境** | `conda env list` | 列出本机全部 conda 环境 |

### 4.2 易错点（拓展理解）

- `conda install python==3.8` 中的 `==3.8` 必须是**已激活目标环境**才会装到该环境，否则装到 base。
- `conda env list` 与 `conda list` 不同：前者看"环境清单"，后者看"当前环境的包清单"。
- 删除环境：`conda remove -n 环境名 --all`。
- 环境隔离意义：不同项目用不同 Python 版本（如 3.8 vs 3.11）或不同框架版本时互不干扰。
