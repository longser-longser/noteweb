### 🎙 开头老师带着回顾了 P2—P3（上节课内容）

> 📖 **教材 P2 · 1.1.1 人工智能的基础知识**
> - **智能**：描述人类所具备的**认知、学习、理解、推理、创造和解决问题**的能力；**人工智能**则是通过机器模拟智能的技术探索。
> - **1. 人工智能的定义**（归纳为 3 类）：
>     1. **从学科层面**：致力于解释和模拟人类智能、人类智能行为及其内在规律的学科，与计算机科学、数学、心理学、神经科学、语言学等密切相关，主要任务是建立智能信息处理理论。
>     2. **从功能层面**：是一种智能系统，使计算机能执行通常需要人类智能方可完成的任务——图像识别/语音识别（**感知**）、自然语言理解/逻辑推理（**认知**）、自动驾驶/医疗诊断（**决策**）、艺术创作/音乐生成（**创造**）。
>     3. **从技术层面**：一系列技术的集合，主要包括机器学习、自然语言处理（NLP）、计算机视觉（Computer Vision）。

> 📖 **教材 P3 · 2. 人工智能的发展历程（4 个阶段）**
>
> | 阶段 | 时间 | 关键事件 / 特征 |
> | :--- | :--- | :--- |
> | （1）萌芽阶段 | 20 世纪 40—50 年代 | 1942 年阿西莫夫提出**机器人三大定律**；1950 年图灵提出**图灵测试**（人与机器通过电传设备对话、人类无法辨别其机器身份即具有智能）；1956 年**达特茅斯会议**首次提出"人工智能"概念，标志其成为一门独立学科 |

## 🧠 二、 人工智能的四大核心要素
人工智能的能力上限由以下四个要素相互作用决定：

> 📖 **教材 P4 · 1.1.2 人工智能的核心要素**
> 人工智能的核心要素主要包括**模型、数据、算法、算力**，这些要素**相互作用，决定了人工智能的能力上限**。**下面对人工智能的这 4 个核心要素进行说明。**

### 1. 模型 (Model)
- **定义**：以数学为根基构建的抽象化结构，具备数据处理、学习与预测能力。可视为一个经过精心设计的“复杂容器”。
- **工作原理**：基于训练数据学习 → 掌握知识/特征 → 对新数据进行预测或决策。
- **应用领域**：
    - *图像识别*：学习标注图像（猫/狗）特征，识别新图像类别。
    - *自然语言处理*：学习文本语法规则，实现翻译、问答等。

> 📖 **教材 P4 · 1. 模型（原文要点）**
> 人工智能中的模型是一种**以数学为根基构建的抽象化结构**，具备对数据进行处理、学习以及预测的能力。简单来讲，模型就像是一个**经过精心设计的复杂容器**，它基于训练数据进行学习，并利用学到的知识完成各种智能任务。
> - 图像识别：模型通过对**大量标注好的图像数据**（如标注出图中物体是猫、狗）进行学习，逐渐了解不同物体的特征，进而在遇到新的未标注图像时，能准确判断物体类别。
> - 自然语言处理：模型通过**学习大量文本数据**，掌握语言的语法规则、语义表达等，从而实现文本分类、机器翻译、智能问答等功能。

#### 📊 模型的三大分类维度

| 分类维度 | 类别 | 核心特点 | 典型应用/示例 |
| :--- | :--- | :--- | :--- |
| **(1) 按学习范式** | ① 监督学习 | 使用**已标注**数据（输入+标签），学习映射关系。 | 天气预报、疾病诊断、图像分类、垃圾邮件过滤。 |
| | ② 无监督学习 | 使用**未标注**数据，自行发现内在结构/规律。 | 客户细分、市场调研、异常检测。 |
| | ③ 半监督学习 | 结合**少量标注 + 大量未标注**数据，降低成本。 | 医疗影像分析（医生标注成本高）。 |
| | ④ 自监督学习 | 从数据本身生成监督信号（部分作输入，部分作目标）。 | 计算机视觉预训练、NLP大模型预训练。 |
| | ⑤ 强化学习 | 智能体(Agent)与环境交互，通过**奖惩机制**试错学习。 | 机器人控制、游戏AI、自动驾驶。 |
| **(2) 按模型架构** | ① 机器学习 | 基于传统统计学，逻辑清晰，**可解释性强**，计算成本低。 | 结构化数据、小规模场景。 |
| | ② 深度学习 | 基于深度神经网络，自动提取深层特征，**需强大算力**。 | 图像、语音、文本等高维数据。 |
| | ③ 混合架构 | 结合ML与DL优点，灵活应对复杂任务。 | 先用ML提特征，再用DL分类。 |
| **(3) 按参数特性** | ① 参数模型 | 结构固定，由一组固定参数决定（如大语言模型）。 | 训练高效，但灵活性较差，依赖分布假设。 |
| | ② 非参数模型 | 无固定参数集，根据数据动态调整，**灵活性高**。 | 复杂数据分布，但预测时计算成本高。 |

> 📖 **教材 P4—P5 ·（1）按学习范式分类（原文要点，共 5 类）**
> **学习范式**＝模型学习和处理数据的方式与准则，它决定了模型如何从数据中提取知识以及进行决策和预测。
> - **① 监督学习模型（P4）**：在**已标注**的数据上进行训练；训练数据集中每个样本都包含**输入特征**和对应的**输出标签（也称目标值）**；模型通过学习输入特征与输出标签之间的**映射关系**，对新的、未标注的数据进行预测。应用：天气预报、疾病诊断、图像分类、垃圾邮件过滤。
> - **判别式模型 / 生成式模型（P5）**：监督学习模型可按**建模方式**分为——**判别式模型**（专注于分类和回归任务）、**生成式模型**（不仅可用于分类，**还能生成新的样本数据**）。⭐这句就是 AIGC 的根。
> - **② 无监督学习模型（P5）**：在**没有标注**的数据上进行训练，模型自行发现数据的**内在结构和规律**，例如将数据分为不同的簇、发现数据中的异常点。应用：客户细分、市场调研、数据可视化、异常检测（例：按客户消费行为、人口统计学特征把客户划分为不同群体，便于精准营销和个性化服务）。
> - **③ 半监督学习模型（P5）**：结合**少量的有标注数据和大量的无标注数据**进行训练，利用无标注数据中的信息辅助学习、提高性能，同时**减少对大量标注数据的依赖，降低数据标注的成本和工作量**。例：医疗领域标注医学图像需要专业医生花费大量时间和精力，故用少量标注图像 + 大量未标注图像训练，用于疾病诊断和图像分析。
> - **④ 自监督学习模型（P5）**：一种**特殊的无监督学习模型**，通过**在数据本身中生成监督信号**来进行学习——利用数据的内在结构和相关性，把数据的**一部分作为预测目标、另一部分作为输入特征**，学习如何根据输入特征预测目标。在计算机视觉和自然语言处理等多个领域有重要应用（例：先学到图像的通用特征表示，再在特定图像分类/目标检测任务上**微调**，显著提高性能与泛化能力）。
> - **⑤ 强化学习模型（P5）**：通过**智能体（Agent）与环境（Environment）**之间的交互来学习**最优行为策略**；环境根据智能体的行动给出相应的**奖励或惩罚**信号，智能体的目标是**通过不断试错，最大化长期累积奖励**。应用：机器人控制、游戏、自动驾驶（例：机器人导航任务中，机器人作为智能体要学习在不同环境条件下采取合适行动——前进、转弯、避障等，以到达目标位置并获得最大奖励，同时避免碰撞）。
>
> 🎙 老师讲这一段的原话（转写）：“在监督学习和无监督有一个半监督学习，你就这样记……”“监督学习就是**有标准答案的学习**”“无监督……**把相似的放一堆**”“自监督……**可以自己打标签**”“强化学习……在环境中不断地试错，然后接收奖励或者惩罚……**得到最大的奖励**”。

> 📖 **教材 P6 ·（2）按模型架构分类（原文要点，共 3 类）**
> **模型架构**指的是模型的**具体结构和设计**，它定义了模型的组成部分、各部分之间的连接方式以及数据如何流动。
> - **① 机器学习模型**：基于**传统的统计学理论和算法**构建，结构相对简单、模型逻辑清晰、**可解释性强**、训练和预测计算成本相对较低，但可能需要较多**人工干预来调整特征**；适用于结构化数据和小规模场景。
> - **② 深度学习模型**：以**深度神经网络**为主要架构，通过**多层非线性变换**自动从原始数据中找出深层次规律，**减少对人工特征工程的依赖**；对大规模数据集和高维数据（图像、语音、文本）处理出色，但**计算量大、需要强大的硬件支持**，如 GPU（图形处理单元）和 TPU（张量处理单元），**可解释性相对较差**。
> - **③ 混合架构模型**：结合**机器学习模型和深度学习模型**的特点，先做初步数据处理或特征提取，再输入深度神经网络。
>
> 🎙 老师讲这一段的原话（转写）：“机器学习模型……**可解释性比较强**，训练成本比较低”“深度学习模型……这个**训练过程非常大，需要非常强大的支持**”“混合架构模型……根据不同模型的优点，提高模型的性能”。

> 📖 **教材 P6—P7 ·（3）按参数特性分类（原文要点，共 2 类）**
> **模型参数**指模型内部**可调整的变量**。
> - **① 参数模型（P6）**：结构和功能由**一组固定参数**决定，参数在训练过程中通过优化算法调整，具有明确的数学表达式，一旦参数确定、模型行为就相对固定；**当前较为流行的大语言模型本质上就属于参数模型**。参数模型结构固定、训练和预测相对高效，但**灵活性相对较差**。
> - **② 非参数模型（P7）**：结构和功能**不依赖于固定的参数集合**，根据数据特点和需求动态调整和确定，通常**没有明确的参数形式**；**灵活性和适应性强**，能处理各种复杂的数据分布和关系，通常基于数据的**局部特征或相似性**来预测或分类；但预测时需对**大量数据进行比较和计算，计算成本通常较高**。

> **💡 补充知识点**：监督学习可进一步分为 **判别式模型**（专注分类/回归）和 **生成式模型**（可生成新样本，AIGC的核心）。

### 2. 数据 (Data)
- **地位**：AI 的基础，如同人类学习的知识与经验。
- **质量四要素**（决定模型性能的关键）：
    1.  **准确性**：真实反映客观事实。
    2.  **完整性**：无缺失或遗漏重要信息。
    3.  **一致性**：不同记录/来源间保持统一。
    4.  **代表性**：涵盖高频/关键情况，避免训练偏差。

> 📖 **教材 P7 · 2. 数据（原文要点）**
> **数据是人工智能的基础**，为模型提供各种现象和问题的信息；模型通过分析处理发现模式、关系和规律，完成对未知数据的预测、分类、生成等任务。**数据质量至关重要**——数据应具有：
> - **准确性**：确保真实反映客观事实；
> - **完整性**：保证没有缺失或遗漏重要信息；
> - **一致性**：要求在不同记录和来源中保持一致；
> - **代表性**：意味着能涵盖问题域中高频和关键的情况，**避免训练偏差**。
>
> 🎙 老师举的例子：完整性像是"找**学生表**，该有的字段不能少"；一致性像是"**你的名字**在一个表里写这个年级、另一个表里写大一，两处要一致"；代表性像是"做**人脸识别**，训练数据里得有儿童、小孩、年轻人，不然识别不准"。

### 3. 算法 (Algorithm)
- **地位**：AI 的核心驱动力，决定如何从数据中学习。
- **作用**：定义模型结构、优化目标和学习规则，通过最小化损失函数或最大化奖励函数来调整参数。
- **常见类型**：机器学习算法（监督/无监督/强化）、深度学习算法（CNN, RNN等）。

> 📖 **教材 P7 · 3. 算法（原文要点）**
> **算法是人工智能的核心驱动力**，决定模型**如何从数据中学习和提取知识**；常见算法包括**机器学习算法**（监督学习、无监督学习、强化学习等）和**深度学习算法**（神经网络、卷积神经网络、循环神经网络等）。

### 4. 算力 (Computing Power)
- **定义**：计算机系统执行数学运算、逻辑判断的能力。
- **硬件支撑**：GPU、TPU、FPGA 等高性能并行计算设备。
- **软件优化**：高效算法设计（如改进梯度下降）、分布式计算策略，以提升资源利用率并缩短训练时间。

> 📖 **教材 P7 · 4. 算力（原文要点）**
> **算力指计算能力**，即计算机系统执行数学运算、逻辑判断、数据处理等任务的能力；常见高性能硬件设备包括 **GPU、TPU、FPGA**（Field Programmable Gate Array，现场可编程门阵列）。算力还依赖**软件层面的支撑**，可通过高效算法设计和先进的**分布式计算策略**提升（把复杂计算任务拆解后分配至多个计算节点并行执行）。

### 1. 命名规范
- **格式**：`姓名拼音_学号后三位`
- **示例**：`zhangsan_001`
- ⚠️ **录音核对**：这一条在 `aigc3to4.txt` 转写稿里**找不到对应原话**（老师只演示了"以你的（名字）命名""创建一个名字为**张三**的"）。原样保留，但请以老师课上或考试要求为准。

### 2. 标准操作流程 (SOP)

```bash
# Step 1: 查看当前所有环境
conda env list

# Step 2: 创建新环境 (替换 <name_id> 为你的姓名学号)
conda create -n <name_id> python=3.9

# Step 3: 激活/切换到新环境
conda activate <name_id>

# Step 4: (实验完成后) 退出当前环境
conda deactivate
```
