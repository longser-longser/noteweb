- 复习时用到的三条：

  2. AI 要**给人机对话**，并**生成到图片、视频上**，再结合生成文本、图像、视频这些东西——也就是**多模态输出**。
  3. **AIGC 与传统生成方式的区别**：传统是由人（专业生产者）来生产内容；AIGC 是**机器把数据学习完之后可以直接拿来用，能够独立地、自动地完成内容生产**。

> 💡 **记忆点**：这一句话就是 AIGC 与 PGC／UGC 的分界——**差别在"生成过程的自主性"**，而不是"用了什么软件"。

## 二、生成式模型之前：产业生态与"判别式 → 生成式"

### 2.1 老师回顾的 AI 基础（对应教材 1.1.3）

- **人工智能的核心要素**：模型、数据、算法、算力；其中**算力层面**老师点得很具体——他提到的是**芯片、存储、网速，以及数据**。
- **数据的形态分两类**（老师原话）：除了常见的**结构化数据**，也包括**非结构化数据**——文本、图片、视频、音频。这些数据要先做**分类操作**（预处理），才能进入后面的环节。
- **主要分支**：老师把 **机器学习与深度学习** 作为重点（第 1 单元讲过它们的特征与区别，本节末尾又列进复习清单）。

### 2.2 为什么会有 AIGC：从判别式模型到生成式模型

这是老师从第 1 单元带过来的那句话，也是本节后面所有生成式模型的"总纲"：

| 模型类别 | 擅长做什么 | 局限／突破 |
| :--- | :--- | :--- |
| **判别式模型** | 分类、回归等判别式任务，例如人脸识别、语音识别 | 只根据输入给出判断结果，**缺乏对数据分布的理解，不能生成新样本** |
| **生成式模型** | **学习数据分布，并依据学习成果生成新数据** | 随着 GAN、变分自编码器、Transformer 架构等技术的进步而成熟，使机器不仅能理解现有数据，还能**创造新内容** |

> 📌 **考点**：**"从判别式模型到生成式模型的转变，是 AIGC 得以实现的技术基础。"**

## 三、AIGC 的产业生态体系（三层）

老师按教材图 1-4 的三层结构讲了一遍，并对应到"我们平时用到的功能落在哪一层"。

### 3.1 基础层——整个体系的基石

- 定位：**依据客观存在的现有资源**提供底层支撑。
- 两块内容：
  - **算力资源**：AI 芯片、存储、网络、安全以及基础设施软件等。
  - **数据资源**：AIGC 模型训练和优化所需的**大量高质量多模态数据**。
- 老师补充的数据形态：除了**结构化数据**，还有**非结构化数据**——文本、图片、视频、音频，这些要先做**分类操作**（分类、清洗、处理）。

### 3.2 中间层——整个体系的核心

- 定位：**大规模数据训练之后**，开发出**特定的模型**。
- 内容：在基础层的大规模预训练模型之上，做**针对特定行业或应用场景的小型化、定制化模型**；同时提供**应用程序接口（API）**、**软件开发工具包（SDK）**、在线服务平台，以及数据标注、模型优化等服务，方便开发者快速部署和集成。

### 3.3 应用层——整个体系的终端

- 定位：**针对不同的场景进行部署**，面向一定的领域和组织，用到具体行业、具体公司。
- 老师的原话很有画面感：**"像我们生成的那些东西，都是在应用层完成的。"**
- 他还强调了一句：**"做出来的东西其实跟现实比，要复杂得多，应用也非常广泛。"**

> ⚠️ **易错点**：三层不能混着记——**基础层给"料"（算力＋数据），中间层给"模型和接口"，应用层给"用得上的功能"**。老师提醒的"我们生成的那些东西在应用层完成"，说的就是这一点。

## 四、生成式模型（1.3 的技术实现）

老师这节课把四种生成式模型连着讲了一遍，**除了 GAN 讲得细一点，其余三种他都提醒"稍微了解一下就行""大家看一下就行了"**——所以下面只保留他确实说到的层次，技术细节点到为止。

### 4.1 生成对抗网络（GAN）

老师用了**"警察与小偷"**这个类比，很值得记：

- **构成**：主要包括**生成器**和**判别器**两个部分，**"它俩是一个博弈（对抗）的过程"**。
- **生成器**：接收一个**随机噪声向量**作为输入，通过一系列变换把噪声**映射为数据样本**（图像、音频等）。
- **判别器**：输入是**生成器生成的样本 ＋ 真实样本**，输出是一个表示**样本真实性的概率值**（0—1 之间的数字：**1** 表示确定是真实样本，**0** 表示判定为伪造样本）。
- **两者的目标是对着来的**：
  - **生成器的目标**：生成能够**欺骗判别器**的样本；
  - **判别器的目标**：**准确区分**真实样本和生成样本。
- **训练过程**：两个部分**都会不断地提高自己的能力**——生成器不断调整参数、让样本更接近真实样本；判别器持续优化自身、提升**辨别真假的能力**。通过反复对抗训练，直到生成的样本与真实样本极为相似。

> 💡 **记忆点（老师原话）**：**"相当于警察抓小偷——警察通过不断提高自己的手段来辨别。"** 一边造假、一边识假，能力互相顶着往上走，这就是"对抗"两个字的由来。

### 4.2 变分自编码器（VAE）

- **定义**：一种生成模型，**基于已有的训练数据集，生成出新的数据样本**；核心思想是**将数据编码到一个潜在空间，再从潜在空间解码出数据**，使解码后的数据尽可能还原为原始输入。
- **老师讲的三个步骤**：
  1. **编码阶段**：把原始的输入数据**映射到潜在空间**（隐空间）中的样本；
  2. **从隐空间取样**：从隐空间里取出一个样本；
  3. **解码阶段**：由解码器把它还原成数据。
- **目标**：**"希望解码出来的数据，尽量跟原始数据是一样的"**——也就是重构。
- 与普通自编码器的区别（教材要点）：变分自编码器**对潜在空间的分布做了约束**，使其**服从先验分布（通常是高斯分布）**，从而让潜在空间具有更强的**连续性和泛化能力**，能生成更多样、更合理的数据。

> 💡 **记忆点**：**"编码进去 → 从隐空间取一个 → 解码回来"**，老师强调这里的主要是"重构得像不像"。技术的具体损失函数（重构损失、KL 散度）老师没有展开，本篇不展开。

### 4.3 扩散模型

- **命名来源**：名字来自自然界的**扩散现象**；它通过**逆转扩散过程**来生成新数据。
- **两个过程**：
  - **正向扩散**：**逐步把数据转换成噪声**——不断往样本上加噪，"加到这个噪声完全覆盖，看不清它原来的样子"；
  - **逆向扩散**：**从噪声中恢复数据**——"通过一定的手段去噪，然后这个照片不断地清晰"，把纯噪声逐步迭代去噪，重建出细节。
- 老师在这里放了一张图片演示，让大家看**加噪到完全被噪声覆盖、再去噪变清晰的整个过程**。

> 💡 **记忆点**：**正向＝把图"糊"成噪声；逆向＝把噪声"洗"回图。** 生成的方向是**逆着来的那一半**。

### 4.4 基于 Transformer 的模型

- **Transformer 是一种基于注意力机制的深度学习模型架构**，被设计用于处理**序列数据**，在自然语言处理领域取得了巨大成功。
- 老师提到的两个关键点：
  - 它**能处理长距离的依赖关系**（对比传统的循环神经网络、长短期记忆网络，Transformer 捕捉长距离依赖更有效）；
  - 它**有并行处理能力，训练速度更快**。
- 工作机制：通过计算输入序列中**每个位置的注意力权重**，动态地关注不同位置的信息。
- 基于 Transformer 的**预训练语言模型**：先在大规模语料上做**无监督预训练**，学习语言的语法、语义和语用知识；再通过**微调**应用到各种 NLP 任务上（文本生成、问答系统、机器翻译等）。
- 结构上由**编码器**和**解码器**组成——这两个部件在后面"文本生成原理"里会再次出现（编码器负责理解，解码器负责生成）。

> ⚠️ **易错点**：**别把"注意力机制"和"注意力权重"当成两个东西**——机制是架构的名字，权重是它算出来的数值。

## 五、AIGC 的工作流程（1.3）

老师把流程串成了"五步走"，重点落在**训练**和**后处理**两步上。

### 5.1 主流程

```text
① 数据收集与处理  →  ② 模型选择与训练  →  ③ 特征学习与优化
        →  ④ 内容生成与后处理  →  ⑤ 反馈与模型优化
```

| 步骤 | 要做什么 | 关键点 |
| :--- | :--- | :--- |
| **① 数据收集与处理** | 收集海量训练数据并做预处理 | 数据涵盖文本、图像、音频、视频；**数据的质量与多样性直接决定最终生成内容的优劣**；预处理包括**数据清洗、标注、格式化以及增强** |
| **② 模型选择与训练** | 依据生成内容的类型精准选择适配的模型，再用大规模数据集训练 | 例：**文本生成通常采用基于 Transformer 的模型（如 GPT）**，**图像生成则可能依赖生成对抗网络**。训练中模型不断调整自身参数，**最小化预测值与真实值之间的误差** |
| **③ 特征学习与优化** | 识别并理解输入数据的核心特征 | **文本数据**：掌握语法规则、语义关系以及**文本的逻辑脉络**；**图像数据**：捕捉色彩、形状、纹理等视觉元素。常采用**梯度下降**等优化算法不断调整参数，经多轮迭代达到理想水平 |
| **④ 内容生成与后处理** | 模型训练达标后，接收特定输入（如种子文本、图像样本）生成全新内容，再做后处理 | 初始生成的内容可能有瑕疵：**文本**需校正语法错误、优化语句表达；**图像**需提升分辨率、增强画质 |
| **⑤ 反馈与模型优化** | 通过反馈持续优化模型 | 使模型生成的内容**更贴合用户预期** |

### 5.2 老师强调的两处

- **模型是没有"好坏之分"的，要针对不同领域选择不同的模型**——老师原话："在数据整理之后……针对不同的领域，我们才会选择不同的模型。"这句和教材"依据生成内容的类型，精准选择适配的模型"是同一件事。
- **训练在干什么**：拿到数据里"不同的物是用什么来表征的"，再"采用优化算法来调整"参数，把误差压小。

### 5.3 生成之后：一定会遇到的两个问题

- **生成的东西"肯定是一个新的东西，不可能都是完美的"**——所以要**不断提升画质、增强（文本的）表达**；
- 因此**必须有一条"不断进行优化"的回路**（对应第 ⑤ 步的反馈与模型优化）。

> 📌 **考点**：五步流程的顺序**不能颠倒**——先有数据、再有模型、再训练优化，然后才谈生成与后处理，最后才轮到反馈。

## 七、提示词的设计（1.5 ＋ 2.3，老师合并讲）

### 7.1 提示词是什么

- **定义**：用户在使用 AIGC 创作平台生成所需内容之前，需要清晰地表达自己的需求，这种需求通常被称为**提示词（Prompt）**。它是**通过创作平台提供给系统的一段信息**，用于指导系统生成特定类型的内容；形式可以是**一句话、词语组合或一系列指令**。
- **重要性**：提示词的质量**直接影响生成内容的相关性、准确性和创造性**。
- 老师的讲法很实在：**"你在生成这个内容之前，要把你的需求表达出来，一般情况下就是一系列的指令"**；而且"不太可能一次就成，你需要对这些东西再加一些限制词"。

### 7.2 第 1 步：明确生成目标

先明确需要工具生成**哪个领域、哪种类型**的文本（如故事、文案、学术分析等）。生成目标要具备两个特性：

| 特性 | 含义 | 书中示例 |
| :--- | :--- | :--- |
| **（1）具体性** | 目标越具体，越有利于文本的准确生成；描述不能含糊不清 | ❌ 模糊：写一篇科普文章。<br>✅ 具体：写一篇关于**自然语言处理原理**的科普文章。 |
| **（2）独一性** | 提示词中**只设置一个生成目标**，避免一次设置多个不同类型的目标导致生成内容杂乱 | ❌ 多个：创作以"春雨"为主题的诗、5 月健身计划及五一旅游攻略。<br>✅ 独一：以"春雨"为主题，创作**一首七言绝句**。 |

> 💡 **老师的原话**：**"只设置一个（生成）目标，避免一次设置各种不同的目标，导致（生成）内容杂乱。"** 他还打了个比方：不能让它"无限地写给你一大片，长长一大片，味儿也不行"——**不给边界，产出就没法用**。

### 7.3 第 2 步：细化需求要点（7 个维度，全是考点）

| 维度 | 说明 | 提示词示例 |
| :--- | :--- | :--- |
| **风格** | 决定生成文本的**语言特点、表达方式和整体氛围** | 请用严谨、正式的**学术风格**，分析人工智能在医疗诊断中的应用和潜在风险 |
| **字数** | 明确文本的**篇幅**；根据具体字数要求和使用场景设定合适范围 | 请创作一首**不超过 20 行**的现代诗歌，主题为"城市的夜晚" |
| **受众** | 文本的**目标读者群体**；要考虑年龄、性别、教育程度、兴趣爱好、专业背景等 | 面向**专业的程序员**，介绍一种新的编程语言特性，需包含技术细节和实际应用案例 |
| **目的** | 文本想达成的目标，如宣传推广、教育科普、娱乐休闲、说服劝导 | 创作一篇关于环保的科普文章，**目的是加强公众的环保意识** |
| **语言** | 文本所使用的**语种或方言** | 使用**四川方言**创作一个简短的幽默故事 |
| **背景** | 与文本相关的**背景情境信息**，如特定的时间、地点、事件、行业背景 | 在**当前全球气候变暖的背景下**，撰写一篇关于可再生能源发展前景的分析报告 |
| **限制条件** | 对生成文本的**特殊要求**，如必须引用特定文献、不能包含某些词汇或内容、要遵循特定规则 | 撰写一篇关于科技发展的文章，**限制条件是不能使用"人工智能"这个词** |

- 老师的讲法：**风格**上他会直接指定——"这个是大学的风格""俏皮可爱风"；**受众**要分清"是老年人还是学生"；**目的**"你肯定要带上，你要干什么"；**限制条件**则是"提前跟它说清楚"。
- 老师现场用的三个例子：**四川方言的幽默故事**、**全球变暖背景下的可再生能源发展前景报告**、**限定不能出现"人工智能"这个词的科技文章**。

> 💡 **速记口诀**：**风格·字数·受众·目的·语言·背景·限制** = 七个维度。答题时任写 4 个就能得分，但**能写全就写全**。

### 7.4 第 3 步：测试和迭代优化（3 类偏差与对应策略）

> 📌 老师的原则：**"你不能写一次这个东西就能用"**——必须根据生成的内容**不断地调**、不断地加要求。

| 偏差类型 | 典型表现 | 优化策略 |
| :--- | :--- | :--- |
| **内容缺失** | 核心信息缺失，例如产品参数、关键数据未呈现 | ① **参数显性化**，明确核心指标——把"介绍续航能力"改为"标注 **72 小时**连续续航参数"；② **场景具象化**，补充时空限定条件——如"分析 **2025 年五一**国内旅游人次数据" |
| **表达精确性差** | 语言风格与目标受众不匹配，例如对青少年群体使用高深的专业术语 | ① **风格锚定**，指定参照对象——如"采用《博物》杂志的科普语言风格"；② **细化受众画像**，补充群体特征——如"面向 **12~15 岁学生**，采用**游戏化表达方式**" |
| **逻辑失衡** | 任务复杂度超出模型单次处理能力，例如逻辑链条断裂、推理步骤缺失 | ① **分步骤下达指令**——"第一步分析行业现状与痛点；第二步基于上述结论提出 3 种解决方案"；② **优先级标注**，明确执行顺序——"优先完成竞品对比分析，次要补充市场趋势" |

老师另外讲到的优化动作（对应 1.5 的优化技巧）：

- **分析生成结果，做针对性调整**（先看差在哪，再改哪一句）；
- **运用迭代思维，反复优化**（多轮调整提示词）；
- **参考优质案例**（看看别人怎么写提示词）；
- **巧用连接词丰富层次**：合理使用"并且""同时""然而"等，使生成内容更有逻辑性和连贯性。

> ⚠️ **易错点**：三类偏差是**"内容缺 → 表达糙 → 逻辑乱"**这个顺序记；别把"独特性"当成偏差类型——独一性是**明确生成目标**时的特性要求，不是偏差。

## 八、AIGC 的文本生成原理（2.1）

### 8.1 底层技术

- 当前 AIGC 文本生成模型大多是**基于 Transformer 架构的大语言模型（Large Language Model, LLM）**。
- 技术路线：**先结合 NLP 技术在"大规模语料"上做预训练，再针对具体任务做微调**，从而实现文本生成。
- 老师的一句话概括很准：**"它基于训练好的模型，就根据你输入的内容，就可以自动生成逻辑连贯以及通顺的全新文本。"**

### 8.2 三大阶段（主干必背）

```text
① 输入文本理解阶段  →  ② 内容决策阶段  →  ③ 输出生成文本阶段
     （3 个环节）          （3 个环节）          （4 个环节）
```

老师原话：**"文本生成的过程分为三个阶段……分别看一下。"**

### 8.3 阶段一：输入文本理解阶段（3 个环节）

| 环节 | 做什么 | 关键要点与例子 |
| :--- | :--- | :--- |
| **（1）文本预处理** | 对用户输入的提示词进行**清洗、分词**等操作 | **① 清洗**：移除无关字符，对明显的拼写错误做基础校正（如把 `the` 写成 `teh`）。<br>**② 分词**：把文本拆分成一个个 **token（词元）**，切分后的 token 可能是**一个词、子词或符号**；**token 是大语言模型的基本计算单位**。<br>**③ 归一化**：把文本转换为**统一的大小写形式**、把单词**还原为基本形式**。例：`App` 与 `apple` 的写法统一；`go / went / gone` 视为不同的词，归一化后统一还原为 `go` |
| **（2）向量化表示** | 把文本中的每个词**映射为低维空间中的向量**，让计算机能理解 | 通常通过**词嵌入（word embedding）技术**实现。目标是捕捉词语之间的**语义关系**：**语义相近的词在向量空间中距离更近**。用向量表示既能**降低数据维度**，又能**保留语义信息** |
| **（3）编码与特征提取** | 向量化后的数据进入 Transformer 的**编码器（Encoder）** | 编码器由**多个相同的层堆叠**而成，每层包含**多头自注意力层**和**前馈神经网络层**。多头自注意力层从多个角度捕捉不同位置的语义信息，为每个词**分配不同的注意力权重**；前馈神经网络再做特征提取与变换，输出**富含上下文信息的中间表示向量** |

老师讲这一段的两个"抓手"：

**（1）关于分词——用"小明"这两句话讲透了**

原话的例子里是：**"小明是北京人，他在北京大学读书。"**

> 💡 **老师的例子**：分词的时候，"逗号是不是就没有用了"——标点会被处理掉；而**"小明""北京""人"会被分成一个个独立的词**。他说得很实在：**"大家不用懂它要怎么划分，就知道分词是把一句话按照词语进行划分"**。

**（2）关于向量化——为什么要变成数字**

- 老师的设问：**"为什么要进行向量化表示？"**
- 答案：**因为计算机本身不能直接识别汉字、词语这些东西**，"所以我们必须要把这个词语转换成数字"，再"把每个词映射为空间中的向量，使计算机能够理解"。
- **词嵌入的目标**：捕捉词语之间的**语义关系**。老师举了两组对比：
  - **"国王"和"皇帝"**：含义上"一般情况下是指同一个人"，所以**计算它们的向量时距离比较近、数值比较小**——**越近就说明它们俩越相似**；
  - **"苹果"和"汽车"**：通过公式计算时**两个向量的距离比较远**，说明这两个词**不相似**。
- **另一个好处是降维**：老师用了一个很直观的比较——**三维的向量和"一百行乘一百"的数据，当然是越小越好算**。用向量表示可以**降低数据的维度**，同时**保留词语之间的语义关系**。

> ⚠️ **易错点**：**向量化表示靠的是词嵌入技术，不是"归一化"**。归一化属于文本预处理环节（统一大小写、还原词形），两者不是一回事——这一点教材课后习题专门考过。

### 8.4 阶段二：内容决策阶段（3 个环节）

| 环节 | 做什么 |
| :--- | :--- |
| **（1）外部资源检索** | 系统会根据理解到的需求，从**数据库、知识图谱以及其他 API** 获取对应信息（处理动态内容时调用 API 获取**实时更新**的信息） |
| **（2）逻辑推理** | 把**模型内部已有的知识**与**检索到的外部资源**结合起来，生成**联合逻辑推理结果**，从而理解输入文本的深层含义并做合理判断 |
| **（3）内容选择或策略生成** | 根据逻辑推理的结果，选择最合适的内容或生成策略（从训练数据中抽取相关信息，或根据**预先设定的规则**选择最佳响应） |

老师在这里专门讲了**知识图谱**：

- **为什么要提出知识图谱**：为了**提高搜索引擎的效率和准确度**。老师原话："提高这个搜索引擎的效率以及准确度，就提出了知识图谱这个概念。"
- **知识图谱长什么样**：以**"小明"这样的实体**为中心，把跟它**有关系**的东西（关系、属性）连起来——"这些东西都有一个联系"，最后**做成一个网络**，检索的时候顺着关系就能找到。
- 老师的定位很清楚：这一块属于"**比较专业的**"内容，**了解概念即可**。

> 📌 **考点**：内容决策阶段的三步＝**检索 → 推理 → 选择/生成策略**。别漏掉"外部资源检索"——它决定了模型能不能用上**最新的信息**。

### 8.5 阶段三：输出生成文本阶段（4 个环节）

| 环节 | 做什么 |
| :--- | :--- |
| **（1）解码器初始化** | 这一段由 Transformer 的**解码器（Decoder）**主导。解码器的输入包括**对原文的理解结果**以及**此前已经生成的内容**；生成第一个词时，使用一个特殊的**起始标记向量**作为输入 |
| **（2）自回归生成（autoregressive）** | **从左到右依次生成每个单词**。生成每个新词时，多头自注意力层同时关注**编码器的输出**和**已生成的信息**，再通过前馈神经网络生成一个**表示所有可能单词的概率分布向量**。<br>例：以"花朵在［生成位置］绽放"为例，模型根据"花朵"的语义信息与注意力计算结果产出概率分布；如果"**花园**"的概率最高，模型就选择"花园"。 |
| **（3）采样策略与多样化生成** | 除选择**概率最高的单词**外，还会采用**温度采样（temperature sampling）**等策略，通过调整概率分布的**"尖锐度"**，让模型有一定可能选择概率较低的词，从而生成**更具创意性**的文本 |
| **（4）生成文本优化与完善** | 用大语言模型对生成文本做评估，检查**流畅性、连贯性和语义合理性**；若评估结果**低于预设阈值**，系统可能**重新生成**或**调整文本**（语法修正、敏感性检查、重复内容过滤等） |

> ⚠️ **易错点**：**"自回归"的意思就是"一个词一个词往后接"**——每生成一个新词，都要把前面已经生成的内容一起看一遍。

## 十、两个实践任务的方法（2-1 / 2-2）

> ⚠️ 下面是教材给出的规范流程；**"分阶段设计提示词"的方法是老师明确讲到并反复强调的**，具体按钮位置以实际平台为准。

### 10.1 总方法：分阶段设计提示词（老师反复强调的一句话）

> 💡 **老师原话（意思）**：**"你写提示词的时候，先写一个大纲的句子，然后根据生成的这个大纲，再生成内容。"**

```text
第 1 步：设计"生成文章大纲"的提示词  →  第 2 步：生成大纲（不满意就手动改或重新生成）
        →  第 3 步：基于大纲设计"生成文章"的提示词  →  第 4 步：生成文章 → 检查、迭代
```

**这样做的道理**：先定骨架、再填内容，才能**确保最终产出与预设架构一致**；一次就让模型写全文，结构容易跑偏。

### 10.2 实践任务 2-1：科普文章——河流是如何形成的（工具：讯飞绘文）

- **任务情境**：假设你是一名优秀的科普文章写作者，需编写一篇**微信公众号文章**，主题是"**河流是如何形成的**"，主要受众是 **8~12 岁的小学生**。
- **生成大纲的提示词（书中原文）**：

```text
假设你是一名儿童科普作家，请你为一篇校园公众号的科普文章撰写一份大纲，文章大纲的要求如下。
（1）文章的主题：河流是如何形成的。
（2）文章的受众：8~12 岁的小学生。
（3）文章的风格：拟人化叙事风格。
（4）大纲标题数量：不少于 3 个大纲标题。
```

- **关键要素**：**写作者角色、生成目的、文章类型、文章主题、文章受众、文章风格、大纲标题数量**——这七个要素就是第 7.3 节"细化需求要点"的落地写法。
- **操作路径**：创作首页 → 单击"**知识科普**"进入起稿页面 → 在"告诉我你想写什么？"输入大纲提示词 → 单击"**大纲成文**"生成大纲 → 大纲满意后，单击"**使用此大纲生成**"（或自己写文章提示词后单击"**直接成文**"）生成文章。
- **注意**：即使提示词里已经写了要素，**生成的大纲仍可能与预期有偏差**——此时可以**手动修改**，也可以单击 **↻ 重新生成**。

### 10.3 实践任务 2-2：课题报告——中学生课后辅导模式优化（工具：豆包）

- **任务情境**：假设你是一名优秀的**初中教师**，需要撰写一篇面向**学校管理人员**的课题报告《**中学生课后辅导模式优化**》。
- **生成大纲的提示词（书中原文）**：

```text
假设你是一名优秀的初中教师，请你为一篇课题报告撰写一份大纲，要求如下。
（1）课题报告的名称：中学生课后辅导模式优化。
（2）课题报告的受众：学校的管理人员。
（3）课题报告的核心结论：现有模式在资源分配和个性化辅导方面存在显著不足，
    建议通过整合教育资源、引入智能化教学工具，以及强化家校社三方联动，
    建立更加灵活和高效的辅导体系。
（4）大纲标题数量：不少于 3 个大纲标题。
```

- **为什么这次换成豆包**：教材说明——豆包能把当前对话的过往历史信息当作**上下文参考**，**灵活调整输出内容、互动性与适应性更强**，**适合后续反复修改**。
- **大纲的六个部分**（可作"好大纲长什么样"的参照）：研究背景与意义 → 现状分析 → 问题成因探究 → 优化策略 → 实施计划 → 预期成效与评估方法。
- **生成报告的提示词**：例如"请根据生成的大纲生成对应的课题报告，需要确保生成的课题报告**内容正确、严谨**"。
- **检查与迭代**：不满意可以**重新生成**；也可以把大纲**复制到文本文档里手动改**，再把修改意见发回去重新生成。

> 📌 **两个任务的对比（考点）**

| 对比项 | 实践任务 2-1 | 实践任务 2-2 |
| :--- | :--- | :--- |
| 文体 | 科普文章（微信公众号） | 课题报告（面向学校管理人员） |
| 使用工具 | **讯飞绘文** | **豆包** |
| 提示词要素 | 角色、目的、文章类型、主题、受众、**风格**、标题数量 | 角色、目的、报告名称、受众、**核心结论**、标题数量 |

## 十一、人工智能幻觉（1.6）

### 11.1 什么是人工智能幻觉

- **定义**：随着生成式模型的发展，人工智能系统在文本、图像、音频和视频生成方面展现出惊人能力；然而，系统**有时会生成事实性错误、逻辑矛盾或虚构的信息**，这种现象被称为**人工智能幻觉（AI Hallucination）**。尽管经过大量数据训练，模型在某些情况下仍会生成**看似合理、实际上不准确或虚构**的结果。
- 老师的讲法：**"这是现实当中不可能存在的场景"**——比如让它生成一个场景，它生成出来的东西是**现实中不存在的**；还有**卡通人物形象、创作的卡通动画**这类例子，**内容里的错误还是错的**。

### 11.2 四类幻觉（按模态分）

| 类型 | 典型表现 |
| :--- | :--- |
| **文本幻觉** | 生成**不存在的历史事件**、编造事实；文字内容"可能还是有的"（即凭空造出看似合理的内容） |
| **图像幻觉** | 创造出现实中**不可能存在的场景**；老师提到卡通人物形象这类生成结果与实际不符（例：**多出一根手指、手部结构错误**这类常见的画面问题） |
| **音频幻觉** | 生成音频内容与实际不符 |
| **视频幻觉** | 老师举的例子是"**在没有开门的情况下直接进入**"这类不合常理的画面；教材补充：**镜头/角色前后不一致、角色形象崩坏**这类的常见错误 |

> 💡 **记忆点**：幻觉的四种类型就是**四类内容**——**文本、图像、音频、视频**；凡是"模型自信地说/画出来，但事实不成立"的，都算幻觉。

### 11.3 产生幻觉的 4 大成因

老师逐条讲了成因（他先让同学"看一下再讲"）：

| 成因 | 说明 | 老师讲的原话要点 |
| :--- | :--- | :--- |
| **（1）数据偏差** | **数据的质量会直接影响模型的性能**；训练数据本身有偏差、错误或不完整，模型就会"积累"错误的思维 | "在训练的时候，基本（数据质量）非常差"；数据需要**清洗** |
| **（2）过度拟合** | 模型**过度地记忆训练数据中的细节**，形成**刻板的认知**，导致泛化能力下降 | "它会记住这些数据的一些缺点，它会**死记硬背**"；等**用新数据的时候，它这个模型效果不是特别好** |
| **（3）常识缺失** | 模型缺乏人类常识与背景知识，因而产出**逻辑矛盾**或明显不合理的内容 | 与后面"引入常识推理模块"的措施相对应 |
| **（4）算法局限** | 部分**算法设计存在固有缺陷**，难以处理复杂语义或抽象概念 | "有些东西肯定不是完美的，它这个设计（存在）一些缺陷" |

> 📌 **考点**：四条原因按顺序记——**数据偏差 → 过度拟合 → 常识缺失 → 算法局限**。教材还给了算法局限的典型例子：图像生成算法在合成细节丰富的画面时常出现**纹理扭曲、物体结构不合理**；NLP 模型遇到**隐喻、双关**等修辞时容易误解语义。

### 11.4 减轻措施（怎么检测与改进）

老师讲的是"**从原因对应的几个方面**去减轻"，教材给出四条：

| 措施 | 说明 |
| :--- | :--- |
| **（1）改进训练数据** | **确保训练数据集的质量是减轻幻觉的基础**；数据清洗时**去除有偏差、错误信息及不相关的内容**，并通过**扩充多样化的高质量数据**，使模型学习到更广泛的知识和模式（老师原话："改变训练数据……提高这个数量"） |
| **（2）改善模型架构** | 设计**更加先进和健壮**的模型架构，提高模型对**上下文的理解能力**和生成内容的**准确性**；**引入常识推理模块**，帮助模型理解复杂背景知识和人类常识，**减少逻辑矛盾**（老师原话："增强更加先进和（健）壮的模型结构……帮这个模型理解复杂的背景知识和人类的一些常识"） |
| **（3）多模态验证** | 结合**多种类型的数据进行交叉验证**，把文本、图像、音频等不同类型的数据结合起来分析，确保不同模态下的信息**相互支持且无冲突** |
| **（4）建立用户反馈机制** | 建立有效的**用户反馈渠道**，允许用户快速报告发现的错误或不准确之处，并根据反馈**不断调整和优化模型**，逐步减少幻觉（老师原话："建立用户反馈机制，就是大家尽量给它进行一些改进"） |

> 💡 **记忆点**：四条措施可以压缩成**"喂好数据 → 换好架构 → 多模态互查 → 用户反馈"**。老师对这段的定位是"**人工智能幻觉的措施**"——**要点是"从原因找对策"，一条原因对应一条措施去记最省力。**
