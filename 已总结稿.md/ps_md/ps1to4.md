# Photoshop 图形图像处理 课堂笔记（第 1—4 节）

---

## 一、这门课到底干什么用

### 1.1 切入方式：老师用"照相馆"举例

老师提到他路过图书馆下面、超市旁边那些**学生创业/办事的地方**，发现他们处理照片用的软件就是 **PS**。用这个例子说明 PS 离生活很近。

### 1.2 PS 在证件照上的四个典型操作（这是理解 PS 用途的最好入口）

| 步骤 | 具体做什么 |
| ① 设定尺寸 | 把宽度、高度按规格定好——**一寸**的、**两寸**的 |
| ② 排版 | 一张相纸排几张、打几份，由软件一次排好 |
| ③ 换底色 | 有些单位要求**红底**，有些要求**其他底色**。现实中不可能正好有一面合适的背景墙，所以**拍完之后用 PS 换底** |
| ④ 修图 | 脸上有斑点、痘印之类的，**用 PS 修掉**（"要学 PS 里面修的怎么样"） |

> **一句话**：PS 不是"画画的软件"，而是**处理照片、做图、排版**的通用工具。这门课先从界面认起，一步步到能独立处理图片。

## 二、PS 的工作界面（重点，界面认不清后面就没法操作）

### 2.1 界面的组成——从上到下、从左到右

| 位置 | 名称 | 说明 |
|---|---|---|
| 最上面一行 | **菜单栏** | 文件、编辑、图像、图层……等菜单 |
| 菜单栏下方 | **属性栏**（也叫"工具属性栏"） | **课本上还有别的叫法**。这一行会随你所选的工具而改变内容 |
| 左侧 | **工具箱** | 各种常用工具都在这里 |
| 中间 | **图像窗口 / 工作区域** | 你所编辑的那张图显示的地方 |
| 右侧 | **面板**（也叫**调板**） | 包括颜色面板、图层面板等，管理着图层信息、通道信息、颜色信息 |
| 图像窗口下方 | **状态栏** | 显示图像相关的状态信息 |

> **记忆顺序**：菜单栏 → 属性栏 → 工具箱 → 图像窗口 → 面板。
> 老师原话：这个工作界面和我们平常使用的很多专业软件**大同小异**，认准这几个区域就行。

### 2.2 工具箱

- **默认有 70 多种工具**，按用途大致分为几类：
  - 选区工具
  - 绘画类
  - 修饰类
  - 颜色类
  - 显示控制类
- 工具数量**可以在设置里增减**，但——
  > **一般不改，就用默认的。**（老师明确说明：平时不会去动它）

### 2.3 工具的"隐藏工具"（二级菜单）——本节最实用的一个坑

**判断方法**：看工具图标的**右下角**。
- 右下角**有三角形** → 说明这个工具里**隐藏了二级菜单**，二级菜单里放着别的工具。
- 右下角**没有三角形** → 这个工具就是独立的，没有隐藏菜单。

**打开方法（关键）**：
1. 把鼠标放在**带三角形**的那个工具上；
2. **按住鼠标左键不放**；
3. 稍等几秒（老师原话"大概过个几秒钟"），二级菜单就会弹出来。

**老师自述的踩坑经历（务必注意）**：
> 老师初学的时候看到三角形，知道里面藏了工具，就去**点**它，结果点了五分钟也点不开，还以为是工具坏了。
> 后来才明白：**这里是"点住不放"，不是"点击一下"。**

**实例**：点击**画笔工具**，展开后里面隐藏着：
- 铅笔工具
- 颜色替换工具
- 混合器画笔工具

> ⚠️ **这一条很容易在实操时卡住**：初次使用工具箱，凡是要取隐藏工具，一律**长按左键**。

### 2.4 面板（调板）的四个操作技巧

**① 折叠 / 展开面板**
- 面板的**右上角**有一个**向左的双箭头**符号；
- 单击它 → 整个面板**收起成一个小图标**；
- 收起后，双箭头**变成向右**；
- 再单击这个向右的双箭头 → **恢复成面板形式**。

**② 关闭面板（两种方法）**
- 方法一：在面板上**右键** → 在快捷菜单里选 **关闭**；
- 方法二：打开**窗口菜单** → 找到对应的面板名 → **点掉前面的对勾**。
  - **判断依据**：窗口菜单里，面板名**前面有对勾**，说明这个面板**当前是显示状态**；
  - 举例：颜色前面打着对勾 → 说明颜色面板现在显示着；点击一下颜色，**第一个面板就被关掉了**。

**③ 调乱了怎么恢复默认——"复位基本功能"**
- 场景：很多同学在面板区**调来调去，一调就调乱了**，反而觉得不如默认的好看；
- 解决：在**基本功能**里找到 **复位基本功能**，点击即可**恢复默认布局**。

**④ 想只看图、不想看工具（配合快捷键，见 2.5）**

### 2.5 界面快捷键

| 快捷键 | 作用 |
| **Tab** | **关闭 / 显示工具箱和面板**——只想看图像本身的信息时用 |
| **Ctrl + N** | **新建文件**（老师原话"使用快捷方式"，比走菜单快） |

> 场景：如果你只想看到这个图像的信息，不想看到其他那些操作工具，**按 Tab** 就能把它们全部隐藏；再按一次恢复。

## 三、文件的基本操作

### 3.1 文件菜单里有什么

打开**文件菜单**可以看到：

| 命令 | 用途 |
| 新建 | 建一个新图像文件（Ctrl+N） |
| 打开 | 打开已有文件 |
| 存储 | 保存文件 |
| **导出** | 导出成其他格式/用途的文件 |
| 自动 | 批处理类操作 |
| 脚本 | 更进一步的自动化操作 |

> 老师原话：这里面还有好些比较有意思的（自动、脚本），后面会用到。

### 3.2 新建文件的对话框——六个参数，逐个说

点击"新建"后会弹出一个对话框，需要填的参数依次是：

**① 文件名**
给文件起个名字。

**② 宽度 / 高度**
- ⚠️ **在设宽度和高度之前，先确认单位！**
- **默认单位是"厘米"**；
- 但**我们平常最常用的是"像素"**；
- 老师原话："我们用像素这个多一些"。
- 演示时做了个稍大的：**宽度 1200**（像素）。

**③ 分辨率**
- **默认是 72**；
- **用途决定数值**：

| 用途 | 建议分辨率 |
| 自己学习、屏幕上制作/观看 | **72 就够了**（"如果不是打印出来的话，72 就可以"） |
| 需要**打印出来**、要求真实好看 | **300 或 300 以上** |

> 老师提问："想打印出来，分辨率是低一点好还是高一点好？" → **高一点**。
> 原因：分辨率越高，打印出来越真实、越好看。

**④ 颜色模式**
可选：**位图、灰度、RGB、CMYK、Lab**
- **默认是 RGB**；
- **没有特殊要求，就用 RGB**。

**⑤ 位深度**
可分为 **1 位、8 位、16 位、32 位**。
- 可以改高一点用，老师演示时选了 **32 位**。

**⑥ 背景内容**
共**三种**：

| 选项 | 含义 |
| **白色** | 默认，白色背景 |
| **背景色** | 用**当前设定的背景色**作为底色 |
| **透明** | 不要背景（"有些时候我们不要背景"就选透明） |

### 3.3 颜色模式详解（老师只展开了两个）

**① 位图**
- 顾名思义，**里面只有两种颜色**：**黑色**和**白色**。
- （位图模式下，图像只能表现黑白两色，没有中间层次。）

**② 灰度**
- 表现的是**黑白灰**的层次。
- **老师举的例子（很典型）**：
  > 有些比较重要的人物**逝世**的时候，你再去看一些网站，会发现网站上面的图片**全都变成了黑白色**。
  > 那是怎么弄的？——就是**把颜色模式改成了灰度**。

> 其余模式（CMYK、Lab 等）**本节课不再展开**，默认用 RGB 即可。

### 3.4 前景色与背景色（配合"背景内容"理解）

**在哪里看**：工具箱里有一组**两个色块**——

- **前面的那个颜色 = 前景色**（默认是黑色，在前）
- **后面的那个颜色 = 背景色**（默认是白色，在后）

**三个结论**：
1. 新建文件时如果"背景内容"选**背景色**，那么**默认就是白色**（因为背景色默认是白）。
2. 如果你**提前把背景色改成了紫色或红色**，再选"背景色"，那么新文件的底色**就按你设定的来**。
3. 所以"背景色"这个选项的含义是——**跟随你在工具箱里设定的背景色**，而不是固定白色。

## 四、完整实例：从新建到画图

### 4.1 新建（把 3.2 的参数走一遍）

操作顺序：
1. 双击桌面上的 **PS 图标**打开软件；
2. 点击 **文件 → 新建**（或 **Ctrl + N**）；
3. 给文件**起名字**；
4. **先改单位**：把默认的"厘米"改成"**像素**"；
5. 设宽度、高度：**宽 1200、高 840**；
6. 分辨率保持 **72**；
7. 颜色模式保持 **RGB**（位深度可调成 32 位）；
8. 背景内容保持默认的 **白色**（这节课先不改）；
9. 点击**确定**。

**最终得到的文件**：
> 宽度 **1200 像素**、高度 **840 像素**、背景为**白色**、分辨率为 **72** 像素的图像文件。

### 4.2 画图：形状工具

在**工具箱**里，**前景色上方**有一个**矩形工具**（图标右下角**带三角形**）。

**展开二级菜单**（长按左键）后可以看到整个形状工具组：

| 工具 | 说明 |
| 矩形 | 默认显示在工具箱上的那个 |
| **圆角矩形** | 四角带圆角 |
| **椭圆** | 可画椭圆 / 圆 |
| **多边形** | 多边形状 |
| **直线** | 画直线 |
| **自定形状** | 使用内置的自定义形状库 |

**画正圆/正方的技巧**：
> 画的时候**按住 `Shift` 键**（老师原话："键盘 Z 旁边那个键""上档键"），再拖动，画出来的就是**正圆形**；松开就不保证是正圆。

### 4.3 填充色和描边色

**① 画出来的图形填充的是什么颜色？**
- 结论：**填充色 = 前景色**。
- 验证：默认前景色是黑色，画出来的图形就是黑的；老师把前景色**换成别的颜色**，再画一个圆，填充色就跟着变了。

**② 在哪改颜色？**
- 在**属性栏**（工具栏那一行）里有**填充**设置，点击可以改填充色。
- 工具箱里除了"填充色"，**还有一个"描边色"**——用来设置图形**边框**的颜色。

> ⚠️ 注意区分三个概念：
> - **前景色 / 背景色**：在**工具箱**里设置，决定**新建文件的底色**和**新画图形的填充色**；
> - **填充**：在**属性栏**里设置，改的是**已画图形内部**的颜色；
> - **描边**：设置图形**边框**的颜色。
