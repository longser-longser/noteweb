## 三、描边：给图形边缘加一圈边

### 3.1 什么是描边

顾名思义，就是**图形的边缘部位**，给这个边缘部位设定它的**形状**和**颜色**。

老师用左右两幅图做对比，看到三个变化：

| 对比项 | 左图 | 右图 |
| --- | --- | --- |
| 颜色 | 黑色 | 红色 |
| 线的形式 | **虚线** | **实线** |
| 宽度 | 窄 | 宽 |

这三个变化，正好对应"描边"对话框里的三个参数：**宽度、颜色**，再加上后面会讲的**位置**。

### 3.2 前提：文字必须先变成图形图像（本次课最容易漏的一步）

老师的演示流程是：**新建文件 → 文字工具拖出一个方框 → 输入文字 → 在上方工具栏把字号改大**（默认 **12 点**，改成 **72 点**）。

接着是本节最关键的一句追问：

> 老师原话：**"我们现在输入的文字，我们要想设置这一个宽度、设置颜色，那是给图形图像来设置的。这个文字现在算不算图形图像？不算图形图像。"**

所以文字要先"降级"成普通图形，两步：

1. **菜单栏「文字」→「转换为形状」**。
2. 在右边**图层面板**里找到这个图层 → **右键** → 在快捷菜单里选「**栅格化图层**」。

做完这两步，"文字"就变成真正的图形像素了，才能对它设描边和填充。

> 老师原话：**"我们在这个图层里面找到这个描边这个图层，然后右键，在这个弹出的快捷菜单里面找到栅格化图层。"**

### 3.3 编辑 → 描边：三个参数逐个说

路径：**编辑菜单 → 描边**（编辑菜单里并排有两个：**填充**和**描边**）。

| 参数 | 说明 | 老师演示的值 |
| --- | --- | --- |
| 宽度 | 描边线条粗细，**默认 1 像素** | 先改 10 像素看效果 → 觉得太宽 → 最后定 **3 像素** |
| 颜色 | 默认黑色；点颜色后面的**方框** → 弹出「**拾色器**」→ 在色谱里点一个颜色 → 确定（也可以拖动右边色谱的滚动条换色，比如换黄色） | 红色 |
| 位置 | **内部 / 居中 / 居外** 三种（老师让同学自己试三者的区别，课上没逐个演示） | 课上未定死 |

> 老师原话：**"大家注意一下，它的下边的话还有位置的设置，就是说你这个描边，还有内部、居中、居外啊三种设置。"**

### 3.4 做错了怎么办：编辑 → 后退

老师当场示范：**编辑 → 后退**，退到你觉得合适的位置，再重新做。（老师还说"多次点可以后退多步"。）

### 3.5 易错点

- **忘了"转换为形状 + 栅格化图层"**，直接对文字图层设描边——做不到。
- 描边宽度单位是**像素**，默认 1 像素太细，改成 10 像素又太宽，3 像素左右比较自然。
- 颜色不是直接输数值，而是点色块进拾色器；换色后**要连点两次确定**（拾色器一次、描边对话框一次）。
- 位置（内部/居中/居外）没设置过就先别下结论，课上只讲了"有三种"。

## 四、填充：给选区内部上色

### 4.1 两个最常用的快捷键（重点）

填充 = 在**选区内部**填充颜色或图案。

| 快捷键 | 作用 |
| --- | --- |
| `Alt + Delete` | 用**前景色**填充选区 |
| `Ctrl + Delete` | 用**背景色**填充选区 |

老师的演示顺序：先用矩形选框创建一个选区 → 看当前**前景色是橘红色** → 按 `Alt+Delete` → 选区被前景色填满；再把**背景色**单击工具箱里的背景色图标、拖色谱改成**紫色** → 按 `Ctrl+Delete` → 选区变成紫色。

> 老师原话：**"我们可以使用 Alt 加 Delete 键来填充选区，也可以使用 Ctrl 加 Delete 键啊，使用背景色来填充选区。"**

### 4.2 编辑 → 填充（`Shift+F5`）与"使用"下拉

用图案或其他颜色填充时，就不是快捷键了：**编辑菜单 → 填充**。

> 老师原话：**"它还有一个快捷键，这个快捷键是上档键加 F5 键。咱们看描边有没有快捷键？没有是吧？"**

老师由此讲了一个判断经验：**用得多的功能才配快捷键**——填充用得多，所以有 `Shift+F5`；描边用得少，就没有。

「填充」对话框里最关键的是「**使用**」下拉，本次课见过的选项：

| 选项 | 说明 |
| --- | --- |
| 前景色 / 背景色 | 最常用，因为外面有快捷键 |
| 颜色 | 点开后可随意挑一个颜色（老师演示换成绿色）；**步骤多，老师不推荐** |
| 图案 | 用图案填充，下面还有"自定图案"下拉可选具体图案 |
| 内容识别 | 用选区周围的背景来补掉选区内容（见第八节） |
| 黑色 / 白色 / 灰色 | 把颜色里最常用的三个颜色单独提出来，省得进拾色器 |

> 老师原话：**"所以说的话我们经常用前景色背景色啊，用这种方式的话就比较少了，因为这个操作步骤比较多。"**

### 4.3 易错点

- `Alt+Delete` 和 `Ctrl+Delete` 都依赖**当前前景色/背景色**，填出来不是想要的色，先看工具箱下方那两个方块。
- 用"颜色"填充要点：编辑 → 填充 → 使用改成"颜色" → 再点色块 → 确定 → 确定，一共四五步，快捷键两秒的事。
- 填充是**填选区内部**，没有选区时填充的是整个图层。

## 五、图案填充与 PS 自带的图案库

### 5.1 用自带图案填充

路径：**编辑 → 填充 → 使用改成"图案" → 点开"自定图案"后面的下拉箭头**。

老师只用了**默认的"气泡"**，点确定即可。

### 5.2 图案库：替换 / 追加 / 取消（重点，选错就丢图案）

点开自定图案面板**右上角的设置按钮**，里面是一批图案库的名字，本次提到：**艺术表面、艺术家画笔、彩色纸**、以及老师演示用的**自然图案**。

选中某个库后弹出的对话框有三个结果：

| 按钮 | 结果 |
| --- | --- |
| 确定 | **替换**——当前图案列表全部被新库替换掉 |
| 追加 | 原来的图案**保留在下方**，新库追加在后面 |
| 取消 | 什么也不加 |

老师演示自然图案后，列表里出现**叶子、常春藤、黄菊、灌木**等。

### 5.3 载入图案：只认 `.PAT`

同一面板右上角设置里还有两项：**新建图案**、**载入图案**。

老师点"载入图案"去找电脑里存的图案，随即发现一个问题：

> 老师原话：**"大家可以看到这里边这个文件类型是什么？是 PAT 的这样的一个文件类型。"**

也就是：**载入图案只认 `.PAT` 格式**，而平常手头的图片都是 **JPG**。所以这条路走不通——想用自己的图片当图案，得走下一节的"定义图案"。

### 5.4 易错点

- 点"确定"会**替换掉**默认图案，想保留就点"追加"。
- 载入图案失败不是操作错了，是**格式不对**（JPG ≠ PAT）。
- 自定图案下拉里选图案时鼠标停一下会显示图案名字，方便确认选对没有。

## 六、案例一：美化小狗——换衣服颜色 + 爱心描边

### 6.1 任务与效果

素材是一只小狗，要做两件事：

1. 小狗的**衣服**：由**绿色变成红色**（用填充）。
2. 小狗手里的**爱心**：描边由**黑色变成土黄色**（用描边）。

### 6.2 第一步：给衣服换色（魔棒 + "连续" + 先定位图层）

| 步骤 | 操作 | 为什么 |
| --- | --- | --- |
| 1 | 用**魔棒工具**点衣服 | 衣服不是矩形，用矩形选框不合适；老师同时推荐"快速选择也不错" |
| 2 | 发现**整张图好像全被选上了** | 魔棒默认会把画面里颜色相近的区域全连起来 |
| 3 | `Ctrl+D` **取消选区** | 重来 |
| 4 | 在**工具属性栏上勾选"连续"** | 只选**相连**的色块，不选画面别处同色的部分 |
| 5 | 再点衣服，还是选到别处 | 说明**点错了图层** |
| 6 | 找到衣服在哪个图层：**把图层 2 和"背景"的眼睛点掉隐藏**，发现图层 2 里是爱心 | 用隐藏法定位图层 |
| 7 | **先选中图层 1**，再用魔棒点衣服 | 魔棒只对**当前图层**的像素起作用——这是本次课的第一个大坑 |
| 8 | 前景色是红色 → 按 `Alt+Delete` 填充 | 用前景色填选区 |
| 9 | 肩膀那块衣服同样再选一次、再填一次 | 衣服分成两块 |
| 10 | `Ctrl+D` 取消选区 | 收尾 |

> 老师原话：**"我们要把工具栏上面这个连续给他选中啊，选中这个连续，然后再去点击这个衣服里面的这个颜色。"**

### 6.3 第二步：给爱心描边（顺带学会用吸管取色）

1. 爱心在**图层 2**，所以**先在图层面板里选中图层 2**（不选中图层就选不中爱心）。
2. 魔棒点爱心 → **编辑 → 描边**。
3. 爱心描边的颜色要求和"小狗脸上、耳朵上"的颜色一样——**把鼠标移出描边对话框，鼠标形状就变成了吸管**，直接在画面上**吸一下耳朵的颜色**，描边颜色就取过来了（前景色也跟着变成这个颜色）。
4. 确定 → `Ctrl+D` 取消选区 → 爱心描边由黑色变成土黄色。

> 老师原话：**"大家发现没有，当我把鼠标移出这个描边对话框的时候，这个鼠标的形状变成了一个什么形状啊？吸管是吧？"**
> 老师原话：**"就是说我们可以使用吸管吸取一个颜色，作为描边颜色。"**

### 6.4 打开描边/填充的第二种入口：右键

老师补充了一条捷径：**做好选区之后，不要点编辑菜单，直接点鼠标右键**，有些版本的右键菜单里就有"描边"和"填充"。不过**本机这个版本里没有**（老师原话："咱们这一个版本可能有点低了，这版本里面没有"）。这个差异后面在"盖房子"案例里又被验证了一次（见 9.4）。

### 6.5 还可以做的部位

小狗的**头部、耳朵、尾巴**，以及旁边的**花草**也可以照衣服和爱心的做法加练；具体内容可以看**课件第 29—32 页**。

> 老师原话：**"在咱们课件的第二十九页到三十二页。"**

### 6.6 易错点

- **没勾"连续"**：一点就全选。
- **没选中正确图层**：魔棒"选不中"其实是选到别的图层上去了；用隐藏图层（点眼睛）来确认东西在哪一层。
- **描边前忘了选图层**：爱心在图层 2，选图层 1 是选不到的。
- 用吸管取色是**描边对话框打开时鼠标移出画面**才触发，不一定人人想得到。

## 七、自定图案：把自己的 JPG 变成 .PAT

### 7.1 为什么要讲这个

老师说：刚才图案列表里**多出来的那些图案（花朵、小孩、眼睛、骷髅脸等）不是 PS 自带的，是自己做的**。而"载入图案"只能读 `.PAT`，手头的图都是 JPG——于是就有了"**定义图案**"这条路。

### 7.2 完整流程（以草莓为例）

| 步骤 | 操作 |
| --- | --- |
| 1 | **打开**要用的图片（草莓 JPG），标签栏里能看到它是普通图像 |
| 2 | 图**太大**了，直接定义会填不进目标区域——所以要**先选一部分** |
| 3 | 用**矩形选框工具**框住草莓的一部分（老师强调"选一部分""选这么多"） |
| 4 | **编辑 → 定义图案** |
| 5 | 弹出对话框要求**给图案起名字**：不起名默认叫"图案 1"，老师建议起名，他起的是"**草莓**" → 确定 |
| 6 | 回到小狗图上**做好选区**（图案是填在选区里的） |
| 7 | **编辑 → 填充 → 使用改成"图案" → 自定图案**里就能找到刚定义的"草莓" |
| 8 | 确定 → `Ctrl+D` 取消选区 |

> 老师原话：**"我们点击编辑菜单，在编辑菜单里面有个东西叫做定义图案。"**
> 老师原话：**"我把鼠标放上去，大家可以看到这个名字就是刚才我起的名字……点击确定，然后 Ctrl 加 D 取消选区。"**

思路可以推广：**做任何一个东西都行——人物头像、一件衣服、一幅风景**，做法都是"**做选区 → 定义图案 → 起名字 → 填充里选图案**"。

### 7.3 一条用血换来的教训：图案大小要反复试

老师坦白讲了两次失败：

- 第一次拿了整张"小孩"的图去定义，**选区太大**，填进去只显示出小孩上面的背景，人整个看不出来；
- 后来改用小孩脸上一小块，做出来"挺吓人"的——**三个眼睛挤在一起**（因为图案会自动平铺重复），当场就取消了；
- 最后换成小孩的脸部再试一次才算能用。

结论（老师原话）：**"这个图案大小的设定啊，需要你反复去做选区，反复修改，才能达到一个最合适的效果。"** 这一条在"盖房子"案例里又踩了一次（见 9.2）。

### 7.4 易错点

- **忘了先做选区**：定义图案必须先框一块，没选区就没得定义。
- **选区选得太大**：图案会自动重复平铺，选大了会出现"双线""三个眼睛"之类的怪效果。
- 图案**一定要起名字**，否则列表里一堆"图案 1"分不清。
- 定义完图案，**填充时还要在选区里操作**，没选区就铺满整个图层。

## 八、案例二：让雪人消失——内容识别填充

### 8.1 任务

素材 24 这张图**右下角有一个雪人**，而目标效果图 24（另一个版本）里**雪人不见了**。要学会"把不想要的东西去掉"。

### 8.2 为什么不能用魔棒

> 老师原话：**"这个时候大家注意啊，右边大家看没有图层，只有一个背景，是不？这背景的话，我们这里面就不太好用魔棒来选了……我们用什么来做呢？就用这个矩形选框工具来做吧。"**

只有一个背景图层、没有分层，魔棒一选就会连到别的东西上，所以改用**矩形选框工具**，把雪人**框得稍微大一点**。

### 8.3 用内容识别填充

1. **编辑 → 填充**（也可以用上一节说的右键菜单，见 9.4）。
2. 把「**使用**」下拉里前面用过的"前景色/背景色/颜色/图案"都看完，剩下：**内容识别、黑色、白色、灰色**。
3. 选「**内容识别**」→ 确定 → 选区里的雪人消失。
4. `Ctrl+D` 取消选区。

### 8.4 内容识别的原理（老师用一句话解释）

> 老师原话：**"他会把这个选区里面的内容用什么图案来填充呢？用雪人后边的这个背景来填充。"**

也就是：**自动取选区周围的背景**，把选区"补"掉，所以看起来比较自然。

### 8.5 什么时候用它

老师评价：图里有些东西想删掉的时候，**内容识别特别好用**；比起"一点一点地去删"，这个方便得多——一点点删"有可能影响会删不起你想要的东西"（原话大意：容易把别的地方也删坏）。

### 8.6 易错点

- 选区**框得太紧**，识别出来的背景衔接会露痕迹；老师要求框得比目标物**大一点**。
- "内容识别"只在「编辑 → 填充」的**使用下拉**里，不是工具箱里的工具。
- 这个操作**会改掉原图**，要留后路就先用"编辑 → 后退"试。

## 九、案例三：盖房子——把图案、选区、复制粘贴全串起来

### 9.1 任务与素材

素材是 25、26、27、28 几张图，还有一张**最终效果图**。老师把效果图拖下来对照着做，最后要把门、窗户、楼顶窗户、右下角的东西拼到 25 这张图上。

第一步先挑**背景**：老师比较后认为 **25 这张做背景最好**，把其他素材都放到 25 上面。

### 9.2 红砖墙壁：用"定义图案"铺出来

效果图里有一面**红色的木板/砖块墙壁**，素材里没有现成的。老师的发现是：

> "我们下方的这个墙壁，是不是和上面这个墙面的图案是一样的？"——既然一样，就**把上面那块墙面定义成图案，再往下铺**。

| 步骤 | 操作 |
| --- | --- |
| 1 | 用**矩形选框工具**在图上框一块墙面 |
| 2 | **编辑 → 定义图案** → 起个名字 → 确定 |
| 3 | 在下方要做墙的位置**建一个选区**（还是矩形选框工具）——因为"填充填充的就是选区" |
| 4 | **编辑 → 填充**（或按 `Shift+F5`）→ 使用改成「图案」→ 自定图案里选刚定义的墙壁 → 确定 |
| 5 | `Ctrl+D` 取消选区，墙壁做好 |

> 老师原话：**"我们点击编辑，使用定义图案，然后起个名字，点击确定。"**

**老师当场发现效果不对**：做出来"和左边的有点不太一样"——右边（效果图）是**单线**，自己做出来变成了**双线**。原因就一句话：**定义图案时选区选多了、选大了**。结论：选的时候要**再小一点**，不合适就自己反复调。

### 9.3 门和窗户：魔棒 + 容差 + 反选

把 26 里的门和窗户搬过来，先试了最省事的办法：`Ctrl+A` **全选** → `Ctrl+C` **复制** → 到 25 上 `Ctrl+V` **粘贴**——**不行**，因为**门和窗户背后带着白色背景**，得先把白色背景去掉。

于是改用魔棒：

| 步骤 | 操作 | 为什么 |
| --- | --- | --- |
| 1 | 用**魔棒**点**白色背景** | 选背景比选门容易 |
| 2 | 发现**门也被选进去了** | 魔棒把相近颜色一起选了 |
| 3 | **把容差值改小**（老师改成 16 试了一下） | **容差大→选得多；容差小→选得少** |
| 4 | 再点白色背景，这次门没被选中 | |
| 5 | **反选**（右键 → 选择反向，或菜单选择 → 反向） | 把"白色背景"反成"门和窗户" |
| 6 | `Ctrl+C` 复制 → 切到 25 → `Ctrl+V` 粘贴 | 讲义里也给了菜单路径：编辑 → 拷贝 / 编辑 → 粘贴 |
| 7 | 用**移动工具**摆到合适位置 | |

> 老师原话：**"你要想多选的，就把容差值改大；要想少选，就把容差值改小。"**
> 老师原话：**"那么这时候白色背景被选中了，那么我们怎么去选这个窗户和门呢？反选是吧？"**

### 9.4 抄近路的两次验证：右键菜单里有没有"填充/描边"

- **魔棒**选区上点右键：**没有**"填充/描边"。
- **选择工具（矩形选框）**选区上点右键：**有**"填充"和"描边"！效果和"编辑菜单 → 填充"完全一样，用起来更方便。

所以本节做墙壁填充时，老师是**直接右键 → 填充**进去的。

### 9.5 楼顶窗户与右下角素材：全选复制 + 方向键微调

- 素材 27 里只有要搬的东西，不涉及去背景，直接 `Ctrl+A` **全选** → `Ctrl+C` → 到 25 上粘贴 → 移动工具摆放。（记不住 `Ctrl+A` 也可以：选择菜单 → 全部；`Ctrl+C` 也可以是编辑菜单 → 拷贝。）
- 素材 28 同理：`Ctrl+A` → `Ctrl+C` → `Ctrl+V` → 移动工具挪到右下角。
- **微调技巧（重点）**：

> 老师原话：**"移动位置的时候，大家注意啊，我们不要用鼠标，用键盘上面的上下左右这四个方向键啊，他是微调啊，但是也是调整一个像素。"**

### 9.6 易错点

- **定义图案时选区选大了** → 平铺出来是双线而不是单线（本节最大的坑，老师现场翻车了一次）。
- **容差不调**就去点白色背景 → 门被一起选走；容差要往**小**调。
- **忘了反选** → 复制走的是白色背景。
- **带白色背景直接复制粘贴** → 到新图上会盖一块白。
- 摆位置用鼠标拖很难对准，**用方向键一次挪一个像素**。

> 老师原话：**"这是我们啊两个（讲过的）案例，一个是去掉雪人，一个是做了一个（房子）。"**

## 十、案例四：卡通企鹅——用形状和选区"拼"出一只企鹅

老师说这是本次课**稍微难一点**的一个："刚才我们做的（图形）比较标准一点，都是椭圆就行了；而这个企鹅是个**不规则的图形**。"

### 10.1 思路：先拆件，再逐个做

第一步先确定**做什么**——先做**头部**；头部又拆成**上半部分**和**下半部分**。

| 部位 | 形状 | 用的工具 |
| --- | --- | --- |
| 头的上半部分 | 圆 | 椭圆选框工具（拖动时按 `Shift` 保证是正圆） |
| 头的下半部分 | 矩形 + 左右两个椭圆（做出弧度） | 矩形选框 + 椭圆选框 |
| 头发 | 不规则尖角 | **钢笔工具**（必须是"形状"模式） |
| 眼眶 | 两个椭圆 | 椭圆选框 + 移动工具/Alt 复制 |
| 眼睛 | 一大一小两个圆 | 椭圆选框 |
| 嘴 | 圆 + 矩形 | 椭圆选框 + 矩形选框 |

配色很简单：**只有黑色、白色，加一个黄色的嘴**——所以老师直接**把前景色设成黑色、背景色设成白色**，后面全靠 `Alt+Delete`（填黑）和 `Ctrl+Delete`（填白）两个键。

### 10.2 头的上半部分：圆 + 前景色填充

1. 选**椭圆选框工具**，在画面里拖。
2. **拖动的过程中按住 `Shift`（上档键）**——拖出来的一定是正圆（不按就是椭圆）。

> 老师原话：**"在拖动的过程中按下上档键，好了，你扣过来的一定是一个圆。"**

3. 按 `Alt+Delete` 用黑色前景色填充 → `Ctrl+D` 取消选区。

### 10.3 头的下半部分：矩形打底 + 椭圆补弧度

1. 把工具**换成矩形选框**，在下边做一个矩形选区 → 填成黑色。
2. 但这个地方**是有弧度的**，矩形是直角，所以要**在左边补一个椭圆**做弧度：
   - 椭圆选区 → **填成背景色（白色）**：`Ctrl+Delete` → `Ctrl+D` 取消选区。
3. **右边同理**，再做一个椭圆 → 也填背景色。
4. 边缘有瑕疵、不够圆就继续补；**下边再收小一点**：换成矩形选框，把选区做小一点，填背景色。
5. 老师现场承认自己做的"左右有点不太对称"，提醒同学**做得稍微对称一点**。

### 10.4 头发：钢笔工具 + "形状"模式（本案例最大的坑）

椭圆做头发太麻烦，老师给了新工具：**工具箱里的钢笔工具**。

1. 选**钢笔工具**，找一个点作为起点 → 往上 → 再往下拖动 → 单击，围出一块形状。
2. **先不要急着填黑色**——老师当场指出：**"刚才我们这个是一个路径啊，我们这里面其实应该选择形状的。"**
3. 正确做法：**在上方属性栏先把模式选成「形状」**，它就会**自动填充**；然后重新画一遍。
4. 右边同理再做一遍，或者直接复制（见下）。

> 老师原话：**"大家注意在工具箱里面有一个钢笔的这样的一个图标啊，叫钢笔工具。"**

### 10.5 Alt 拖动复制 + 水平翻转做对称

老师演示时先想用"变换"翻转，结果操作出问题（"但原来都没了"），于是换了一条更稳的路：

1. **按住 `Alt` 键，选中这个形状向右拖动一下** → 复制出一个。
2. 选中复制出来的这个 → **编辑 → 变换 → 水平翻转**。
3. 把两个往一块凑。

> 老师原话：**"我们做一个什么？（做）水平翻转还是做垂直翻转呀？"**

**Alt 复制是通用技巧**（老师原话）：按下 `Alt` 键，可以向**上、下、左、右**拖动，拖动之后就复制了，**可以复制多个**。

### 10.6 一个极重要的坑：形状图层里填不上颜色

做眼眶（两个椭圆）时，老师遇到"填不上"的情况，当场解释：

> 老师原话：**"注意现在我们是在哪个图层里面？我是在形状一里边……这个大家注意啊，这里边的话是没有像素的，我们填是填充不上的。"**

**结论：形状图层里没有像素，填充命令对它无效。** 想填色，要**换成普通图层（老师原话是"换成背景"）**，或者先把形状**栅格化**（对照 3.2 与第二节的文字处理）。

### 10.7 眼睛、白描边和嘴

- 眼眶做好、复制到一块之后，`Ctrl+D` 取消选区，发现**多出来一条边线** → 撤销 → **编辑 → 描边 → 颜色改成白色** → 确定 → 取消选区，用**白色描边把黑边盖掉**。
- 眼睛：**先做一个稍微大点的圆**，涂成需要的颜色（黑），`Alt+Delete` → 取消选区；**下方再做一个更小的圆，涂成白色**。
- 嘴：同样是"先做一个圆，用**黄色**，再把上半部分做一个矩形（盖掉）"的做法——老师没有一步步讲完，让同学自己做。

## 十一、案例五：液晶电视怎么做

液晶电视的做法被老师说成"看起来有难度，实际上这个很好做"：**里面是一个变形金刚，外边套了个电视的壳子。**

### 11.1 完整步骤

| 步骤 | 操作 | 为什么 |
| --- | --- | --- |
| 1 | 打开**变形金刚**原图 | |
| 2 | 用**矩形选框工具**把变形金刚的**上半身**截取下来 | 只要上半身 |
| 3 | `Ctrl+C` **复制** | |
| 4 | 看图片有多大：**图像 → 图像大小**，看到是 **1600 × 900** | 新建文件要照这个尺寸来 |
| 5 | **新建文件**：宽度要比截取的图像**大一点**，设为 **1700**；高度设 **900** | 电视还有边框、还有下面的底座，所以要比原图宽 |

| 8 | 用**移动工具**移到中间 | |

### 11.2 老师现场踩的坑（很值得记）

做完黑色外壳后老师发现：**"是不是把我们这个变形金刚（盖住了）？"**——因为**先粘贴了变形金刚、后填的黑底**，黑色把主体挡了。所以正确顺序是：**先做好黑色背景，再把变形金刚粘贴上去**。老师也补了一句"这个也无所谓，我们再考虑一下"——即可以撤销重来。

## 十二、纠错：做不好就后退

### 12.1 做不好就"后退"

老师提醒：觉得效果不好，**在编辑菜单里可以选"后退"（后退一步）**；**多次点可以后退多步**，通过后退重做。这与 3.4 讲的描边纠错是同一个命令。
