# Windows Server 2022 服务器配置步骤（全程在虚拟机里做）

> 一条主线：**装系统 → 改计算机名和固定 IP → 提升成域控 → 架 DHCP → 架 IIS → 建共享 → 开远程桌面 → 客户机加域并用域用户登录 → DNS 完整操作 → 打快照**。
> 每一步后面都给「怎么验证」，做完一条打一个勾；命令用管理员身份的 PowerShell 执行。

---

## 〇、开工前的准备

| 项目 | 建议值 | 说明 |
|---|---|---|
| 虚拟机软件 | VMware Workstation 15 及以上 | VirtualBox 亦可，菜单名略有差异 |
| 安装镜像 | Windows Server 2022 中文 64 位 ISO | 评估版可用 180 天 |
| CPU / 内存 | 2 核 / 4 GB（最低 2 GB） | 域控 + IIS + DHCP 同时跑，4 GB 更稳 |
| 硬盘 | 60 GB，SCSI，单文件 | 系统 + 角色足够 |
| 网络 | 桥接（要别的机器访问）或 NAT（只本机实验） | 下面以 NAT 网段 `192.168.10.0/24`、网关 `.2` 为例 |
| 固件 | UEFI | 与教材一致 |

> ⚠️ 安装时**版本必须选「Windows Server 2022 Standard（桌面体验）」**。选了不带「桌面体验」的版本只有命令行，后面全部图形步骤都做不了。

## 一、安装系统

1. VMware「新建虚拟机」→ 典型 → 安装程序光盘映像文件选 ISO → 客户机操作系统 `Microsoft Windows`、版本 `Windows Server 2022`。
2. 虚拟机名称 `SRV01` → 位置选空间大的盘 → 磁盘 60 GB、拆成单个文件 → 自定义硬件里核对内存/CPU/网络。
3. 启动虚拟机 → 语言与键盘「中文（简体）」→ **现在安装** → 我没有产品密钥 → 选 **Standard（桌面体验）** → 接受许可 → **自定义：仅安装 Windows** → 选中 60 GB 未分配空间 → 下一步。
4. 安装完自动重启 → 设 Administrator 密码（≥8 位，含大小写、数字、符号）→ 登录。
5. 装 VMware Tools：VM 菜单 → 安装 VMware Tools → 打开「此电脑」里的虚拟光驱 → 运行 `setup64.exe` → 典型安装 → 重启。
   装好后能自适应分辨率、宿主与虚拟机可复制粘贴文件。

> ✅ 验证：桌面出现「服务器管理器」，且能全屏无黑边。

## 二、改计算机名 + 固定 IP

```powershell
# 1) 改计算机名（改完要重启）
Rename-Computer -NewName "SRV01" -Restart

# 2) 固定 IP（网卡名以 Get-NetAdapter 查到的为准，通常是 Ethernet0）
New-NetIPAddress -InterfaceAlias "Ethernet0" -IPAddress 192.168.10.10 -PrefixLength 24 -DefaultGateway 192.168.10.2
Set-DnsClientServerAddress -InterfaceAlias "Ethernet0" -ServerAddresses 127.0.0.1

# 3) 时区与时间
Set-TimeZone "China Standard Time"
w32tm /resync
```

> 💡 懒得敲命令就用 `sconfig`：菜单 1 改 IP、2 改 DNS、8 改计算机名，一个界面全搞定。
> ⚠️ DNS 先写成 `127.0.0.1`（后面这台机器自己当 DNS），不要写外网 DNS，否则提升域控会报找不到域。

实验阶段想省事可以先关防火墙，**生产环境不要关**，按下表放行端口即可：

```powershell
Set-NetFirewallProfile -Profile Domain,Public,Private -Enabled False
```

> ✅ 验证：`ipconfig /all` 里 IP、网关、DNS 与上面一致；`hostname` 输出 `SRV01`。

## 三、提升为域控制器（AD DS）

1. 服务器管理器 → **添加角色和功能** → 下一步到「服务器角色」→ 勾选 **Active Directory 域服务** → 添加功能 → 一路下一步 → 安装。
2. 装完点右上角旗帜 → **将此服务器提升为域控制器**。
3. 部署配置 → **添加新林** → 根域名填 `class.local`（实验用 `.local`，别用 `.com`）。
4. 域控制器选项：林/域功能级别都选 **Windows Server 2022**，勾选 **DNS 服务器**，填 DSRM 密码。
5. 后面的 DNS 选项、NetBIOS 名、路径、先决条件检查全部下一步 → **安装** → 自动重启。
6. 重启后用 `CLASS\Administrator` 登录。

```powershell
# 验证域控是否健康
dcdiag /q          # 没有输出最好
Get-ADDomain | Select-Object Name, DomainMode, DistinguishedName
```

建组织单位与域用户：

```powershell
New-ADOrganizationalUnit -Name "教学部" -Path "DC=class,DC=local"
New-ADUser -Name "张三" -SamAccountName "zhangsan" -UserPrincipalName "zhangsan@class.local" `
  -Path "OU=教学部,DC=class,DC=local" -AccountPassword (Read-Host -AsSecureString "设密码") -Enabled $true
```

> ✅ 验证：`Get-ADUser zhangsan` 有结果；「Active Directory 用户和计算机」里能看到「教学部」。

## 四、架 DHCP

1. 添加角色和功能 → 勾选 **DHCP 服务器** → 安装 → 装完点旗帜 → **完成 DHCP 配置** → 用域管理员提交授权。
2. 工具 → **DHCP** → 展开 `srv01.class.local` → IPv4 → 右键「新建作用域」：
   - 名称 `教学网`；起始 IP `192.168.10.100`、结束 `192.168.10.200`、长度 24；
   - 排除 `192.168.10.1` — `192.168.10.99`（留给服务器）；
   - 租用期限 8 天；
   - 路由器（默认网关）`192.168.10.2`；域名称和 DNS `192.168.10.10`、`class.local`；
   - 选「是，我想现在激活此作用域」。
3. 也可以全用命令：

```powershell
Add-DhcpServerv4Scope -Name "教学网" -StartRange 192.168.10.100 -EndRange 192.168.10.200 -SubnetMask 255.255.255.0
Add-DhcpServerv4ExclusionRange -ScopeId 192.168.10.0 -StartRange 192.168.10.1 -EndRange 192.168.10.99
Set-DhcpServerv4OptionValue -ScopeId 192.168.10.0 -Router 192.168.10.2 -DnsServer 192.168.10.10 -DnsDomain class.local
Set-DhcpServerv4Scope -ScopeId 192.168.10.0 -State Active
```

> ⚠️ 作用域没激活（State 不是 Active）时客户端拿不到地址，这是最常见的「DHCP 不工作」原因。

> ✅ 验证：`Get-DhcpServerv4Scope`、`Get-DhcpServerv4OptionValue -ScopeId 192.168.10.0`；
> 再开一台同网段的虚拟机设成「自动获取 IP」，`ipconfig` 应拿到 `192.168.10.1xx`。

## 五、架 IIS（Web 服务器）

1. 添加角色 → 勾选 **Web 服务器(IIS)** → 添加功能 → 默认功能全留 → 安装。
2. 装完浏览器访问 `http://localhost` 看到 IIS 欢迎页即成功。
3. 加一个自己的站点：

```powershell
New-Item -ItemType Directory -Path C:\www\demo -Force
# 用记事本在该目录存一个 index.html，内容随意，例如 <h1>Hello WS2022</h1>
New-WebSite -Name "demo" -PhysicalPath "C:\www\demo" -Port 8080 -HostHeader "demo.class.local"
New-NetFirewallRule -DisplayName "HTTP-8080" -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow
```

4. 让域名能解析（DNS 里加一条 A 记录）：

```powershell
Add-DnsServerResourceRecordA -Name "demo" -ZoneName "class.local" -IPv4Address 192.168.10.10
```

> ✅ 验证：浏览器打开 `http://demo.class.local:8080` 与 `http://192.168.10.10:8080` 都显示你的页面。

## 六、文件共享与 NTFS 权限

1. 添加角色 → 勾选 **文件服务器**（顺带选「文件服务器资源管理器」）→ 安装。
2. 建目录并共享：

```powershell
New-Item -ItemType Directory -Path C:\Share\教学资料 -Force
New-SmbShare -Name "教学资料" -Path C:\Share\教学资料 -ChangeAccess "CLASS\Domain Users"
```

3. 图形做法：右键文件夹 → 属性 → **共享** → 高级共享 → 勾「共享此文件夹」→ 权限里给 `Domain Users`「更改」；
   再切到 **安全** 页，确认 `Domain Users` 有「读取和执行」。

> ⚠️ **共享权限与 NTFS 权限同时生效，取更严的那个**。只改共享权限、NTFS 里没给，用户照样进不去。

> ✅ 验证：`Get-SmbShare`、`Get-SmbShareAccess -Name "教学资料"`；
> 在客户机 `\\192.168.10.10\教学资料` 能打开并新建文件。

## 八、客户机连上域控 + 用域用户登录

这一段是「两台机器配合」的完整闭链：客户机能找到域控 → 加入域 → 服务器上建用户 → 客户机用这个用户登录成功。

### 8.1 客户机准备

再建一台虚拟机（Windows 10/11 都行，1—2 GB 内存即可），要点三条：

| 项目 | 要求 |
|---|---|
| 网络 | 与域控在同一个虚拟网络（同为 NAT 或同一块桥接网卡） |
| IP | 自动获取（第四节的 DHCP），或手动 `192.168.10.50`、网关 `192.168.10.2` |
| **首选 DNS** | **必须填 `192.168.10.10`（域控的 IP）** |

> ⚠️ 客户机 DNS 不指向域控，就一定会出现「找不到域」「加入域时出错」，这是新手排错的第一嫌疑。

### 8.2 先验通不通（四条，全部要过）

```powershell
ping 192.168.10.10                  # 通 = 网络层没问题
nslookup class.local                # 能解析出 192.168.10.10 = DNS 指对了
nslookup srv01.class.local          # 能解析出主机记录
Test-NetConnection 192.168.10.10 -Port 389    # LDAP 通
Test-NetConnection 192.168.10.10 -Port 88     # Kerberos 通
```

浏览器或用运行框 `\\192.168.10.10\SYSVOL` 能打开共享，说明 SMB 也通（加域要用到 445）。

> 💡 前两条过不了就别急着加域 —— 加域失败的 90% 是 DNS 或网段问题，不是域控坏了。DNS 怎么建记录、怎么清缓存、怎么配转发器，见**第九节 DNS 完整操作**。

### 8.3 把客户机加入域

图形做法：设置 → 系统 → 关于 → **重命名这台电脑（高级）** → 更改 → 成员属于选 **域** → 填 `class.local` → 输入 `CLASS\Administrator` 与密码 → 提示「欢迎加入 class.local」→ 重启。

一条命令的做法（在客户机上用管理员 PowerShell）：

```powershell
Add-Computer -DomainName "class.local" -Credential (Get-Credential CLASS\Administrator) -Restart
```

> ✅ 验证：`systeminfo | findstr /C:"域"` 显示 `class.local`；或 `echo %USERDOMAIN%` 出现 `CLASS` 前的登录界面已有「登录到：CLASS」。

### 8.4 在服务器上创建用户（两种方式，任选）

**图形**：服务器管理器 → 工具 → **Active Directory 用户和计算机** → `class.local` → `教学部` → 右键新建 → 用户 →
姓名 `张三`、用户登录名 `zhangsan` → 设密码 → 按需勾选「用户下次登录时必须更改密码」（想直接登录就取消勾选）。

**命令**（在域控上用管理员 PowerShell）：

```powershell
New-ADUser -Name "张三" -SamAccountName "zhangsan" -UserPrincipalName "zhangsan@class.local" `
  -Path "OU=教学部,DC=class,DC=local" -AccountPassword (Read-Host -AsSecureString "给 zhangsan 设密码") `
  -Enabled $true -ChangePasswordAtLogon $false

# 顺便建一个组，方便批量授权
New-ADGroup -Name "学生" -GroupScope Global -GroupCategory Security -Path "OU=教学部,DC=class,DC=local"
Add-ADGroupMember -Identity "学生" -Members "zhangsan"
```

> ✅ 验证：`Get-ADUser zhangsan -Properties Enabled,PasswordLastSet | Select-Object Name,SamAccountName,Enabled`
> 输出 `Enabled = True` 就说明账号可用、密码已设。

### 8.5 客户机上用域用户登录

1. 客户机注销（或重启）→ 登录界面点左下角 **其他用户**。
2. 用户名写 `CLASS\zhangsan`（也可以写 `zhangsan@class.local`），密码是 8.4 里设的那个。
3. 首次登录若提示「必须更改密码」，说明当时勾了那一项，改完即可进桌面。

登录成功后逐条自证：

```powershell
whoami                          # class\zhangsan
echo %USERDOMAIN%               # CLASS
echo %LOGONSERVER%              # \\SRV01   ← 证明是域控验证的登录
gpresult /r                     # 能看到应用的组策略（域策略生效）
net use \\SRV01\教学资料         # 能挂上共享（第六节建的）
```

> ✅ 验证三件套：`whoami` 是域账号、`%LOGONSERVER%` 指向 SRV01、能打开 `\\SRV01\教学资料`。三条都对，客户机与域控的「连接 + 登录」就算通了。

### 8.6 加域 / 登录失败的常见原因

| 现象 | 原因 | 处理 |
|---|---|---|
| 加入域报「找不到网络路径」 | 客户机 DNS 不是域控 | 首选 DNS 改 `192.168.10.10`，`ipconfig /flushdns` 后再试 |
| 加入域报「无法联系域」但 ping 得通 | 防火墙拦 389/88/445 | 域控临时关防火墙验证，再按需放行端口 |
| 提示「用户名或密码不正确」 | 用了本地账号 / 域前缀写错 | 用户名写 `CLASS\zhangsan` |
| 提示「时钟与服务器时间相差太大 / Kerberos 失败」 | 两机时间差 > 5 分钟 | 两台都 `w32tm /resync`；客户机可 `w32tm /config /manualpeerlist:192.168.10.10 /syncfromflags:manual /update` |
| 提示「账户已被禁用 / 已锁定」 | 新建用户没启用，或多次输错 | `Enable-ADAccount zhangsan`；锁定用 AD 用户和计算机里「解锁账户」 |
| 登录进去看不到共享 | 共享或 NTFS 没给 `Domain Users` | 回第六节补权限 |
| 客户机进了域但拿不到 DHCP 地址 | 作用域未激活 / 网段不符 | 按第四节查 |

## 九、DNS 完整操作

DNS 在提升域控时已经自动装好并建好了区域，这一节把「怎么查、怎么加、怎么清、怎么排错」一次讲全。

### 9.1 先确认 DNS 已装、区域已建

```powershell
Get-WindowsFeature DNS | Select-Object Name,InstallState      # Installed 就对了
Get-DnsServerZone | Select-Object ZoneName,ZoneType,IsDsIntegrated,IsReverseLookupZone
```

图形：服务器管理器 → 工具 → **DNS** → 展开 `SRV01` → **正向查找区域** → 应能看到 `class.local`（类型写着「Active Directory 集成」）。

> ⚠️ 区域里那些 `_msdcs`、`_sites`、`_tcp`、`_udp`、`(与父文件夹相同)` 的记录是 AD 自动生成的服务记录，**一条都不要删**（删了客户机加域、找域控都会失败）。

### 9.2 新建主机记录（A 记录）：域名 → IP

```powershell
Add-DnsServerResourceRecordA -Name "www" -ZoneName "class.local" -IPv4Address 192.168.10.10
Add-DnsServerResourceRecordA -Name "files" -ZoneName "class.local" -IPv4Address 192.168.10.10

# 查已经有哪些记录
Get-DnsServerResourceRecord -ZoneName "class.local" -RRType A | Select-Object HostName,RecordType,RecordData
```

图形：DNS → 正向查找区域 → `class.local` → 右键 → **新建主机(A 或 AAAA)** → 名称 `www`、IP `192.168.10.10` → 勾「创建相关的指针(PTR)记录」可顺手建反向记录。

### 9.3 新建别名（CNAME）：一个 IP 对多个域名

```powershell
Add-DnsServerResourceRecordCName -Name "web" -ZoneName "class.local" -HostNameAlias "www.class.local"
```

图形：`class.local` → 右键 → **新建别名(CNAME)** → 别名 `web`、目标 `www.class.local`。

> 💡 A 记录指向 IP，CNAME 指向另一个域名。IP 变了只改 A 记录，所有 CNAME 自动跟着变。

### 9.4 新建反向查找区域 + PTR：IP → 域名

```powershell
Add-DnsServerPrimaryZone -NetworkId 192.168.10.0/24 -ReplicationScope Domain
Add-DnsServerResourceRecordPtr -Name "10" -ZoneName "10.168.192.in-addr.arpa" -PtrDomainName "srv01.class.local"
```

图形：**反向查找区域** → 新建区域 → 主要区域 → IPv4 → 网络 ID `192.168.10` → 允许安全动态更新 → 再在区域里右键「新建指针(PTR)」。

> ✅ 验证：`nslookup 192.168.10.10` 能返回 `srv01.class.local`。

### 9.5 配置转发器（让内网也能解析外网域名）

```powershell
Add-DnsServerForwarder -IPAddress 223.5.5.5, 114.114.114.114
Get-DnsServerForwarder
# 删除某个转发器
Remove-DnsServerForwarder -IPAddress 223.5.5.5
```

图形：DNS → 右键服务器名 → **属性** → **转发器** 选项卡 → 编辑 → 填公网 DNS。

> ⚠️ 分工要清楚：**服务器网卡上的 DNS 只写 `127.0.0.1`**（查自己），外网域名由「转发器」往外问。网卡上直接写 8.8.8.8 会让域内解析绕路甚至失败。

### 9.6 动态更新、老化与清理

```powershell
# 只允许已加入域、通过身份验证的计算机自己注册记录（域环境推荐）
Set-DnsServerPrimaryZone -Name "class.local" -DynamicUpdate Secure
Get-DnsServerPrimaryZone -Name "class.local" | Select-Object DynamicUpdate

# 开启老化清理，防止过期记录越积越多
Set-DnsServerScavenging -ScavengingState $true -RefreshInterval 7.00:00:00 -NoRefreshInterval 7.00:00:00 -ApplyOnAllZones
```

| 动态更新取值 | 含义 |
|---|---|
| `None` | 禁止客户端自己注册（全手工建记录） |
| `Secure` | 只接受已认证（已加域）计算机的注册 —— **域环境用这个** |
| `NonsecureAndSecure` | 任何机器都能注册，实验方便、生产不安全 |

客户机想让自己的记录更新，执行一次 `ipconfig /registerdns`。

### 9.7 清缓存与验证（改完记录必须做）

```powershell
Clear-DnsServerCache -Force     # 清服务器缓存
ipconfig /flushdns              # 清本机缓存
Resolve-DnsName www.class.local # 看解析结果与来源
nslookup www.class.local 192.168.10.10
```

> ⚠️ 记录改了却不生效，九成是缓存：**服务器和客户机两边都要清**。

### 9.8 常用 DNS 命令一览

| 命令 | 作用 |
|---|---|
| `Get-DnsServerZone` / `Get-DnsServerResourceRecord -ZoneName x` | 看区域 / 看记录 |
| `Add-DnsServerResourceRecordA -Name www -ZoneName x -IPv4Address IP` | 加 A 记录 |
| `Add-DnsServerResourceRecordCName -Name web -HostNameAlias www.x` | 加别名 |
| `Add-DnsServerPrimaryZone -NetworkId 192.168.10.0/24` | 建反向区域 |
| `Add-DnsServerResourceRecordPtr` | 加 PTR |
| `Add-DnsServerForwarder` / `Get-DnsServerForwarder` | 配 / 查转发器 |
| `Set-DnsServerPrimaryZone -DynamicUpdate Secure` | 设动态更新 |
| `Clear-DnsServerCache -Force` / `ipconfig /flushdns` | 清缓存 |
| `Resolve-DnsName` / `nslookup` | 测试解析 |
| `Restart-Service Netlogon` | 修 AD 服务记录（SRV）异常 |

### 9.9 DNS 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 客户机 `nslookup www.class.local` 解析不到 | 客户机 DNS 不是域控 / 记录没建 | 首选 DNS 改 `192.168.10.10`；按 9.2 建记录 |
| 记录明明加了，客户机还是解析不到 | 服务器或客户端缓存 | `Clear-DnsServerCache -Force` + 客户机 `ipconfig /flushdns` |
| 内网域名能解析，外网站打不开 | 没配转发器 | 按 9.5 加公网 DNS |
| 域控上外网解析很慢 | 网卡 DNS 写了公网地址 | 网卡 DNS 只留 `127.0.0.1`，外网交给转发器 |
| 反向解析失败 | 没建反向区域 | 按 9.4 建 `10.168.192.in-addr.arpa` |
| 客户机忽然加不了域了 | `_msdcs`/`_tcp` 的 SRV 记录被删 | `Restart-Service Netlogon`，或 `nltest /dsregdns` 重建 |
| 动态更新被拒绝 | 区域是 `Secure`、客户机没加域 | 先加域再 `ipconfig /registerdns`；实验期可临时改 `NonsecureAndSecure` |

## 十一、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 装完只有黑窗口，没有桌面 | 装成了 Server Core | `sconfig` 可用但改不回去，重装并选「桌面体验」 |
| 提升域控报「找不到域」/ DNS 错误 | DNS 写了外网地址 | 网卡 DNS 改成 `127.0.0.1`，或先装 DNS 角色 |
| 客户机拿不到 IP | 作用域未激活 / 服务器未授权 / 网段不符 | 按第四节逐项查 |
| 网站打不开（403/404） | 没放行端口 / 绑定不对 / 缺默认文档 | 查防火墙、`New-WebSite` 的端口与主机名、目录里是否有 `index.html` |
| 共享能连但打不开 | NTFS 权限没给 | 安全页加 `Domain Users` 读取 |
| 远程桌面提示凭据不对 | 用的是本地账户 | 用户名写 `CLASS\zhangsan` |
| 装角色报「需要重启」 | 前一次安装未重启 | 重启后重装该角色 |
| 时间越走越偏 | 虚拟机时间同步 | VMware 选项里勾「与主机同步时间」，或 `w32tm /resync` |
