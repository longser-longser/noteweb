## 一、认识网络操作系统

### 1.1 从"服务器"说起

- **服务器的本质**：给用户**提供服务**。提供服务靠两样东西——**硬件 + 软件**。
  - 硬件：CPU、内存、硬盘、显卡以及各种接口等（与本机电脑类似，但**性能强得多**）。
  - 形态：服务器通常不是一台，而是**很多台组成集群**，以承载更大并发。
    - 例：全国几亿人同时刷抖音、淘宝双十一/双十二每秒海量请求，都是靠**硬件 + 软件调度 + 算法**完成的。
- **软件要跑，必须有个"底座"**：就像手机 App 需要手机操作系统、电脑软件需要电脑操作系统一样，服务器上的各种服务软件也需要一个系统来承载与调度——**这个系统就是"网络操作系统"**。

### 1.2 网络操作系统的定义（要背）

> **操作系统**：计算机系统中负责**提供应用程序管理**以及**用户操作环境**的系统软件，同时是**计算机系统的核心**。
> —— 操作系统一旦出问题，直接蓝屏/黑屏、启动不了，也就是我们常说的"系统崩了"。

> **网络操作系统**：除了能够实现**单机操作系统的全部功能**之外，还具备
> ① **管理网络中的共享资源**、② **实现用户通信**、③ **方便用户使用网络** 的功能。

一句话对照：**网络操作系统 = 单机操作系统全部功能 + 网络资源管理与通信能力**。

### 1.3 网络的分层结构（理解这张图）

从下到上三层，缺一不可：

| 层次 | 内容 | 说明 |
|---|---|---|
| ① 通信协议 / 标准 | TCP/IP 等协议、接口标准（如 **RJ45** 网口、标准水晶头、标准网线） | 没有统一规范，"有设备也无法互通"，就像一门语言没有语法规则 |
| ② 数据链路 / 网络设备层 | 交换机、路由器、终端；双绞线、光纤、同轴电缆 | 在其上配置协议与标准，实现**网络层面的数据传输**（数据从一端到另一端） |
| ③ 网络操作系统层 | 服务器上承载各类**服务** | 光能传数据还不够，为什么搜一个词就能弹出海量结果？因为服务器上承载了数据库、Web 服务等，这些都需要**网络操作系统**支撑 |

> 关键理解：**网络操作系统不是单指某一台电脑的系统**，而是能支撑整个网络架构对外提供服务的系统。

### 1.4 网络操作系统提供的典型服务（重点，后续都会动手配）

| 服务 | 全称/含义 | 作用与举例 |
|---|---|---|
| **DHCP** | 动态主机配置协议 | 相当于路由器里的"地址池"：下面接的电脑能**自动获取 IP**；同步、统一；某台电脑搬走，地址**自动回收**。即"自动分发、自动回收、统一管理 IP 地址" |
| **FTP** | 文件传输协议 | 建一个 FTP 服务器，把资源上传进去，给别人地址来下载；公司里把常用文件放共享目录供同事下载，**类似网盘** |
| **DNS** | 域名解析服务 | 把**域名翻译成 IP**（详见 1.5.4） |
| Web / 邮件等 | — | 服务器端其他常见服务，后续章节展开 |

### 1.5 前置知识复习：IP、子网掩码、网关、DNS（考试与实操都要用）

#### 1.5.1 IP 地址
- 网络中**每一台设备的唯一身份标识**：同一局域网内，一个 IP 代表一个终端/一块网卡。
- IPv4 是 **32 位二进制数**，写成**点分十进制**（4 段数字，如 `10.170.19.51`），难记——这正是需要域名的原因。

#### 1.5.2 子网掩码（掩码）
- 作用：**标识这台设备属于哪一个网络/子网**，把 IP "框进"某个网段。
- 类比：IP 像"人名"，掩码像"班级号"——"计算机应用 1 班的学生"，一说班号就限定了范围。
- **重要结论**：**同一子网内的终端互相通信，不需要经过网关**；掩码决定了谁和谁"算同一个子网"。

#### 1.5.3 网关
- 作用：**不同子网/不同局域网之间通信的出口**。
- 类比：同班同学说话直接说；要和隔壁班同学说话，得先走到**门**，出门再到另一个教室——这个"门"就是网关。
- 网关本身**代表一台设备**。
- 课堂演示（CMD 中验证）：
  - `ping 10.170.19.51`（**同网段**地址）→ **直接到达**，因为属于同一网段。
  - `ping <另一个网段地址>` 并用 `tracert` 跟踪路由 → 第一跳就**跑到网关**，再由网关转发出去。
- **结论**：数据要通信，必须在同一网络内；不在同一网络，就必须借助**网关/路由**。

#### 1.5.4 DNS（域名解析）
- **域名**：如 `www.baidu.com`、`www.sohu.com`、`www.mi.com`、`www.360.com`——好记的"名字"，但**在网络中不代表终端**，只是方便人记忆。
- **IP 才是网络中真正使用的地址**，所以必须有人把域名 → IP 翻译过来，这个翻译过程就是 **DNS 的作用**。
- 演示：`ping www.baidu.com` → 返回一个 IP，那就是百度众多服务器中的一台。
- **谁来存这么多域名？** → **公共 DNS 服务器**：联通、移动、电信三大运营商各有自己的 DNS，阿里、腾讯、百度也有。
  - 选择原则：**用哪家线路，就配哪家的 DNS**（例如学校走电信线路，就配电信 DNS）。
- **完整访问流程**：浏览器输入域名 → 向 DNS 服务器查询对应 IP → 返回 IP 给终端 → 终端发出数据包（包里的目的地址就是解析出来的 IP）→ 访问到目标服务器。

> 老师提醒：IP 划分、子网划分大家多半忘了，后面课程会再讲。**现阶段只需记住：通信必须在同一网络；跨网络必须走网关/路由。**

### 1.6 网络操作系统的功能特性

1. **共享资源管理**：服务器上的资源（电影、文件等）能共享给大量用户访问，并可对其管理。
2. **网络通信**：与用户终端之间的信息交互；同时管理员可对网络中的设备与服务进行管理。
3. **网络管理 / 不中断操作**：对设备、服务的管理能力。
4. **并行性（支持并行）**：多用户**同时**访问，不是"来一个人服务一个、其余排队"。例：大家同时选课、同时操作系统，都能同时响应。
5. **开放性、可移植性**：适应不同硬件与平台。
6. **安全性与高可靠性**：本身自带**防火墙**功能（Win10/Win11 也有），可通过入站/出站规则进行安全设置。
7. **图形化界面**：通过界面完成操作，而不是只靠命令行。

### 1.7 两种架构：C/S 与 B/S

| 架构 | 全称 | 特点 | 举例 |
|---|---|---|---|
| **C/S** | Client / Server，客户机与服务器 | 需要**先下载安装客户端**，通过客户端与服务器交互 | 微信、QQ |
| **B/S** | Browser / Server，浏览器与服务器 | **不用装客户端**，打开浏览器输入网址即可 | 百度等各类网站 |

### 1.8 常见网络操作系统有哪些

1. **UNIX**
   - 最早的网络型操作系统，可看作 **Linux 的"前身"**（但两者并不相同）。
   - 也有图形界面，但**以文件系统为核心**，更多使用**命令行**、偏轻量化，不像 Windows 那样图形化。
2. **Linux**
   - 由 **Linus Torvalds** 开发并开源、**免费**的操作系统。
   - 目前**很多国产操作系统都是基于 Linux 内核**做完善或二次开发而形成的。
3. **Windows**
   - PC（个人电脑）端：**最主流**的就是 Windows 操作系统。
   - 服务器端：**Windows Server**，版本有 2008、2012、2016、2019、2022 等（目前仍广泛在用）。
4. **国产化替代与"核高基"**（了解即可）
   - **核高基** = **核**心电子器件、**高**端通用芯片、**基**础软件产品。
   - 背景：国外技术封锁导致芯片/硬盘等涨价；近年来华为等企业发展迅速，高端国产芯片进步明显。
     - 例：GPU 领域最知名的是 **NVIDIA（英伟达）**，一块显卡数万元；国产有**昇腾**等，性能逐步追近。
   - 趋势：政府机关、企事业单位正在逐步推行国产软硬件，未来这门课可能改讲**麒麟、统信（红芯/国产 Linux 发行版）**等国产操作系统。
   - **但这不代表现在学 Windows Server 没用**：市面上大量企业（尤其中小公司）服务器仍在使用，**毕业时它仍是服务器端主流**，要认真学。

## 二、Windows Server 的安装与规划（虚拟机环境）

### 2.1 版本选择：标准版 vs 数据中心版

| 对比项 | **标准版（Standard）** | **数据中心版（Datacenter）** |
|---|---|---|
| 适用规模 | **最多 25 个用户 / 50 台设备**的小型企业 | 对数据操作、性能要求较高的大规模环境 |
| 适用场景 | 物理环境或**最低限度的虚拟化**环境 | **高虚拟化**、大规模云/虚拟化输出 |
| 不支持项（标准版缺） | **主机保护（Shielded VM）**、**软件定义的网络**、**软件定义的存储** | 全部支持 |

> 安装选项还有：**Server Core（无图形界面）** 与 **带桌面体验的服务器（完整 Windows 图形环境）**。本课程**选带桌面体验的版本**，便于操作。
> **硬件要求**不必担心，现有机器都能满足。

### 2.2 虚拟机软件的安装

1. 拿到两个安装包：**虚拟机软件**（约 100MB）+ **操作系统镜像 ISO**（约 6.5GB）。
2. 保存位置：**放到 D 盘自己建的文件夹**（以自己姓名/学号命名，路径建议用英文），**不要放桌面、不要放 C 盘**。
3. 双击安装：接受许可条款 → 一路"下一步" → 完成，桌面出现图标。

### 2.3 创建虚拟机（一步一步）

1. 打开软件 → 左侧列表是**当前物理机**，下面是已创建的虚拟机。
   - 概念：在一台物理机（如 8 核 16G 的电脑）上，用虚拟机**虚拟出若干台"小机器"**（如 2 核 2G），实现多系统并存与统一管理。
   - 能建多少台，取决于物理机配置：**配置越高，能建的越多**。
2. 点击"创建新的虚拟机" → 可选"典型"或"自定义" → **选择"稍后安装操作系统"**。
3. 客户机操作系统类型：选 **Windows**，版本**必须与镜像对应**（镜像是 2022 就选 2022，2016 就选 2016）。
4. 虚拟机名称与位置：起名（建议用自己姓名/学号）；**位置放 D 盘，不要放 C 盘（C 盘是还原盘）**。
5. 磁盘大小：**Windows Server 2022 建议 60GB**；可拆分为多个文件或单文件。**不要设得过大**，否则占用物理磁盘空间。
6. **自定义硬件**（重点，按物理机实际配置来选）：
   - **内存**：默认 2048MB（=2G）。16G 内存的机器可选 2G/4G；32G 的可选更大。
   - **处理器**：先看内核数。**处理器个数 × 每处理器核心数 = 总核心数**，**不能超过物理机总核心数**，并且需要**开启虚拟化功能（CPU 虚拟化技术）**。
     - 查看本机核心数：**设备管理器 → 处理器**，能看到几个条目就是几核（如 4 个条目 = 4 核）。
   - **CD/DVD**：选择"使用 ISO 映像文件"，浏览加载 **Windows Server 2022 的 ISO**。
   - **网络适配器**：可选**桥接**或 **NAT**（NAT 见 2.6）。
   - **USB 控制器、声卡、打印机**等用不到的设备可以**移除**。
7. 完成后，左侧出现新建的虚拟机；右侧显示内存、处理器、磁盘等信息。点击**开启此虚拟机**进入系统安装。

### 2.4 UEFI 与传统 BIOS 引导
- **传统 BIOS（Legacy）**：开机后需按键（Del、F2、F8、F12 等）进入 BIOS 设置界面才能修改启动项等。
- **UEFI**：直接引导，**相对传统 BIOS 启动更快**。
- （修过电脑的同学应见过：进 BIOS 改设置就是传统方式。）

### 2.5 操作系统的安装步骤

1. 选择安装语言：**中文**。
2. 出现"激活 Windows"：2012 之前必须输入序列号（输错也能过）；**2016/2019/2022 可选"我没有产品密钥"**，未激活也能继续安装使用。
3. 选择要安装的操作系统版本 → 选 **"带桌面体验的标准版"（第 2 项）**（第 1 项为标准版/Server Core，下面两项为数据中心版及其图形界面版）。
   - 每选中一项，下方会有说明文字，可据此判断。
4. 接受许可条款 → 安装类型选 **"自定义：仅安装 Windows"**。
5. 选择安装位置：显示刚才分配的 **60GB 未分配空间**。
   - 直接"新建 → 应用" = 整个 60G 做一个分区（练习环境推荐）。
   - 想分区就减小数值：**1GB = 1024MB**，如要 100GB 就输入 `102400`，点"应用"后再对剩余空间继续划分。
   - 系统本身会占用少量空间和保留分区，所以实际显示 **59.9GB** 左右属正常。
6. 点击"下一步" → 等待复制文件与自动重启（时间较长）。
7. **设置管理员（Administrator）密码**：
   - 至少 **6 个字符**；
   - 复杂度要求：**必须包含大写字母、小写字母、数字、特殊符号中的三类**。
   - **必须记住！** 下次课就靠这个密码登录，忘了只能重装。
8. 登录：按 Ctrl+Alt+Delete（虚拟机中用菜单"发送 Ctrl+Alt+Delete"）→ 输入密码 → 进入 Windows Server 2022 桌面，**服务器管理器自动启动**。
   - 笔记本若用小键盘输密码，先按 **NumLock**（键盘右侧小键盘 7 上方的 Num Lock 键）解除数字锁定，否则数字打不出来。
   - 此时界面看起来与普通 Windows 差别不大，但**功能与配置完全不同**。

### 2.6 安装虚拟机工具（VMware Tools）——必做

- 在虚拟机菜单中选择"安装 VMware Tools / 安装虚拟机工具"。
- 此时虚拟机光驱里会出现该工具的安装程序（若**不点安装**，光驱里显示的仍是刚才加载的 ISO 镜像）。
- 双击运行 → 一路下一步 → 安装完成后**重启虚拟机** → 支持**全屏显示**与网络等适配。
- 至此，服务器的基础环境搭建完成。

### 2.7 虚拟机的三种网络模式（重点，理解区别）

| 模式 | 原理 | 特点 | 典型用途 |
|---|---|---|---|
| **桥接（Bridged）** | 虚拟机**桥接到物理网卡**，相当于教室里一台独立主机，与本机同一网段 | **最开放**：可与宿主机互访、可被局域网其他机器访问、能直接上网 | 需要被外部访问的实验 |
| **NAT** | 通过 **VMnet8** 虚拟网卡 + **VMware NAT 服务**（内含 DHCP，地址池约 `192.168.x.128 ~ 192.168.x.254`），相当于一台**小路由器** | 虚拟机可**借宿主机上网**、能访问宿主机；**外部主机默认访问不到虚拟机** | 需要联网又不想暴露（本课程方便上网可用它） |
| **仅主机（Host-Only）** | 通过 **VMnet1**，与外部网络隔离 | **只能与宿主机通信**，完全独立隔离，不影响物理网络 | 网络攻防演练、安全测试、靶机、木马/病毒样本测试 |

> 记忆：**桥接最开放 → NAT 能上网但隐藏 → 仅主机最封闭**。

### 2.8 虚拟机的日常管理操作

1. **移除 ≠ 删除**
   - 右键"移除"只是**从库中移出**，文件仍在磁盘上，**并没有真正删除**。
   - **真正删除**：右键 → **管理 → 从磁盘中删除**。（老师提醒：此处容易误操作，务必注意。）
2. **快照（Snapshot）**
   - 作用：**保存虚拟机当前的状态和时间点**。做完快照后再去操作，出错可**一键恢复**。
   - 场景：一节课要完成四五个任务，后续操作可能影响前面状态；或配置了半天没配通，**不必重装系统**，直接恢复到快照重来。
   - 也可以删除不需要的快照。
3. **克隆（Clone）**
   - 作用：**快速复制出一台配置相同的虚拟机**，用于后续涉及**多台主机/多台服务器**的实验，省去重复安装。
   - 类型：**完整克隆**（完全独立副本）/ **链接克隆**（引用原虚拟机磁盘，与母机有关联）。
   - 克隆出的机器与母机配置基本一致，同样需要设置/牢记账号密码。
