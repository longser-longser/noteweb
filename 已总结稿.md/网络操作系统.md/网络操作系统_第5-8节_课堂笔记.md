### ⚠️ 一个重要的认知前提（老师开场就强调）

> **这些功能，在我们最初装完系统之后，很多是"没有开启"的。**
> 也就是说——**系统里有这个功能，但是没有开启，需要我们自己去开启。**

**为什么要这样设计？**

- 因为服务器本身**提供了很多功能**；
- 但**每个人用的功能不一样**；
- 所以系统把这些功能**都做成了"可选项"**：
  > **功能我（系统）提供给你，装不装、开不开，由你决定。**

> **记住这一点**：后面所有实操的第一步，几乎都是**"先去添加角色和功能，把它装上/开起来"**。

## 一、本节学什么

### 1.1 教材情境（案例背景）

> **公司内部的办公网络，原本是基于"工作组"的方式部署的。**
> 近期由于公司业务发展的需要，基于**方便**和**网络安全管理**的需要——
> **需要将一台或多台计算机升级为"域控制器"，并将其他所有计算机"加入到域"。**

翻译成操作层面，就是三步：

1. 找**几台服务器**；
2. 把它**变成域控制器**；
3. **其他终端计算机再加入这个域**。

### 1.2 学习目标（老师逐条念的）

| 序号 | 目标 | 要求程度 |
|---|---|---|
| ① | 掌握**规划和安装局域网中活动目录**的方法 | **掌握（最主要）** |
| ② | 掌握**创建域（域目录根）与域林**的方法 | 掌握 |
| ③ | 掌握**安装额外域控制器**的方法 | 掌握 |
| ④ | 如何**创建子域**，包括熟悉**多台服务器**的情况 | **熟悉**（后面讲） |

> 老师原话总结：后面那几条是"熟悉"的，**最主要的是——大家要学会如何去安装活动目录，以及如何让我们局域网里面的一些计算机加入到域里面**。

### 1.3 ⚠️ 老师建议的学习顺序：先实操，再看概念

> **"前面这个章节是它的理论知识，后面是它的实操。"**
> 只听理论，**不太好理解**这些概念之间是什么关系。
> 所以老师的做法是——**先把操作做一遍，再回头去看概念**，这样"更好理解"。
>
> **本节就按这个顺序走：先讲"为什么需要域"→ 直接做实操 → 最后回头讲活动目录的结构。**

## 二、为什么要用"域"——老师给的最简单的理由

### 2.1 一个公司里的例子

> 比如你在一个公司里，**用一台服务器去做相关的管理**。
>
> 那么——**使用了"域"之后，最简单、最直接的一点是什么？**
> **就是能够管理当前公司里面所有的其他终端。**
>
> 具体说：假如你现在在这个公司里建了一个**域服务器**，那么你下面的这些终端，
> **只要都去开启了、加入到这个域**，那么你**就能够通过后台去对这些计算机进行管理**。

**最直接的好处**：

> **你就不用管每台电脑各自的账户和密码了**——
> 可以通过**域服务统一去进行**（统一开启、统一设置），
> **而不用像以前那样，一台电脑一台电脑单独去设密码。**

### 2.2 域 vs 工作组：一张表看懂（本节核心对比）

| 对比项 | **工作组方式**（传统方式） | **域方式**（AD 方式） |
|---|---|---|
| 资源位置 | 每台服务器上**各自都有**相应的资源 | 多台服务器**都加入到同一个域** |
| 账号怎么建 | 用户要访问这些资源，**需要在每台服务器上分别建账号** | 管理员**只需要为用户创建一个域账号** |
| 举例 | 有 3 台服务器（1、2、3），每台都有资源；用户要访问哪台，就得在哪台上建账号 | 3 台服务器都属于**同一个域**，管理员**只建一个**用户 |
| 登录次数 | 访问不同服务器**要分别登录** | **只要登录一次**，访问域里其他服务器资源时**不用二次登录** |
| 管理方式 | 分散、逐台管理 | **集中管理**（管理员统一分配用户） |
| 现状 | 老师提到：**现在大家的电脑用的还是工作组方式**（默认工作组名为 `WORKGROUP`） | 本节课要学的方式 |

> **判断当前是哪种**：在"此电脑 → 属性"里看——**显示的是"工作组"，说明还在工作组方式**；
> 如果加进了域，**界面会变得不一样**。

### 2.3 老师打的比方：学校门卫（**一定要理解这个比方**）

> 你**只要从学校大门进去，门卫审核通过**，那你就是学校的学生；
> 那么你在学校里面的**各个宿舍、各个楼宇**里，**就可以随意走动**。
>
> **而不是说：我们每一栋楼都放一个门卫，你每进一栋楼都要重新登记一次。**

**对应到域**：

| 学校 | 域 |
|---|---|
| 学校大门门卫审核一次 | **登录域一次** |
| 学生证 | **域账号 + 密码** |
| 校内各栋楼随意进出 | **域里面的各种资源都能访问** |
| 学校新盖楼、拆楼，学生凭证不变 | **域里增加/减少服务器，用户凭证不变** | 

> **一句话结论**：
> **登录一次，全域名资源都能访问**——这就是域最大的便利。

### 2.4 顺带提到的两个管理场景

| 场景 | 域方式下怎么做 |
|---|---|
| **新员工入职** | 管理员**给他一个相应的域账号和密码**，**不用让他自己去设置账号密码**；而且**这个密码只有管理员知道** |
| **员工离职** | 直接找管理员处理；**因为管理员知道密码**（原始转写此处不清，见附录 B） |

## 三、基本概念：活动目录（AD）

### 3.1 什么是活动目录

> **活动目录是 Windows 当中的目录服务。**
> 它是一个**分布式的目录服务**。

**"分布式"体现在哪**：
- **信息可以分散在多台不同的计算机上**；
- 这样能**保证用户快速访问**；
- 而且可以**提高管理效率**，让网络的应用**更加方便**。

### 3.2 活动目录负责什么

> **活动目录负责目录数据库的保存、新建、删除、修改等。**

> 老师原话："这个里面可能大家现在还感觉不到……**一会儿让我们去实际去测试，就能实际地感受到**。"

## 四、实操：安装 AD DS 并提升为域控制器（一步一步）

> 老师原话：**"安装很简单，关键是看后续如何去管理。"**

### 4.0 前提

要在服务器上**安装 AD DS 这个服务**（`Active Directory 域服务`）并**启动它**。

### 4.1 第一步：添加角色和功能

1. 打开**服务器管理器**；
2. 点击 **"添加角色和功能"**；
3. **一路"下一步"**往下走；
4. 在角色列表里找到 **`Active Directory 域服务`（AD DS）**；
5. **把它勾选上**；
6. 点击 **"添加功能"**；
7. 继续"下一步"，**直到安装成功**。

> 老师提示：角色列表里面项目很多，比如 **AD 域服务、AD 轻量级目录服务、AD FS（"d c d 服务"）、Web 服务器**等等，还有下面的功能项。
> **本次我们只选 AD DS 这一个。**

### 4.2 第二步：把服务器"提升为域控制器"

> ⚠️ **这一步是很多人会漏掉的关键**：
> **服务安装成功之后，还要在服务器管理器里，将这个服务器"提升为域控制器"。**

**为什么必须提升**：
> 我在这台服务器上安装了这个服务——**如果我想让它当成一个"管理者"，就需要手动去点击，把它提升为域控制器。**

### 4.3 第三步：部署配置

| 步骤 | 要做什么 |
|---|---|
| ① 选择部署操作 | 因为是**第一台**，选择 **"添加新林"**（新建林） |
| ② 起域名 | **给它起一个域名**（这就是将来域的域名） |
| ③ 选择功能级别 / 操作系统版本 | 例如 **Windows Server 2012**，把指定的选项**都选上** |
| ④ 设置密码 | 设置 **目录服务还原模式（DSRM）密码** |
| ⑤ 后续选项 | **不用管，都是默认的**，可以直接往下点 |
| ⑥ 路径设置 | 也**不用管**，保持默认即可 |

### 4.4 第四步：先决条件检查（**装之前必看**）

> 在安装之前，**首先它会有一个"先决条件检查"**。

| 检查结果 | 说明 |
|---|---|
| **是对号（√）** | **可以安装** |
| **不是对号** | 它会**提示你这里面有哪些是有问题的**，**需要你去处理**（处理完才能装） |

### 4.5 第五步：创建完成后的验证（**五个检查点**）

创建好之后，**去验证一下当前的结果**：

| 序号 | 检查什么 |
|---|---|
| ① | 查看**计算机的名称**（是否已变） |
| ② | 查看**管理工具**（多了域相关的工具） |
| ③ | 查看**（AD 用户和计算机里的）对象** |
| ④ | 查看 **AD 的数据库** |
| ⑤ | 查看 **SYSVOL 记录** |

> 老师现场的对比演示：
> **没安装之前，此电脑属性里显示的是"工作组"**；
> **提升为域控制器之后，界面就不一样了**——会变成域的界面。

## 五、活动目录的结构

结合安装过程中系统生成的内容来讲：

| 组成 | 说明 |
|---|---|
| **数据存储（数据库）** | 域控制器相关的一些数据，**存在本机服务器上**（安装时那个路径里） |
| **域控制器** | 承担域管理角色的这台服务器；相当于**本机上的一个服务/角色** |
| **全局编录** | 全局编录（服务器） |
| **独立的服务器** | 未加入域、单独存在的服务器 |

**域控制器的适用范围**：

- 域控制器**在 Windows Server 2022 上有**；
- **其实在 2016 等版本上也都有**（不是 2022 独有的）；
- 在 Windows 网络环境中，它是**组建"客户机 / 服务器"（C/S）网络**的实验方式；
- 它是**"域"的基本管理单元**。
